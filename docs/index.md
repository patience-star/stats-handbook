## 这里和教材有什么不同

- **讲法**：每个核心知识点都按 **直观引入 → 几何直观 → 严格表述 → 应用** 四层展开。L1 的读者读到几何直观就能用；L2 的读者继续看定理与证明；L3 给出超出两本教材的视角。
- **标注**：<span class="chip" style="--c: var(--c-core)">核心</span> <span class="chip" style="--c: var(--c-key)">重点</span> <span class="chip" style="--c: var(--c-hard)">难点</span> 直接标在标题和方框上，每章开头自动汇总成索引。
- **时间序列**：黄书讲到趋势、季节与循环的分解；这里在此基础上继续讲指数平滑、平稳性、ARMA、Box–Jenkins 建模、单位根与伪回归，以及谱分析、GARCH、协整、卡尔曼滤波等专题。
- **原创**：讲解、例题和习题都是原创的，章节编排参照两本教材，方便对照着读。
