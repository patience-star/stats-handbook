# 随机变量函数的分布

已知 $X$ 的分布，$Y=g(X)$ 服从什么分布？这个问题随处可见：已知边长的分布，求面积的分布；已知摄氏温度的分布，求华氏温度的分布；已知对数收益率的分布，求价格的分布。

它也是统计学的核心技术之一：统计量就是样本的函数，求统计量的分布，本质上就是求随机变量函数的分布。本章的关键是一个几何事实：**变换会拉伸或压缩数轴，而概率守恒，所以密度要反过来压缩或拉伸**。

## 离散情形

$X$ 离散时，$Y=g(X)$ 也离散。把 $X$ 的每个取值代入 $g$，再把 $Y$ 取值相同的概率 **合并** 即可。

例如 $X$ 的分布列为 $P(X=-1)=0.2$，$P(X=0)=0.3$，$P(X=1)=0.5$，则 $Y=X^2$ 取 0 的概率为 0.3，取 1 的概率为 $0.2+0.5=0.7$。

## 连续情形：分布函数法 {.core}

最一般的方法是 **先求分布函数，再求导**：
$$F_Y(y)=P(g(X)\le y)=\int_{\{x:\ g(x)\le y\}}p_X(x)\,\mathrm dx,\qquad p_Y(y)=F_Y'(y).$$
关键是把事件 $\{g(X)\le y\}$ 改写成关于 $X$ 的事件。

::: example 例 1　标准正态的平方
设 $X\sim N(0,1)$，求 $Y=X^2$ 的密度。

**解** $y\le0$ 时 $F_Y(y)=0$。$y>0$ 时，
$$F_Y(y)=P(X^2\le y)=P(-\sqrt y\le X\le\sqrt y)=2\Phi(\sqrt y)-1,$$
求导得
$$p_Y(y)=2\varphi(\sqrt y)\cdot\frac1{2\sqrt y}=\frac1{\sqrt{2\pi y}}e^{-y/2},\qquad y>0.$$
这就是自由度为 1 的 **卡方分布** $\chi^2(1)$，也就是 $\mathrm{Ga}(1/2,1/2)$。
:::

## 单调变换的密度公式 {.core}

::: core 定理（单调变换）
设 $X$ 的密度为 $p_X(x)$，$y=g(x)$ 严格单调、可导，其反函数为 $x=h(y)$，则 $Y=g(X)$ 的密度为
$$p_Y(y)=p_X\big(h(y)\big)\,\big|h'(y)\big|,$$
其中 $y$ 取 $g$ 的值域内的值，值域外 $p_Y(y)=0$。
:::

::: proof 证明（$g$ 严格单调增的情形）
$F_Y(y)=P(g(X)\le y)=P(X\le h(y))=F_X(h(y))$，求导得 $p_Y(y)=p_X(h(y))\,h'(y)$。单调减时 $F_Y(y)=1-F_X(h(y))$，求导多出一个负号，而 $h'(y)<0$，合起来正是 $p_X(h(y))\,|h'(y)|$。
:::

::: geo 几何直观：概率守恒，密度随伸缩反向变化
密度是“单位长度上的概率”。取 $x$ 附近的一小段 $[x,x+\Delta x]$，它的概率约为 $p_X(x)\Delta x$。变换把这一小段映成 $y$ 附近长约 $\Delta y=|g'(x)|\Delta x$ 的一段，而 **概率不变**，于是
$$p_Y(y)\,\Delta y=p_X(x)\,\Delta x\quad\Longrightarrow\quad p_Y(y)=\frac{p_X(x)}{|g'(x)|}=p_X(x)\,|h'(y)|.$$
变换把哪里 **拉长**，哪里的密度就被 **压低**；把哪里 **压短**，哪里的密度就被 **抬高**。公式里的 $|h'(y)|$ 就是这个伸缩因子。
:::

::: core 推论：正态分布的线性变换仍是正态分布
若 $X\sim N(\mu,\sigma^2)$，$a\neq0$，则
$$Y=aX+b\sim N(a\mu+b,\ a^2\sigma^2).$$
标准化 $\dfrac{X-\mu}{\sigma}\sim N(0,1)$ 是它的特例。
:::

::: example 例 2　对数正态分布
设 $X\sim N(\mu,\sigma^2)$，求 $Y=e^X$ 的密度。

**解** $g(x)=e^x$ 严格单调增，$h(y)=\ln y$，$h'(y)=1/y$（$y>0$）。由公式
$$p_Y(y)=\frac{1}{\sqrt{2\pi}\,\sigma y}\exp\Big\{-\frac{(\ln y-\mu)^2}{2\sigma^2}\Big\},\qquad y>0.$$
这就是 **对数正态分布** $LN(\mu,\sigma^2)$。因子 $1/y$ 说明：$y$ 越大，$e^x$ 的拉伸越厉害，密度被压得越低。
:::

::: pitfall 非单调变换不能直接套公式
$g$ 不单调时，一个 $y$ 可能对应多个 $x$（如 $y=x^2$ 对应 $\pm\sqrt y$）。这时要么用分布函数法，要么把定义域分成若干单调的段，对每一段用公式，再把各段的贡献 **相加**：
$$p_Y(y)=\sum_{x_i:\ g(x_i)=y}\frac{p_X(x_i)}{|g'(x_i)|}.$$
例 1 中两段 $\pm\sqrt y$ 的贡献相等，所以出现了因子 2。
:::

设 $X\sim U(0,1)$，则 $Y=-2\ln X$ 服从

## 概率积分变换与逆变换抽样 {.key}

例 1 中的 $Y=\Phi(X)$ 并不是巧合，而是一条普遍的规律。

::: core 定理（概率积分变换）
设 $X$ 的分布函数 $F(x)$ 连续，则 $Y=F(X)\sim U(0,1)$。反过来，若 $U\sim U(0,1)$，则 $X=F^{-1}(U)$ 的分布函数恰为 $F$（$F$ 不严格单调时，取 $F^{-1}(u)=\inf\{x:F(x)\ge u\}$）。
:::

::: proof 证明（$F$ 严格单调增的情形）
对 $0<u<1$，$P(F(X)\le u)=P(X\le F^{-1}(u))=F(F^{-1}(u))=u$，所以 $F(X)\sim U(0,1)$。反过来，$P(F^{-1}(U)\le x)=P(U\le F(x))=F(x)$。
:::

第二句话给出了计算机上产生任意分布随机数的通用方法——**逆变换抽样**：先产生均匀随机数 $U$，再算 $X=F^{-1}(U)$。例如指数分布的 $F^{-1}(u)=-\ln(1-u)/\lambda$，所以 $X=-\ln(1-U)/\lambda\sim\mathrm{Exp}(\lambda)$；由于 $1-U$ 与 $U$ 同分布，常直接写成 $X=-\ln U/\lambda$。

::: insight 两个方向的同一件事
概率积分变换把 **任意** 连续分布变成均匀分布，逆变换抽样把均匀分布变成 **任意** 分布，它们说的是同一件事：分布函数在纵轴上把概率“均匀地铺开”。这个思想在统计中反复出现：$p$ 值在原假设下服从 $U(0,1)$；拟合优度检验把数据代入假设的分布函数后检验均匀性；Copula 方法用它把多维分布的边际与相依结构分开。
:::

## 分布的其他特征数 {.key}

期望和方差描述了分布的位置和离散程度。描述分布形状，还需要更多的特征数。

::: core 矩、变异系数、分位数
- **$k$ 阶原点矩** $\mu_k=E(X^k)$；**$k$ 阶中心矩** $\nu_k=E(X-EX)^k$。期望是一阶原点矩，方差是二阶中心矩。
- **变异系数** $C_v=\dfrac{\sigma(X)}{E(X)}$：用期望作单位来衡量离散程度，没有量纲，适合比较量级不同的数据。
- **分位数**：对 $0<p<1$，满足 $F(x_p)=p$ 的 $x_p$ 称为 $X$ 的（下侧）$p$ 分位数。$x_{0.5}$ 称为 **中位数**。
:::

::: core 偏度与峰度
- **偏度系数** $\beta_s=\dfrac{\nu_3}{\nu_2^{3/2}}$：$\beta_s>0$ 为右偏（长尾在右），$\beta_s<0$ 为左偏，对称分布 $\beta_s=0$。
- **峰度系数** $\beta_k=\dfrac{\nu_4}{\nu_2^{2}}-3$：以正态分布为基准（正态分布 $\beta_k=0$），$\beta_k>0$ 表示尾部比正态更厚、峰更尖。
:::

| 分布 | 偏度 $\beta_s$ | 峰度 $\beta_k$ | 中位数 |
| --- | --- | --- | --- |
| $N(\mu,\sigma^2)$ | 0 | 0 | $\mu$ |
| $U(a,b)$ | 0 | $-1.2$ | $\frac{a+b}2$ |
| $\mathrm{Exp}(\lambda)$ | 2 | 6 | $\frac{\ln2}\lambda$ |
| $t(n)$，$n>4$ | 0 | $\frac6{n-4}$ | 0 |

::: insight 为什么用三次方、四次方
三阶中心矩把偏离中心的距离取三次方，**保留了正负号**，于是左右两边的偏离会互相抵消，只剩下“不对称”的部分。四阶中心矩把远离中心的偏离放大得特别厉害，所以对 **尾部** 最敏感。除以 $\sigma^3$、$\sigma^4$ 是为了去掉量纲。峰度大的分布容易出现极端值，金融收益率常常如此，这正是“黑天鹅”的统计含义。
:::

::: quiz 0.6931 0.0005
指数分布 $\mathrm{Exp}(1)$ 的中位数是多少？（保留四位小数）
> 解 $1-e^{-x}=0.5$ 得 $x=\ln2\approx0.6931$，小于期望 1。右偏分布的中位数通常在期望的左边：长长的右尾把期望拉向右边，中位数却不受影响。
:::

## 本章小结

- **分布函数法** 普遍适用：$F_Y(y)=P(g(X)\le y)$，再求导。
- **单调变换**：$p_Y(y)=p_X(h(y))\,|h'(y)|$；伸缩因子 $|h'(y)|$ 反映概率守恒——拉长处密度变低，压短处密度变高。非单调时各段贡献相加。
- **正态的线性变换仍是正态**；$e^X$ 为对数正态；$X^2$（$X\sim N(0,1)$）为 $\chi^2(1)$。
- **概率积分变换**：$F(X)\sim U(0,1)$；**逆变换抽样**：$F^{-1}(U)\sim F$。
- **特征数**：矩、变异系数、分位数、偏度、峰度。

| 变换 | 结果 |
| --- | --- |
| $X\sim N(\mu,\sigma^2)$，$Y=aX+b$ | $Y\sim N(a\mu+b,a^2\sigma^2)$ |
| $X\sim N(0,1)$，$Y=X^2$ | $Y\sim\chi^2(1)$ |
| $X\sim N(\mu,\sigma^2)$，$Y=e^X$ | $Y\sim LN(\mu,\sigma^2)$ |
| $U\sim U(0,1)$，$X=-\ln U/\lambda$ | $X\sim\mathrm{Exp}(\lambda)$ |
| $X$ 连续，$Y=F(X)$ | $Y\sim U(0,1)$ |

## 分层练习

### 基础

**1.** 设 $X\sim U(0,1)$，求 $Y=3X+2$ 的密度。

::: details 解答
$h(y)=(y-2)/3$，$|h'(y)|=1/3$，所以 $p_Y(y)=1/3$（$2<y<5$），即 $Y\sim U(2,5)$。均匀分布经线性变换仍是均匀分布。
:::

**2.** 设 $X\sim N(0,1)$，求 $Y=|X|$ 的密度和 $E(Y)$。

::: details 解答
$y>0$ 时 $F_Y(y)=P(-y\le X\le y)=2\Phi(y)-1$，所以 $p_Y(y)=2\varphi(y)=\sqrt{2/\pi}\,e^{-y^2/2}$（$y>0$），称为半正态分布。$E(Y)=\int_0^\infty y\sqrt{2/\pi}\,e^{-y^2/2}\,\mathrm dy=\sqrt{2/\pi}\approx0.798$。
:::

**3.** 求 $\mathrm{Exp}(1)$ 的上四分位数 $x_{0.75}$ 和变异系数。

::: details 解答
$1-e^{-x}=0.75$，$x_{0.75}=\ln4\approx1.386$。$E(X)=1$，$\sigma(X)=1$，变异系数 $C_v=1$。指数分布的变异系数恒为 1，与 $\lambda$ 无关。
:::

**4.** 设 $X\sim N(1,4)$。$Y=\dfrac{X-1}2$ 服从什么分布？$Z=1-2X$ 呢？

::: details 解答
$Y\sim N(0,1)$；$Z\sim N(1-2\times1,\ 4\times4)=N(-1,16)$。
:::

### 提高

**5.** 设 $\Theta\sim U(-\pi/2,\pi/2)$，$Y=\tan\Theta$。求 $Y$ 的密度，并给出一个物理解释。

::: details 解答
$h(y)=\arctan y$，$h'(y)=\frac1{1+y^2}$，所以 $p_Y(y)=\frac1\pi\cdot\frac1{1+y^2}$，这是 **柯西分布**。

物理解释：在离墙 1 米处放一盏可以旋转的灯，让它随机地转向一个均匀分布的角度，光斑在墙上的位置就服从柯西分布。角度接近 $\pm\pi/2$ 时，光斑会跑到非常远的地方——这就是柯西分布厚尾、期望不存在的原因。
:::

**6.** 设 $X\sim N(\mu,\sigma^2)$，求对数正态变量 $Y=e^X$ 的期望。

::: details 解答
$E(Y)=E(e^X)=\int e^x\frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}\,\mathrm dx$。把指数部分配方：$x-\frac{(x-\mu)^2}{2\sigma^2}=\mu+\frac{\sigma^2}2-\frac{(x-\mu-\sigma^2)^2}{2\sigma^2}$，于是 $E(Y)=e^{\mu+\sigma^2/2}$。

注意 $E(e^X)=e^{\mu+\sigma^2/2}>e^{\mu}=e^{E(X)}$：取指数后，期望比“期望的指数”大，差距随 $\sigma^2$ 增大。这是詹森不等式的一个例子。
:::

**7.** 说明怎样用均匀随机数产生服从柯西分布的随机数。

::: details 解答
柯西分布的分布函数 $F(x)=\frac12+\frac1\pi\arctan x$，反函数 $F^{-1}(u)=\tan\big(\pi(u-\frac12)\big)$。所以若 $U\sim U(0,1)$，则 $X=\tan(\pi(U-\frac12))$ 服从柯西分布——与第 5 题的“随机角度”一致。
:::

### 挑战

**8.** 求 $\mathrm{Exp}(1)$ 的偏度和峰度。（提示：$E(X^k)=k!$。）

::: details 解答
$\mu_1=1$，$\mu_2=2$，$\mu_3=6$，$\mu_4=24$。中心矩：$\nu_2=\mu_2-1=1$；$\nu_3=\mu_3-3\mu_2\mu_1+2\mu_1^3=6-6+2=2$；$\nu_4=\mu_4-4\mu_3\mu_1+6\mu_2\mu_1^2-3\mu_1^4=24-24+12-3=9$。所以 $\beta_s=2$，$\beta_k=9-3=6$。指数分布明显右偏、尾部比正态厚得多。
:::

**9.** 设 $X\sim U(-1,2)$，求 $Y=X^2$ 的密度，并验证其积分为 1。

::: details 解答
$p_X(x)=1/3$（$-1<x<2$）。$Y$ 取值于 $[0,4)$。

- $0<y<1$ 时，$\pm\sqrt y$ 都在 $(-1,2)$ 内，两段贡献相加：$p_Y(y)=2\cdot\frac{1/3}{2\sqrt y}=\frac1{3\sqrt y}$；
- $1<y<4$ 时，只有 $\sqrt y$ 在定义域内：$p_Y(y)=\frac{1/3}{2\sqrt y}=\frac1{6\sqrt y}$。

验证：$\int_0^1\frac{\mathrm dy}{3\sqrt y}=\frac23$，$\int_1^4\frac{\mathrm dy}{6\sqrt y}=\frac13$，合计为 1。密度在 $y=1$ 处突然减半，因为从那里开始“负半边”已经用完了。
:::

## 代码实现（Python）

::: details 展开代码：验证变换的结论、逆变换抽样、偏度与峰度
```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(7)
n = 200_000

# 1. X ~ N(0,1) 时 X^2 ~ chi2(1)：比较若干分位数
x = rng.standard_normal(n)
for p in [0.25, 0.5, 0.9]:
    print(p, np.quantile(x**2, p).round(4), stats.chi2(1).ppf(p).round(4))

# 2. 逆变换抽样：用均匀随机数产生指数分布和柯西分布
u = rng.random(n)
expo = -np.log(u) / 2.0                      # Exp(2)，期望 0.5
cauchy = np.tan(np.pi * (u - 0.5))
print("指数样本均值：", expo.mean().round(4))
print("柯西样本的中位数：", np.median(cauchy).round(4), "（柯西分布没有期望）")

# 3. 概率积分变换：F(X) 应当服从 U(0,1)，用 KS 检验看看
y = stats.norm.cdf(x)
print("KS 检验 p 值：", stats.kstest(y, "uniform").pvalue.round(3))

# 4. 偏度与峰度：scipy 的 kurtosis 默认就减去了 3
for name, s in [("正态", x), ("均匀", rng.random(n)), ("指数", rng.exponential(1, n))]:
    print(name, "偏度", stats.skew(s).round(3), "峰度", stats.kurtosis(s).round(3))
```
:::

::: info 史话：随机数与蒙特卡洛
第二次世界大战期间，乌拉姆、冯·诺伊曼等人在洛斯阿拉莫斯研究中子扩散时，需要大量服从各种分布的随机数，他们以摩纳哥的赌城为这类方法命名为“蒙特卡洛方法”。1951 年冯·诺伊曼发表的论文系统讨论了用均匀随机数产生其他分布的技术，逆变换法和舍选法就在其中。今天几乎所有统计软件的随机数生成，都建立在这些思想之上。
:::
