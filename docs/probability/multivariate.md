# 多维随机变量

研究身高时，往往也要研究体重；研究价格时，往往也要研究销量。一个随机现象常常同时产生 **多个** 数值，它们之间可能互相关联。只看每个变量各自的分布是不够的：身高和体重各自的分布，回答不了“身高 180 cm 的人体重大概多少”。

这一章用 **联合分布** 描述多个随机变量的整体，讨论如何从联合分布得到每个变量的 **边际分布**、怎样判断 **独立**，以及多个随机变量的函数（尤其是 **和**）服从什么分布。

## 联合分布 {.core}

::: core 定义（二维随机变量与联合分布函数）
$(X,Y)$ 称为二维随机变量。对任意实数 $x,y$，称
$$F(x,y)=P(X\le x,\ Y\le y)$$
为 $(X,Y)$ 的 **联合分布函数**。它关于每个变量单调不减、右连续，$F(-\infty,y)=F(x,-\infty)=0$，$F(+\infty,+\infty)=1$。
:::

::: core 联合分布列与联合密度
- **离散**：$p_{ij}=P(X=x_i,\ Y=y_j)$，满足 $p_{ij}\ge0$，$\sum_i\sum_jp_{ij}=1$。
- **连续**：若存在非负函数 $p(x,y)$ 使 $F(x,y)=\int_{-\infty}^x\int_{-\infty}^yp(u,v)\,\mathrm dv\,\mathrm du$，则称 $p(x,y)$ 为 **联合密度**。对平面上的区域 $D$，
$$P\big((X,Y)\in D\big)=\iint_Dp(x,y)\,\mathrm dx\,\mathrm dy.$$
:::

::: geo 几何直观：概率是曲面下的体积
一维时，概率是密度曲线下的 **面积**；二维时，联合密度是平面上方的一张 **曲面**，$(X,Y)$ 落在区域 $D$ 内的概率就是 $D$ 上方、曲面下方的 **体积**。整张曲面下的总体积为 1。在下面实验的热力图里，颜色越深，曲面越高。
:::

::: example 例 1　不放回摸球
袋中有 2 个红球、3 个白球，不放回地摸两次。记 $X$、$Y$ 分别为第一次、第二次摸到的红球数（0 或 1）。由乘法公式，联合分布列为

| | $Y=0$ | $Y=1$ | $P(X=x)$ |
| --- | --- | --- | --- |
| $X=0$ | $\frac35\cdot\frac24=0.3$ | $\frac35\cdot\frac24=0.3$ | 0.6 |
| $X=1$ | $\frac25\cdot\frac34=0.3$ | $\frac25\cdot\frac14=0.1$ | 0.4 |
| $P(Y=y)$ | 0.6 | 0.4 | 1 |

表的边缘一行一列就是 $X$ 与 $Y$ 各自的分布——这正是“边际分布”名称的来历。
:::

## 边际分布 {.core}

::: core 边际分布
由联合分布可以得到每个分量的分布，称为 **边际分布**：
$$F_X(x)=F(x,+\infty),\qquad p_X(x)=\int_{-\infty}^{\infty}p(x,y)\,\mathrm dy,\qquad P(X=x_i)=\sum_jp_{ij}.$$
:::

::: geo 几何直观：边际分布是“投影”
固定 $x$，把联合密度沿 $y$ 方向全部加起来，就得到 $p_X(x)$。想象用平行光沿 $y$ 轴方向照射密度曲面，它在 $x$ 轴所在的墙上留下的“影子”，就是边际密度。

投影会丢失信息：不同的联合分布可以有完全相同的边际分布。**联合分布决定边际分布，反之不然。**
:::

## 随机变量的独立性 {.core}

::: core 定义（随机变量相互独立）
若对任意 $x,y$ 有 $F(x,y)=F_X(x)F_Y(y)$，则称 $X$ 与 $Y$ **相互独立**。等价地：
- 离散：$p_{ij}=P(X=x_i)\,P(Y=y_j)$ 对一切 $i,j$ 成立；
- 连续：$p(x,y)=p_X(x)\,p_Y(y)$ 几乎处处成立。
:::

例 1 中 $P(X=1,Y=1)=0.1\neq0.4\times0.4$，所以 $X$ 与 $Y$ 不独立：第一次摸走了红球，第二次摸到红球的可能就变小了。

**试一试**

1. 依次点“独立的标准正态”和“正方形上的均匀分布”：左右两幅图一模一样，说明联合密度等于边际之积。
2. 点“相关的正态”：两个边际都是标准正态，和“独立的标准正态”完全相同，联合密度却不同——边际决定不了联合分布。
3. 点“三角形”：边际密度分别是什么形状？为什么一眼就能看出不独立？
4. 点“圆盘”：右图（边际之积）是什么形状？它和左图的圆盘差在哪里？

::: insight 判断独立性的两条捷径
1. **因子分解**：若联合密度能写成 $p(x,y)=g(x)h(y)$（且支撑是矩形），则 $X$ 与 $Y$ 独立，不必先求边际。
2. **看支撑集**：若 $p(x,y)>0$ 的区域不是一个“矩形” $\{x\in A,\ y\in B\}$，则一定不独立——知道 $x$ 会改变 $y$ 的取值范围。三角形、圆盘上的均匀分布都属于这种情形。
:::

::: example 例 2　谁先发生
设 $X\sim\mathrm{Exp}(\lambda_1)$，$Y\sim\mathrm{Exp}(\lambda_2)$ 相互独立，求 $P(X<Y)$。

**解** 联合密度 $p(x,y)=\lambda_1e^{-\lambda_1x}\lambda_2e^{-\lambda_2y}$（$x,y>0$），积分区域是直线 $y=x$ 上方：
$$P(X<Y)=\int_0^\infty\lambda_1e^{-\lambda_1x}\Big(\int_x^\infty\lambda_2e^{-\lambda_2y}\,\mathrm dy\Big)\mathrm dx=\int_0^\infty\lambda_1e^{-(\lambda_1+\lambda_2)x}\,\mathrm dx=\frac{\lambda_1}{\lambda_1+\lambda_2}.$$
例如两台设备寿命的均值分别为 1/2 年和 1/3 年（$\lambda_1=2$，$\lambda_2=3$），第一台先坏的概率为 $2/5$。
:::

## 多维随机变量函数的分布 {.core}

### 和的分布：卷积公式 {.key}

::: core 卷积公式
设 $X$ 与 $Y$ 相互独立，密度分别为 $p_X,p_Y$，则 $Z=X+Y$ 的密度为
$$p_Z(z)=\int_{-\infty}^{\infty}p_X(x)\,p_Y(z-x)\,\mathrm dx.$$
离散情形：$P(Z=k)=\sum_iP(X=i)\,P(Y=k-i)$。
:::

::: geo 几何直观：沿斜线收集概率
$Z=z$ 意味着点 $(X,Y)$ 落在直线 $x+y=z$ 上。所以 $p_Z(z)$ 就是 **沿这条斜线** 把联合密度 $p_X(x)p_Y(z-x)$ 加起来。也可以换个角度：把 $p_Y$ 左右翻转、平移到 $z$，与 $p_X$ 逐点相乘，乘积曲线下的面积就是 $p_Z(z)$。让 $z$ 从左扫到右，就画出了整条 $p_Z$。
:::

<ConvolutionLab />

**试一试**

1. $X,Y$ 都选 $U(0,1)$，拖动 $z$：两个矩形的重叠部分先变大、再变小，$p_Z$ 是一个三角形。
2. 都选 $\mathrm{Exp}(1)$：和的密度从 0 开始上升，这是 $\mathrm{Ga}(2,1)$。
3. 切换到“n 个同分布相加”，选“偏斜”分布，把 $n$ 从 1 加到 12。和的密度最终变成什么形状？

::: core 常用分布的可加性
设下列各对随机变量相互独立：
- $b(n_1,p)+b(n_2,p)=b(n_1+n_2,p)$；
- $P(\lambda_1)+P(\lambda_2)=P(\lambda_1+\lambda_2)$；
- $N(\mu_1,\sigma_1^2)+N(\mu_2,\sigma_2^2)=N(\mu_1+\mu_2,\ \sigma_1^2+\sigma_2^2)$；
- $\mathrm{Ga}(\alpha_1,\lambda)+\mathrm{Ga}(\alpha_2,\lambda)=\mathrm{Ga}(\alpha_1+\alpha_2,\lambda)$，特别地 $\chi^2(m)+\chi^2(n)=\chi^2(m+n)$。

注意：二项分布要求 $p$ 相同，伽马分布要求 $\lambda$ 相同；正态分布相加时 **方差相加**，标准差并不相加。
:::

::: proof 证明（泊松分布的可加性）
$$P(X+Y=k)=\sum_{i=0}^k\frac{\lambda_1^i}{i!}e^{-\lambda_1}\frac{\lambda_2^{k-i}}{(k-i)!}e^{-\lambda_2}=\frac{e^{-(\lambda_1+\lambda_2)}}{k!}\sum_{i=0}^k\binom ki\lambda_1^i\lambda_2^{k-i}=\frac{(\lambda_1+\lambda_2)^k}{k!}e^{-(\lambda_1+\lambda_2)}.$$
最后一步用了二项式定理。
:::

::: quiz 0.0067 0.0002
设 $X\sim P(2)$，$Y\sim P(3)$ 相互独立，求 $P(X+Y=0)$。（保留四位小数）
> $X+Y\sim P(5)$，$P(X+Y=0)=e^{-5}\approx0.0067$。
:::

### 最大值与最小值的分布 {.key}

设 $X_1,\dots,X_n$ 相互独立，分布函数分别为 $F_1,\dots,F_n$。

::: core 最大值、最小值
$$F_{\max}(z)=P(X_1\le z,\dots,X_n\le z)=\prod_{i=1}^nF_i(z),$$
$$F_{\min}(z)=1-P(X_1>z,\dots,X_n>z)=1-\prod_{i=1}^n\big[1-F_i(z)\big].$$
:::

它们的直接应用是系统可靠性：**串联** 系统的寿命是各元件寿命的最小值，**并联** 系统的寿命是最大值。

::: example 例 3　串联系统的寿命
三个元件串联，寿命相互独立，都服从 $\mathrm{Exp}(\lambda)$。系统寿命 $T=\min(X_1,X_2,X_3)$，
$$P(T>t)=\big(e^{-\lambda t}\big)^3=e^{-3\lambda t},$$
所以 $T\sim\mathrm{Exp}(3\lambda)$，平均寿命只有单个元件的三分之一。一般地，$n$ 个独立指数变量的最小值仍服从指数分布，参数为各参数之和。
:::

::: quiz 0.3333 0.001
三个元件寿命独立且都服从均值为 1 的指数分布，串联成系统。系统的平均寿命是多少？
> $T\sim\mathrm{Exp}(3)$，$E(T)=1/3\approx0.3333$。
:::

### 变量变换法 {.hard}

:::: l2 进阶：二维变量变换与雅可比行列式
设 $(X,Y)$ 的联合密度为 $p(x,y)$，变换 $u=g_1(x,y)$，$v=g_2(x,y)$ 一一对应，反变换为 $x=x(u,v)$，$y=y(u,v)$，且偏导数连续。则 $(U,V)$ 的联合密度为
$$p_{UV}(u,v)=p\big(x(u,v),\,y(u,v)\big)\,|J|,\qquad J=\frac{\partial(x,y)}{\partial(u,v)}=\begin{vmatrix}\partial x/\partial u&\partial x/\partial v\\ \partial y/\partial u&\partial y/\partial v\end{vmatrix}.$$

**几何直观**：这是一维公式 $p_Y(y)=p_X(h(y))|h'(y)|$ 的二维版本。$|J|$ 是变换的 **面积缩放因子**：$(u,v)$ 平面上的一个小矩形 $\mathrm du\,\mathrm dv$，在 $(x,y)$ 平面上对应一个面积约为 $|J|\,\mathrm du\,\mathrm dv$ 的小平行四边形。概率守恒，所以密度要乘以 $|J|$。

求 $Z=g(X,Y)$ 的分布时，常增补一个变量（如 $V=X$），用变量变换求出 $(Z,V)$ 的联合密度，再对 $V$ 积分得到边际密度，这叫 **增补变量法**。卷积公式就是这样推出来的。
::::

## 本章小结

- **联合分布** 描述多个随机变量的整体；概率是联合密度曲面下的体积。
- **边际分布** 是联合分布的“投影”；联合决定边际，边际决定不了联合。
- **独立** ⟺ 联合密度（分布列）等于边际之积；支撑集不是矩形就不独立。
- **和的分布** 用卷积公式：沿直线 $x+y=z$ 收集概率；二项、泊松、正态、伽马、卡方分布有可加性。
- **最大值与最小值**：$F_{\max}=\prod F_i$，$1-F_{\min}=\prod(1-F_i)$。
- **变量变换** 中 $|J|$ 是面积缩放因子。

| 公式 | 表达式 |
| --- | --- |
| 边际密度 | $p_X(x)=\int p(x,y)\,\mathrm dy$ |
| 独立 | $p(x,y)=p_X(x)\,p_Y(y)$ |
| 卷积公式 | $p_{X+Y}(z)=\int p_X(x)\,p_Y(z-x)\,\mathrm dx$ |
| 最大值 | $F_{\max}(z)=\prod F_i(z)$ |
| 最小值 | $F_{\min}(z)=1-\prod[1-F_i(z)]$ |
| 变量变换 | $p_{UV}(u,v)=p(x(u,v),y(u,v))\,\lvert J\rvert$ |

## 分层练习

### 基础

**1.** 设 $(X,Y)$ 的联合分布列为：$P(0,0)=0.1$，$P(0,1)=0.2$，$P(1,0)=0.3$，$P(1,1)=0.4$。求边际分布，并判断 $X$ 与 $Y$ 是否独立。

::: details 解答
$P(X=0)=0.3$，$P(X=1)=0.7$；$P(Y=0)=0.4$，$P(Y=1)=0.6$。$P(0,0)=0.1\neq0.3\times0.4=0.12$，所以不独立。
:::

**2.** 设 $X,Y$ 独立且都服从 $\mathrm{Exp}(1)$，求 $P(X+Y\le1)$。

::: details 解答
$X+Y\sim\mathrm{Ga}(2,1)$，密度 $ze^{-z}$，$P(X+Y\le1)=\int_0^1ze^{-z}\,\mathrm dz=1-2e^{-1}\approx0.264$。
:::

**3.** 设 $X\sim N(1,2)$，$Y\sim N(2,3)$ 相互独立。求 $X+Y$ 的分布和 $P(X+Y>3)$。

::: details 解答
$X+Y\sim N(3,5)$，$P(X+Y>3)=0.5$。注意 $N(1,2)$ 的第二个参数是方差，相加时是 $2+3=5$。
:::

**4.** 五个元件并联，寿命相互独立，每个元件工作超过 1000 小时的概率都是 0.6。求系统工作超过 1000 小时的概率。

::: details 解答
系统寿命是最大值，$P(T\le1000)=0.4^5$，所以 $P(T>1000)=1-0.4^5\approx0.990$。
:::

### 提高

**5.** 设 $X,Y$ 独立且都服从 $U(0,1)$，用卷积公式求 $Z=X+Y$ 的密度。

::: details 解答
$p_Z(z)=\int p_X(x)p_Y(z-x)\,\mathrm dx$，被积函数在 $0<x<1$ 且 $0<z-x<1$ 时为 1，即 $\max(0,z-1)<x<\min(1,z)$。所以 $0<z\le1$ 时 $p_Z(z)=z$，$1<z<2$ 时 $p_Z(z)=2-z$，是 $(0,2)$ 上的三角形分布，与实验结果一致。
:::

**6.** 设 $X_1,\dots,X_n$ 独立同分布于 $U(0,1)$，求 $M=\max X_i$ 的密度与期望。

::: details 解答
$F_M(z)=z^n$（$0<z<1$），$p_M(z)=nz^{n-1}$，$E(M)=\int_0^1nz^n\,\mathrm dz=\frac{n}{n+1}$。样本越多，最大值越接近 1。若总体是 $U(0,\theta)$，$\frac{n+1}nM$ 是 $\theta$ 的无偏估计（见“[点估计](/inference/point-estimation)”一章）。
:::

**7.** 设 $(X,Y)$ 在三角形 $\{0<y<x<1\}$ 上均匀分布。求边际密度，并说明二者为什么不独立。

::: details 解答
联合密度为 2（三角形面积为 1/2）。$p_X(x)=\int_0^x2\,\mathrm dy=2x$（$0<x<1$），$p_Y(y)=\int_y^12\,\mathrm dx=2(1-y)$（$0<y<1$）。$p_X(x)p_Y(y)=4x(1-y)$ 不等于联合密度，所以不独立。直观上，支撑集不是矩形，知道 $x$ 后 $y$ 只能在 $(0,x)$ 内取值。
:::

### 挑战

**8.** 设 $X,Y$ 独立且都服从 $N(0,1)$，令 $X=R\cos\Theta$，$Y=R\sin\Theta$。证明 $R$ 与 $\Theta$ 相互独立，$\Theta\sim U(0,2\pi)$，$R^2\sim\mathrm{Exp}(1/2)$。由此说明怎样用两个均匀随机数产生两个独立的标准正态随机数。

::: details 解答
雅可比行列式 $J=\frac{\partial(x,y)}{\partial(r,\theta)}=r$，所以
$$p(r,\theta)=\frac1{2\pi}e^{-r^2/2}\cdot r=\underbrace{\frac1{2\pi}}_{\Theta}\cdot\underbrace{re^{-r^2/2}}_{R},\qquad r>0,\ 0<\theta<2\pi.$$
联合密度可以分解，所以 $R$ 与 $\Theta$ 独立，$\Theta\sim U(0,2\pi)$。$P(R^2>s)=P(R>\sqrt s)=e^{-s/2}$，所以 $R^2\sim\mathrm{Exp}(1/2)$。

于是若 $U_1,U_2$ 独立同分布于 $U(0,1)$，令 $R=\sqrt{-2\ln U_1}$，$\Theta=2\pi U_2$，则 $R\cos\Theta$ 与 $R\sin\Theta$ 是两个独立的标准正态随机数。这就是 **Box–Muller 方法**，本站的模拟实验也用到了类似的思想。
:::

**9.** 举例说明：两个联合分布不同、边际分布相同的二维随机变量。

::: details 解答
设 $X\sim N(0,1)$。取 $(X,Y_1)$，其中 $Y_1=X$；再取 $(X,Y_2)$，其中 $Y_2$ 与 $X$ 独立且 $Y_2\sim N(0,1)$。两者的边际分布都是两个标准正态，但前者的联合分布集中在直线 $y=x$ 上，后者是圆对称的钟形。又如例 1 的表格中，把 $p_{ij}$ 分别加减同一个小量 $\varepsilon$（对角线加、反对角线减），边际不变而联合分布改变。

**拓展**：Sklar 定理说明，任何联合分布都可以分解为“边际分布 + 一个刻画相依结构的 Copula 函数”。金融风险管理中常用它来单独建模资产之间的相依性。
:::

## 代码实现（Python）

::: details 展开代码：联合分布的模拟、卷积与最大最小值
```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(3)
n = 500_000

# 1. 例 2：两个独立指数变量，P(X < Y) = λ1 / (λ1 + λ2)
x = rng.exponential(1 / 2, n)        # numpy 用 scale = 1/λ
y = rng.exponential(1 / 3, n)
print("P(X < Y)：模拟", np.mean(x < y).round(4), " 理论", 2 / 5)

# 2. 卷积：两个 U(0,1) 之和的密度是三角形，用数值卷积验证
h = 0.001
grid = np.arange(0, 1, h)
f = np.ones_like(grid)                       # U(0,1) 的密度
conv = np.convolve(f, f) * h                 # 和的密度在 z = 0, h, 2h, ... 上的值
for zv in [0.5, 1.0, 1.5]:
    print(f"p_Z({zv}) 数值卷积 = {conv[int(zv / h)]:.3f}")

# 3. 泊松可加性
s = rng.poisson(2, n) + rng.poisson(3, n)
print("P(X + Y = 0)：模拟", np.mean(s == 0).round(4), " 理论", np.exp(-5).round(4))

# 4. 串联系统的寿命：三个 Exp(1) 的最小值
t = rng.exponential(1, (n, 3)).min(axis=1)
print("串联系统平均寿命：", t.mean().round(4), "（理论 1/3）")

# 5. Box-Muller：用两个均匀随机数产生两个独立的标准正态随机数
u1, u2 = rng.random(n), rng.random(n)
r, th = np.sqrt(-2 * np.log(u1)), 2 * np.pi * u2
z1, z2 = r * np.cos(th), r * np.sin(th)
print("均值", z1.mean().round(3), " 方差", z1.var().round(3), " 相关系数", np.corrcoef(z1, z2)[0, 1].round(3))
```

1909 年，丹麦哥本哈根电话公司的工程师爱尔朗研究电话呼叫的规律：呼叫次数服从泊松分布，相邻两次呼叫的间隔服从指数分布，而第 $k$ 次呼叫到达的时刻是 $k$ 个独立指数变量之和，服从参数为整数的伽马分布——后来被称为 **爱尔朗分布**。他据此计算一个交换台需要多少条线路，开创了 **排队论**。今天的呼叫中心、网络服务器、医院急诊的容量设计，仍在使用他的方法。
:::
