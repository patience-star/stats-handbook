# 随机事件与概率

抛一枚硬币，正面朝上的可能性是多少？“一半”——几乎人人都会这样回答。可是“可能性”到底是什么？它能像长度、重量那样被精确地定义和计算吗？

这一章从最基本的对象出发：用 **集合** 描述随机现象的结果，用 **公理** 规定概率必须满足的规则，再介绍确定概率的几种方法。之后所有的概率论与统计学，都建立在这几块基石之上。

## 随机现象与样本空间 {.core}

在一定条件下，结果不止一种、事先无法确定会出现哪一种的现象，称为 **随机现象**。可以在相同条件下重复进行的随机现象称为 **随机试验**。

::: core 定义（样本空间与随机事件）
随机现象的一切可能的基本结果组成的集合称为 **样本空间**，记作 $\Omega=\{\omega\}$，其中的元素 $\omega$ 称为 **样本点**。

样本空间的子集称为 **随机事件**，简称事件，常用 $A,B,C$ 表示。某次试验的结果 $\omega\in A$ 时，称事件 $A$ **发生**。只含一个样本点的事件称为 **基本事件**；$\Omega$ 本身称为 **必然事件**；空集 $\varnothing$ 称为 **不可能事件**。
:::

例如：

- 掷一颗骰子，$\Omega=\{1,2,3,4,5,6\}$，“点数为偶数”是事件 $A=\{2,4,6\}$；
- 一天内到达某银行的顾客数，$\Omega=\{0,1,2,\dots\}$，是可列的无限集；
- 一只灯泡的寿命，$\Omega=[0,\infty)$，是不可列的连续集。

::: insight 为什么要用集合
把“事件”翻译成“样本空间的子集”，事件之间的逻辑关系（“或”“且”“非”）就变成了集合运算（并、交、补）。逻辑推理从此可以 **画出来**、**算出来**——这就是下面维恩图的意义，也是整个概率论能够严格化的前提。
:::

## 事件的关系与运算 {.key}

| 关系或运算 | 记号 | 含义 |
| --- | --- | --- |
| 包含 | $A\subset B$ | $A$ 发生必然导致 $B$ 发生 |
| 相等 | $A=B$ | $A\subset B$ 且 $B\subset A$ |
| 互不相容 | $AB=\varnothing$ | $A$ 与 $B$ 不能同时发生 |
| 并（和） | $A\cup B$ | $A$ 与 $B$ 至少有一个发生 |
| 交（积） | $A\cap B$，简记 $AB$ | $A$ 与 $B$ 同时发生 |
| 差 | $A-B$ | $A$ 发生而 $B$ 不发生，$A-B=A\bar B$ |
| 对立 | $\bar A=\Omega-A$ | $A$ 不发生 |

事件的运算满足交换律、结合律、分配律，以及最常用的 **德摩根律**：
$$\overline{A\cup B}=\bar A\,\bar B,\qquad \overline{AB}=\bar A\cup\bar B.$$
它可以推广到任意多个事件：“至少一个发生”的对立是“一个都不发生”，“都发生”的对立是“至少一个不发生”。

::: pitfall 互不相容与对立的区别
对立事件一定互不相容，但互不相容的事件不一定对立：$A$ 与 $\bar A$ 不但不能同时发生，而且必有一个发生（$A\cup\bar A=\Omega$）；互不相容只要求前一半。掷骰子时，“点数为 1”与“点数为 2”互不相容，但不对立。
:::

:::: l2 进阶：事件域
当样本空间是不可列集（如 $[0,\infty)$）时，并不是所有子集都能合理地定义概率。概率论只对一个足够丰富的子集族 $\mathcal F$ 定义概率，要求它满足：

1. $\Omega\in\mathcal F$；
2. 若 $A\in\mathcal F$，则 $\bar A\in\mathcal F$；
3. 若 $A_1,A_2,\dots\in\mathcal F$，则 $\bigcup_{n=1}^\infty A_n\in\mathcal F$。

这样的 $\mathcal F$ 称为 **事件域**（$\sigma$ 代数）。它对可列次的并、交、补运算封闭，保证我们关心的事件都“可以谈概率”。三元组 $(\Omega,\mathcal F,P)$ 称为 **概率空间**。
::::

## 概率的公理化定义 {.core}

“可能性的大小”应当满足哪些规则？1933 年，柯尔莫哥洛夫给出了只有三条的答案。

::: core 定义（概率的公理化定义）
设 $\Omega$ 为样本空间，$\mathcal F$ 为事件域。若对每个事件 $A\in\mathcal F$，定义在 $\mathcal F$ 上的实值函数 $P(A)$ 满足：

1. **非负性**：$P(A)\ge 0$；
2. **正则性**：$P(\Omega)=1$；
3. **可列可加性**：若 $A_1,A_2,\dots$ 两两互不相容，则 $P\Big(\bigcup_{n=1}^\infty A_n\Big)=\sum_{n=1}^\infty P(A_n)$，

则称 $P(A)$ 为事件 $A$ 的 **概率**。
:::

::: geo 几何直观：概率就是“面积”
把样本空间画成面积为 1 的正方形，事件是其中的区域。三条公理恰好是面积的三条性质：面积不为负；整个正方形的面积是 1；互不重叠的区域合在一起，面积相加。所以 **凡是关于面积成立的推理，对概率都成立**。下面几节的性质，在维恩图上都一目了然。
:::

::: insight 公理不回答“概率是多少”
公理只规定概率必须遵守的规则，并不告诉我们某个具体事件的概率是多少。确定具体的概率，要靠下一节的方法：频率、等可能性、几何度量，或者主观判断。公理化的意义在于，无论用哪种方法得到的“概率”，只要满足这三条，后面的全部理论就都适用。
:::

## 确定概率的方法

### 频率方法

在相同条件下重复试验 $n$ 次，事件 $A$ 发生了 $n_A$ 次，称 $f_n(A)=n_A/n$ 为 $A$ 发生的 **频率**。大量实验表明，$n$ 增大时频率会稳定在某个常数附近，这个常数就可以作为 $A$ 的概率。历史上，蒲丰掷硬币 4040 次得到正面 2048 次，皮尔逊掷 24000 次得到正面 12012 次，频率都非常接近 0.5。

频率稳定性的严格表述是伯努利大数定律，见“[大数定律与中心极限定理](/probability/limit-theorems)”一章。

### 古典方法 {.key}

::: core 古典概型
若样本空间只含 **有限个** 样本点，且每个样本点出现的可能性 **相等**，则事件 $A$ 的概率为
$$P(A)=\frac{A\ \text{中所含样本点的个数}}{\Omega\ \text{中样本点的总数}}=\frac{k}{n}.$$
:::

古典概型的计算归结为计数。常用的计数工具：

- **乘法原理**：完成一件事要分 $k$ 步，各步分别有 $m_1,\dots,m_k$ 种方法，则共有 $m_1m_2\cdots m_k$ 种方法；
- **排列**：从 $n$ 个不同元素中取 $r$ 个排成一列，有 $P_n^r=\dfrac{n!}{(n-r)!}$ 种（有放回时为 $n^r$ 种）；
- **组合**：从 $n$ 个不同元素中取 $r$ 个，不计顺序，有 $\dbinom nr=\dfrac{n!}{r!\,(n-r)!}$ 种。

::: example 例 1　抽样检验
一批产品共 100 件，其中 5 件次品。任取 10 件，求恰有 1 件次品的概率：(1) 不放回抽样；(2) 有放回抽样。

**解** (1) 不放回：从 100 件中取 10 件共 $\binom{100}{10}$ 种取法，恰有 1 件次品的取法有 $\binom51\binom{95}{9}$ 种，所以
$$P=\frac{\binom51\binom{95}{9}}{\binom{100}{10}}\approx0.339.$$
(2) 有放回：每次取到次品的概率都是 0.05，10 次中恰有 1 次取到次品的概率为
$$P=\binom{10}{1}\times0.05\times0.95^9\approx0.315.$$
这两个答案分别对应“[常用分布](/probability/distributions)”一章的 **超几何分布** 和 **二项分布**。批量很大时，两者非常接近。
:::

::: example 例 2　生日问题
一个班有 $n$ 个人，至少有两人同一天生日的概率是多少？（一年按 365 天计，各天等可能。）

**解** 先算对立事件“所有人生日都不同”：第一个人可以是任何一天，第二个人只能是剩下的 364 天之一……由乘法原理，
$$P(\text{至少两人同生日})=1-\frac{365\times364\times\cdots\times(365-n+1)}{365^n}.$$
$n=23$ 时这个概率已经超过 50%，$n=50$ 时约为 97%。
:::

<BirthdayCurve />

::: insight 为什么直觉错得这么离谱
人们常把问题想成“有人和 **我** 同一天生日”，这个概率在 $n=23$ 时只有 $1-(364/365)^{22}\approx5.9\%$。但“至少两人同生日”考虑的是 **所有的配对**：23 个人能组成 $\binom{23}{2}=253$ 对，每一对同生日的概率是 $1/365$。粗略地说，概率约为 $1-e^{-253/365}\approx0.50$——这正是图中那条橙色虚线的近似。配对数随 $n^2$ 增长，所以概率上升得比直觉快得多。
:::

### 几何方法 {.key}

当样本点有无穷多个、但“均匀地”分布在某个区域里时，用长度、面积或体积代替计数。

::: core 几何概型
若样本空间 $\Omega$ 是一个可以度量的几何区域（长度、面积、体积有限），且样本点落在 $\Omega$ 中任一区域 $A$ 内的可能性只与 $A$ 的度量成正比、与位置和形状无关，则
$$P(A)=\frac{A\ \text{的度量}}{\Omega\ \text{的度量}}.$$
:::

::: example 例 3　会面问题
甲乙两人约定在下午 1 点到 2 点之间在某处见面，先到者等候 20 分钟，过时就离开。设两人在这一小时内的到达时刻相互独立且都均匀分布，求两人能会面的概率。

**解** 以 $x,y$ 表示两人到达的时刻（分钟），样本空间是边长为 60 的正方形。两人能会面当且仅当 $|x-y|\le20$，这是正方形中夹在两条直线 $y=x\pm20$ 之间的带状区域。带外是两个直角边为 40 的等腰直角三角形，所以
$$P=1-\frac{40^2}{60^2}=1-\frac49=\frac59\approx0.556.$$
:::

::: example 例 4　蒲丰投针
平面上画着间距为 $d$ 的平行线，向平面任意投一根长为 $l$（$l\le d$）的针，求针与平行线相交的概率。

**解** 以 $x$ 表示针的中点到最近一条平行线的距离，$\theta$ 表示针与平行线的夹角，则 $(\theta,x)$ 均匀分布在矩形 $[0,\pi]\times[0,d/2]$ 上，面积为 $\pi d/2$。针与直线相交当且仅当 $x\le\dfrac l2\sin\theta$，这块区域的面积为
$$\int_0^\pi\frac l2\sin\theta\,\mathrm d\theta=l,$$
所以 $P=\dfrac{l}{\pi d/2}=\dfrac{2l}{\pi d}$。

反过来，如果投针 $n$ 次、相交 $k$ 次，用频率 $k/n$ 代替概率，就得到 $\pi$ 的估计 $\hat\pi=\dfrac{2ln}{dk}$。这是 **随机模拟**（蒙特卡洛方法）最早的例子之一。
:::

:::: l3 深入：贝特朗悖论——“随机”必须说清楚
在单位圆内随机取一条弦，求弦长超过圆内接正三角形边长 $\sqrt3$ 的概率。三种“随机”给出三个答案：

- 在圆周上随机取两个端点：所求概率为 $1/3$；
- 随机取一条半径，在半径上随机取一点，过该点作垂直于半径的弦：所求概率为 $1/2$；
- 在圆内随机取一点作为弦的中点：所求概率为 $1/4$。

三种做法都没有算错，它们对应不同的 **概率模型**。几何概型中的“均匀”是对某个具体参数（端点位置、到圆心的距离、中点位置）而言的，换一个参数，“均匀”的含义就变了。这个悖论提醒我们：没有明确的随机机制，“随机取一条弦”这个问题本身就不完整。
::::

### 主观方法

一些事件无法重复，例如“某项新产品明年畅销”。这时人们根据经验和信息对可能性作出的判断，也可以视为概率，称为 **主观概率**。只要满足三条公理，主观概率同样可以参与运算。贝叶斯统计中的先验分布就常带有主观成分，见“[贝叶斯估计](/inference/bayesian)”一章。

## 概率的性质 {.core}

由三条公理可以推出概率的一系列性质，它们都是面积性质的翻版。

::: core 概率的基本性质
1. $P(\varnothing)=0$；
2. **有限可加性**：若 $A_1,\dots,A_n$ 两两互不相容，则 $P\big(\bigcup_{i=1}^nA_i\big)=\sum_{i=1}^nP(A_i)$；
3. **对立事件**：$P(\bar A)=1-P(A)$；
4. **减法公式**：$P(A-B)=P(A)-P(AB)$；特别地，若 $B\subset A$，则 $P(A-B)=P(A)-P(B)$，且 $P(A)\ge P(B)$（**单调性**）；
5. **加法公式**：$P(A\cup B)=P(A)+P(B)-P(AB)$。
:::

::: proof 证明（加法公式）
$A\cup B=A\cup(B-AB)$，且 $A$ 与 $B-AB$ 互不相容。由有限可加性和减法公式，
$$P(A\cup B)=P(A)+P(B-AB)=P(A)+P(B)-P(AB).$$
在维恩图上看：$P(A)+P(B)$ 把交集 $AB$ 算了两次，要减掉一次。
:::

::: insight 对立事件是计算“至少一个”的利器
“至少一个发生”常常很难直接算，它的对立事件“一个都不发生”却往往简单。生日问题就是这样做的。经验法则：**题目里出现“至少”，先想对立事件**。
:::

### 容斥原理 {.hard}

加法公式可以推广到 $n$ 个事件：
$$P\Big(\bigcup_{i=1}^nA_i\Big)=\sum_iP(A_i)-\sum_{i<j}P(A_iA_j)+\sum_{i<j<k}P(A_iA_jA_k)-\cdots+(-1)^{n-1}P(A_1A_2\cdots A_n).$$
三个事件时为
$$P(A\cup B\cup C)=P(A)+P(B)+P(C)-P(AB)-P(BC)-P(AC)+P(ABC).$$

::: geo 几何直观：加了减、减了加
在三个圆的维恩图里数一数：中间三圆都重叠的区域在三个单项中被加了 3 次，在三个两两交中被减了 3 次，最后要再加回 1 次，才恰好计 1 次。容斥原理就是让每块区域 **不多不少只算一次** 的记账方法。
:::

::: example 例 5　整除问题
从 1 到 100 中随机取一个整数，求它能被 2、3、5 中至少一个整除的概率。

**解** 记 $A_k$=“能被 $k$ 整除”。$P(A_2)=\frac{50}{100}$，$P(A_3)=\frac{33}{100}$，$P(A_5)=\frac{20}{100}$；$A_2A_3=A_6$，$P(A_6)=\frac{16}{100}$；$P(A_{10})=\frac{10}{100}$；$P(A_{15})=\frac{6}{100}$；$P(A_{30})=\frac{3}{100}$。由容斥原理
$$P=\frac{50+33+20-16-10-6+3}{100}=0.74.$$
:::

::: quiz 0.3
设 $P(A)=0.4$，$P(B)=0.3$，$P(A\cup B)=0.6$，求 $P(A\bar B)$。
> $P(AB)=0.4+0.3-0.6=0.1$，$P(A\bar B)=P(A)-P(AB)=0.3$。
:::

:::: l2 进阶：概率的连续性
若 $A_1\subset A_2\subset\cdots$ 是单调增的事件序列，则
$$P\Big(\bigcup_{n=1}^\infty A_n\Big)=\lim_{n\to\infty}P(A_n);$$
若 $A_1\supset A_2\supset\cdots$ 单调减，则 $P\big(\bigcap_nA_n\big)=\lim_nP(A_n)$。

证明的关键是把单调增的并写成互不相容的“增量” $A_1,\ A_2-A_1,\ A_3-A_2,\dots$ 的并，再用可列可加性。连续性是可列可加性的等价形式，它保证了极限运算可以和概率交换次序，是后面讨论分布函数右连续性、大数定律的基础。
::::

## 本章小结

- **样本空间与事件**：事件是样本空间的子集；事件的关系与运算就是集合的关系与运算，维恩图把逻辑变成了图形。
- **公理化定义**：非负性、正则性、可列可加性。概率就像“面积”。
- **确定概率的方法**：频率方法、古典方法（计数）、几何方法（度量之比）、主观方法。
- **性质**：对立事件、减法公式、加法公式、容斥原理；“至少一个”先想对立事件。

| 公式 | 表达式 |
| --- | --- |
| 德摩根律 | $\overline{A\cup B}=\bar A\bar B$，$\overline{AB}=\bar A\cup\bar B$ |
| 古典概型 | $P(A)=k/n$ |
| 几何概型 | $P(A)=A\ \text{的度量}/\Omega\ \text{的度量}$ |
| 对立事件 | $P(\bar A)=1-P(A)$ |
| 加法公式 | $P(A\cup B)=P(A)+P(B)-P(AB)$ |
| 容斥原理（三个事件） | $\sum P(A)-\sum P(AB)+P(ABC)$ |

## 分层练习

### 基础

**1.** 用 $A,B,C$ 的运算表示下列事件：(1) 只有 $A$ 发生；(2) 至少一个发生；(3) 都不发生；(4) 不多于一个发生。

::: details 解答
(1) $A\bar B\bar C$；(2) $A\cup B\cup C$；(3) $\bar A\bar B\bar C$；(4) $\bar A\bar B\bar C\cup A\bar B\bar C\cup\bar AB\bar C\cup\bar A\bar BC$，也可以写成 $\overline{AB\cup BC\cup AC}$。
:::

**2.** 掷两颗均匀的骰子，求点数之和为 7 的概率与点数之和为 8 的概率。

::: details 解答
样本空间有 36 个等可能的样本点。和为 7 的有 $(1,6),(2,5),\dots,(6,1)$ 共 6 个，概率 $1/6$；和为 8 的有 $(2,6),(3,5),(4,4),(5,3),(6,2)$ 共 5 个，概率 $5/36$。
:::

**3.** 10 件产品中有 3 件次品，从中任取 3 件，求至少有 1 件次品的概率。

::: details 解答
对立事件是“3 件都是正品”，概率 $\binom73/\binom{10}3=35/120$。所以所求概率为 $1-35/120=17/24\approx0.708$。
:::

**4.** 证明：$P(A\cup B)\le P(A)+P(B)$，并说明等号何时成立。

::: details 解答
由加法公式 $P(A\cup B)=P(A)+P(B)-P(AB)\le P(A)+P(B)$，等号成立当且仅当 $P(AB)=0$，例如 $A,B$ 互不相容时。推广到 $n$ 个事件就是 **布尔不等式** $P(\bigcup A_i)\le\sum P(A_i)$，后面做多重比较时会用到。
:::

### 提高

**5.** 会面问题中，若先到者只等 15 分钟，会面的概率是多少？要使会面的概率至少为 0.75，先到者至少要等多久？

::: details 解答
等 15 分钟时 $P=1-(45/60)^2=7/16\approx0.4375$。一般地，等 $t$ 分钟时 $P=1-\big(\frac{60-t}{60}\big)^2$。令它 $\ge0.75$，得 $(60-t)/60\le0.5$，即 $t\ge30$ 分钟。
:::

**6.** 证明 **邦费罗尼不等式**：$P(AB)\ge P(A)+P(B)-1$。若 $P(A)=0.9$，$P(B)=0.8$，$P(AB)$ 至少是多少？

::: details 解答
由 $P(A\cup B)\le1$ 和加法公式，$P(AB)=P(A)+P(B)-P(A\cup B)\ge P(A)+P(B)-1$。代入得 $P(AB)\ge0.7$。

这个不等式的意义是：即使对事件之间的关系一无所知，也能给出“同时发生”的下界。
:::

**7.** 从 1 到 1000 中随机取一个整数，求它既不能被 6 整除、也不能被 8 整除的概率。

::: details 解答
能被 6 整除的有 166 个，能被 8 整除的有 125 个，同时被 6 和 8 整除即被 24 整除的有 41 个。能被 6 或 8 整除的有 $166+125-41=250$ 个，所以所求概率为 $1-250/1000=0.75$。注意同时被 6 和 8 整除等价于被它们的 **最小公倍数** 24 整除，而不是被 48 整除。
:::

### 挑战

**8.**（配对问题）$n$ 封写好的信随机装进 $n$ 个写好地址的信封，求至少有一封信装对的概率 $p_n$，并求 $n\to\infty$ 时的极限。

::: details 解答
记 $A_i$=“第 $i$ 封信装对”。$P(A_i)=\frac1n$，$P(A_iA_j)=\frac{1}{n(n-1)}$，一般地，指定的 $k$ 封都装对的概率为 $\frac{(n-k)!}{n!}$，这样的组合有 $\binom nk$ 种，所以容斥原理的第 $k$ 项为 $\binom nk\frac{(n-k)!}{n!}=\frac1{k!}$。于是
$$p_n=1-\frac1{2!}+\frac1{3!}-\cdots+(-1)^{n-1}\frac1{n!}\ \longrightarrow\ 1-e^{-1}\approx0.632.$$
有趣的是，极限与 $n$ 无关：无论 10 封信还是 10000 封信，至少装对一封的概率都约为 63.2%。
:::

**9.**（贝特朗悖论）就正文中的三种取弦方式，分别计算弦长超过 $\sqrt3$ 的概率。

::: details 解答
弦长超过 $\sqrt3$，等价于弦到圆心的距离小于 $1/2$。

- **随机端点**：固定一个端点，另一个端点在圆周上均匀分布。弦长超过 $\sqrt3$ 当且仅当另一端点落在与第一点相对的 $120°$ 弧上，概率为 $1/3$。
- **随机半径上的点**：弦的中点到圆心的距离在 $[0,1]$ 上均匀分布，小于 $1/2$ 的概率为 $1/2$。
- **随机中点**：中点在单位圆内均匀分布，落在半径为 $1/2$ 的同心圆内的概率为面积之比 $1/4$。

三个答案的差别，来自三种不同的“均匀”。
:::

## 代码实现（Python）

::: details 展开代码：生日问题、蒲丰投针、配对问题的模拟
```python
import numpy as np
from math import comb, factorial, e

rng = np.random.default_rng(1)

# 1. 生日问题：精确值与模拟
n = 23
exact = 1 - np.prod([(365 - i) / 365 for i in range(n)])
days = np.sort(rng.integers(0, 365, size=(100_000, n)), axis=1)
sim = np.mean((np.diff(days, axis=1) == 0).any(axis=1))
print(f"生日问题 n = {n}：精确值 {exact:.4f}，模拟 {sim:.4f}")

# 2. 蒲丰投针：l = 0.8，d = 1
l, d, m = 0.8, 1.0, 1_000_000
x = rng.uniform(0, d / 2, m)          # 针的中点到最近直线的距离
theta = rng.uniform(0, np.pi, m)      # 针与直线的夹角
k = np.sum(x <= l / 2 * np.sin(theta))
print(f"蒲丰投针：相交频率 {k / m:.4f}，理论 {2 * l / (np.pi * d):.4f}，pi 的估计 {2 * l * m / (d * k):.4f}")

# 3. 配对问题：n 封信随机装进 n 个信封，至少一封装对
n = 10
exact = sum((-1) ** (j + 1) / factorial(j) for j in range(1, n + 1))
perms = np.argsort(rng.random((200_000, n)), axis=1)
sim = np.mean((perms == np.arange(n)).any(axis=1))
print(f"配对问题：精确值 {exact:.4f}，模拟 {sim:.4f}，极限 1 - 1/e = {1 - 1 / e:.4f}")

# 4. 例 1：100 件产品中 5 件次品，不放回抽 10 件，恰有 1 件次品
print(f"超几何概率 {comb(5, 1) * comb(95, 9) / comb(100, 10):.4f}")
```

::: info 史话：从赌桌到公理
概率论的起点常被追溯到 1654 年帕斯卡与费马关于“赌金分配问题”的通信。此后两百多年，概率论在惠更斯、伯努利、棣莫弗、拉普拉斯等人手中迅速发展，却一直缺少严格的基础——“等可能”“随机取一点”这些说法时常引出贝特朗悖论那样的矛盾。1900 年，希尔伯特在著名的 23 个问题中，把概率论的公理化列入第六问题。1933 年，苏联数学家柯尔莫哥洛夫出版《概率论基础》，用测度论建立了今天通用的公理体系，概率论从此成为严格的数学分支。
:::
