# 常用分布

世界上的随机现象千差万别，但描述它们的分布却出奇地少：十来个常用分布就覆盖了绝大多数应用。每个分布背后都有一个 **故事**——它从什么样的随机机制中产生。记住故事，比记住公式更重要：看到“稀有事件的次数”想到泊松，看到“等待时间”想到指数，看到“大量微小因素的叠加”想到正态。

这一章先逐个介绍常用的离散分布和连续分布，最后用一张 **分布图谱** 把它们串起来。

## 二项分布 {.core}

::: core 定义（二项分布）
在 $n$ 重伯努利试验中，每次成功的概率为 $p$，成功的次数 $X$ 服从 **二项分布**，记作 $X\sim b(n,p)$：
$$P(X=k)=\binom nkp^k(1-p)^{n-k},\qquad k=0,1,\dots,n.$$
$$E(X)=np,\qquad \operatorname{Var}(X)=np(1-p).$$
$n=1$ 时称为 **两点分布**（0-1 分布）$b(1,p)$。
:::

::: insight 二项分布 = n 个两点分布之和
记 $X_i$ 为第 $i$ 次试验成功的次数（0 或 1），则 $X=X_1+\cdots+X_n$，各 $X_i$ 独立同分布于 $b(1,p)$。每个 $X_i$ 的期望是 $p$、方差是 $p(1-p)$，相加就得到 $np$ 与 $np(1-p)$（独立随机变量的方差可加，见“[协方差、相关与条件期望](/probability/dependence)”一章）。“化整为零”是求期望和方差最有力的技巧之一。
:::

二项分布的概率在 $k$ 增大时先升后降，最可能出现的次数是 $\lfloor(n+1)p\rfloor$。$p=0.5$ 时分布对称，$p$ 偏离 0.5 时分布偏斜，但 $n$ 很大时又趋于对称的钟形——这是中心极限定理的第一个例子（棣莫弗–拉普拉斯定理），首页的高尔顿钉板演示的正是它。

## 泊松分布 {.core}

::: core 定义（泊松分布）
若
$$P(X=k)=\frac{\lambda^k}{k!}e^{-\lambda},\qquad k=0,1,2,\dots,$$
则称 $X$ 服从参数为 $\lambda>0$ 的 **泊松分布**，记作 $X\sim P(\lambda)$。$E(X)=\operatorname{Var}(X)=\lambda$。
:::

泊松分布描述 **单位时间（或单位面积、单位体积）内稀有事件发生的次数**：一分钟内到达的电话呼叫、一页书上的印刷错误、一平方米布匹上的疵点、一年内某路口的交通事故。它的来历是下面这条定理。

::: core 泊松定理
在 $n$ 重伯努利试验中，记成功的概率为 $p_n$。若 $n\to\infty$ 时 $np_n\to\lambda>0$，则对任意固定的 $k$，
$$\binom nkp_n^k(1-p_n)^{n-k}\ \longrightarrow\ \frac{\lambda^k}{k!}e^{-\lambda}.$$
实用上：$n$ 很大、$p$ 很小时，$b(n,p)\approx P(np)$。
:::

::: example 例 1　次品数的泊松近似
某厂产品的次品率为 1%，任取 100 件，求次品不超过 1 件的概率。

**解** 精确地，$X\sim b(100,0.01)$，$P(X\le1)=0.99^{100}+100\times0.01\times0.99^{99}\approx0.7358$。用泊松近似，$\lambda=np=1$，$P(X\le1)\approx e^{-1}(1+1)=0.7358$。两者在小数点后四位一致。
:::

::: insight 稀有事件的规律
历史上最著名的泊松数据来自鲍特基维茨（1898）：普鲁士军队 10 个军团、20 年间（共 200 个“军团·年”）被马踢死的士兵人数。死亡 0、1、2、3、4 人的“军团·年”分别有 109、65、22、3、1 个，样本均值 $\lambda=0.61$；按 $P(0.61)$ 计算的理论频数为 108.7、66.3、20.2、4.1、0.6，与观测惊人地吻合。每个士兵被马踢死的概率极小，但士兵很多，总次数就服从泊松分布——这被称为 **小数定律**。
:::

> $P(X=0)=e^{-2}\approx0.1353$。

## 超几何分布 {.key}

::: core 定义（超几何分布）
$N$ 件产品中有 $M$ 件次品，**不放回** 地抽取 $n$ 件，其中的次品数 $X$ 服从 **超几何分布** $h(n,N,M)$：
$$P(X=k)=\frac{\binom Mk\binom{N-M}{n-k}}{\binom Nn}.$$
$$E(X)=n\frac MN,\qquad \operatorname{Var}(X)=n\frac MN\Big(1-\frac MN\Big)\frac{N-n}{N-1}.$$
:::

与有放回抽样的二项分布 $b(n,M/N)$ 相比，期望相同，方差多了一个因子 $\frac{N-n}{N-1}$——这正是“[区间估计](/inference/interval)”一章中 **不重复抽样的修正系数**。$N$ 远大于 $n$ 时，这个因子接近 1，超几何分布可以用二项分布近似。

## 几何分布与负二项分布 {.key}

::: core 定义（几何分布、负二项分布）
独立重复试验，每次成功的概率为 $p$。

- **首次** 成功所需的试验次数 $X$ 服从 **几何分布** $Ge(p)$：$P(X=k)=(1-p)^{k-1}p$，$k=1,2,\dots$；$E(X)=\frac1p$，$\operatorname{Var}(X)=\frac{1-p}{p^2}$。
- **第 $r$ 次** 成功所需的试验次数 $X$ 服从 **负二项分布** $Nb(r,p)$：$P(X=k)=\binom{k-1}{r-1}p^r(1-p)^{k-r}$，$k=r,r+1,\dots$；$E(X)=\frac rp$，$\operatorname{Var}(X)=\frac{r(1-p)}{p^2}$。

负二项分布是 $r$ 个独立的几何分布之和。
:::

::: core 几何分布的无记忆性
对任意正整数 $m,n$，
$$P(X>m+n\mid X>m)=P(X>n).$$
已经失败了 $m$ 次，再等下去所需的次数，和从头开始一样。几何分布是 **唯一** 具有这一性质的离散分布。
:::

::: pitfall 赌徒谬误
轮盘赌连续出了 10 次红色，下一次出黑色的概率会不会更大？不会。各次结果独立，“等待黑色”的次数服从几何分布，而几何分布没有记忆——过去的 10 次红色对未来没有任何影响。“该轮到黑色了”的想法，叫 **赌徒谬误**。
:::

## 正态分布 {.core}

::: core 定义（正态分布）
若 $X$ 的密度为
$$p(x)=\frac{1}{\sqrt{2\pi}\,\sigma}\exp\Big\{-\frac{(x-\mu)^2}{2\sigma^2}\Big\},\qquad -\infty<x<\infty,$$
则称 $X$ 服从 **正态分布** $N(\mu,\sigma^2)$，$E(X)=\mu$，$\operatorname{Var}(X)=\sigma^2$。$\mu=0$、$\sigma=1$ 时称为 **标准正态分布**，其分布函数记作 $\Phi(x)$，有 $\Phi(-x)=1-\Phi(x)$。
:::

::: geo 几何直观：一条曲线的平移与伸缩
所有正态分布都是同一条钟形曲线的 **平移和伸缩**：$\mu$ 决定钟的位置，$\sigma$ 决定钟的宽窄；由于面积必须保持为 1，钟变宽时也变矮。拐点恰好在 $\mu\pm\sigma$ 处。

正因为如此，任何正态分布的概率都可以通过 **标准化** 化成标准正态分布来计算：
$$X\sim N(\mu,\sigma^2)\ \Longrightarrow\ \frac{X-\mu}{\sigma}\sim N(0,1),\qquad P(a<X\le b)=\Phi\Big(\frac{b-\mu}\sigma\Big)-\Phi\Big(\frac{a-\mu}\sigma\Big).$$
标准化就是把坐标原点移到 $\mu$、把长度单位换成 $\sigma$。
:::

::: key 3σ 原则
$$P(|X-\mu|<\sigma)\approx0.6827,\qquad P(|X-\mu|<2\sigma)\approx0.9545,\qquad P(|X-\mu|<3\sigma)\approx0.9973.$$
正态变量几乎（99.73%）总在 $\mu\pm3\sigma$ 之内。质量控制中的“3σ 控制限”、“六西格玛”管理，都来源于此。对比切比雪夫不等式给出的“至少 $1-1/9\approx88.9\%$”，正态分布的尾部要轻得多。
:::

::: example 例 2　考试成绩
某次考试成绩 $X\sim N(70,10^2)$。求 (1) 90 分以上的比例；(2) 成绩排在前 10% 的分数线。

**解** (1) $P(X\ge90)=1-\Phi\big(\frac{90-70}{10}\big)=1-\Phi(2)\approx0.0228$，约 2.3% 的考生在 90 分以上。

(2) 设分数线为 $c$，要求 $P(X>c)=0.1$，即 $\Phi\big(\frac{c-70}{10}\big)=0.9$。查表得 $u_{0.9}\approx1.2816$，所以 $c=70+1.2816\times10\approx82.8$ 分。
:::

::: quiz
设 $X\sim N(3,4)$，则 $P(1<X\le5)$ 约为
- [ ] 0.3413
- [x] 0.6827
- [ ] 0.9545
- [ ] 0.8413

> $\sigma=2$，$P(1<X\le5)=\Phi(1)-\Phi(-1)\approx0.6827$。注意 $N(3,4)$ 的第二个参数是 **方差**，标准差是 2。
:::

为什么正态分布无处不在？粗略的回答是：一个量如果由 **大量微小、独立的因素叠加** 而成，它就近似服从正态分布。这就是中心极限定理，见“[大数定律与中心极限定理](/probability/limit-theorems)”一章。

## 均匀分布与指数分布 {.key}

::: core 定义（均匀分布、指数分布）
- **均匀分布** $U(a,b)$：密度 $p(x)=\frac1{b-a}$（$a<x<b$）。$E(X)=\frac{a+b}2$，$\operatorname{Var}(X)=\frac{(b-a)^2}{12}$。
- **指数分布** $\mathrm{Exp}(\lambda)$：密度 $p(x)=\lambda e^{-\lambda x}$（$x\ge0$），分布函数 $F(x)=1-e^{-\lambda x}$。$E(X)=\frac1\lambda$，$\operatorname{Var}(X)=\frac1{\lambda^2}$。
:::

### 指数分布的无记忆性 {.hard}

::: core 无记忆性
对任意 $s,t>0$，
$$P(X>s+t\mid X>s)=P(X>t).$$
**证明**：$P(X>s+t\mid X>s)=\dfrac{e^{-\lambda(s+t)}}{e^{-\lambda s}}=e^{-\lambda t}=P(X>t)$。指数分布是 **唯一** 具有无记忆性的连续分布。
:::

::: geo 几何直观：尾巴和整体长得一样
把指数密度在 $x=s$ 处截断，只看右边的尾巴，再把它放大到总面积为 1：得到的曲线与原来的密度 **一模一样**，只是平移了 $s$。指数曲线 $e^{-\lambda x}$ 的这种“自相似”，正是无记忆性的图形含义。
:::

::: example 例 3　元件寿命
某电子元件的寿命（小时）服从均值为 1000 的指数分布。求 (1) 寿命超过 1500 小时的概率；(2) 已经正常工作了 500 小时，还能再工作 1000 小时以上的概率。

**解** $\lambda=0.001$。(1) $P(X>1500)=e^{-1.5}\approx0.223$。(2) 由无记忆性，$P(X>1500\mid X>500)=P(X>1000)=e^{-1}\approx0.368$，与一个全新元件能工作 1000 小时以上的概率相同。
:::

::: insight 什么时候寿命“无记忆”
无记忆意味着“旧的和新的一样好”。这适合由 **偶然的外部冲击** 导致的失效（如电路被雷击），不适合因 **磨损老化** 导致的失效（如轮胎、轴承），后者越用越容易坏。可靠性理论用 **失效率** $\lambda(t)=\dfrac{p(t)}{1-F(t)}$ 刻画这一点：指数分布的失效率是常数 $\lambda$；韦布尔分布的失效率可以随时间增大或减小，因而更适合描述老化或“早期故障”。
:::

## 伽马分布与贝塔分布 {.l2}

:::: l2 进阶：伽马分布、贝塔分布、对数正态分布
**伽马分布** $\mathrm{Ga}(\alpha,\lambda)$ 的密度为
$$p(x)=\frac{\lambda^\alpha}{\Gamma(\alpha)}x^{\alpha-1}e^{-\lambda x}\quad(x>0),\qquad E(X)=\frac\alpha\lambda,\quad\operatorname{Var}(X)=\frac{\alpha}{\lambda^2}.$$
$\alpha=1$ 时就是指数分布。$\alpha=n$ 为整数时，$\mathrm{Ga}(n,\lambda)$ 是 $n$ 个独立 $\mathrm{Exp}(\lambda)$ 之和，即泊松过程中第 $n$ 次事件发生的时刻。$\mathrm{Ga}(n/2,1/2)$ 就是自由度为 $n$ 的 **卡方分布** $\chi^2(n)$。

**贝塔分布** $\mathrm{Be}(a,b)$ 的密度为
$$p(x)=\frac{\Gamma(a+b)}{\Gamma(a)\Gamma(b)}x^{a-1}(1-x)^{b-1}\quad(0<x<1),\qquad E(X)=\frac a{a+b}.$$
它取值于 $(0,1)$，形状极其灵活，适合描述比例；$\mathrm{Be}(1,1)=U(0,1)$。在贝叶斯统计中，它是二项分布参数 $p$ 最常用的先验分布。

**对数正态分布**：若 $\ln X\sim N(\mu,\sigma^2)$，称 $X$ 服从对数正态分布 $LN(\mu,\sigma^2)$。正态分布来自大量因素的 **相加**，对数正态分布来自大量因素的 **相乘**：收入、股价、城市人口都呈现右偏的对数正态形状。
::::

::: insight 记住关系，而不是公式
- **相加**：$b(1,p)\xrightarrow{n\text{ 个}}b(n,p)$；$Ge(p)\xrightarrow{r\text{ 个}}Nb(r,p)$；$\mathrm{Exp}(\lambda)\xrightarrow{\alpha\text{ 个}}\mathrm{Ga}(\alpha,\lambda)$；
- **取极限**：$b(n,p)\to P(\lambda)$（$np=\lambda$）；$h(n,N,M)\to b(n,M/N)$；很多分布在参数变大时 $\to$ 正态；
- **离散与连续的对应**：几何分布 ↔ 指数分布（都无记忆），负二项分布 ↔ 伽马分布（第 $r$ 次成功 ↔ 第 $\alpha$ 次事件）；
- **由正态派生**：平方和得 $\chi^2$，$Z/\sqrt{\chi^2/n}$ 得 $t$，两个 $\chi^2$ 之比得 $F$——这三个“抽样分布”是数理统计的主角，在“[统计量与抽样分布](/inference/sampling)”一章详细讨论。
:::

## 分层练习

### 基础

**1.** 某射手每次命中的概率为 0.7，独立射击 5 次。求恰好命中 3 次的概率和至少命中 1 次的概率。

::: details 解答
$X\sim b(5,0.7)$。$P(X=3)=\binom53\times0.7^3\times0.3^2=0.3087$；$P(X\ge1)=1-0.3^5\approx0.9976$。
:::

**2.** 某交换台每分钟的呼叫次数服从 $P(4)$。求一分钟内恰有 2 次呼叫的概率和至多 1 次呼叫的概率。

::: details 解答
$P(X=2)=\frac{4^2}{2!}e^{-4}\approx0.1465$；$P(X\le1)=e^{-4}(1+4)\approx0.0916$。
:::

**3.** 设 $X\sim N(10,2^2)$，求 $P(8<X\le13)$。

::: details 解答
$P(8<X\le13)=\Phi(1.5)-\Phi(-1)=0.9332-0.1587=0.7745$。
:::

**4.** 某品牌电器的寿命（年）服从均值为 2 的指数分布，厂家承诺一年内损坏可以免费更换。求一台电器被免费更换的概率。

::: details 解答
$\lambda=1/2$，$P(X\le1)=1-e^{-0.5}\approx0.393$。将近四成的电器要免费更换——厂家要么提高质量，要么缩短保修期。
:::

### 提高

**5.** 利用“二项分布是 $n$ 个两点分布之和”，推导二项分布的期望与方差。

::: details 解答
$X=X_1+\cdots+X_n$，$X_i\sim b(1,p)$ 相互独立。$E(X_i)=p$，$E(X_i^2)=p$，$\operatorname{Var}(X_i)=p-p^2=p(1-p)$。由期望的线性性 $E(X)=np$；由独立随机变量方差的可加性 $\operatorname{Var}(X)=np(1-p)$。
:::

**6.** 证明几何分布具有无记忆性。

::: details 解答
$P(X>n)=\sum_{k>n}(1-p)^{k-1}p=(1-p)^n$（前 $n$ 次都失败）。于是
$$P(X>m+n\mid X>m)=\frac{P(X>m+n)}{P(X>m)}=\frac{(1-p)^{m+n}}{(1-p)^m}=(1-p)^n=P(X>n).$$
:::

**7.** 某指标 $X\sim N(100,15^2)$。求常数 $c$，使 $P(X>c)=0.05$。

::: details 解答
$\Phi\big(\frac{c-100}{15}\big)=0.95$，$u_{0.95}\approx1.645$，所以 $c\approx100+1.645\times15\approx124.7$。
:::

### 挑战

**8.** 证明泊松定理。

::: details 解答
记 $\lambda_n=np_n\to\lambda$。对固定的 $k$，
$$\binom nkp_n^k(1-p_n)^{n-k}=\frac{\lambda_n^k}{k!}\cdot\frac{n(n-1)\cdots(n-k+1)}{n^k}\cdot\Big(1-\frac{\lambda_n}n\Big)^{n}\cdot\Big(1-\frac{\lambda_n}n\Big)^{-k}.$$
$n\to\infty$ 时，第二个因子 $\to1$，第三个因子 $\to e^{-\lambda}$，第四个因子 $\to1$，所以整体 $\to\frac{\lambda^k}{k!}e^{-\lambda}$。
:::

**9.** 设 $X\sim\mathrm{Exp}(\lambda)$，$Y=\lceil X\rceil$（向上取整）。证明 $Y$ 服从几何分布，并求它的参数。这说明了指数分布与几何分布之间的什么关系？

::: details 解答
对正整数 $k$，$P(Y=k)=P(k-1<X\le k)=e^{-\lambda(k-1)}-e^{-\lambda k}=(e^{-\lambda})^{k-1}(1-e^{-\lambda})$，所以 $Y\sim Ge(1-e^{-\lambda})$。

指数分布“按整数时间点观察”就得到几何分布：几何分布是指数分布的离散版本，二者共享无记忆性。
:::

## 代码实现（Python）

::: details 展开代码：用 scipy.stats 计算各种分布
```python
import numpy as np
from scipy import stats

# 1. 二项与泊松：例 1
print("二项精确：", stats.binom(100, 0.01).cdf(1))
print("泊松近似：", stats.poisson(1).cdf(1))

# 2. 正态：例 2
X = stats.norm(loc=70, scale=10)          # 注意 scale 是标准差
print("90 分以上的比例：", X.sf(90))       # sf = 1 - cdf
print("前 10% 的分数线：", X.ppf(0.9))     # ppf 是分位数函数

# 3. 指数：scipy 用 scale = 1/λ 参数化
L = stats.expon(scale=1000)
print("P(X > 1500) =", L.sf(1500), " P(X > 1500 | X > 500) =", L.sf(1500) / L.sf(500))

# 4. 鲍特基维茨的马踢数据：观测频数与泊松理论频数
obs = np.array([109, 65, 22, 3, 1])
lam = (obs * np.arange(5)).sum() / obs.sum()
expected = 200 * stats.poisson(lam).pmf(np.arange(5))
print("lambda =", lam, " 理论频数：", expected.round(1))

# 5. 软件的参数化各不相同，用前先核对期望
print(stats.gamma(a=3, scale=1 / 2).mean())         # Ga(3, 2) 的期望 3/2
print(stats.nbinom(3, 0.4).mean())                  # scipy 的负二项数的是“失败次数”：3*0.6/0.4 = 4.5
print(stats.hypergeom(M=60, n=15, N=12).mean())    # scipy：M 总数，n 次品数，N 抽取数 → 12*15/60 = 3
```
:::

::: pitfall 软件中的参数化
同一个分布，不同教材和软件的参数化可能不同：scipy 的指数分布与伽马分布用 **尺度参数** $1/\lambda$（`scale`）；scipy 的负二项分布数的是成功 $r$ 次之前的 **失败次数**，比本书的“试验次数”少 $r$；scipy 超几何分布的参数名 `M, n, N` 分别表示总数、次品数、抽取数，与本书的 $N,M,n$ 恰好错开。用软件前，先算一下期望核对参数。
:::

::: info 史话：泊松与马踢
泊松在 1837 年研究法庭判决的概率时得到了这个分布，但它当时并未引起重视。直到 1898 年，鲍特基维茨用普鲁士军队被马踢死的数据说明，许多稀有事件都服从泊松分布，并称之为“小数定律”，它才名声大振。正态分布的历史更早：1733 年棣莫弗把它作为二项分布的近似提出；1809 年高斯在研究天文观测误差时把它作为误差的分布，所以正态分布也叫 **高斯分布**。
:::
