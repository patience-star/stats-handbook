# 大数定律与中心极限定理

抛一枚硬币，单次的结果完全无法预测；抛一万次，正面的比例却几乎一定在 0.49 到 0.51 之间。测量一个零件，单次的误差可大可小；把许多次测量平均起来，误差的分布却总是钟形的。

**大量随机性叠加之后，会出现稳定的规律**——这是概率论最深刻的结论。它有两层含义：平均值会稳定在期望附近（**大数定律**），而平均值在期望附近的波动服从正态分布（**中心极限定理**）。统计学之所以能用样本推断总体，靠的正是这两条定理。

## 两种收敛 {.key}

随机变量序列的“收敛”不能照搬数列的收敛：抛硬币一万次，全部正面的可能性虽然微乎其微，但并非为零。所以要用概率来定义收敛。

::: core 定义（依概率收敛与依分布收敛）
- 若对任意 $\varepsilon>0$，$\lim\limits_{n\to\infty}P(|X_n-X|\ge\varepsilon)=0$，称 $X_n$ **依概率收敛** 于 $X$，记作 $X_n\xrightarrow{P}X$。
- 若在 $F(x)$ 的每个连续点 $x$ 上 $\lim\limits_{n\to\infty}F_n(x)=F(x)$，称 $X_n$ **依分布收敛** 于 $X$，记作 $X_n\xrightarrow{L}X$。
:::

依概率收敛说的是：$n$ 很大时，$X_n$ 与 $X$ 相差较大的 **可能性** 很小，但不排除个别时候相差很大。依分布收敛更弱，只要求分布函数越来越像，$X_n$ 与 $X$ 本身甚至可以毫无关系。

:::: l2 进阶：两种收敛的关系
依概率收敛蕴含依分布收敛；反过来一般不成立。但若极限是 **常数** $c$，则二者等价：$X_n\xrightarrow{L}c\iff X_n\xrightarrow{P}c$。此外还有更强的 **几乎处处收敛**（$P(\lim X_n=X)=1$），对应 **强大数定律**：样本均值以概率 1 收敛于期望。本章只讨论弱的形式。
::::

## 大数定律 {.core}

::: core 伯努利大数定律
设 $n_A$ 是 $n$ 重伯努利试验中事件 $A$ 发生的次数，每次试验中 $P(A)=p$，则
$$\frac{n_A}n\ \xrightarrow{P}\ p.$$
:::

这是“频率稳定于概率”的严格表述，也是用频率估计概率的理论依据。

::: core 切比雪夫大数定律与辛钦大数定律
- **切比雪夫大数定律**：若 $X_1,X_2,\dots$ 两两不相关，方差有共同的上界 $c$，则
$$\frac1n\sum_{i=1}^nX_i-\frac1n\sum_{i=1}^nE(X_i)\ \xrightarrow{P}\ 0.$$
- **辛钦大数定律**：若 $X_1,X_2,\dots$ 独立同分布，期望 $\mu$ 存在，则 $\bar X_n=\dfrac1n\sum_{i=1}^nX_i\xrightarrow{P}\mu$。它 **不要求方差存在**。
:::

::: proof 证明（独立同分布、方差 $\sigma^2$ 存在的情形）
$E(\bar X_n)=\mu$，$\operatorname{Var}(\bar X_n)=\sigma^2/n$。由切比雪夫不等式，
$$P(|\bar X_n-\mu|\ge\varepsilon)\le\frac{\sigma^2}{n\varepsilon^2}\ \longrightarrow\ 0.$$
关键在于 **平均之后方差缩小为 $1/n$**：独立的随机误差会互相抵消。
:::

::: geo 几何直观：收拢的漏斗
把前 $n$ 次观测的平均值画成一条随 $n$ 变化的路径。每条路径一开始上下乱跳，渐渐被压进一个越来越窄的 **漏斗**：漏斗的宽度约为 $\pm2\sigma/\sqrt n$。大数定律说漏斗的口会收到任意窄；漏斗宽度按 $1/\sqrt n$ 缩小，则预告了中心极限定理。
:::

::: pitfall 大数定律不是“补偿”
抛了 10 次都是正面，接下来是否更可能出现反面，好让比例“回到”一半？不是。大数定律说的是 **比例** $n_A/n$ 趋于 $p$，而不是 **次数之差** $n_A-np$ 趋于 0。事实上 $n_A-np$ 的典型大小约为 $\sqrt{np(1-p)}$，随 $n$ 增大而 **变大**；比例之所以趋于 $p$，是因为分母 $n$ 增长得更快，把早期的偏差“稀释”掉了，而不是后面的结果去“补偿”前面的结果。
:::

::: example 例 1　蒙特卡洛积分
求 $I=\int_0^1e^{-x^2}\,\mathrm dx$。这个积分没有初等原函数，但若 $U\sim U(0,1)$，则 $E(e^{-U^2})=I$。由辛钦大数定律，产生 $n$ 个均匀随机数 $u_i$，就有
$$\hat I=\frac1n\sum_{i=1}^ne^{-u_i^2}\ \xrightarrow{P}\ I\approx0.7468.$$
$n=10000$ 时，$\hat I$ 的标准差约为 $\sqrt{0.0404/10000}\approx0.002$。蒙特卡洛方法的误差按 $1/\sqrt n$ 减小，与积分的维数无关——这使它成为计算高维积分的主要方法。
:::

## 特征函数 {.l2}

:::: l2 进阶：特征函数——证明极限定理的工具
随机变量 $X$ 的 **特征函数** 定义为
$$\varphi(t)=E\big(e^{itX}\big)=E\cos(tX)+i\,E\sin(tX),\qquad -\infty<t<\infty.$$
因为 $|e^{itX}|=1$，它对 **任何** 分布都存在。常用的例子：$N(\mu,\sigma^2)$ 的特征函数为 $e^{i\mu t-\sigma^2t^2/2}$；$P(\lambda)$ 的为 $e^{\lambda(e^{it}-1)}$；$\mathrm{Exp}(\lambda)$ 的为 $\big(1-\frac{it}\lambda\big)^{-1}$。

它有三条关键性质：
1. **唯一性**：特征函数唯一地确定分布；
2. **独立和变乘积**：$X,Y$ 独立时 $\varphi_{X+Y}(t)=\varphi_X(t)\varphi_Y(t)$——繁琐的卷积变成了简单的乘法；
3. **连续性定理**：$X_n\xrightarrow{L}X$ ⟺ 对每个 $t$，$\varphi_{X_n}(t)\to\varphi_X(t)$。

**几何直观**：对固定的 $t$，$e^{itX}$ 是单位圆上的一个点，它的辐角是 $tX$。随机变量 $X$ 的分布被“缠绕”到了单位圆上，$\varphi(t)$ 就是这些点的 **重心**。$t$ 很小时，各点挤在 1 附近，重心靠近 1；$t$ 增大，各点散开到整个圆周，重心向圆心靠拢，$|\varphi(t)|$ 变小。分布越分散，重心向圆心靠拢得越快——这就是 $N(0,\sigma^2)$ 的特征函数 $e^{-\sigma^2t^2/2}$ 随 $\sigma$ 增大而衰减得更快的原因。
::::

## 中心极限定理 {.core}

大数定律告诉我们 $\bar X_n\to\mu$，但没有说 $\bar X_n$ 在 $\mu$ 附近 **怎样分布**。中心极限定理回答了这个问题，而且答案几乎与总体分布无关。

::: core 林德伯格–莱维中心极限定理
设 $X_1,X_2,\dots$ 独立同分布，$E(X_i)=\mu$，$\operatorname{Var}(X_i)=\sigma^2>0$ 存在，则对任意实数 $x$，
$$\lim_{n\to\infty}P\Big(\frac{\sum_{i=1}^nX_i-n\mu}{\sigma\sqrt n}\le x\Big)=\Phi(x).$$
等价地，$n$ 较大时 $\bar X_n\stackrel{\text{近似}}{\sim}N\big(\mu,\ \sigma^2/n\big)$，$\sum X_i\stackrel{\text{近似}}{\sim}N(n\mu,\ n\sigma^2)$。
:::

::: geo 几何直观：两种“放大倍数”
看 $S_n=\sum X_i$ 的分布，换不同的放大倍数观察：

- **除以 $n$**（看平均值 $\bar X_n$）：分布的宽度 $\sigma/\sqrt n\to0$，缩成一个点 $\mu$——这是大数定律；
- **除以 $\sqrt n$**（看 $(S_n-n\mu)/\sqrt n$）：宽度恒为 $\sigma$，分布不会缩成一点，而它的 **形状** 越来越像正态曲线——这是中心极限定理。

为什么偏偏是正态？“[多维随机变量](/probability/multivariate)”一章的卷积实验给出了几何图像：每加一个独立变量，密度就被卷积“抹平”一次，尖角变圆、偏斜变小。正态分布是这个抹平过程的 **不动点**：独立正态变量之和仍是正态分布，形状不再改变。
:::

::: core 棣莫弗–拉普拉斯中心极限定理
设 $Y_n\sim b(n,p)$，$0<p<1$，则 $n$ 很大时
$$P(a\le Y_n\le b)\approx\Phi\Big(\frac{b+0.5-np}{\sqrt{np(1-p)}}\Big)-\Phi\Big(\frac{a-0.5-np}{\sqrt{np(1-p)}}\Big),$$
其中 $\pm0.5$ 称为 **连续性修正**。上面的高尔顿钉板就是这个定理的物理模型：每个小球的落点是 $n$ 次左右弹跳的结果，服从二项分布。
:::

::: geo 几何直观：连续性修正
二项分布的每个概率 $P(Y=k)$ 可以画成一根宽为 1、以 $k$ 为中心的矩形条，它占据 $[k-0.5,\ k+0.5]$。用正态曲线下的面积去近似这些矩形条的面积时，$P(a\le Y\le b)$ 对应的区间应是 $[a-0.5,\ b+0.5]$ 而不是 $[a,b]$。$n$ 不太大时，这半个单位的修正能明显提高精度。
:::

::: example 例 2　航班超售
某航班有 200 个座位。根据经验，订票的乘客中有 90% 会按时登机，各乘客是否登机相互独立。航空公司最多接受多少张订票，才能使“到场人数超过 200”的概率不超过 5%？

**解** 设接受 $n$ 张订票，到场人数 $Y\sim b(n,0.9)$，$E(Y)=0.9n$，$\operatorname{Var}(Y)=0.09n$。要求
$$P(Y\ge201)\approx1-\Phi\Big(\frac{200.5-0.9n}{0.3\sqrt n}\Big)\le0.05,\qquad\text{即}\quad\frac{200.5-0.9n}{0.3\sqrt n}\ge1.645.$$
$n=214$ 时左边约为 1.80，满足；$n=215$ 时约为 1.59，不满足。所以正态近似给出最多接受 214 张订票，超售概率约 3.6%。

用软件精确计算二项分布：$n=214$ 时超售概率为 0.0297，$n=215$ 时为 0.0496，其实还可以多卖一张。差别来自二项分布的偏斜：$p=0.9$ 时分布的右尾比正态曲线更轻，正态近似在这里稍嫌保守。
:::

::: pitfall 正态近似什么时候不可靠
经验法则是 $np\ge5$ 且 $n(1-p)\ge5$（更稳妥地要求都 $\ge10$）。$p$ 很小时二项分布严重右偏，应当用泊松近似；$p$ 接近 1 时同理处理“失败次数”。总之，中心极限定理是一个 **极限** 结论，$n$ 要多大才“够大”，取决于总体分布有多偏、尾部有多厚。
:::

::: quiz 0.0416 0.002
100 个独立的 $U(0,1)$ 随机变量之和超过 55 的概率约是多少？（用中心极限定理，保留四位小数）
> 和的期望为 50，方差为 $100/12\approx8.33$，标准差约 2.887。$P(S>55)\approx1-\Phi(5/2.887)=1-\Phi(1.732)\approx0.0416$。
:::

:::: l3 深入：独立不同分布、收敛速度
**林德伯格–费勒定理** 把中心极限定理推广到独立但不同分布的情形：只要满足 **林德伯格条件**——大意是“没有任何一个 $X_i$ 的方差在总和中占主导地位”——标准化的和仍趋于标准正态。这解释了为什么由许多 **大小相近** 的独立因素叠加而成的量（测量误差、身高）近似正态；如果某一个因素起主导作用，结果就会保留它的分布特征。

**贝里–埃森定理** 给出收敛的速度：若 $E|X_i-\mu|^3=\rho<\infty$，则
$$\sup_x\Big|P\Big(\frac{S_n-n\mu}{\sigma\sqrt n}\le x\Big)-\Phi(x)\Big|\le\frac{C\rho}{\sigma^3\sqrt n},$$
其中 $C$ 是一个小于 0.5 的常数。误差按 $1/\sqrt n$ 减小，比值 $\rho/\sigma^3$ 越大（总体越偏、尾越厚）收敛越慢——上面实验中两点分布 $b(1,0.1)$ 比均匀分布收敛慢得多，正是这个原因。
::::

## 本章小结

- **两种收敛**：依概率收敛（偏差大的可能性趋于 0）、依分布收敛（分布函数趋于极限）。
- **大数定律**：平均值依概率收敛于期望；方差按 $1/n$ 缩小是关键；柯西分布没有期望，大数定律失效；大数定律不是“补偿”。
- **中心极限定理**：标准化的和依分布收敛于 $N(0,1)$；除以 $n$ 看到一个点，除以 $\sqrt n$ 看到正态曲线。
- **棣莫弗–拉普拉斯**：二项分布的正态近似，配合连续性修正。

| 定理 | 条件 | 结论 |
| --- | --- | --- |
| 伯努利大数定律 | $n$ 重伯努利试验 | $n_A/n\xrightarrow{P}p$ |
| 切比雪夫大数定律 | 两两不相关，方差一致有界 | $\bar X_n-\overline{E X}\xrightarrow{P}0$ |
| 辛钦大数定律 | 独立同分布，期望存在 | $\bar X_n\xrightarrow{P}\mu$ |
| 林德伯格–莱维定理 | 独立同分布，方差存在 | $\dfrac{S_n-n\mu}{\sigma\sqrt n}\xrightarrow{L}N(0,1)$ |
| 棣莫弗–拉普拉斯定理 | $Y_n\sim b(n,p)$ | $\dfrac{Y_n-np}{\sqrt{np(1-p)}}\xrightarrow{L}N(0,1)$ |

## 分层练习

### 基础

**1.** 抛一枚均匀硬币 10000 次，用中心极限定理估计正面的频率在 0.49 与 0.51 之间的概率，并与切比雪夫不等式给出的下界比较。

::: details 解答
频率的标准差为 $\sqrt{0.25/10000}=0.005$，$P(|f-0.5|<0.01)\approx P(|Z|<2)=0.9545$（精确值约 0.953）。切比雪夫不等式只能给出 $\ge1-\frac{0.25}{10000\times0.01^2}=0.75$。
:::

**2.** 一个物理量测量 100 次，每次的测量误差独立同分布，均值为 0、标准差为 0.5。求 100 次测量的平均误差的绝对值小于 0.1 的概率。

::: details 解答
平均误差的标准差为 $0.5/10=0.05$，$P(|\bar X|<0.1)\approx P(|Z|<2)\approx0.954$。
:::

**3.** 下列哪个序列依概率收敛到一个常数？(a) 独立同分布 $\mathrm{Exp}(2)$ 的样本均值；(b) 独立同分布柯西变量的样本均值；(c) 独立同分布 $U(0,1)$ 的样本最大值。

::: details 解答
(a) 收敛到 $1/2$（辛钦大数定律）；(b) 不收敛，柯西分布的样本均值仍服从同一个柯西分布；(c) 收敛到 1：$P(\max<1-\varepsilon)=(1-\varepsilon)^n\to0$。
:::

**4.** 用中心极限定理说明：为什么在“[区间估计](/inference/interval)”一章中，非正态总体在大样本时也可以用 $\bar x\pm u_{1-\alpha/2}s/\sqrt n$ 作为均值的置信区间？

::: details 解答
由中心极限定理，$\frac{\bar X-\mu}{\sigma/\sqrt n}$ 近似服从 $N(0,1)$；再由大数定律，样本标准差 $S\xrightarrow{P}\sigma$，用 $S$ 代替 $\sigma$ 不改变极限分布。所以 $\frac{\bar X-\mu}{S/\sqrt n}$ 近似是枢轴量，由它可以得到近似的置信区间。
:::

### 提高

**5.** 用蒙特卡洛方法估计 $\int_0^1e^{-x^2}\,\mathrm dx$，要使估计误差不超过 0.001 的概率至少为 95%，大约需要多少个随机数？（已知 $\operatorname{Var}(e^{-U^2})\approx0.0404$。）

::: details 解答
要求 $1.96\sqrt{0.0404/n}\le0.001$，$n\ge1.96^2\times0.0404/10^{-6}\approx155200$，约 16 万个。精度每提高 10 倍，样本量就要增加 100 倍——这是 $1/\sqrt n$ 收敛速度的代价。
:::

**6.** 证明：若 $X_1,X_2,\dots$ 独立同分布，方差 $\sigma^2$ 存在，则 $\bar X_n\xrightarrow{P}\mu$。

::: details 解答
见正文“证明”：$\operatorname{Var}(\bar X_n)=\sigma^2/n$，再用切比雪夫不等式 $P(|\bar X_n-\mu|\ge\varepsilon)\le\sigma^2/(n\varepsilon^2)\to0$。
:::

**7.** 抛一枚均匀硬币，要使“正面的频率与 0.5 之差小于 0.01”的概率至少为 95%，至少要抛多少次？分别用中心极限定理和切比雪夫不等式计算。

::: details 解答
中心极限定理：$1.96\times\frac{0.5}{\sqrt n}\le0.01$，$n\ge9604$。切比雪夫不等式：$\frac{0.25}{n\times0.0001}\le0.05$，$n\ge50000$。切比雪夫的要求高出 5 倍多，因为它要对 **一切** 分布成立，没有用到“和近似正态”这一信息。
:::

### 挑战

**8.** 利用特征函数，给出林德伯格–莱维中心极限定理的证明梗概。

::: details 解答
记 $Y_i=(X_i-\mu)/\sigma$，$E(Y_i)=0$，$E(Y_i^2)=1$。由泰勒展开，$\varphi_Y(t)=1-\frac{t^2}2+o(t^2)$。标准化的和 $Z_n=\frac1{\sqrt n}\sum Y_i$ 的特征函数为
$$\varphi_{Z_n}(t)=\Big[\varphi_Y\Big(\frac t{\sqrt n}\Big)\Big]^n=\Big[1-\frac{t^2}{2n}+o\Big(\frac1n\Big)\Big]^n\ \longrightarrow\ e^{-t^2/2},$$
这正是 $N(0,1)$ 的特征函数，由连续性定理得证。证明中只用到了前两阶矩，这就是极限与总体分布形状无关的原因。
:::

**9.** 设 $n_A$ 为 $n$ 次抛均匀硬币中正面的次数。证明：$n_A/n\xrightarrow{P}0.5$，但对任意常数 $c$，$P(|n_A-n/2|>c)\to1$。这与“赌徒谬误”有什么关系？

::: details 解答
第一条是伯努利大数定律。对第二条，由中心极限定理，$P(|n_A-n/2|\le c)=P\Big(\big|\frac{n_A-n/2}{0.5\sqrt n}\big|\le\frac{2c}{\sqrt n}\Big)\approx2\Phi\big(\frac{2c}{\sqrt n}\big)-1\to0$。

所以，正面与反面次数之差非但不会趋于 0，反而会越来越大（典型大小约 $0.5\sqrt n$）。比例趋于一半，是因为分母 $n$ 比这个差增长得快。不存在使次数“扯平”的补偿机制，赌徒谬误在这里没有任何依据。
:::

## 代码实现（Python）

::: details 展开代码：大数定律、中心极限定理与正态近似
```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(2024)

# 1. 大数定律：硬币正面的频率
flips = rng.integers(0, 2, 100_000)
for n in [10, 100, 1000, 100_000]:
    print(f"n = {n:>6}：频率 {flips[:n].mean():.4f}")

# 2. 中心极限定理：指数分布样本均值标准化后的偏度随 n 减小
for n in [1, 5, 30, 100]:
    means = rng.exponential(1, size=(20_000, n)).mean(axis=1)
    z = (means - 1) / (1 / np.sqrt(n))
    print(f"n = {n:>3}：偏度 {stats.skew(z):.3f}，|z| <= 1.96 的比例 {np.mean(np.abs(z) <= 1.96):.3f}")

# 3. 例 2：航班超售，正态近似与精确值
for n in range(212, 218):
    exact = stats.binom(n, 0.9).sf(200)                       # P(Y >= 201)
    approx = stats.norm.sf((200.5 - 0.9 * n) / np.sqrt(0.09 * n))
    print(f"n = {n}：精确 {exact:.4f}，正态近似 {approx:.4f}")

# 4. 蒙特卡洛积分
u = rng.random(100_000)
print("积分估计：", np.exp(-u**2).mean().round(4), "（精确值 0.7468）")
```

::: info 史话：黄金定理与中心极限定理
1713 年，雅各布·伯努利的遗著《猜度术》出版，书中证明了伯努利大数定律，他称之为“黄金定理”，为此花了整整二十年。1733 年，棣莫弗发现二项分布在 $p=1/2$ 时可以用正态曲线近似；1812 年，拉普拉斯把它推广到一般的 $p$，并指出大量独立误差之和近似服从正态分布。此后切比雪夫、李雅普诺夫（1901）、林德伯格（1922）等人逐步给出了严格的证明和最一般的条件。“中心极限定理”这个名字是波利亚在 1920 年起的，意思是它在概率论中居于“中心”地位。
:::
