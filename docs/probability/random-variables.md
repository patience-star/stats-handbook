# 随机变量及其数字特征

上一章用集合描述随机现象：“掷出偶数点”是 $\{2,4,6\}$。但统计关心的大多是 **数量**：一天的销售额、一批产品中的次品数、灯泡的寿命。把随机结果对应成一个数，就得到 **随机变量**。有了随机变量，概率论就从集合运算走进了微积分：分布函数、密度、期望、方差，都是用数学分析的语言描述随机性。

## 随机变量与分布函数 {.core}

::: core 定义（随机变量）
定义在样本空间 $\Omega$ 上的实值函数 $X=X(\omega)$ 称为 **随机变量**。只取有限个或可列个值的称为 **离散随机变量**；取值充满某个区间、并且有密度函数的称为 **连续随机变量**。
:::

例如掷三枚硬币，$\Omega$ 有 8 个样本点，令 $X$=“正面朝上的枚数”，则 $X$ 把每个样本点对应成 0、1、2、3 中的一个数。“$X=2$”是事件 $\{\text{正正反},\text{正反正},\text{反正正}\}$，所以 $P(X=2)=3/8$。

要描述一个随机变量，只要知道它落在各个范围内的概率。最统一的工具是分布函数。

::: core 定义（分布函数）
设 $X$ 是随机变量，对任意实数 $x$，称
$$F(x)=P(X\le x)$$
为 $X$ 的 **分布函数**。对任意 $a<b$，$P(a<X\le b)=F(b)-F(a)$。
:::

::: key 分布函数的三条性质
1. **单调性**：$F(x)$ 单调不减；
2. **有界性**：$0\le F(x)\le1$，且 $F(-\infty)=\lim\limits_{x\to-\infty}F(x)=0$，$F(+\infty)=1$；
3. **右连续性**：$F(x+0)=F(x)$。

反过来，满足这三条的函数一定是某个随机变量的分布函数。另外，$P(X=a)=F(a)-F(a-0)$：**分布函数在 $a$ 处的跳跃高度，就是 $X$ 取值 $a$ 的概率**。
:::

## 离散随机变量：分布列

离散随机变量 $X$ 的取值为 $x_1,x_2,\dots$，称 $p_i=P(X=x_i)$ 为它的 **分布列**（概率分布）。分布列满足 $p_i\ge0$ 且 $\sum_ip_i=1$。它的分布函数是阶梯函数，在每个 $x_i$ 处跳高 $p_i$。

::: example 例 1　三枚硬币
掷三枚均匀硬币，正面朝上的枚数 $X$ 的分布列为

| $X$ | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| $P$ | $1/8$ | $3/8$ | $3/8$ | $1/8$ |

分布函数在 0、1、2、3 处依次跳高 $\frac18,\frac38,\frac38,\frac18$。例如 $F(1.5)=P(X\le1.5)=\frac18+\frac38=\frac12$，$F(2)=\frac78$，而 $F(2-0)=\frac12$，跳跃高度 $\frac38$ 正是 $P(X=2)$。
:::

## 连续随机变量：密度函数 {.core}

::: core 定义（概率密度函数）
若存在非负可积函数 $p(x)$，使得对任意实数 $x$ 有
$$F(x)=\int_{-\infty}^x p(t)\,\mathrm dt,$$
则称 $X$ 为连续随机变量，$p(x)$ 称为它的 **概率密度函数**，简称密度。密度满足 $p(x)\ge0$，$\int_{-\infty}^{\infty}p(x)\,\mathrm dx=1$，并且在 $p$ 的连续点处 $F'(x)=p(x)$。
:::

::: geo 几何直观：概率是面积，分布函数是“累积的面积”
在密度曲线下，区间 $(a,b]$ 上方的面积就是 $P(a<X\le b)$；分布函数 $F(x)$ 是从最左边累积到 $x$ 的面积。于是同一个概率有两种画法：**密度图上的一块面积**，等于 **分布函数图上的一段高度差** $F(b)-F(a)$。

下面的实验把两幅图并排放在一起。拖动上图的 $a$、$b$，看阴影面积和下图的高度差如何同步变化。
:::

**试一试**

1. 选正态分布，把区间拖成 $(-1,1]$、$(-2,2]$、$(-3,3]$，概率分别约是多少？这就是“3σ 原则”的来历。
2. 选指数分布：密度在 $x=0$ 处最高，分布函数在哪里上升得最快？二者是什么关系？
3. 选二项分布：分布函数是阶梯形的。把 $a$ 拖过某个整数点时，概率怎样变化？为什么区间要写成左开右闭？
4. 选“双峰混合”：两个峰之间密度很低，分布函数在那里几乎是平的。

::: pitfall 密度不是概率
$p(x)$ 本身不是概率，它可以大于 1。例如 $U(0,0.5)$ 的密度在区间上恒等于 2。真正的概率是密度乘上一小段长度：$P(x<X\le x+\Delta x)\approx p(x)\Delta x$。所以对连续随机变量，**任何一个点的概率都是 0**：$P(X=a)=0$，从而 $P(a<X\le b)=P(a\le X\le b)=P(a<X<b)$。“概率为 0 的事件”不一定是不可能事件。
:::

::: example 例 2　确定密度中的常数
设 $X$ 的密度为 $p(x)=cx^2$（$0<x<1$），其他处为 0。求 $c$、分布函数，以及 $P(0.5<X\le1)$。

**解** 由 $\int_0^1cx^2\,\mathrm dx=c/3=1$ 得 $c=3$。$0\le x<1$ 时 $F(x)=\int_0^x3t^2\,\mathrm dt=x^3$；$x<0$ 时 $F(x)=0$，$x\ge1$ 时 $F(x)=1$。所以 $P(0.5<X\le1)=F(1)-F(0.5)=1-0.125=0.875$。
:::

## 数学期望 {.core}

把随机变量的所有可能取值按概率加权平均，就得到它的“平均值”。

::: core 定义（数学期望）
离散情形：若 $\sum_i|x_i|p_i<\infty$，称 $E(X)=\sum_ix_ip_i$ 为 $X$ 的 **数学期望**。

连续情形：若 $\int|x|p(x)\,\mathrm dx<\infty$，称 $E(X)=\int_{-\infty}^{\infty}xp(x)\,\mathrm dx$ 为 $X$ 的数学期望。

要求 **绝对收敛**，是为了让期望的值不依赖于求和的次序；不满足时说 $X$ 的期望不存在。
:::

::: geo 几何直观：期望是重心
把分布列想象成数轴上的一组砝码：在 $x_i$ 处放质量 $p_i$；把密度想象成一根质量分布不均匀的细杆。$E(X)$ 就是让它们 **保持平衡的支点**，也就是重心。上面实验中的 ▲ 标出了这个位置：对称分布的重心在对称中心，指数分布的重心被长长的右尾拉到了峰的右边。
:::

::: core 期望的性质
1. $E(c)=c$；
2. $E(aX+b)=aE(X)+b$；
3. **随机变量函数的期望**：$E[g(X)]=\sum_ig(x_i)p_i$ 或 $\int g(x)p(x)\,\mathrm dx$。

第 3 条很实用：求 $E[g(X)]$ 时 **不必先求出 $g(X)$ 的分布**，直接用 $X$ 的分布加权即可。例如 $X\sim U(0,1)$ 时，$E(X^2)=\int_0^1x^2\,\mathrm dx=\frac13$。
:::

::: example 例 3　保险公司的定价
某保险公司为一种意外险定价，每份保费 100 元。投保人在一年内出险的概率为 0.001，出险时公司赔付 50000 元。公司每份保单的期望利润是多少？

**解** 记利润为 $X$，$X=100$ 的概率为 0.999，$X=100-50000$ 的概率为 0.001，所以
$$E(X)=100-0.001\times50000=50\ \text{（元）}.$$
单份保单的结果是 100 元或亏损 49900 元，从不会是 50 元；但大量保单的平均利润会稳定在 50 元附近。期望描述的是“长期平均”，这一点由大数定律保证。
:::

:::: l2 进阶：期望不存在的例子
柯西分布的密度为 $p(x)=\dfrac{1}{\pi(1+x^2)}$，它关于 0 对称，“看起来”期望应该是 0。但 $\int|x|p(x)\,\mathrm dx=\infty$，期望 **不存在**。后果很严重：柯西分布的样本均值不会随样本量增大而稳定下来，大数定律对它失效（见“[大数定律与中心极限定理](/probability/limit-theorems)”一章的实验）。期望存在的前提，是尾部要“足够轻”。
::::

## 方差与标准差 {.core}

期望说明了“中心在哪里”，还需要描述“散开有多大”。

::: core 定义（方差与标准差）
若 $E(X-EX)^2$ 存在，称
$$\operatorname{Var}(X)=E\big(X-E(X)\big)^2$$
为 $X$ 的 **方差**，$\sigma(X)=\sqrt{\operatorname{Var}(X)}$ 为 **标准差**。计算时常用
$$\operatorname{Var}(X)=E(X^2)-[E(X)]^2.$$
:::

::: geo 几何直观：方差是转动惯量
继续把分布看成质量分布。方差 $E(X-\mu)^2$ 是每一小块质量乘以它到重心距离的平方再求和，正是力学里绕重心的 **转动惯量**。质量离重心越远，转起来越费力，方差越大。

力学里还有“平行轴定理”：绕任意一点 $c$ 的转动惯量等于绕重心的转动惯量加上 $(\mu-c)^2$。对应到概率就是
$$E(X-c)^2=\operatorname{Var}(X)+(E X-c)^2,$$
所以 $E(X-c)^2$ 在 $c=E(X)$ 时最小——**期望是均方意义下最好的“代表值”**。
:::

::: core 方差的性质
1. $\operatorname{Var}(c)=0$；
2. $\operatorname{Var}(aX+b)=a^2\operatorname{Var}(X)$，平移不改变离散程度，伸缩按平方改变；
3. 称 $X^*=\dfrac{X-E(X)}{\sigma(X)}$ 为 $X$ 的 **标准化**，$E(X^*)=0$，$\operatorname{Var}(X^*)=1$。
:::

::: example 例 4　三枚硬币的方差
例 1 中 $E(X)=0\times\frac18+1\times\frac38+2\times\frac38+3\times\frac18=1.5$，$E(X^2)=0+\frac38+\frac{12}8+\frac98=3$，所以 $\operatorname{Var}(X)=3-1.5^2=0.75$，$\sigma(X)\approx0.866$。
:::

::: quiz 0.0375 0.0005
例 2 中密度为 $p(x)=3x^2$（$0<x<1$）的随机变量，方差是多少？（保留四位小数）
> $E(X)=\int_0^13x^3\,\mathrm dx=\frac34$，$E(X^2)=\int_0^13x^4\,\mathrm dx=\frac35$，$\operatorname{Var}(X)=\frac35-\frac9{16}=\frac3{80}=0.0375$。
:::

## 切比雪夫不等式 {.key}

只知道期望和方差、不知道具体分布时，能对“偏离中心很远”的概率说些什么？

::: core 切比雪夫不等式
设 $X$ 的方差存在，则对任意 $\varepsilon>0$，
$$P\big(|X-E(X)|\ge\varepsilon\big)\le\frac{\operatorname{Var}(X)}{\varepsilon^2}.$$
取 $\varepsilon=k\sigma$，即 $P(|X-\mu|\ge k\sigma)\le\dfrac1{k^2}$：**任何** 方差存在的分布，落在 $\mu\pm2\sigma$ 之外的概率都不超过 25%，落在 $\mu\pm3\sigma$ 之外的概率都不超过 $1/9\approx11\%$。
:::

::: proof 证明（连续情形）
$$P(|X-\mu|\ge\varepsilon)=\int_{|x-\mu|\ge\varepsilon}p(x)\,\mathrm dx\le\int_{|x-\mu|\ge\varepsilon}\frac{(x-\mu)^2}{\varepsilon^2}p(x)\,\mathrm dx\le\frac1{\varepsilon^2}\int(x-\mu)^2p(x)\,\mathrm dx=\frac{\sigma^2}{\varepsilon^2}.$$
关键的一步：在积分区域上 $(x-\mu)^2/\varepsilon^2\ge1$，把被积函数放大了。
:::

::: insight 一个粗糙但普遍的界
把上面实验切换到“切比雪夫”模式试试：正态分布在 $\mu\pm2\sigma$ 外的真实概率只有约 4.6%，远小于上界 25%。切比雪夫不等式很“粗”，因为它要对 **所有** 分布成立，包括最坏的情形；它的价值在于 **普遍性**。在“[大数定律与中心极限定理](/probability/limit-theorems)”一章，它将成为证明大数定律的关键工具。
:::

:::: l2 进阶：马尔可夫不等式与上界能否达到
若 $X\ge0$ 且期望存在，则对 $a>0$ 有 **马尔可夫不等式** $P(X\ge a)\le E(X)/a$。把它用于 $(X-\mu)^2$ 就得到切比雪夫不等式。

切比雪夫的上界是可以达到的：取 $X$ 以概率 $\frac1{2k^2}$ 取 $\pm k$、以概率 $1-\frac1{k^2}$ 取 0，则 $E(X)=0$，$\operatorname{Var}(X)=1$，而 $P(|X|\ge k)=\frac1{k^2}$ 恰好等于上界。所以不改变前提，这个不等式就不能再改进。
::::

## 本章小结

- **随机变量** 把随机结果数量化；**分布函数** $F(x)=P(X\le x)$ 单调不减、有界、右连续，跳跃高度是点概率。
- **离散** 用分布列，**连续** 用密度：概率是密度曲线下的面积，单点概率为 0，密度不是概率。
- **期望** 是重心，要求绝对收敛；$E[g(X)]$ 可以直接用 $X$ 的分布计算。
- **方差** 是转动惯量，$\operatorname{Var}(X)=E(X^2)-(EX)^2$，$\operatorname{Var}(aX+b)=a^2\operatorname{Var}(X)$；期望使 $E(X-c)^2$ 最小。
- **切比雪夫不等式** 对一切分布成立，粗糙但普遍。

| 量 | 离散 | 连续 |
| --- | --- | --- |
| 分布 | $p_i=P(X=x_i)$ | $p(x)$，$F(x)=\int_{-\infty}^xp(t)\,\mathrm dt$ |
| 期望 | $\sum x_ip_i$ | $\int xp(x)\,\mathrm dx$ |
| $E[g(X)]$ | $\sum g(x_i)p_i$ | $\int g(x)p(x)\,\mathrm dx$ |
| 方差 | $E(X^2)-(EX)^2$ | $E(X^2)-(EX)^2$ |
| 切比雪夫 | $P(\lvert X-\mu\rvert\ge\varepsilon)\le\sigma^2/\varepsilon^2$ | 同左 |

## 分层练习

### 基础

**1.** 设 $X$ 的分布列为 $P(X=k)=c/k$，$k=1,2,3$。求 $c$ 与 $E(X)$。

::: details 解答
$c(1+\frac12+\frac13)=\frac{11}6c=1$，$c=\frac6{11}$。$E(X)=\sum k\cdot\frac ck=3c=\frac{18}{11}\approx1.64$。
:::

**2.** 设 $X$ 的分布函数为：$x<0$ 时 $F(x)=0$；$0\le x<2$ 时 $F(x)=x^2/4$；$x\ge2$ 时 $F(x)=1$。求 $P(0.5<X\le1.5)$、密度函数和 $E(X)$。

::: details 解答
$P(0.5<X\le1.5)=F(1.5)-F(0.5)=\frac{2.25-0.25}4=0.5$。密度 $p(x)=F'(x)=x/2$（$0<x<2$），其他处为 0。$E(X)=\int_0^2x\cdot\frac x2\,\mathrm dx=\frac43$。
:::

**3.** 已知 $E(X)=2$，$\operatorname{Var}(X)=1$，求 $E(3X-2)$、$\operatorname{Var}(3X-2)$ 和 $E(X^2)$。

::: details 解答
$E(3X-2)=3\times2-2=4$；$\operatorname{Var}(3X-2)=9\times1=9$；$E(X^2)=\operatorname{Var}(X)+(EX)^2=1+4=5$。
:::

**4.** 某零件长度的期望为 50 mm，标准差为 4 mm，分布未知。用切比雪夫不等式估计长度在 40～60 mm 之间的概率。

::: details 解答
$P(40<X<60)=P(|X-50|<10)\ge1-\frac{16}{100}=0.84$。如果长度服从正态分布，这个概率实际约为 0.988，切比雪夫给出的是对任何分布都成立的保守下界。
:::

### 提高

**5.** 证明 $E(X-c)^2=\operatorname{Var}(X)+(E X-c)^2$，并说明它的几何含义。

::: details 解答
记 $\mu=E(X)$。$E(X-c)^2=E[(X-\mu)+(\mu-c)]^2=E(X-\mu)^2+2(\mu-c)E(X-\mu)+(\mu-c)^2$，中间项因 $E(X-\mu)=0$ 而消失，得证。

几何上，它是力学中的平行轴定理，也是一种“勾股定理”：$X-c$ 分解为 $X-\mu$ 与常数 $\mu-c$ 两个“正交”部分，平方的期望等于两部分平方的期望之和。由此可知，用常数 $c$ 预测 $X$ 时，均方误差在 $c=\mu$ 时最小。
:::

**6.** 独立地重复抛一枚出现正面概率为 $p$ 的硬币，直到出现正面为止。求所需次数 $X$ 的期望。

::: details 解答
$P(X=k)=(1-p)^{k-1}p$，$k=1,2,\dots$。记 $q=1-p$，
$$E(X)=\sum_{k\ge1}kq^{k-1}p=p\cdot\frac{1}{(1-q)^2}=\frac1p.$$
另一种思路：第一次若是正面就结束；若是反面，问题“从头再来”，于是 $E(X)=p\cdot1+q\,(1+E(X))$，解得 $E(X)=1/p$。平均要抛 $1/p$ 次，符合直觉。
:::

**7.** 设 $X\sim U(a,b)$，推导 $E(X)=\frac{a+b}2$、$\operatorname{Var}(X)=\frac{(b-a)^2}{12}$。

::: details 解答
$E(X)=\int_a^b\frac x{b-a}\,\mathrm dx=\frac{a+b}2$；$E(X^2)=\int_a^b\frac{x^2}{b-a}\,\mathrm dx=\frac{a^2+ab+b^2}3$；
$\operatorname{Var}(X)=\frac{a^2+ab+b^2}3-\frac{(a+b)^2}4=\frac{(b-a)^2}{12}$。
:::

### 挑战

**8.** 设 $X\ge0$ 且期望存在。证明 $E(X)=\int_0^\infty[1-F(x)]\,\mathrm dx$（连续情形），并用它计算 $\mathrm{Exp}(\lambda)$ 的期望。

::: details 解答
$\int_0^\infty[1-F(x)]\,\mathrm dx=\int_0^\infty\int_x^\infty p(t)\,\mathrm dt\,\mathrm dx=\int_0^\infty p(t)\Big(\int_0^t\mathrm dx\Big)\mathrm dt=\int_0^\infty tp(t)\,\mathrm dt=E(X)$，其中交换了积分次序。

几何上，$E(X)$ 等于分布函数曲线 **上方**、直线 $y=1$ **下方** 那块区域的面积。对指数分布，$1-F(x)=e^{-\lambda x}$，所以 $E(X)=\int_0^\infty e^{-\lambda x}\,\mathrm dx=1/\lambda$。离散的非负整数值随机变量有类似的公式 $E(X)=\sum_{k\ge1}P(X\ge k)$。
:::

**9.**（圣彼得堡悖论）抛一枚均匀硬币直到出现正面，若第 $k$ 次首次出现正面，你获得 $2^k$ 元。这个游戏的期望收益是多少？你愿意花多少钱玩一次？

::: details 解答
$E=\sum_{k\ge1}2^k\cdot\frac1{2^k}=\sum_{k\ge1}1=\infty$。期望收益无穷大，可是几乎没有人愿意花 100 元玩一次——因为赢得 128 元以上的概率只有 $1/64$。

这个悖论说明：期望只是分布的一个概括，不足以代表一切。丹尼尔·伯努利在 1738 年提出用“效用”（例如收益的对数）的期望来衡量，这成为经济学期望效用理论的起点。另一方面，实际的赌场资金有限，若庄家最多付 $2^{30}$ 元，期望就只有约 31 元。
:::

## 代码实现（Python）

::: details 展开代码：分布函数、期望与切比雪夫不等式
```python
import numpy as np
from scipy import stats, integrate

# 1. scipy.stats 里的分布对象：pdf 密度、cdf 分布函数、mean 期望、var 方差
X = stats.norm(loc=0, scale=1)
print("P(-1 < X <= 1) =", X.cdf(1) - X.cdf(-1))
print("期望", X.mean(), "方差", X.var())

# 2. 例 2：密度 p(x) = 3x^2（0 < x < 1），数值积分求期望与方差
p = lambda x: 3 * x**2
EX, _ = integrate.quad(lambda x: x * p(x), 0, 1)
EX2, _ = integrate.quad(lambda x: x**2 * p(x), 0, 1)
print("E(X) =", EX, " Var(X) =", EX2 - EX**2)

# 3. 切比雪夫不等式：几种分布在 μ ± 2σ 之外的真实概率，与上界 1/4 比较
for name, dist in [("正态", stats.norm()), ("指数", stats.expon()),
                   ("均匀", stats.uniform(0, 2)), ("t(3)", stats.t(3))]:
    mu, sd = dist.mean(), dist.std()
    tail = dist.cdf(mu - 2 * sd) + dist.sf(mu + 2 * sd)
    print(f"{name}：P(|X - mu| >= 2 sigma) = {tail:.4f}  （上界 0.25）")

# 4. 圣彼得堡游戏：样本均值不会稳定下来
rng = np.random.default_rng(0)
k = rng.geometric(0.5, size=1_000_000)       # 首次出现正面所需的次数
pay = 2.0 ** k
for n in [100, 10_000, 1_000_000]:
    print(f"前 {n} 局的平均收益：{pay[:n].mean():.1f}")
```

::: info 史话：期望从赌局中诞生
1654 年，帕斯卡与费马讨论“赌博中途停止时，赌金应如何分配”，答案是按每个人 **最终获胜的机会** 分配，这就是期望思想的萌芽。1657 年，惠更斯写成《论赌博中的计算》，第一次明确提出了“期望”的概念。方差的不等式则晚了两百年：1853 年法国数学家比奈梅首先得到它，1867 年切比雪夫独立给出并用于证明大数定律，所以它也常被称为比奈梅–切比雪夫不等式。
