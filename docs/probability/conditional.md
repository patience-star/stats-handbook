# 条件概率与独立性

一种疾病的患病率是 0.1%。某种检测对患者有 99% 的概率给出阳性，对健康人有 99% 的概率给出阴性。一个人检测结果为阳性，他真的患病的概率是多少？

多数人的第一反应是“99%”，真实答案却只有 **约 9%**。差距来自一个常被忽视的因素：**先验**。本章的三个公式——乘法公式、全概率公式、贝叶斯公式——会让你一眼看出这个答案是怎么来的。它们的起点是一个看似简单的定义：条件概率。

## 条件概率：缩小了的样本空间 {.core}

掷两颗均匀的骰子，样本空间有 36 个等可能的样本点。如果已知“两颗点数之和为 8”，第一颗是 6 点的概率是多少？

“点数之和为 8”这条信息，把可能的结果从 36 个缩小到 5 个：

$$(2,6),\ (3,5),\ (4,4),\ (5,3),\ (6,2).$$

这 5 个结果仍然等可能，其中第一颗为 6 点的只有 $(6,2)$，所以答案是 $1/5$，而不是不加条件时的 $1/6$。记 $A$=“第一颗是 6 点”，$B$=“点数之和为 8”，这个计算可以写成

$$\frac{1}{5}=\frac{1/36}{5/36}=\frac{P(AB)}{P(B)}.$$

::: core 定义（条件概率）
设 $A,B$ 是两个事件，且 $P(B)>0$。称
$$P(A\mid B)=\frac{P(AB)}{P(B)}$$
为 **在事件 $B$ 发生的条件下事件 $A$ 发生的条件概率**。
:::

::: geo 用面积看条件概率：放大，再重新归一化
把样本空间画成面积为 1 的正方形，事件是其中的区域，概率就是面积。

“已知 $B$ 发生”就是把视野限制在 $B$ 内，$B$ 成了新的“全空间”。$A$ 在这个新空间里所占的比例就是
$$P(A\mid B)=\frac{\text{面积}(A\cap B)}{\text{面积}(B)}.$$
区域本身没变，变的是分母：把 $B$ 的面积重新当作 1。条件概率就是 **缩小样本空间之后重新归一化**。
:::

::: insight 条件概率本身也是概率
固定 $B$，把 $P(\cdot\mid B)$ 看成事件的函数，它满足概率的三条公理：

1. 非负性：$P(A\mid B)\ge 0$；
2. 正则性：$P(\Omega\mid B)=1$；
3. 可列可加性：若 $A_1,A_2,\dots$ 两两互不相容，则 $P\big(\bigcup_i A_i\mid B\big)=\sum_i P(A_i\mid B)$。

所以概率的一切性质对条件概率照样成立，例如 $P(\bar A\mid B)=1-P(A\mid B)$。“在 $B$ 的条件下”只是换了一个概率空间，计算规则不变。
:::

::: pitfall 不要混淆 $P(A\mid B)$ 与 $P(B\mid A)$
两者一般不相等。由定义立刻得到
$$\frac{P(A\mid B)}{P(B\mid A)}=\frac{P(A)}{P(B)}.$$
“如果被告无辜，出现这一证据的概率只有千分之一”说的是 $P(\text{证据}\mid\text{无辜})$，它 **不等于**“既然出现了这一证据，被告无辜的概率只有千分之一”，即 $P(\text{无辜}\mid\text{证据})$。把两者混为一谈，叫作 **检察官谬误**。它们之间隔着一个贝叶斯公式，以及被告无辜的先验概率。
:::

掷两颗均匀的骰子，已知点数之和为 8，则 **至少有一颗是 6 点** 的条件概率为
- [ ] $1/5$

## 乘法公式 {.key}

把条件概率的定义倒过来写，就得到计算“几件事同时发生”的工具。

::: core 乘法公式
若 $P(B)>0$，则 $P(AB)=P(B)\,P(A\mid B)$。一般地，若 $P(A_1A_2\cdots A_{n-1})>0$，则
$$P(A_1A_2\cdots A_n)=P(A_1)\,P(A_2\mid A_1)\,P(A_3\mid A_1A_2)\cdots P(A_n\mid A_1\cdots A_{n-1}).$$
:::

::: example 例 1　三张都是红心
从一副 52 张的扑克牌中不放回地依次抽取 3 张，求三张都是红心的概率。

**解** 记 $A_i$=“第 $i$ 张是红心”。由乘法公式
$$P(A_1A_2A_3)=P(A_1)\,P(A_2\mid A_1)\,P(A_3\mid A_1A_2)=\frac{13}{52}\cdot\frac{12}{51}\cdot\frac{11}{50}\approx 0.0129.$$
每个因子都是“在前面已经发生的情况下”的概率：抽走一张红心后，剩下的 51 张里只有 12 张红心。
:::

::: geo 树形图：沿路径相乘
把分几步完成的试验画成一棵树，每个分叉标上条件概率。走到某片叶子的概率，就是沿途各段概率的乘积——这就是乘法公式。上例中“红心 → 红心 → 红心”这条路径的三段概率依次是 $\tfrac{13}{52}$、$\tfrac{12}{51}$、$\tfrac{11}{50}$。
:::

## 全概率公式：分而治之 {.core}

很多事件的概率很难直接算，但分情况讨论之后，每种情况都很好算。全概率公式就是分情况讨论的数学形式。

::: core 全概率公式
设 $B_1,B_2,\dots,B_n$ 是样本空间 $\Omega$ 的一个 **分割**，即它们两两互不相容，且 $\bigcup_{i=1}^n B_i=\Omega$。若 $P(B_i)>0$，则对任一事件 $A$，
$$P(A)=\sum_{i=1}^n P(B_i)\,P(A\mid B_i).$$
:::

::: proof 证明
因为 $B_1,\dots,B_n$ 构成分割，$A=AB_1\cup AB_2\cup\cdots\cup AB_n$，而且 $AB_1,\dots,AB_n$ 两两互不相容。由有限可加性和乘法公式，
$$P(A)=\sum_{i=1}^n P(AB_i)=\sum_{i=1}^n P(B_i)\,P(A\mid B_i).$$
:::

::: geo 分块求面积
把正方形竖着切成 $n$ 条，第 $i$ 条的宽度是 $P(B_i)$；在第 $i$ 条里，$A$ 所占的高度比例是 $P(A\mid B_i)$。$A$ 的总面积就是各条的“宽 × 高”之和。

换个角度看，$P(A)$ 是各个 $P(A\mid B_i)$ 以 $P(B_i)$ 为权重的 **加权平均**。所以 $P(A)$ 一定介于最小和最大的 $P(A\mid B_i)$ 之间，这是检查计算结果的好办法。
:::

::: example 例 2　抽签不分先后
10 张签中有 3 张“中”签。甲先抽、乙后抽，抽后不放回。求乙抽中的概率。

**解** 以甲是否抽中作为分割：
$$P(\text{乙中})=\frac{3}{10}\cdot\frac{2}{9}+\frac{7}{10}\cdot\frac{3}{9}=\frac{3}{10}.$$
与甲抽中的概率相同，先抽后抽机会均等。一般情形见练习 6。
:::

::: insight 由因导果：怎样选分割
可以把 $B_i$ 看成导致 $A$ 的各种“原因”或“情形”。直接算 $P(A)$ 困难、而在每种情形下算 $P(A\mid B_i)$ 容易时，就用全概率公式。选分割的常用办法是 **按“第一步发生了什么”来分**：按甲的抽签结果、按产品来自哪条生产线、按受检者是否患病。
:::

::: quiz 0.024
甲、乙两台机床加工同一种零件。甲的产量占 60%，次品率 2%；乙的产量占 40%，次品率 3%。从全部产品中任取一件，它是次品的概率是多少？
> 由全概率公式，$P(\text{次品})=0.6\times0.02+0.4\times0.03=0.024$。结果介于 2% 与 3% 之间，符合“加权平均”的直观。
:::

## 贝叶斯公式：由果溯因 {.hard}

全概率公式从原因推结果。实际中更常见的是反过来的问题：**已经看到了结果，要推断它是由哪种原因造成的**。检测呈阳性，是因为真的患病，还是误报？

::: core 贝叶斯公式
在全概率公式的条件下，若 $P(A)>0$，则
$$P(B_i\mid A)=\frac{P(B_i)\,P(A\mid B_i)}{\sum_{j=1}^n P(B_j)\,P(A\mid B_j)},\qquad i=1,2,\dots,n.$$
$P(B_i)$ 称为 **先验概率**，是看到结果之前对各个原因的估计；$P(B_i\mid A)$ 称为 **后验概率**，是看到结果 $A$ 之后修正过的估计。
:::

分子是乘法公式给出的 $P(B_iA)$，分母是全概率公式给出的 $P(A)$，所以贝叶斯公式在形式上只是条件概率的定义。它的力量在于思想：**用观测到的结果更新对原因的判断**。

::: example 例 3　阳性意味着什么
回到开头的问题。记 $D$=“患病”，$+$=“检测阳性”，已知
$$P(D)=0.001,\qquad P(+\mid D)=0.99,\qquad P(+\mid\bar D)=1-0.99=0.01.$$
由贝叶斯公式
$$\begin{aligned}
P(D\mid +)&=\frac{P(D)\,P(+\mid D)}{P(D)\,P(+\mid D)+P(\bar D)\,P(+\mid\bar D)}\\
&=\frac{0.001\times0.99}{0.001\times0.99+0.999\times0.01}=\frac{0.00099}{0.00099+0.00999}\approx 0.090.
\end{aligned}$$
阳性者真正患病的概率只有约 9%。
:::

**试一试**

1. 患病率保持 0.1%，看左图：阳性者（两种深色）只是正方形顶部的一条细带，其中绝大部分是 **健康人的误报**。右图把这条细带拉伸成整条，真阳性只占一小段。
2. 把患病率慢慢调到 10%，后验概率怎样变化？先验对结论的影响有多大？
3. 患病率调回 0.1%。把灵敏度从 99% 提高到 99.9%，后验几乎不变；把特异度从 99% 提高到 99.9%，后验变成多少？为什么对罕见病来说，特异度更关键？
4. 点“阳性后再测一次”，把第一次的后验当作第二次的先验（假设两次检测在给定病情时相互独立）。两次都阳性之后，患病的可能性有多大？

::: geo 几何直观：只看“阳性”这块区域
贝叶斯公式又一次用到了“缩小样本空间”：已知阳性，就只看阳性的区域。这块区域由两部分组成：

- **真阳性**：患病那一竖条的上部，面积 $P(D)\,P(+\mid D)$。患病率很小，这一条就很窄；
- **假阳性**：健康那一大块的上部，面积 $P(\bar D)\,P(+\mid\bar D)$。误报率虽然只有 1%，但健康人太多。

后验概率就是真阳性在阳性区域里所占的比例。患病率越低，真阳性那一小块就越不起眼。
:::

::: insight 几率形式：后验几率 = 先验几率 × 似然比
把两个原因的后验概率相除，分母 $P(+)$ 就约掉了：
$$\underbrace{\frac{P(D\mid +)}{P(\bar D\mid +)}}_{\text{后验几率}}=\underbrace{\frac{P(D)}{P(\bar D)}}_{\text{先验几率}}\times\underbrace{\frac{P(+\mid D)}{P(+\mid\bar D)}}_{\text{似然比}}.$$
本例中先验几率是 $1:999$，似然比是 $0.99/0.01=99$，后验几率约为 $99:999\approx1:10$，后验概率约 $1/11\approx9\%$。

这个形式说清了证据的作用：**一次证据把几率乘上它的似然比**。似然比为 99 的检测能把几率放大 99 倍，却救不了一个本来就极小的先验。再来一次独立的阳性，几率再乘 99，约为 $9.8:1$，后验概率约 91%。

“先验 × 似然 ∝ 后验”正是“[贝叶斯估计](/inference/bayesian)”一章的出发点。
:::

::: pitfall 基础率谬误
只看检测的准确率、忽视患病率（基础率），是最常见的概率直觉错误，称为 **基础率谬误**。同样的错误出现在很多场合：罕见故障的报警系统、可疑交易的筛查、人脸识别找逃犯……只要目标本身很罕见，即使方法很准，报警里的大多数也可能是误报。
:::

::: quiz 0.5
接着前面的机床问题：从全部产品中任取一件，发现是次品，它来自甲机床的概率是多少？
> 由贝叶斯公式，$P(\text{甲}\mid\text{次品})=\dfrac{0.6\times0.02}{0.024}=0.5$。甲的次品率低，但产量大，两者恰好抵消。
:::

:::: l2 进阶：连续形式的贝叶斯公式
当“原因”不是有限个事件，而是连续取值的参数 $\theta$ 时，求和变成积分。设参数的先验密度为 $\pi(\theta)$，给定参数时数据的密度为 $p(x\mid\theta)$，则后验密度为
$$\pi(\theta\mid x)=\frac{\pi(\theta)\,p(x\mid\theta)}{\int\pi(\theta')\,p(x\mid\theta')\,\mathrm d\theta'}\ \propto\ \pi(\theta)\,p(x\mid\theta).$$
分母与 $\theta$ 无关，只起归一化的作用。这是贝叶斯统计的出发点，“[贝叶斯估计](/inference/bayesian)”一章会详细展开。
::::

## 事件的独立性 {.core}

如果知道 $B$ 发生并不改变对 $A$ 的判断，即 $P(A\mid B)=P(A)$，就说 $A$ 与 $B$ 独立。代入条件概率的定义，得到一个对称、而且不要求 $P(B)>0$ 的形式。

::: core 定义（两个事件相互独立）
若
$$P(AB)=P(A)\,P(B),$$
则称事件 $A$ 与 $B$ **相互独立**。当 $P(B)>0$ 时，这等价于 $P(A\mid B)=P(A)$。
:::

::: geo 几何直观：比例不变
在面积图里，$A$ 与 $B$ 独立意味着：$A$ 在 $B$ 中所占的比例，等于它在 $\bar B$ 中所占的比例，也等于它在整个正方形中所占的比例。若把 $B$ 画成一个竖条，$A$ 的上下分界线在 $B$ 与 $\bar B$ 两侧 **一样高**，是一条贯穿全图的水平线。

在上面的贝叶斯实验中，把灵敏度设为 70%、特异度设为 30%，这时 $P(+\mid D)=P(+\mid\bar D)=0.7$，左图两侧的分界线齐平，后验概率等于先验概率：检测结果与是否患病独立，检测毫无价值。用几率形式说，就是似然比等于 1。
:::

::: key 性质：独立性在取对立事件后保持
若 $A$ 与 $B$ 相互独立，则 $A$ 与 $\bar B$、$\bar A$ 与 $B$、$\bar A$ 与 $\bar B$ 也都相互独立。
:::

::: proof 证明（以 $A$ 与 $\bar B$ 为例）
$$P(A\bar B)=P(A)-P(AB)=P(A)-P(A)P(B)=P(A)\,[1-P(B)]=P(A)\,P(\bar B).$$
其余两种情形同理，或者对已证的结论再用一次。
:::

::: pitfall 独立不是互不相容
若 $P(A)>0$，$P(B)>0$，且 $A$ 与 $B$ 互不相容，则 $P(AB)=0\neq P(A)P(B)$，它们 **一定不独立**。事实上它们“强烈相关”：知道 $A$ 发生，就确定 $B$ 不发生。

在面积图里，互不相容是两块不重叠的区域；而独立要求 $A$ 在 $B$ 中占有和全局相同的比例，两者必然重叠。
:::

::: quiz
设 $P(A)=0.4$，$P(B)=0.5$，且 $A$ 与 $B$ 相互独立，则 $P(A\cup B)=$
- [ ] $0.9$
- [x] $0.7$
- [ ] $0.2$
- [ ] $0.5$

> $P(A\cup B)=P(A)+P(B)-P(A)P(B)=0.4+0.5-0.2=0.7$；也可以用对立事件：$1-P(\bar A)P(\bar B)=1-0.6\times0.5=0.7$。选 0.9 是把独立当成了互不相容。
:::

### 多个事件的独立性 {.hard}

三个事件两两独立，是否就“三个一起”独立？答案是否定的。

::: core 定义（$n$ 个事件相互独立）
设 $A_1,A_2,\dots,A_n$ 是 $n$ 个事件。若对任意 $2\le k\le n$ 和任意 $1\le i_1<i_2<\cdots<i_k\le n$，都有
$$P(A_{i_1}A_{i_2}\cdots A_{i_k})=P(A_{i_1})\,P(A_{i_2})\cdots P(A_{i_k}),$$
则称 $A_1,\dots,A_n$ **相互独立**。这一共是 $2^n-n-1$ 个等式。只要求 $k=2$ 的等式成立时，称为 **两两独立**。
:::

::: example 例 4　伯恩斯坦四面体
一个均匀的正四面体，三个面分别涂成红、白、黑色，第四个面三种颜色都有。掷一次，记 $A,B,C$ 分别为“朝下的面上有红色”“有白色”“有黑色”。

每种颜色出现在两个面上，所以 $P(A)=P(B)=P(C)=\tfrac12$；任意两种颜色只同时出现在第四个面上，所以 $P(AB)=P(BC)=P(AC)=\tfrac14$，三个事件两两独立。但是
$$P(ABC)=\tfrac14\neq\tfrac18=P(A)P(B)P(C),$$
它们不是相互独立的。
:::

::: insight 为什么要检验所有子集
两两独立只保证任意两个事件之间“互不透露信息”。但两个事件合在一起，仍可能完全决定第三个：在四面体的例子里，知道“有红”而且“有白”，就知道朝下的是第四个面，于是一定“有黑”。相互独立要求 **任何一组事件都不能为其余事件提供信息**。
:::

### 应用：系统可靠性 {.key}

元件的 **可靠度** 是它正常工作的概率。设各元件独立工作，可靠度分别为 $p_1,\dots,p_n$：

- **串联** 系统要求所有元件都正常，$R=p_1p_2\cdots p_n$；
- **并联** 系统只要有一个元件正常，$R=1-(1-p_1)(1-p_2)\cdots(1-p_n)$。

串联系统的可靠度低于其中任何一个元件，并联系统的可靠度高于其中任何一个元件，这就是关键设备要冗余备份的道理。

::: quiz 0.999
三个元件独立工作，可靠度都是 0.9，并联成一个系统。系统的可靠度是多少？
> 并联系统失效，要求三个元件同时失效：$R=1-0.1^3=0.999$。若改为串联，可靠度只有 $0.9^3=0.729$。
:::

:::: l2 进阶：条件独立
若 $P(AB\mid C)=P(A\mid C)\,P(B\mid C)$，称 $A$ 与 $B$ 在给定 $C$ 时 **条件独立**。条件独立与独立互不蕴含。

比如前面的两次检测：给定是否患病，两次结果相互独立，这是“再测一次”时的假设。但不给定病情时，两次结果并不独立：第一次阳性提高了患病的可能，也就提高了第二次阳性的概率。条件独立是贝叶斯网络、隐马尔可夫模型等现代方法的基础。

### 伯努利试验 {.key}

只有两个结果——“成功” $A$ 与“失败” $\bar A$——的试验称为 **伯努利试验**。把它独立地重复 $n$ 次，称为 **$n$ 重伯努利试验**。设每次成功的概率为 $p$。由独立性，指定的某 $k$ 次成功、其余 $n-k$ 次失败的概率是 $p^k(1-p)^{n-k}$，而指定的方式有 $\binom{n}{k}$ 种，所以
$$P(\text{恰好成功 }k\text{ 次})=\binom{n}{k}p^k(1-p)^{n-k},\qquad k=0,1,\dots,n.$$
这就是“[常用分布](/probability/distributions)”一章的二项分布。首页的高尔顿钉板就是一个 $n$ 重伯努利试验：小球每经过一排钉子，就向右（成功）或向左（失败）弹一次。

## 本章小结

- **条件概率** $P(A\mid B)=P(AB)/P(B)$：把样本空间缩小到 $B$，再重新归一化。条件概率也是概率。
  - **乘法公式**：沿树形图的路径相乘。
  - **全概率公式**：分情况讨论，由因导果；$P(A)$ 是各个 $P(A\mid B_i)$ 的加权平均。
  - **贝叶斯公式**：由果溯因；后验几率 = 先验几率 × 似然比。不要忽视先验。
- **独立性** $P(AB)=P(A)P(B)$：条件概率等于无条件概率，面积图中比例不变。
  - 独立与互不相容是两回事。
  - 多个事件相互独立，要求所有子集都满足乘法规则；两两独立推不出相互独立。

| 公式 | 表达式 | 什么时候用 |
| --- | --- | --- |
| 条件概率 | $P(A\mid B)=\dfrac{P(AB)}{P(B)}$ | 已知某事发生，求另一事的概率 |
| 乘法公式 | $P(AB)=P(B)\,P(A\mid B)$ | 分步骤发生的几件事同时发生 |
| 全概率公式 | $P(A)=\sum_i P(B_i)\,P(A\mid B_i)$ | 分情况讨论，由原因求结果 |
| 贝叶斯公式 | $P(B_i\mid A)=\dfrac{P(B_i)\,P(A\mid B_i)}{\sum_j P(B_j)\,P(A\mid B_j)}$ | 已知结果，反推原因 |
| 独立 | $P(AB)=P(A)\,P(B)$ | 判断或利用“互不影响” |

## 分层练习

### 基础

**1.** 设 $P(A)=0.5$，$P(B)=0.4$，$P(A\mid B)=0.6$，求 $P(AB)$、$P(A\cup B)$ 和 $P(B\mid A)$。

::: details 解答
$P(AB)=P(B)P(A\mid B)=0.24$；$P(A\cup B)=0.5+0.4-0.24=0.66$；$P(B\mid A)=0.24/0.5=0.48$。
:::

**2.** 一批产品中 4% 是次品，合格品中有 75% 是一等品。任取一件，求它是一等品的概率。

::: details 解答
一等品一定是合格品，所以 $P(\text{一等品})=P(\text{合格})\,P(\text{一等品}\mid\text{合格})=0.96\times0.75=0.72$。
:::

**3.** 甲、乙两人独立地向同一目标各射击一次，命中率分别为 0.6 和 0.5。求目标被击中的概率；已知目标被击中，求它被甲击中的概率。

::: details 解答
$P(\text{击中})=1-0.4\times0.5=0.8$。“甲击中”包含在“目标被击中”之中，所以
$$P(\text{甲中}\mid\text{击中})=\frac{P(\text{甲中})}{P(\text{击中})}=\frac{0.6}{0.8}=0.75.$$
:::

**4.** 判断并说明理由：若 $P(A)>0$，$P(B)>0$，且 $P(A\mid B)>P(A)$，则 $P(B\mid A)>P(B)$。

::: details 解答
正确。$P(A\mid B)>P(A)\iff P(AB)>P(A)P(B)\iff P(B\mid A)>P(B)$。“$B$ 的发生使 $A$ 更可能”是对称的关系，称 $A$ 与 $B$ **正相关**。
:::

### 提高

**5.**（随机化回答）为了调查考试作弊的比例 $p$，让每位受访者私下抛一枚均匀硬币：正面朝上就回答“你作弊过吗？”，反面朝上就回答“你的生日在上半年吗？”。调查者只看到“是”或“否”，不知道对方回答的是哪个问题。若回答“是”的比例为 30%，估计 $p$（设生日在上半年的概率为 0.5）。

::: details 解答
以硬币的结果作分割，由全概率公式，$P(\text{是})=0.5\,p+0.5\times0.5$。令它等于 0.3，得 $p=0.1$。

受访者的隐私得到了保护——一个“是”并不说明他作弊过——但总体比例仍然可以估计。这种方法叫 **随机化回答技术**，是敏感问题调查的常用做法。
:::

**6.** 袋中有 $a$ 个红球、$b$ 个白球，不放回地依次摸出全部球。证明第 $k$ 次摸到红球的概率为 $\dfrac{a}{a+b}$，与 $k$ 无关。

::: details 解答
**方法一（对称性）** 把 $a+b$ 个球看成互不相同的，所有摸球顺序等可能。第 $k$ 个位置上是任何一个球的可能性都一样，所以它是红球的概率为 $\dfrac{a}{a+b}$。

**方法二（全概率公式与归纳法）** 对 $k$ 归纳。$k=1$ 显然。设结论对 $k-1$ 和任意球数成立，以第一次摸到的颜色作分割：去掉第一个球后，第 $k$ 次就是剩下的球里的第 $k-1$ 次，于是
$$\frac{a}{a+b}\cdot\frac{a-1}{a+b-1}+\frac{b}{a+b}\cdot\frac{a}{a+b-1}=\frac{a(a+b-1)}{(a+b)(a+b-1)}=\frac{a}{a+b}.$$
:::

**7.** 设 $0<P(B)<1$。证明：$A$ 与 $B$ 相互独立 $\iff P(A\mid B)=P(A\mid\bar B)$。

::: details 解答
“$\Rightarrow$”：独立时 $P(A\mid B)=P(A)$；由性质，$A$ 与 $\bar B$ 也独立，$P(A\mid\bar B)=P(A)$。

“$\Leftarrow$”：设 $P(A\mid B)=P(A\mid\bar B)=c$，由全概率公式 $P(A)=P(B)\,c+P(\bar B)\,c=c=P(A\mid B)$，所以独立。

这就是“比例不变”的代数形式：分界线在 $B$ 与 $\bar B$ 两侧一样高。
:::

### 挑战

**8.**（三门问题）三扇门后有一辆汽车和两只山羊。你选了 1 号门。主持人 **知道** 汽车在哪里，他从另外两扇门中打开一扇后面是山羊的门（两扇都是山羊时随机选一扇），比如打开了 3 号门。现在允许你换成 2 号门，换不换？如果主持人 **不知道** 汽车在哪，只是随机打开了 2、3 号门中的一扇，恰好看到山羊呢？

::: details 解答
记 $C_i$=“汽车在 $i$ 号门后”，先验 $P(C_i)=1/3$。

**主持人知情**：记 $H_3$=“主持人打开 3 号门”。$P(H_3\mid C_1)=1/2$（两扇都是山羊，随机选），$P(H_3\mid C_2)=1$（只能开 3 号），$P(H_3\mid C_3)=0$。由贝叶斯公式
$$P(C_2\mid H_3)=\frac{\tfrac13\times1}{\tfrac13\times\tfrac12+\tfrac13\times1+0}=\frac23.$$
换门赢的概率是 $2/3$，应该换。

**主持人不知情**：记 $G_3$=“他打开 3 号门，恰好是山羊”。$P(G_3\mid C_1)=P(G_3\mid C_2)=1/2$，$P(G_3\mid C_3)=0$，于是 $P(C_2\mid G_3)=1/2$，换不换都一样。

同样是“3 号门后是山羊”，信息量却不同：知情的主持人 **被迫** 避开汽车，他的选择本身透露了信息。条件概率不只取决于观察到了什么，还取决于 **这个观察是怎样产生的**。
:::

**9.**（赌徒输光问题）赌徒有本金 $k$ 元，每局以概率 $1/2$ 赢 1 元、以概率 $1/2$ 输 1 元，各局独立。他打算赢到 $N$ 元（$N>k$）就停手，输光也停。求他最终输光的概率 $q_k$。

::: details 解答
以第一局的结果作分割，由全概率公式
$$q_k=\tfrac12\,q_{k+1}+\tfrac12\,q_{k-1}\quad(0<k<N),\qquad q_0=1,\quad q_N=0.$$
上式说明 $q_{k+1}-q_k=q_k-q_{k-1}$，即 $q_k$ 是 $k$ 的线性函数。代入边界条件得
$$q_k=1-\frac{k}{N}.$$
本金越少、目标越高，越可能输光。若每局赢的概率 $p\neq\tfrac12$，记 $r=(1-p)/p$，同样的方法给出 $q_k=\dfrac{r^k-r^N}{1-r^N}$。
:::

## 代码实现（Python）

::: details 展开代码：贝叶斯公式的计算与模拟、三门问题模拟
```python
import numpy as np

rng = np.random.default_rng(2024)

# 1. 贝叶斯公式：阳性者的患病概率
prior, sens, spec = 0.001, 0.99, 0.99
posterior = prior * sens / (prior * sens + (1 - prior) * (1 - spec))
print(f"P(患病 | 阳性) = {posterior:.4f}")

# 2. 模拟一百万人，用频率验证
n = 1_000_000
sick = rng.random(n) < prior
positive = np.where(sick, rng.random(n) < sens, rng.random(n) < 1 - spec)
print(f"模拟：阳性者中患病的比例 = {sick[positive].mean():.4f}")

# 3. 连续几次独立检测都阳性：每次把后验当作新的先验
p = prior
for k in range(1, 4):
    p = p * sens / (p * sens + (1 - p) * (1 - spec))
    print(f"第 {k} 次阳性后：P(患病) = {p:.4f}")

# 4. 三门问题：知情的主持人打开一扇既不是你选的、也没有汽车的门
trials = 100_000
car = rng.integers(0, 3, trials)
pick = 0                                   # 总是先选 0 号门
host = np.array([rng.choice([d for d in (1, 2) if d != c]) for c in car])
switch = 3 - pick - host                   # 剩下的那扇门
print(f"不换门胜率 {np.mean(car == pick):.3f}，换门胜率 {np.mean(car == switch):.3f}")
```

托马斯·贝叶斯（Thomas Bayes，约 1701—1761）是英国的一位长老会牧师。他研究“逆概率”问题的论文在他去世后由朋友理查德·普莱斯整理，于 1763 年发表。拉普拉斯在 1774 年独立得到了同样的思想，并把它系统地用于天文学、人口统计等问题。今天以贝叶斯命名的统计学派，很大程度上是由拉普拉斯开创的。
