# 贝叶斯估计

一种新药在 10 名患者身上试用，7 人有效。有效率的最大似然估计是 70%。可是医生知道，同类药物的有效率大多在 30%～60% 之间，70% 这个数字，他会全盘接受吗？大概不会。他会把 **以往的经验** 和 **这次的数据** 结合起来，得出一个更稳妥的判断。

贝叶斯统计就是把这种“结合”形式化的方法：把未知参数看成随机变量，用 **先验分布** 表达试验之前的认识，用观测数据通过贝叶斯公式把它更新为 **后验分布**，一切推断都基于后验分布。

## 三种信息与贝叶斯公式 {.core}

频率学派的推断只用两种信息：**总体信息**（总体分布的类型）和 **样本信息**（观测数据）。贝叶斯学派还使用第三种：**先验信息**——在抽样之前，关于参数的经验、历史资料或专家判断。

::: core 贝叶斯公式的密度形式
设参数 $\theta$ 的先验密度为 $\pi(\theta)$，给定 $\theta$ 时样本的联合密度为 $p(\boldsymbol x\mid\theta)$，则 $\theta$ 的 **后验密度** 为
$$\pi(\theta\mid\boldsymbol x)=\frac{p(\boldsymbol x\mid\theta)\,\pi(\theta)}{\int p(\boldsymbol x\mid\theta)\,\pi(\theta)\,\mathrm d\theta}\ \propto\ p(\boldsymbol x\mid\theta)\,\pi(\theta).$$
一句话：**后验 ∝ 似然 × 先验**。分母只是使后验积分为 1 的常数。
:::

这正是“[条件概率与独立性](/probability/conditional)”一章贝叶斯公式的连续版本：“原因”换成了参数 $\theta$，“结果”换成了观测数据 $\boldsymbol x$。那里的“后验几率 = 先验几率 × 似然比”，在这里变成了“后验密度 ∝ 先验密度 × 似然函数”。

## 贝叶斯估计 {.core}

后验分布包含了关于 $\theta$ 的全部信息。若要给出一个数作为估计，常用后验分布的某个“中心”：

::: core 贝叶斯估计
- **后验均值** $E(\theta\mid\boldsymbol x)$：使后验期望平方损失 $E[(\theta-a)^2\mid\boldsymbol x]$ 最小（又一次“均值使平方偏差最小”）；
- **后验中位数**：使后验期望绝对损失最小；
- **后验众数**（最大后验估计，MAP）：后验密度的最高点。先验为均匀分布时，它就是最大似然估计。
:::

## 共轭先验 {.key}

如果先验与后验属于同一个分布族，称这个先验为 **共轭先验**。共轭先验让更新变成参数的简单加减。

::: core 贝塔–二项共轭
设 $X\sim b(n,p)$，观测到 $k$ 次成功，$p$ 的先验为 $\mathrm{Be}(a,b)$，则
$$\pi(p\mid k)\propto p^k(1-p)^{n-k}\cdot p^{a-1}(1-p)^{b-1}=p^{a+k-1}(1-p)^{b+n-k-1},$$
即后验为 $\mathrm{Be}(a+k,\ b+n-k)$：**成功次数加到 $a$ 上，失败次数加到 $b$ 上**。
:::

::: geo 几何直观：后验均值落在一条线段上
后验均值可以改写成
$$\frac{a+k}{a+b+n}=\underbrace{\frac{a+b}{a+b+n}}_{1-w}\cdot\underbrace{\frac{a}{a+b}}_{\text{先验均值}}+\underbrace{\frac{n}{a+b+n}}_{w}\cdot\underbrace{\frac kn}_{\text{样本比例}}.$$
它是先验均值与样本比例的 **加权平均**，位于两者之间的线段上。权重之比是 $(a+b):n$——先验相当于 **$a+b$ 次“虚拟”的试验**，其中 $a$ 次成功。数据越多，后验越靠近样本比例；先验越“坚定”（$a+b$ 越大），后验越靠近先验均值。
:::

**试一试**

1. 先验取 $(a,b)=(2,2)$，数据为 10 次中 7 次成功：后验均值在先验均值 0.5 与样本比例 0.7 之间的什么位置？
2. 把先验改成 $(a,b)=(20,20)$（“坚定”地相信 $p$ 接近 0.5），再看后验均值。
3. 清空数据，设真实成功率 0.3，反复点“再做 20 次”：后验分布如何变窄、移向真值？先验的影响是否越来越小？

::: example 例 1　新药的有效率
沿用开头的例子。医生根据同类药物的经验取先验 $\mathrm{Be}(4,6)$（先验均值 0.4，相当于 10 次虚拟试验中 4 次有效）。观测到 10 人中 7 人有效，后验为 $\mathrm{Be}(11,9)$，后验均值为
$$\frac{11}{20}=0.55=\frac{10}{20}\times0.4+\frac{10}{20}\times0.7.$$
先验与数据各占一半权重。如果后续试验了 100 人、70 人有效，后验均值将是 $\frac{74}{110}\approx0.673$，几乎完全由数据决定。
:::

::: core 正态–正态共轭（方差已知）
设 $X_1,\dots,X_n$ 来自 $N(\theta,\sigma^2)$，$\sigma^2$ 已知；先验 $\theta\sim N(\mu_0,\tau^2)$。则后验为 $N(\mu_1,\tau_1^2)$，其中
$$\frac1{\tau_1^2}=\frac1{\tau^2}+\frac{n}{\sigma^2},\qquad\mu_1=\frac{\mu_0/\tau^2+n\bar x/\sigma^2}{1/\tau^2+n/\sigma^2}.$$
方差的倒数称为 **精度**：**后验精度 = 先验精度 + 数据精度**，后验均值是先验均值与样本均值 **按精度加权** 的平均。
:::

::: example 例 2　一次考试说明了什么
某学生所在的班级，学生的真实水平 $\theta$ 大致服从 $N(70,10^2)$。这名学生考了 85 分，而一次考试的测量误差约为 $N(0,5^2)$。他的真实水平的后验分布是什么？

**解** 先验精度 $1/100=0.01$，数据精度 $1/25=0.04$，后验精度 0.05，后验方差 20（标准差约 4.47）。后验均值
$$\mu_1=\frac{70\times0.01+85\times0.04}{0.05}=82.$$
估计值从 85 向班级平均 70 “收缩”了 3 分。原因是：考了 85 分，一部分来自真实水平，一部分可能来自运气；结合班级的整体情况，最可能的真实水平是 82 分。这和“[协方差、相关与条件期望](/probability/dependence)”一章的回归效应是同一件事。
:::

## 可信区间与置信区间 {.key}

::: core 可信区间
若 $P(\hat\theta_L\le\theta\le\hat\theta_U\mid\boldsymbol x)=1-\alpha$，则称 $[\hat\theta_L,\hat\theta_U]$ 为 $\theta$ 的 **可信水平为 $1-\alpha$ 的可信区间**。常取后验分布的 $\alpha/2$ 与 $1-\alpha/2$ 分位数作为端点。
:::

::: insight 两种区间，两种语言
- **置信区间**（频率学派）：$\theta$ 是固定的，区间是随机的。“95%”是 **造区间的方法** 的长期成功率，不能说“$\theta$ 落在这个具体区间里的概率是 95%”。
- **可信区间**（贝叶斯学派）：数据已经观测到，是固定的；$\theta$ 是随机的。“95%”就是 **在已知数据的条件下，$\theta$ 落在这个区间里的概率**——这正是许多人对置信区间的（错误）理解。

在大样本和“平坦”先验下，两种区间在数值上往往非常接近；在小样本或有可靠先验时，可信区间能更好地利用信息。例如 10 次试验 0 次成功时，Wald 置信区间退化为 $[0,0]$，而均匀先验下的 95% 可信区间为 $[0.002,\ 0.285]$，仍然合理。
:::

::: quiz
观测数据后算得参数 $\theta$ 的 95% 可信区间为 $[0.42,\,0.61]$。下列说法正确的是
- [x] 在已知这些数据的条件下，$\theta$ 落在 $[0.42,0.61]$ 内的后验概率为 95%
- [ ] 反复抽样时，约 95% 的这类区间会包含 $\theta$ 的真值
- [ ] 95% 的观测值落在 $[0.42,0.61]$ 内
- [ ] $\theta$ 一定在 $[0.42,0.61]$ 内

> 可信区间是后验分布的一个概率陈述。B 是置信区间的频率解释，对可信区间并不一定成立（它依赖于先验是否“正确”）。
:::

## 先验的选择 {.l2}

:::: l2 进阶：无信息先验与拉普拉斯继承法则
没有先验信息时，常用“无信息”的先验。对二项分布的 $p$，最自然的是均匀分布 $U(0,1)=\mathrm{Be}(1,1)$——这就是“贝叶斯假设”：对 $p$ 的各个取值一视同仁。这时后验均值为
$$\hat p=\frac{k+1}{n+2},$$
称为 **拉普拉斯继承法则**。它在数据少的时候避免了极端结论：试验 1 次成功 1 次，MLE 给出 $\hat p=1$，继承法则给出 $2/3$。

“均匀”依赖于参数化：对 $p$ 均匀，对 $\ln\frac p{1-p}$ 就不均匀。**杰弗里斯先验** $\pi(\theta)\propto\sqrt{I(\theta)}$ 不依赖于参数化的选择（$I$ 为 Fisher 信息量），对二项分布它是 $\mathrm{Be}(\frac12,\frac12)$。

先验的选择是贝叶斯方法最受争议的地方：不同的人可能选不同的先验，得到不同的结论。实践中常做 **敏感性分析**：换几种合理的先验，看结论是否稳定。
::::

:::: l3 深入：数据终将压倒先验
在正则条件下，样本量 $n\to\infty$ 时，后验分布近似为
$$\theta\mid\boldsymbol x\ \stackrel{\text{近似}}{\sim}\ N\Big(\hat\theta_{\text{MLE}},\ \frac{1}{nI(\hat\theta)}\Big),$$
与先验无关（只要先验在真值附近的密度为正）。这就是 **伯恩斯坦–冯·米塞斯定理**：大样本时，贝叶斯后验与频率学派的 MLE 渐近分布 **在数值上一致**，可信区间与置信区间趋于相同。两大学派的分歧，主要在小样本和解释上。

对于不共轭的复杂模型，后验分布没有显式公式。20 世纪 90 年代以来，**马尔可夫链蒙特卡洛**（MCMC）方法使得从任意后验分布中抽样成为可能，贝叶斯方法从此在生物、医学、经济、机器学习等领域被大量使用。
::::

## 本章小结

- 贝叶斯统计使用 **总体信息、样本信息、先验信息** 三种信息；参数是随机变量。
- **后验 ∝ 似然 × 先验**；贝叶斯估计常用后验均值（平方损失）、后验中位数、后验众数。
- **共轭先验**：贝塔–二项（成功加到 $a$、失败加到 $b$）、正态–正态（精度相加，按精度加权）、伽马–泊松。
- 后验均值是先验均值与样本估计的加权平均，先验相当于若干次“虚拟试验”；数据越多，先验的影响越小。
- **可信区间** 是后验概率陈述，**置信区间** 是方法的长期成功率；大样本时二者数值接近。

| 模型 | 先验 | 后验 | 后验均值 |
| --- | --- | --- | --- |
| $b(n,p)$，$k$ 次成功 | $\mathrm{Be}(a,b)$ | $\mathrm{Be}(a+k,\ b+n-k)$ | $\frac{a+k}{a+b+n}$ |
| $N(\theta,\sigma^2)$，$\sigma^2$ 已知 | $N(\mu_0,\tau^2)$ | $N(\mu_1,\tau_1^2)$，$\frac1{\tau_1^2}=\frac1{\tau^2}+\frac n{\sigma^2}$ | 按精度加权 |
| $P(\lambda)$，样本和为 $s$ | $\mathrm{Ga}(\alpha,\beta)$ | $\mathrm{Ga}(\alpha+s,\ \beta+n)$ | $\frac{\alpha+s}{\beta+n}$ |

## 分层练习

### 基础

**1.** $p$ 的先验为 $U(0,1)$，12 次试验中 3 次成功。求后验分布、后验均值和后验众数。

::: details 解答
后验 $\mathrm{Be}(4,10)$。后验均值 $4/14\approx0.286$；后验众数 $\frac{4-1}{4+10-2}=\frac3{12}=0.25$，恰好等于 MLE——均匀先验下 MAP 就是 MLE。
:::

**2.** 某类人群智商的分布为 $N(100,15^2)$。某人一次测验得 130 分，测验的误差为 $N(0,10^2)$。求他的真实智商的后验均值与后验标准差。

::: details 解答
先验精度 $1/225\approx0.00444$，数据精度 $1/100=0.01$，后验精度约 0.01444，后验方差约 69.2，标准差约 8.32。后验均值 $\frac{100\times0.00444+130\times0.01}{0.01444}\approx120.8$。高分被“收缩”向总体平均。
:::

**3.** 某路段每天的事故数服从 $P(\lambda)$，$\lambda$ 的先验为 $\mathrm{Ga}(2,1)$。连续 3 天的事故数为 3、5、4。求 $\lambda$ 的后验分布与后验均值，并与 MLE 比较。

::: details 解答
样本和 $s=12$，后验 $\mathrm{Ga}(14,4)$，后验均值 $14/4=3.5$；MLE 为 $\bar x=4$。先验均值 2 把估计向下拉了一些。
:::

### 提高

**4.** 推导正态–正态共轭的后验分布（方差已知）。

::: details 解答
$\pi(\theta\mid\boldsymbol x)\propto\exp\Big\{-\frac{n(\bar x-\theta)^2}{2\sigma^2}\Big\}\exp\Big\{-\frac{(\theta-\mu_0)^2}{2\tau^2}\Big\}$（似然中只保留与 $\theta$ 有关的部分，它只通过 $\bar x$ 依赖数据）。指数部分是 $\theta$ 的二次式，配方得
$$-\frac12\Big(\frac n{\sigma^2}+\frac1{\tau^2}\Big)\theta^2+\Big(\frac{n\bar x}{\sigma^2}+\frac{\mu_0}{\tau^2}\Big)\theta+\text{常数},$$
所以后验是正态分布，精度为 $\frac n{\sigma^2}+\frac1{\tau^2}$，均值为一次项系数除以精度，即正文的公式。
:::

**5.** 设 10 次试验 0 次成功，取均匀先验。求 95% 可信区间，并与 Wald 置信区间比较。

::: details 解答
后验 $\mathrm{Be}(1,11)$，分布函数 $1-(1-p)^{11}$。2.5% 分位数 $1-0.975^{1/11}\approx0.0023$，97.5% 分位数 $1-0.025^{1/11}\approx0.285$，可信区间约为 $[0.002,\ 0.285]$。Wald 区间为 $[0,0]$，显然不合理。“[区间估计](/inference/interval)”一章介绍的 Wilson 区间约为 $[0,\ 0.278]$，与可信区间相近。
:::

### 挑战

**6.** 推导二项分布参数 $p$ 的杰弗里斯先验。

::: details 解答
单次试验的 Fisher 信息 $I(p)=\frac1{p(1-p)}$，所以 $\pi(p)\propto\sqrt{I(p)}=p^{-1/2}(1-p)^{-1/2}$，即 $\mathrm{Be}(\frac12,\frac12)$。它在 0 和 1 附近密度较高：在这两个端点附近，数据对 $p$ 的分辨能力最强（$I(p)$ 大），先验也相应地“给这些位置更多机会”，使得它在任何重新参数化下形式保持一致。
:::

**7.**（拉普拉斯的日出问题）假设太阳每天升起是成功概率为 $p$ 的独立伯努利试验，$p$ 的先验为 $U(0,1)$。已知太阳连续升起了 $n$ 天，求明天太阳升起的概率。

::: details 解答
后验 $\mathrm{Be}(n+1,1)$，明天升起的概率为后验均值 $\frac{n+1}{n+2}$。拉普拉斯取有记载的约 5000 年（1826213 天），得到 $\frac{1826214}{1826215}$。他同时指出，懂得天体运行规律的人会给出高得多的概率——这本身就说明了先验信息的作用：“均匀先验”只适合真正一无所知的情形。
:::

## 代码实现（Python）

::: details 展开代码：共轭更新与可信区间
```python
import numpy as np
from scipy import stats

# 1. 贝塔–二项：例 1
a, b, k, n = 4, 6, 7, 10
post = stats.beta(a + k, b + n - k)
print("后验均值", post.mean(), " 95% 可信区间", post.ppf([0.025, 0.975]).round(3))

# 2. 逐个更新与一次更新结果相同
rng = np.random.default_rng(0)
data = rng.random(50) < 0.3
aa, bb = 2, 2
for x in data:                     # 每来一个观测就更新一次
    aa, bb = aa + x, bb + (1 - x)
print("逐个更新：Be(", aa, ",", bb, ")；一次更新：Be(", 2 + data.sum(), ",", 2 + (~data).sum(), ")")

# 3. 正态–正态：例 2
mu0, tau2, xbar, sigma2, m = 70, 100, 85, 25, 1
prec = 1 / tau2 + m / sigma2
mu1 = (mu0 / tau2 + m * xbar / sigma2) / prec
print("后验均值", mu1, " 后验标准差", round(np.sqrt(1 / prec), 3))

# 4. 0 次成功时的可信区间与 Wilson 区间
print("可信区间", stats.beta(1, 11).ppf([0.025, 0.975]).round(4))
from statsmodels.stats.proportion import proportion_confint
print("Wilson 区间", np.round(proportion_confint(0, 10, method="wilson"), 4))
```
:::

::: info 史话：被冷落两百年的方法
贝叶斯的论文发表于 1763 年，拉普拉斯随后把“逆概率”方法发扬光大，在 19 世纪被普遍使用。20 世纪初，费希尔、奈曼等人批评先验分布“主观”、不科学，频率学派成为主流，贝叶斯方法几乎被边缘化。杰弗里斯（1939）、萨维奇（1954）、德菲内蒂等人坚持为它奠定基础。转折来自计算：1990 年前后，MCMC 方法使复杂的后验计算变得可行，贝叶斯方法迅速复兴。今天，两种思想在实践中常常相互借鉴，而不再是你死我活的对立。
:::
