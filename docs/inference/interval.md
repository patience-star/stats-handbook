# 区间估计

民意调查常这样报告结果：“支持率为 52%，误差为 ±3 个百分点，置信水平 95%。”点估计 52% 给出了一个数，却没有说它有多可靠；“±3%”和“95%”补上了这一点。

这一章回答三个问题：区间怎么造？“95%”到底是什么意思？想让误差不超过 ±3%，需要调查多少人？

## 置信区间：随机的是区间 {.core}

点估计 $\hat\theta$ 几乎不可能恰好等于 $\theta$。与其只报一个数，不如给出一个范围 $[\hat\theta_L,\hat\theta_U]$，同时说明这个范围有多大把握包含 $\theta$。

::: core 定义（置信区间）
设 $\theta$ 是总体的未知参数，$X_1,\dots,X_n$ 是样本，$\hat\theta_L=\hat\theta_L(X_1,\dots,X_n)$ 和 $\hat\theta_U=\hat\theta_U(X_1,\dots,X_n)$ 是两个统计量，且 $\hat\theta_L<\hat\theta_U$。对给定的 $0<\alpha<1$，若对参数的一切可能取值都有
$$P_\theta\big(\hat\theta_L\le\theta\le\hat\theta_U\big)\ge 1-\alpha,$$
则称随机区间 $[\hat\theta_L,\hat\theta_U]$ 为 $\theta$ 的 **置信水平为 $1-\alpha$ 的置信区间**。若等号对一切 $\theta$ 成立，称为 **同等置信区间**。
:::

::: insight 随机的是区间，不是参数
$\theta$ 是一个固定的常数，只是我们不知道它。随机的是由样本算出的区间：换一组样本，就得到另一个区间。“95%”描述的是 **造区间的方法**：如果反复抽样、每次都用同一方法造区间，大约 95% 的区间会盖住 $\theta$。

下面的实验正是这样做的：从总体中反复抽样，每次造一个区间，盖住真值的画成蓝色，没盖住的画成红色。
:::

<CiCoverage />

**试一试**

1. 方法选“σ 未知（t 区间）”，点几次“抽样 20 次”，再点“自动抽样”。实际覆盖率最后稳定在哪里？每个区间的长度一样吗？
2. 把置信水平从 95% 改成 80% 和 99%，区间的长短和覆盖率怎样变化？
3. 选“σ 未知却用 u 分位数（误用）”，把 $n$ 调到 5，覆盖率还是 95% 吗？再把 $n$ 调到 60 呢？
4. 选“比例 · Wald 区间”，令 $p=0.05$、$n=20$，覆盖率是多少？换成 Wilson 区间再看。

::: pitfall 易错：“这个区间包含 μ 的概率是 95%”？
算出一个具体区间，比如 $[14.80,\,15.20]$ 之后，$\mu$ 要么在里面、要么不在，在频率学派的框架里，这里已经没有概率可言。正确的说法是：“这个区间是用一种成功率为 95% 的方法造出来的。”若想对参数本身谈概率，需要贝叶斯学派的 **可信区间**，见“[贝叶斯估计](/inference/bayesian)”一章。
:::

::: quiz
关于“$\mu$ 的 95% 置信区间为 $[14.80,\,15.20]$”，下列说法正确的是
- [ ] $\mu$ 落在 $[14.80,\,15.20]$ 内的概率为 95%
- [ ] 95% 的样本观测值落在 $[14.80,\,15.20]$ 内
- [x] 若反复抽样并用同一方法造区间，约 95% 的区间包含 $\mu$
- [ ] 重复抽样时，约 95% 的样本均值落在 $[14.80,\,15.20]$ 内

> 置信水平是造区间 **方法** 的性质。A 把参数当成了随机变量；B 混淆了个体观测值与参数；D 也不对：样本均值以 $\mu$ 为中心波动，而不是以这个具体区间的中点为中心。
:::

## 枢轴量法 {.key}

怎样造出置信区间？最常用的办法是找一个 **枢轴量**。

::: core 枢轴量法
1. 找一个样本与 $\theta$ 的函数 $G=G(X_1,\dots,X_n;\theta)$，它的分布 **完全已知、不依赖任何未知参数**，称为枢轴量；
2. 选两个常数 $c<d$，使 $P(c\le G\le d)=1-\alpha$，通常两端各留 $\alpha/2$；
3. 把不等式 $c\le G\le d$ 等价变形为 $\hat\theta_L\le\theta\le\hat\theta_U$，就得到 $\theta$ 的置信区间。
:::

::: geo 几何直观：一把定长的尺子
以正态总体 $N(\mu,\sigma^2)$、$\sigma$ 已知为例。$\bar X\sim N(\mu,\sigma^2/n)$，所以
$$U=\frac{\bar X-\mu}{\sigma/\sqrt n}\sim N(0,1)$$
的分布与 $\mu$ 无关，是一个枢轴量。事件 $|U|\le u_{1-\alpha/2}$ 的概率是 $1-\alpha$，它可以读成两句等价的话：

- “$\bar X$ 落在以 $\mu$ 为中心、半径 $d=u_{1-\alpha/2}\,\sigma/\sqrt n$ 的范围内”；
- “$\mu$ 落在以 $\bar X$ 为中心、半径同样为 $d$ 的范围内”。

想象一把长为 $2d$ 的尺子，中心钉在 $\bar X$ 上。$\bar X$ 随样本左右摆动，尺子跟着移动。尺子盖住 $\mu$，当且仅当 $\bar X$ 离 $\mu$ 不超过 $d$，而这件事的概率恰好是 $1-\alpha$。
:::

## 单个正态总体参数的置信区间 {.core}

设 $X_1,\dots,X_n$ 来自正态总体 $N(\mu,\sigma^2)$，$\bar x$ 和 $s$ 分别是样本均值和样本标准差。

### σ 已知时 μ 的置信区间

枢轴量 $U=\dfrac{\bar X-\mu}{\sigma/\sqrt n}\sim N(0,1)$，置信区间为
$$\Big[\ \bar x-u_{1-\alpha/2}\frac{\sigma}{\sqrt n},\ \ \bar x+u_{1-\alpha/2}\frac{\sigma}{\sqrt n}\ \Big].$$

### σ 未知时 μ 的置信区间 {.key}

把 $\sigma$ 换成样本标准差，枢轴量变为 $T=\dfrac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)$（见“[统计量与抽样分布](/inference/sampling)”一章），置信区间为
$$\Big[\ \bar x-t_{1-\alpha/2}(n-1)\frac{s}{\sqrt n},\ \ \bar x+t_{1-\alpha/2}(n-1)\frac{s}{\sqrt n}\ \Big].$$

::: insight 为估计 σ 付出的代价
$t$ 分布的尾部比正态分布厚，所以 $t_{1-\alpha/2}(n-1)>u_{1-\alpha/2}$，$t$ 区间更宽，这是“$\sigma$ 也要从数据中估计”付出的代价。样本越大，代价越小：$t_{0.975}(9)=2.262$，$t_{0.975}(29)=2.045$，$t_{0.975}(99)=1.984$，逐渐接近 $u_{0.975}=1.960$。

在上面的实验中，$n$ 较小时用 $u$ 代替 $t$，覆盖率明显不足 95%。
:::

### σ² 的置信区间 {.hard}

由 $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$，取
$$P\Big(\chi^2_{\alpha/2}(n-1)\le\frac{(n-1)S^2}{\sigma^2}\le\chi^2_{1-\alpha/2}(n-1)\Big)=1-\alpha,$$
解出
$$\sigma^2\in\Big[\ \frac{(n-1)s^2}{\chi^2_{1-\alpha/2}(n-1)},\ \ \frac{(n-1)s^2}{\chi^2_{\alpha/2}(n-1)}\ \Big].$$

::: pitfall 不对称的区间
$\chi^2$ 分布不对称，所以 $\sigma^2$ 的置信区间不以 $s^2$ 为中心，而是向右拉长。“两端各留 $\alpha/2$”只是为了方便，得到的并不是最短的区间。还要注意分位数的位置：较大的分位数 $\chi^2_{1-\alpha/2}$ 在分母上，给出的是区间的 **下** 端点。
:::

::: example 例 1　零件长度
某零件的长度服从正态分布。随机抽取 9 件，测得长度（单位：mm）为
$$14.6,\ 15.1,\ 14.9,\ 14.8,\ 15.2,\ 15.1,\ 14.8,\ 15.0,\ 15.5.$$
求置信水平 95% 的置信区间：(1) 已知 $\sigma=0.3$ 时 $\mu$ 的区间；(2) $\sigma$ 未知时 $\mu$ 的区间；(3) $\sigma^2$ 的区间。

**解** 计算得 $\bar x=15.0$，$\sum(x_i-\bar x)^2=0.56$，$s^2=0.56/8=0.07$，$s\approx0.2646$。

(1) $u_{0.975}=1.96$，半宽 $1.96\times0.3/3=0.196$，区间为 $[14.804,\ 15.196]$。

(2) $t_{0.975}(8)=2.306$，半宽 $2.306\times0.2646/3\approx0.203$，区间为 $[14.797,\ 15.203]$，比 (1) 略宽。

(3) $\chi^2_{0.025}(8)=2.180$，$\chi^2_{0.975}(8)=17.535$，区间为
$$\Big[\frac{0.56}{17.535},\ \frac{0.56}{2.180}\Big]=[0.0319,\ 0.2569],$$
相应地，$\sigma$ 的区间为 $[0.179,\ 0.507]$。
:::

::: quiz 0.203 0.002
例 1 第 (2) 问中，$t$ 区间的半宽是多少？（保留三位小数）
> 半宽 $=t_{0.975}(8)\,s/\sqrt n=2.306\times0.2646/3\approx0.203$。
:::

:::: l2 进阶：两个正态总体的置信区间
设两个独立样本分别来自 $N(\mu_1,\sigma_1^2)$ 和 $N(\mu_2,\sigma_2^2)$，样本量为 $m,n$，样本均值为 $\bar x,\bar y$，样本方差为 $s_x^2,s_y^2$。

- **$\mu_1-\mu_2$，方差相等但未知**：合并方差 $s_w^2=\dfrac{(m-1)s_x^2+(n-1)s_y^2}{m+n-2}$，区间为
$$\bar x-\bar y\pm t_{1-\alpha/2}(m+n-2)\,s_w\sqrt{\frac1m+\frac1n}.$$
- **$\mu_1-\mu_2$，方差不等且未知**：用 Welch 近似，$\bar x-\bar y\pm t_{1-\alpha/2}(l)\sqrt{s_x^2/m+s_y^2/n}$，自由度 $l$ 由 Welch–Satterthwaite 公式确定。
- **$\sigma_1^2/\sigma_2^2$**：由 $\dfrac{S_x^2/\sigma_1^2}{S_y^2/\sigma_2^2}\sim F(m-1,n-1)$ 得
$$\Big[\ \frac{s_x^2/s_y^2}{F_{1-\alpha/2}(m-1,n-1)},\ \ \frac{s_x^2/s_y^2}{F_{\alpha/2}(m-1,n-1)}\ \Big].$$

若 $\mu_1-\mu_2$ 的区间不含 0，可以认为两个均值有差异；若 $\sigma_1^2/\sigma_2^2$ 的区间不含 1，可以认为两个方差有差异。这正是下一章假设检验的思想。
::::

## 大样本置信区间与比例 {.key}

总体不是正态分布时怎么办？只要样本量足够大，由中心极限定理，
$$\frac{\bar X-\mu}{S/\sqrt n}\ \stackrel{\text{近似}}{\sim}\ N(0,1),$$
于是 $\bar x\pm u_{1-\alpha/2}\,s/\sqrt n$ 是 $\mu$ 的近似置信区间。

最重要的应用是 **比例**。设 $X_1,\dots,X_n$ 来自两点分布 $b(1,p)$，样本比例 $\hat p=\bar x$，则 $p$ 的近似置信区间为
$$\hat p\pm u_{1-\alpha/2}\sqrt{\frac{\hat p(1-\hat p)}{n}}.$$

::: example 例 2　民调的“误差 ±3%”
随机调查 1000 人，其中 520 人支持某项政策。支持率 $p$ 的 95% 置信区间为
$$0.52\pm1.96\sqrt{\frac{0.52\times0.48}{1000}}=0.52\pm0.031=[0.489,\ 0.551].$$
这就是“支持率 52%，误差 ±3 个百分点”的来历。注意区间包含 0.5，所以这次调查 **不足以** 断言支持者过半。
:::

:::: l3 深入：Wald 区间的缺陷与 Wilson 区间
上面的区间叫 **Wald 区间**。它在 $p$ 接近 0 或 1、或 $n$ 不大时表现很差：在实验中取 $p=0.05$、$n=20$，覆盖率只有约 64%。原因之一是 $\hat p=0$ 时区间退化成一个点 $[0,0]$。

**Wilson 区间** 不把 $\hat p(1-\hat p)$ 当作方差，而是直接解不等式 $\dfrac{|\hat p-p|}{\sqrt{p(1-p)/n}}\le u$（$u=u_{1-\alpha/2}$），得到
$$\frac{\hat p+\frac{u^2}{2n}}{1+\frac{u^2}{n}}\ \pm\ \frac{u}{1+\frac{u^2}{n}}\sqrt{\frac{\hat p(1-\hat p)}{n}+\frac{u^2}{4n^2}}.$$
它的中心向 1/2 收缩，在小样本和极端比例下覆盖率仍接近名义水平。不少统计软件把它作为比例区间的推荐方法。
::::

## 样本量的确定 {.key}

调查之前常要先回答：想让估计误差不超过 $E$，至少要抽多少个样本？

以 $\sigma$ 已知时估计 $\mu$ 为例，令区间半宽 $u_{1-\alpha/2}\,\sigma/\sqrt n\le E$，解得
$$n\ \ge\ \Big(\frac{u_{1-\alpha/2}\,\sigma}{E}\Big)^2.$$
估计比例时，把 $\sigma^2$ 换成 $p(1-p)$：$n\ge u_{1-\alpha/2}^2\,p(1-p)/E^2$。$p$ 未知时取使 $p(1-p)$ 最大的 $p=0.5$，这是最保守的做法。

<SampleSize />

::: insight 精度翻倍，样本翻四倍
区间半宽与 $1/\sqrt n$ 成正比：误差减半，样本量要变成 4 倍；误差缩小到 1/10，样本量要变成 100 倍。在双对数坐标里，$n\propto E^{-2}$ 是一条斜率为 $-2$ 的直线。这也解释了为什么全国性民调通常只调查一千多人：把误差从 ±3% 降到 ±1%，需要约 9600 人，成本约是原来的 9 倍。
:::

::: quiz 1068 0
在 95% 置信水平下，要使比例的估计误差不超过 3 个百分点，在 $p$ 未知时至少要调查多少人？
> 取 $p=0.5$，$n\ge1.96^2\times0.25/0.03^2\approx1067.1$，向上取整为 1068 人。
:::

::: pitfall 两书记号对照
| 含义 | 茆书 | 经管类教材的常见写法 |
| --- | --- | --- |
| 95% 区间用的正态分位数 | 下侧分位数 $u_{0.975}$ | 上侧分位数 $z_{0.025}$，一般写作 $z_{\alpha/2}$ |
| 均值的标准误 $\sigma/\sqrt n$ | 直接写出 | **抽样平均误差** $\mu_{\bar x}$ |
| 区间半宽 | 直接写出 | **抽样极限误差** $\Delta=z_{\alpha/2}\,\mu_{\bar x}$ |

同一个数 1.96，茆书写作 $u_{0.975}$，经管类教材写作 $z_{0.025}$。“抽样平均误差”就是标准误，“抽样极限误差”就是区间半宽。
:::

### 不重复抽样的修正 {.key}

以上公式假定 **重复抽样**（有放回），或者总体规模 $N$ 远大于样本量 $n$。在有限总体中 **不重复抽样** 时，样本均值的方差要乘上一个修正系数：
$$\operatorname{Var}(\bar X)=\frac{\sigma^2}{n}\cdot\frac{N-n}{N-1}\approx\frac{\sigma^2}{n}\Big(1-\frac nN\Big).$$
相应地，所需样本量从 $n_0$ 降为
$$n=\frac{n_0}{1+(n_0-1)/N}.$$
抽样比 $n/N$ 很小（比如不到 5%）时，修正可以忽略。在上面的计算器里填入总体规模 $N$，可以看到修正的效果。

:::: l2 进阶：单侧置信限
有时只关心一侧，例如“元件的平均寿命 **至少** 是多少”。若 $P_\theta(\hat\theta_L\le\theta)\ge1-\alpha$ 对一切 $\theta$ 成立，称 $\hat\theta_L$ 为 $\theta$ 的置信水平为 $1-\alpha$ 的 **单侧置信下限**；单侧置信上限的定义类似。

例如正态总体 $\sigma$ 未知时，$\mu$ 的单侧置信下限为 $\bar x-t_{1-\alpha}(n-1)\,s/\sqrt n$。分位数从 $1-\alpha/2$ 变成了 $1-\alpha$：全部 $\alpha$ 都留在一侧。
::::

:::: l3 深入：置信区间与假设检验是一回事
对每个可能的参数值 $\theta_0$，设 $A(\theta_0)$ 是水平为 $\alpha$ 的检验 $H_0:\theta=\theta_0$ 的接受域。那么
$$C(x)=\{\theta_0:\ x\in A(\theta_0)\},$$
即所有“不会被数据拒绝”的参数值，构成一个置信水平为 $1-\alpha$ 的置信区域，因为 $P_\theta(\theta\in C(X))=P_\theta(X\in A(\theta))\ge1-\alpha$。

把它画在“参数 × 数据”的平面上：每个 $\theta_0$ 对应一段竖直的接受域，它们拼成一条“置信带”。**竖着切** 是检验的接受域，**横着切** 就是置信区间。这就是奈曼的构造方法。下一章会看到，$\mu$ 的 $t$ 区间与双侧 $t$ 检验正是这样一一对应的。
::::

## 本章小结

- 置信区间是 **随机区间**；置信水平是造区间方法的长期成功率，不是某个具体区间包含参数的概率。
- **枢轴量法**：找分布已知的 $G(X;\theta)$，取分位数，再解不等式。
- 区间半宽 ∝ $1/\sqrt n$：精度翻倍，样本翻四倍。
- 小样本、$\sigma$ 未知时要用 $t$ 分位数；比例的样本量小或 $p$ 极端时，Wald 区间不可靠。

| 参数 | 条件 | 枢轴量 | 置信区间 |
| --- | --- | --- | --- |
| $\mu$ | $\sigma$ 已知 | $\dfrac{\bar X-\mu}{\sigma/\sqrt n}\sim N(0,1)$ | $\bar x\pm u_{1-\alpha/2}\,\sigma/\sqrt n$ |
| $\mu$ | $\sigma$ 未知 | $\dfrac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)$ | $\bar x\pm t_{1-\alpha/2}(n-1)\,s/\sqrt n$ |
| $\sigma^2$ | $\mu$ 未知 | $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$ | $\Big[\dfrac{(n-1)s^2}{\chi^2_{1-\alpha/2}(n-1)},\ \dfrac{(n-1)s^2}{\chi^2_{\alpha/2}(n-1)}\Big]$ |
| $p$ | 大样本 | 近似 $N(0,1)$ | $\hat p\pm u_{1-\alpha/2}\sqrt{\hat p(1-\hat p)/n}$ |
| 样本量 | 估计 $\mu$ | — | $n\ge(u_{1-\alpha/2}\,\sigma/E)^2$ |

## 分层练习

### 基础

**1.** 设总体 $X\sim N(\mu,4)$，抽取容量为 16 的样本，$\bar x=50$。求 $\mu$ 的 95% 置信区间。

::: details 解答
$\sigma=2$，半宽 $1.96\times2/\sqrt{16}=0.98$，区间为 $[49.02,\ 50.98]$。
:::

**2.** 从正态总体中抽取 $n=25$ 的样本，$\bar x=12$，$s=3$。求 $\mu$ 的 99% 置信区间。

::: details 解答
$t_{0.995}(24)=2.797$，半宽 $2.797\times3/5\approx1.678$，区间为 $[10.32,\ 13.68]$。
:::

**3.** 判断对错：(a) 样本量固定时，置信水平越高，区间越宽；(b) 样本量变为原来的 4 倍，区间半宽大约减半；(c) 95% 置信区间意味着 95% 的样本观测值落在区间内。

::: details 解答
(a) 对，分位数随置信水平增大而增大。(b) 对，半宽 ∝ $1/\sqrt n$；对 $t$ 区间来说，分位数也会略微变小，所以半宽比一半还要小一点。(c) 错，置信区间是关于参数的；描述个体观测值范围的是 **预测区间** 或 **容忍区间**。
:::

**4.** 已知某指标的标准差约为 10。在 95% 置信水平下，要使均值的估计误差不超过 2，至少需要多大的样本？

::: details 解答
$n\ge(1.96\times10/2)^2=96.04$，至少需要 97 个。
:::

### 提高

**5.** 为比较两种工艺的产品强度，分别抽样：工艺甲 $m=10$，$\bar x=20.5$，$s_x=2.0$；工艺乙 $n=12$，$\bar y=18.2$，$s_y=2.4$。设两总体都服从正态分布且方差相等，求 $\mu_1-\mu_2$ 的 95% 置信区间。能否认为两种工艺的平均强度不同？

::: details 解答
$s_w^2=\dfrac{9\times4+11\times5.76}{20}=4.968$，$s_w\approx2.229$；标准误 $s_w\sqrt{1/10+1/12}\approx0.954$；$t_{0.975}(20)=2.086$，半宽约 1.991。区间为 $2.3\pm1.991=[0.31,\ 4.29]$。区间不含 0，可以认为工艺甲的平均强度更高。
:::

**6.** 抽查 400 件产品，发现 60 件次品。用 Wald 区间求次品率的 95% 置信区间，并说明此时用 Wald 区间是否合适。

::: details 解答
$\hat p=0.15$，标准误 $\sqrt{0.15\times0.85/400}\approx0.0179$，半宽约 0.035，区间为 $[0.115,\ 0.185]$。$n\hat p=60$ 和 $n(1-\hat p)=340$ 都远大于 10，正态近似可靠，用 Wald 区间是合适的。
:::

**7.** 设 $\sigma$ 已知。证明在所有形如 $[\bar x-a,\ \bar x+b]$、置信水平为 $1-\alpha$ 的区间中，对称区间（$a=b$）最短。

::: details 解答
记 $Z=(\bar X-\mu)/(\sigma/\sqrt n)\sim N(0,1)$，$a'=a\sqrt n/\sigma$，$b'=b\sqrt n/\sigma$。区间包含 $\mu$ 等价于 $-b'\le Z\le a'$。问题变成：在约束 $\Phi(a')-\Phi(-b')=1-\alpha$ 下最小化 $a'+b'$。由拉格朗日乘数法，最优点满足 $\varphi(a')=\varphi(-b')$。标准正态密度关于 0 对称，在 $[0,\infty)$ 上严格递减，所以 $a'=b'$。

几何上：要用最短的底边围出面积 $1-\alpha$，应该取密度最高的那一段，所以两个端点处的密度高度必须相等。这个结论对任何单峰对称的枢轴量分布都成立。
:::

### 挑战

**8.** 设 $X_1,\dots,X_n$ 来自均值为 $\theta$ 的指数分布。利用 $\dfrac{2n\bar X}{\theta}\sim\chi^2(2n)$ 构造 $\theta$ 的置信水平为 $1-\alpha$ 的置信区间，并说明这个分布结论从何而来。

::: details 解答
$X_i/\theta$ 服从均值为 1 的指数分布，即 $\mathrm{Ga}(1,1)$，所以 $2X_i/\theta\sim\mathrm{Ga}(1,1/2)=\chi^2(2)$。由 $\chi^2$ 分布的可加性，$2n\bar X/\theta=\sum_i 2X_i/\theta\sim\chi^2(2n)$，它不含未知参数，是枢轴量。由
$$P\Big(\chi^2_{\alpha/2}(2n)\le\frac{2n\bar X}{\theta}\le\chi^2_{1-\alpha/2}(2n)\Big)=1-\alpha$$
解出
$$\theta\in\Big[\ \frac{2n\bar x}{\chi^2_{1-\alpha/2}(2n)},\ \ \frac{2n\bar x}{\chi^2_{\alpha/2}(2n)}\ \Big].$$
这是 **精确** 区间，不需要大样本近似。
:::

**9.** 从不等式 $\dfrac{|\hat p-p|}{\sqrt{p(1-p)/n}}\le u$ 出发推导 Wilson 区间，并解释为什么它在 $\hat p=0$ 时仍能给出有意义的区间。

::: details 解答
两边平方，$(\hat p-p)^2\le u^2p(1-p)/n$，整理成关于 $p$ 的二次不等式
$$\Big(1+\frac{u^2}{n}\Big)p^2-\Big(2\hat p+\frac{u^2}{n}\Big)p+\hat p^2\le0,$$
解集是两根之间的区间，用求根公式化简即得正文的 Wilson 区间。

$\hat p=0$ 时，Wald 区间退化为 $[0,0]$；Wilson 区间变成 $\Big[0,\ \dfrac{u^2/n}{1+u^2/n}\Big]$，例如 $n=20$、$u=1.96$ 时约为 $[0,\ 0.161]$，仍然给出了合理的上界。原因是 Wilson 区间用 **待检验的** $p$ 计算方差，而不是用观测到的 $\hat p=0$。
:::

## 代码实现（Python）

::: details 展开代码：各种置信区间与覆盖率模拟
```python
import numpy as np
from scipy import stats
from statsmodels.stats.proportion import proportion_confint

x = np.array([14.6, 15.1, 14.9, 14.8, 15.2, 15.1, 14.8, 15.0, 15.5])
n, xbar, s = len(x), x.mean(), x.std(ddof=1)

# σ 已知（σ = 0.3）时 μ 的 95% 区间
print(stats.norm.interval(0.95, loc=xbar, scale=0.3 / np.sqrt(n)))
# σ 未知时 μ 的 95% 区间（t 区间）
print(stats.t.interval(0.95, df=n - 1, loc=xbar, scale=s / np.sqrt(n)))
# σ² 的 95% 区间：较大的分位数给出下端点
hi_q, lo_q = stats.chi2.ppf([0.975, 0.025], df=n - 1)
print((n - 1) * s**2 / hi_q, (n - 1) * s**2 / lo_q)

# 比例：Wald 区间与 Wilson 区间
print(proportion_confint(520, 1000, alpha=0.05, method="normal"))
print(proportion_confint(520, 1000, alpha=0.05, method="wilson"))

# 覆盖率模拟：小样本时用 u 代替 t 会怎样？
rng = np.random.default_rng(0)
reps, m = 100_000, 5
samples = rng.normal(0, 1, size=(reps, m))
means, sds = samples.mean(axis=1), samples.std(axis=1, ddof=1)
for name, q in [("u", stats.norm.ppf(0.975)), ("t", stats.t.ppf(0.975, m - 1))]:
    half = q * sds / np.sqrt(m)
    print(f"用 {name} 分位数的覆盖率：{np.mean(np.abs(means) <= half):.3f}")
```
:::

::: info 史话：奈曼与费希尔之争
置信区间理论由波兰裔统计学家耶日·奈曼（Jerzy Neyman）在 20 世纪 30 年代建立。几乎同时，费希尔提出了“信念推断”（fiducial inference），也给出了参数的区间。两种方法在许多问题中给出相同的数字，解释却截然不同：奈曼坚持概率只描述“方法”的长期表现，费希尔则希望对参数本身作出概率陈述。两人为此争论多年。今天，奈曼的解释成了频率学派的标准；“对参数本身谈概率”的愿望，则由贝叶斯方法以另一种方式实现。
:::
