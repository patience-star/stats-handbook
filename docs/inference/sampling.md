# 统计量与抽样分布

从这一章起，我们由概率论进入数理统计。两者研究的是同一类对象，方向却相反：

- **概率论**：已知分布，推算数据会呈现什么规律——“已知袋中有 3 红 7 白，摸 10 次大约摸到几个红球”；
- **数理统计**：已知数据，反推分布是什么样子——“摸了 10 次得到 4 个红球，袋中红球的比例大约是多少”。

连接这两个方向的桥梁，是 **统计量** 和它的 **抽样分布**：样本是随机的，由样本算出的统计量也是随机的，它的分布告诉我们统计量会在什么范围内波动，从而告诉我们由它作出的推断有多可靠。

## 总体与样本 {.core}

::: core 总体、样本、简单随机样本
研究对象的某个数量指标的全体可能取值称为 **总体**，它可以用一个随机变量 $X$ 及其分布 $F(x)$ 来描述，所以也常说“总体 $X$”“总体 $F$”。

从总体中抽取 $n$ 个个体，观测值 $X_1,\dots,X_n$ 称为容量为 $n$ 的 **样本**。若 $X_1,\dots,X_n$ **相互独立** 且都与总体 **同分布**，则称为 **简单随机样本**，简称样本。样本的联合分布为
$$F(x_1,\dots,x_n)=\prod_{i=1}^nF(x_i).$$
:::

抽样之前，$X_1,\dots,X_n$ 是随机变量；抽样之后，得到一组具体的数 $x_1,\dots,x_n$，称为 **样本观测值**。这种“随机变量—观测值”的双重身份贯穿整个数理统计：理论分析时把样本看成随机变量，计算时代入观测值。

::: insight 经验分布函数：样本是总体的“缩影”
把样本观测值从小到大排列，令
$$F_n(x)=\frac{\#\{i:\ x_i\le x\}}{n},$$
称为 **经验分布函数**，它是一个在每个观测值处跳高 $1/n$ 的阶梯函数，正是“[数据的整理与显示](/descriptive/organization)”一章中累计频率图的精确版本。

由伯努利大数定律，对每个固定的 $x$，$F_n(x)\xrightarrow{P}F(x)$。**格里汶科定理** 更进一步：$\sup_x|F_n(x)-F(x)|$ 以概率 1 趋于 0，即整条经验分布函数一致地逼近总体分布函数。这是“用样本推断总体”的根本依据：样本量足够大时，样本几乎完整地复制了总体的分布。
:::

## 统计量 {.core}

::: core 定义（统计量）
样本 $X_1,\dots,X_n$ 的函数 $T=T(X_1,\dots,X_n)$，若 **不含任何未知参数**，则称为 **统计量**。统计量的分布称为 **抽样分布**。
:::

常用的统计量：

- **样本均值** $\bar X=\frac1n\sum X_i$；
- **样本方差** $S^2=\frac1{n-1}\sum(X_i-\bar X)^2$，以及 $S_n^2=\frac1n\sum(X_i-\bar X)^2$；
- **样本 $k$ 阶矩** $A_k=\frac1n\sum X_i^k$，**$k$ 阶中心矩** $B_k=\frac1n\sum(X_i-\bar X)^k$；
- **次序统计量** $X_{(1)}\le X_{(2)}\le\cdots\le X_{(n)}$，以及由它们算出的样本中位数、样本分位数、极差。

::: core 样本均值与样本方差的期望
设总体的均值为 $\mu$、方差为 $\sigma^2$，则
$$E(\bar X)=\mu,\qquad\operatorname{Var}(\bar X)=\frac{\sigma^2}n,\qquad E(S^2)=\sigma^2.$$
这三条对 **任何** 方差存在的总体都成立。
:::

::: proof 证明 $E(S^2)=\sigma^2$
利用“[分布特征的描述](/descriptive/measures)”一章的恒等式 $\sum(X_i-\mu)^2=\sum(X_i-\bar X)^2+n(\bar X-\mu)^2$，取期望：
$$n\sigma^2=E\sum(X_i-\bar X)^2+n\cdot\frac{\sigma^2}n,$$
所以 $E\sum(X_i-\bar X)^2=(n-1)\sigma^2$，除以 $n-1$ 即得。可以看到，以 $\bar X$ 代替未知的 $\mu$，偏差平方和平均少了一个 $\sigma^2$——这正是分母要用 $n-1$ 的原因。
:::

::: quiz 0.4
总体 $X$ 的方差为 4，从中抽取容量为 10 的样本。样本均值的方差是多少？
> $\operatorname{Var}(\bar X)=\sigma^2/n=4/10=0.4$，标准差约 0.632。样本量增大到 40，标准差才减半。
:::

## 三大抽样分布 {.core}

来自正态总体的样本，许多统计量的分布可以精确地求出。它们都由三个基本分布构成。

::: core $\chi^2$ 分布
设 $Z_1,\dots,Z_n$ 独立同分布于 $N(0,1)$，则
$$\chi^2=Z_1^2+Z_2^2+\cdots+Z_n^2$$
服从自由度为 $n$ 的 **卡方分布** $\chi^2(n)$。$E(\chi^2)=n$，$\operatorname{Var}(\chi^2)=2n$；它就是 $\mathrm{Ga}(n/2,1/2)$；具有可加性：独立时 $\chi^2(m)+\chi^2(n)=\chi^2(m+n)$。
:::

::: geo 几何直观：卡方是距离的平方
$(Z_1,\dots,Z_n)$ 是 $n$ 维空间中的一个随机点，它的分布 **关于原点旋转对称**（联合密度只依赖于到原点的距离 $\sqrt{\sum z_i^2}$）。$\chi^2(n)$ 就是这个随机点到原点 **距离的平方**。维数越高，随机点越倾向于远离原点，平均距离平方恰为 $n$——每个维度贡献 1。“自由度”就是这个点能自由活动的维数。
:::

::: core $t$ 分布
设 $Z\sim N(0,1)$，$Y\sim\chi^2(n)$，二者独立，则
$$T=\frac{Z}{\sqrt{Y/n}}$$
服从自由度为 $n$ 的 **$t$ 分布** $t(n)$。它关于 0 对称，尾部比标准正态厚；$n\to\infty$ 时趋于 $N(0,1)$；$n=1$ 时就是柯西分布。
:::

::: core $F$ 分布
设 $Y_1\sim\chi^2(m)$，$Y_2\sim\chi^2(n)$，二者独立，则
$$F=\frac{Y_1/m}{Y_2/n}$$
服从自由度为 $(m,n)$ 的 **$F$ 分布** $F(m,n)$。由定义立刻得到：$1/F\sim F(n,m)$；若 $T\sim t(n)$，则 $T^2\sim F(1,n)$。查表时常用 $F_{\alpha}(m,n)=\dfrac{1}{F_{1-\alpha}(n,m)}$。
:::

3. 选 $F$，固定 $m=5$，把分母自由度 $n$ 增大，分布的中心向哪里靠拢？

::: insight $t$ 分布的厚尾从哪里来
$T=Z/\sqrt{Y/n}$ 的分母也是随机的。$Y/n$ 的期望是 1，但它有时会偏小——这时 $T$ 被放大，跑到尾部。自由度越小，$Y/n$ 波动越大，尾部越厚。在统计中，分母就是用样本估计出来的标准差：$t$ 分布的厚尾，是 **“标准差也要估计”带来的额外不确定性**。
:::

## 正态总体的抽样定理 {.hard}

::: core 定理（正态总体的样本均值与样本方差）
设 $X_1,\dots,X_n$ 是来自 $N(\mu,\sigma^2)$ 的样本，则
1. $\bar X\sim N\Big(\mu,\ \dfrac{\sigma^2}n\Big)$；
2. $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$；
3. $\bar X$ 与 $S^2$ **相互独立**；
4. $T=\dfrac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)$。
:::

第 4 条由前三条和 $t$ 分布的定义立即得到：$\frac{\bar X-\mu}{\sigma/\sqrt n}\sim N(0,1)$，除以独立的 $\sqrt{\chi^2(n-1)/(n-1)}=S/\sigma$，$\sigma$ 恰好约掉。这就是“[区间估计](/inference/interval)”与“[假设检验](/inference/testing)”两章中 $t$ 区间、$t$ 检验的理论基础。

为什么 $S^2$ 的自由度是 $n-1$？为什么 $\bar X$ 与 $S^2$ 独立？几何图像会让答案一目了然。

::: geo 几何直观：投影与它的正交补
把样本 $\boldsymbol x=(x_1,\dots,x_n)$ 看成 $n$ 维空间中的一个向量，$\boldsymbol 1=(1,\dots,1)$ 是“对角线”方向。

- $\boldsymbol x$ 在 $\boldsymbol 1$ 方向上的 **正交投影** 恰好是 $\bar x\,\boldsymbol 1$：均值就是投影的系数；
- 剩下的 **残差** $\boldsymbol x-\bar x\boldsymbol 1=(x_1-\bar x,\dots,x_n-\bar x)$ 与 $\boldsymbol 1$ 垂直，它落在一个 $n-1$ 维的子空间里；它长度的平方正是 $\sum(x_i-\bar x)^2=(n-1)s^2$；
- 勾股定理：$\|\boldsymbol x\|^2=n\bar x^2+\sum(x_i-\bar x)^2$。

现在设样本来自 $N(\mu,\sigma^2)$。$\boldsymbol x-\mu\boldsymbol 1$ 的分布是 **旋转对称** 的。把坐标系旋转，使第一根坐标轴对准 $\boldsymbol 1$ 的方向：新坐标仍然是独立的正态变量（旋转不改变旋转对称的分布）。第一个新坐标只与 $\bar x$ 有关，其余 $n-1$ 个新坐标只与残差有关，所以

- $\bar X$ 与残差 **独立**，从而与 $S^2$ 独立；
- 残差的长度平方是 $n-1$ 个独立 $N(0,\sigma^2)$ 的平方和，所以 $(n-1)S^2/\sigma^2\sim\chi^2(n-1)$。

**自由度就是残差能够自由活动的维数**：$n$ 维空间减掉均值占用的那 1 维。
:::

:::: l2 进阶：两个正态总体的抽样分布
设 $X_1,\dots,X_m$ 来自 $N(\mu_1,\sigma_1^2)$，$Y_1,\dots,Y_n$ 来自 $N(\mu_2,\sigma_2^2)$，两样本独立，则

- $\dfrac{S_x^2/\sigma_1^2}{S_y^2/\sigma_2^2}\sim F(m-1,n-1)$；
- 若 $\sigma_1^2=\sigma_2^2=\sigma^2$，记 $S_w^2=\dfrac{(m-1)S_x^2+(n-1)S_y^2}{m+n-2}$，则
$$\frac{(\bar X-\bar Y)-(\mu_1-\mu_2)}{S_w\sqrt{\frac1m+\frac1n}}\sim t(m+n-2).$$

它们是比较两个总体的方差和均值时（两样本 $F$ 检验、$t$ 检验）所用的抽样分布。

## 次序统计量 {.key}

::: core 次序统计量的分布
设总体有密度 $p(x)$、分布函数 $F(x)$，则第 $k$ 个次序统计量 $X_{(k)}$ 的密度为
$$p_k(x)=\frac{n!}{(k-1)!\,(n-k)!}\,[F(x)]^{k-1}\,[1-F(x)]^{n-k}\,p(x).$$
特别地，最大值 $X_{(n)}$ 的分布函数为 $[F(x)]^n$，最小值 $X_{(1)}$ 的为 $1-[1-F(x)]^n$。
:::

::: geo 几何直观：多项式计数
要让第 $k$ 小的值恰好落在 $x$ 附近的一小段 $[x,x+\mathrm dx]$ 里，需要：$k-1$ 个观测值落在 $x$ 左边（每个概率 $F(x)$），1 个落在这一小段里（概率 $p(x)\mathrm dx$），$n-k$ 个落在右边（每个概率 $1-F(x)$）。把这 $n$ 个观测值分到三组的方式有 $\frac{n!}{(k-1)!\,1!\,(n-k)!}$ 种，乘起来就是公式。
:::

例如来自 $U(0,1)$ 的样本，$X_{(k)}\sim\mathrm{Be}(k,\ n-k+1)$，$E(X_{(k)})=\frac k{n+1}$：$n$ 个均匀随机点平均地把区间分成 $n+1$ 段。

## 充分统计量 {.l3}

:::: l3 深入：充分统计量与因子分解定理
抛一枚硬币 $n$ 次估计正面概率 $p$，记录完整的正反面序列，和只记录正面的次数 $T=\sum X_i$，对推断 $p$ 来说有没有区别？没有：给定 $T=t$ 时，各种正反面序列是等可能的（每种的条件概率都是 $1/\binom nt$），与 $p$ 无关。序列中除了 $T$ 以外的信息，对 $p$ 而言只是“噪声”。

**定义**：若给定 $T$ 时样本的条件分布与参数 $\theta$ 无关，则称 $T$ 为 $\theta$ 的 **充分统计量**。

**因子分解定理**：$T$ 是充分统计量，当且仅当样本的联合密度（或分布列）可以分解为
$$p(x_1,\dots,x_n;\theta)=g\big(T(x_1,\dots,x_n);\theta\big)\cdot h(x_1,\dots,x_n),$$
其中 $h$ 不含 $\theta$。例如：

- 两点分布：$p^{\sum x_i}(1-p)^{n-\sum x_i}$，$T=\sum X_i$ 充分；
- 正态 $N(\mu,\sigma^2)$：联合密度只通过 $\sum x_i$ 和 $\sum x_i^2$ 依赖参数，$(\bar X,S^2)$ 充分；
- 均匀 $U(0,\theta)$：联合密度为 $\theta^{-n}\,I\{x_{(n)}\le\theta\}$，最大值 $X_{(n)}$ 充分。

充分统计量是对数据的 **无损压缩**：只保留它，关于参数的信息一点也不丢。“[点估计](/inference/point-estimation)”一章的 Rao–Blackwell 定理会说明，好的估计量应当只依赖于充分统计量。
::::

## 本章小结

- **样本** 是独立同分布的随机变量；**统计量** 是不含未知参数的样本函数；统计量的分布是 **抽样分布**。
- $E(\bar X)=\mu$，$\operatorname{Var}(\bar X)=\sigma^2/n$，$E(S^2)=\sigma^2$——对任意总体成立。
- **三大分布**：$\chi^2$ 是标准正态向量长度的平方；$t=Z/\sqrt{\chi^2/n}$ 的厚尾来自“标准差也要估计”；$F$ 是两个 $\chi^2$（除以自由度）之比。
- **正态总体抽样定理**：$\bar X$ 与 $S^2$ 独立，$(n-1)S^2/\sigma^2\sim\chi^2(n-1)$，$T\sim t(n-1)$；几何上是投影与正交补，自由度是残差的维数。
- **次序统计量** 的密度由多项式计数得到；**充分统计量** 是无损的数据压缩。

| 统计量 | 条件 | 分布 |
| --- | --- | --- |
| $\dfrac{\bar X-\mu}{\sigma/\sqrt n}$ | 正态总体，$\sigma$ 已知 | $N(0,1)$ |
| $\dfrac{(n-1)S^2}{\sigma^2}$ | 正态总体 | $\chi^2(n-1)$ |
| $\dfrac{\bar X-\mu}{S/\sqrt n}$ | 正态总体 | $t(n-1)$ |
| $\dfrac{S_x^2/\sigma_1^2}{S_y^2/\sigma_2^2}$ | 两个独立正态总体 | $F(m-1,n-1)$ |
| $\dfrac{\bar X-\mu}{S/\sqrt n}$ | 任意总体，$n$ 大 | 近似 $N(0,1)$ |

## 分层练习

### 基础

**1.** 设总体 $X\sim N(10,4)$，样本容量 $n=16$。求 $P(\bar X>11)$。

::: details 解答
$\bar X\sim N(10,4/16)=N(10,0.25)$，标准差 0.5。$P(\bar X>11)=1-\Phi(2)\approx0.0228$。
:::

**2.** 查表或用软件求：$\chi^2_{0.95}(10)$、$t_{0.975}(15)$、$F_{0.95}(4,10)$，并利用关系式求 $F_{0.05}(10,4)$。

::: details 解答
$\chi^2_{0.95}(10)\approx18.307$，$t_{0.975}(15)\approx2.131$，$F_{0.95}(4,10)\approx3.478$。$F_{0.05}(10,4)=1/F_{0.95}(4,10)\approx0.2875$。
:::

**3.** 设 $X_1,\dots,X_5$ 来自 $N(0,1)$。$Y=X_1^2+X_2^2$ 与 $\dfrac{X_1}{\sqrt{(X_2^2+X_3^2+X_4^2)/3}}$ 各服从什么分布？

::: details 解答
$Y\sim\chi^2(2)$（即均值为 2 的指数分布）。第二个统计量是 $N(0,1)$ 除以独立的 $\sqrt{\chi^2(3)/3}$，服从 $t(3)$。
:::

### 提高

**4.** 设 $X_1,\dots,X_n$ 来自 $N(\mu,\sigma^2)$，$n=16$，$\sigma^2$ 未知。求 $P\Big(\dfrac{S^2}{\sigma^2}\le1.666\Big)$。

::: details 解答
$\frac{15S^2}{\sigma^2}\sim\chi^2(15)$，所求概率为 $P(\chi^2(15)\le24.99)\approx0.95$（$\chi^2_{0.95}(15)=24.996$）。即样本方差比总体方差大 66.6% 以上的概率只有约 5%。
:::

**5.** 设 $X_1,\dots,X_n$ 来自 $U(0,\theta)$。求 $X_{(n)}$ 的密度、期望，并说明 $\frac{n+1}nX_{(n)}$ 是 $\theta$ 的无偏估计。

::: details 解答
$F_{X_{(n)}}(x)=(x/\theta)^n$，$p(x)=\frac{nx^{n-1}}{\theta^n}$（$0<x<\theta$），$E(X_{(n)})=\frac{n}{n+1}\theta$。所以 $E\big(\frac{n+1}nX_{(n)}\big)=\theta$。最大观测值总是低估 $\theta$，乘以 $\frac{n+1}n$ 恰好修正了这个偏差。
:::

**6.** 证明：若 $T\sim t(n)$，则 $T^2\sim F(1,n)$。

::: details 解答
$T=Z/\sqrt{Y/n}$，$T^2=\frac{Z^2/1}{Y/n}$，其中 $Z^2\sim\chi^2(1)$ 与 $Y\sim\chi^2(n)$ 独立，由 $F$ 分布的定义 $T^2\sim F(1,n)$。这说明双侧 $t$ 检验与 $F$ 检验在单个参数的情形下是等价的。
:::

### 挑战

**7.** 设 $X_1,\dots,X_n$ 来自 $N(0,1)$。用旋转（正交变换）的论证证明：$\bar X$ 与 $\sum(X_i-\bar X)^2$ 独立，且 $\sum(X_i-\bar X)^2\sim\chi^2(n-1)$。

::: details 解答
取正交矩阵 $A$，第一行为 $\frac1{\sqrt n}(1,\dots,1)$（其余行由施密特正交化补全，如 Helmert 矩阵）。令 $\boldsymbol Y=A\boldsymbol X$。由于 $\boldsymbol X\sim N(\boldsymbol 0,I)$，$\boldsymbol Y\sim N(\boldsymbol 0,AA^\top)=N(\boldsymbol 0,I)$，即 $Y_1,\dots,Y_n$ 仍独立同分布于 $N(0,1)$。

$Y_1=\sqrt n\,\bar X$；正交变换保持长度，$\sum Y_i^2=\sum X_i^2$，所以
$$\sum_{i=2}^nY_i^2=\sum X_i^2-n\bar X^2=\sum(X_i-\bar X)^2.$$
左边只依赖于 $Y_2,\dots,Y_n$，与 $Y_1$ 独立，且是 $n-1$ 个独立标准正态的平方和，服从 $\chi^2(n-1)$。
:::

**8.** 用因子分解定理求泊松总体 $P(\lambda)$ 的参数 $\lambda$ 的充分统计量，并说明“只记录样本总和”为什么不损失信息。

::: details 解答
联合分布列 $\prod\frac{\lambda^{x_i}}{x_i!}e^{-\lambda}=\underbrace{\lambda^{\sum x_i}e^{-n\lambda}}_{g(\sum x_i;\lambda)}\cdot\underbrace{\frac1{\prod x_i!}}_{h(\boldsymbol x)}$，所以 $T=\sum X_i$ 是充分统计量。

给定 $T=t$ 时，$(X_1,\dots,X_n)$ 服从多项分布 $M(t;\frac1n,\dots,\frac1n)$，与 $\lambda$ 无关：知道了总数，总数在各次观测之间如何分配是“纯随机”的，不再含有 $\lambda$ 的信息。
:::

## 代码实现（Python）

::: details 展开代码：抽样分布的模拟与查表
```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(5)
n, R = 5, 200_000
X = rng.normal(10, 2, size=(R, n))            # 来自 N(10, 4) 的 R 个样本
xbar = X.mean(axis=1)
s2 = X.var(axis=1, ddof=1)

# 1. E(Xbar) = μ，Var(Xbar) = σ²/n，E(S²) = σ²
print("Xbar 的均值", xbar.mean().round(3), " 方差", xbar.var().round(3), "（理论 0.8）")
print("S2 的均值", s2.mean().round(3), "（理论 4）；以 n 为分母的均值", (s2 * (n - 1) / n).mean().round(3))

# 2. (n-1)S²/σ² ~ χ²(n-1)：比较分位数
q = np.quantile((n - 1) * s2 / 4, [0.1, 0.5, 0.9])
print("模拟分位数", q.round(3), " 理论", stats.chi2(n - 1).ppf([0.1, 0.5, 0.9]).round(3))

# 3. Xbar 与 S² 独立：相关系数接近 0（对指数总体则不然）
print("正态总体 Corr(Xbar, S2) =", np.corrcoef(xbar, s2)[0, 1].round(4))
E = rng.exponential(1, size=(R, n))
print("指数总体 Corr(Xbar, S2) =", np.corrcoef(E.mean(axis=1), E.var(axis=1, ddof=1))[0, 1].round(4))

# 4. 查表：三大分布的分位数
print(stats.chi2(10).ppf(0.95), stats.t(15).ppf(0.975), stats.f(4, 10).ppf(0.95))
```
:::

::: info 史话：“学生”与 t 分布
1908 年，在都柏林健力士啤酒厂工作的戈塞特发现：小样本时用 $\frac{\bar X-\mu}{S/\sqrt n}$ 查正态表，结论会过于乐观。他推导出了这个统计量的精确分布，因为公司不允许员工发表论文，他以笔名“学生”（Student）发表了结果。费希尔后来给出了严格的证明，并把它推广为今天的 $t$ 分布。$\chi^2$ 分布由赫尔默特（1876）和皮尔逊（1900）分别得到；$F$ 分布源自费希尔的方差比研究，斯内德克在 1934 年以费希尔名字的首字母将它命名为 $F$。
:::
