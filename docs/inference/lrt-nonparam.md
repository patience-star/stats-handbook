# 似然比检验与非参数检验

上一章的检验都建立在“总体服从正态分布”之上。可是：一颗骰子是否均匀，问的是整个分布是否符合假设；性别与偏好是否有关，涉及的是分类数据；数据是否服从正态分布，本身就需要检验；而当总体明显偏离正态、样本又很小时，$t$ 检验也不再可靠。

这一章介绍三类工具：构造检验的一般方法——**似然比检验**；检验分布与独立性的 **$\chi^2$ 检验** 及 **正态性检验**；不依赖总体分布形式的 **非参数检验**。

## 似然比检验 {.core}

::: core 似然比检验
设参数空间为 $\Theta$，原假设 $H_0:\theta\in\Theta_0$。称
$$\Lambda=\frac{\sup_{\theta\in\Theta_0}L(\theta)}{\sup_{\theta\in\Theta}L(\theta)}$$
为 **似然比**。它总在 0 与 1 之间：分子是“在 $H_0$ 的约束下数据能被解释得多好”，分母是“不加约束时能被解释得多好”。$\Lambda$ 越小，$H_0$ 越难以解释数据，所以 $\Lambda\le c$ 时拒绝 $H_0$。
:::

::: insight 用似然的高度差作检验
取对数，$-2\ln\Lambda=2\big[\ell(\hat\theta)-\ell(\hat\theta_0)\big]$ 是对数似然曲线上 **两个高度之差** 的两倍：无约束的最高点 $\hat\theta$，与 $H_0$ 范围内的最高点 $\hat\theta_0$。在“[点估计](/inference/point-estimation)”一章的似然实验中，阴影区间就是所有“与峰顶高度差不超过 1.92”的参数值——它们正是似然比检验在 $\alpha=0.05$ 下不会拒绝的参数值，因为 $2\times1.92=3.84=\chi^2_{0.95}(1)$。似然比检验与似然比置信区间是同一枚硬币的两面。
:::

:::: l2 进阶：Wilks 定理
对正态均值（$\sigma$ 已知），$-2\ln\Lambda=\frac{n(\bar x-\mu_0)^2}{\sigma^2}=u^2$，似然比检验恰好就是 $u$ 检验。一般情况下，似然比的精确分布难以求出，但有一个普适的大样本结论——**Wilks 定理**：在正则条件下，$H_0$ 成立时
$$-2\ln\Lambda\ \xrightarrow{L}\ \chi^2(k),$$
其中 $k$ 是 $H_0$ 比 $H_1$ 少的自由参数个数。这使得似然比检验可以用于几乎任何参数模型：广义线性模型中的“偏差分析”、模型选择中的嵌套模型比较，都基于这条定理。
::::

## 分布拟合检验 {.core}

### 皮尔逊 $\chi^2$ 拟合优度检验

::: core $\chi^2$ 拟合优度检验
把数据分成 $k$ 类，第 $i$ 类的观测频数为 $O_i$；在 $H_0$ 所假设的分布下，期望频数为 $E_i=np_i$。统计量
$$\chi^2=\sum_{i=1}^k\frac{(O_i-E_i)^2}{E_i}$$
在 $H_0$ 下近似服从 $\chi^2(k-1-r)$，其中 $r$ 是用样本估计的未知参数个数。$\chi^2$ 越大，观测与期望差别越大，所以 $\chi^2\ge\chi^2_{1-\alpha}(k-1-r)$ 时拒绝 $H_0$。一般要求每类的期望频数不小于 5，否则应合并相邻的类。
:::

::: example 例 1　骰子是否均匀
掷一颗骰子 120 次，1～6 点分别出现 25、17、15、23、24、16 次。这颗骰子是否均匀（$\alpha=0.05$）？

**解** $H_0$：每面的概率都是 $1/6$，期望频数各为 20。
$$\chi^2=\frac{5^2+3^2+5^2+3^2+4^2+4^2}{20}=\frac{100}{20}=5.0.$$
自由度为 $6-1=5$，$\chi^2_{0.95}(5)=11.07$，不拒绝 $H_0$（p 值约 0.42）。看上去差别不小的频数，其实完全在随机波动的范围之内。
:::

::: insight 为什么除以 $E_i$
同样差 5 次，期望 20 次时差了 25%，期望 1000 次时只差 0.5%。除以 $E_i$ 是在“标准化”：在 $H_0$ 下 $O_i$ 近似服从均值为 $E_i$、方差约为 $E_i$ 的分布（泊松近似），所以 $\frac{O_i-E_i}{\sqrt{E_i}}$ 近似是标准正态，平方后相加就近似是卡方。自由度少 1，是因为 $\sum O_i=\sum E_i=n$ 这个约束让各项并不完全自由。
:::

### 列联表的独立性检验 {.key}

两个分类变量是否独立？把数据整理成 $r\times c$ 的 **列联表**，在独立的假设下，第 $(i,j)$ 格的期望频数为
$$E_{ij}=\frac{(\text{第 }i\text{ 行合计})\times(\text{第 }j\text{ 列合计})}{n},\qquad\chi^2=\sum_{i,j}\frac{(O_{ij}-E_{ij})^2}{E_{ij}}\sim\chi^2\big((r-1)(c-1)\big).$$

::: example 例 2　性别与产品偏好
调查 200 名顾客对某产品的态度：

| | 喜欢 | 不喜欢 | 合计 |
| --- | --- | --- | --- |
| 男 | 60 | 40 | 100 |
| 女 | 45 | 55 | 100 |
| 合计 | 105 | 95 | 200 |

**解** 独立时各格的期望频数：喜欢一列为 $100\times105/200=52.5$，不喜欢一列为 47.5。
$$\chi^2=2\Big(\frac{7.5^2}{52.5}+\frac{7.5^2}{47.5}\Big)\approx4.51>\chi^2_{0.95}(1)=3.84,$$
拒绝“性别与偏好独立”的假设（p 值约 0.034）。注意：$\chi^2$ 检验只说明二者 **有关联**，不说明关联的方向和强弱，更不说明因果。
:::

::: quiz 8 0
一张 $3\times5$ 的列联表做独立性检验，$\chi^2$ 统计量的自由度是多少？
> $(3-1)\times(5-1)=8$。
:::

## 正态性检验 {.key}

$t$ 检验、方差分析、回归分析都假定误差服从正态分布。怎样检验这个假定？

::: core 正态概率图（QQ 图）
把样本排序 $x_{(1)}\le\cdots\le x_{(n)}$，与标准正态分布的相应分位数 $q_i=\Phi^{-1}\big(\frac{i-0.375}{n+0.25}\big)$ 配对画点。若样本来自正态总体 $N(\mu,\sigma^2)$，则 $x_{(i)}\approx\mu+\sigma q_i$，点近似落在一条直线上，直线的截距和斜率分别估计 $\mu$ 和 $\sigma$。
:::

<QQLab />

**试一试**

1. 依次选五种总体，记住各自的形状：直线、反 S、上弯、S、中间平台。
2. 选正态总体，把 $n$ 调到 10，多抽几次：即使总体是正态的，点也会偏离直线多少？
3. 选 $t(3)$，把 $n$ 从 30 增大到 300，$r^2$ 怎样变化？大样本时，正态性检验会变得“非常敏感”。

::: insight W 检验的几何意义
Shapiro–Wilk 的 W 检验是最常用的正态性检验，它的统计量本质上是 QQ 图中点的 **相关系数的平方**（精确的 W 用了更细致的加权）：点越接近直线，W 越接近 1；W 显著小于 1 就拒绝正态性。所以 W 检验就是把“看 QQ 图是不是直线”这件事数量化了。

实践中两者应配合使用：小样本时检验的功效很低，图形更有帮助；大样本时检验会把微不足道的偏离判为“显著”，而 $t$ 检验等方法在大样本下本来就对轻微的非正态不敏感（中心极限定理）。
:::

## 非参数检验 {.core}

当总体分布未知、明显非正态，或者数据本身只是等级（定序数据）时，可以使用 **不依赖总体分布形式** 的检验方法，称为 **非参数检验**。它们大多只利用数据的 **符号** 或 **秩**。

### 符号检验

成对数据中，只看每对差值的 **正负号**。若两种处理没有差别，每个差值为正的概率都是 1/2，正号的个数服从 $b(n,1/2)$。

::: example 例 3　品尝试验
10 名品尝者比较两种饮料，8 人更喜欢新配方，2 人更喜欢老配方。新配方是否更受欢迎？

**解** $H_0$：两种配方受欢迎程度相同。正号个数 $S\sim b(10,0.5)$，$P(S\ge8)=\frac{45+10+1}{1024}\approx0.055$（单侧），双侧 p 值约 0.109。在 $\alpha=0.05$ 下证据还不够——10 个人太少了。
:::

### 秩和检验 {.key}

::: core 威尔科克森秩和检验
两个独立样本，容量分别为 $n_1,n_2$。把全部 $N=n_1+n_2$ 个数据混合后从小到大排序，每个数据的名次称为 **秩**。第一个样本的秩之和 $W$ 在“两总体分布相同”的 $H_0$ 下，有
$$E(W)=\frac{n_1(N+1)}2,\qquad\operatorname{Var}(W)=\frac{n_1n_2(N+1)}{12}.$$
$W$ 过大或过小都说明两组数据有系统的位置差别。小样本时可以精确计算 $W$ 的分布，大样本时用正态近似。（它与 Mann–Whitney $U$ 检验等价：$U=W-\frac{n_1(n_1+1)}2$。）
:::

::: geo 几何直观：所有分法一样可能
在 $H_0$ 下，两组数据来自同一个总体，“哪些数据属于第一组”完全是随机的：$N$ 个秩随机地分给两组，$\binom N{n_1}$ 种分法都等可能。把每种分法下的 $W$ 都算出来，就得到 $W$ 的 **置换分布**；观测到的分法若落在这个分布的极端位置，就说明“随机分组”的解释不太可信。这里没有用到总体分布的任何形式——这就是“非参数”的含义。
:::

<RankPermutation />

**试一试**

1. 把移动量调到 0，多生成几次：观测的 $W$ 在置换分布的什么位置？p 值大约多大？
2. 把移动量调到 2：$W$ 落到了分布的边缘，p 值变得很小。
3. 勾选“柯西分布”，多生成几次，比较秩和检验与 $t$ 检验的 p 值。为什么一个极端值能“毁掉” $t$ 检验，却对秩和检验影响很小？

::: example 例 4　两组反应时间
A 组 6 人的反应时间（秒）为 12.1、13.5、11.8、14.2、12.9、13.1，B 组 6 人为 14.5、15.2、13.8、16.1、14.9、15.7。两组是否有差别？

**解** 混合排序后，A 组的秩为 1、2、3、4、5、7，$W=22$。$E(W)=39$，$\operatorname{Var}(W)=39$。在 924 种等可能的分法中，$W\le22$ 的只有两种（秩和为 21 的 $\{1,\dots,6\}$ 与秩和为 22 的这一种），精确双侧 p 值 $=2\times2/924\approx0.0043$，拒绝 $H_0$。正态近似给出 $z=\frac{22-39}{\sqrt{39}}\approx-2.72$，p 值约 0.0065，相差不大。
:::

::: insight 非参数方法的代价与回报
秩检验丢掉了数据的具体数值，只保留顺序，看起来损失了信息。但令人惊讶的是：当总体确实是正态分布时，秩和检验相对于 $t$ 检验的 **渐近效率** 约为 $3/\pi\approx95.5\%$——几乎没有损失；而当总体厚尾或有离群值时，它可以比 $t$ 检验有效得多。这种“小代价、大保险”的性质，使秩方法成为数据分布可疑时的首选。
:::

:::: l3 深入：柯尔莫哥洛夫–斯米尔诺夫检验
检验样本是否来自某个完全确定的连续分布 $F_0$，可以直接比较经验分布函数与 $F_0$：
$$D_n=\sup_x\big|F_n(x)-F_0(x)\big|.$$
$H_0$ 下 $D_n$ 的分布与 $F_0$ 无关（由概率积分变换，$F_0(X)\sim U(0,1)$），并且 $\sqrt nD_n$ 有已知的极限分布。几何上，它是两条“阶梯—曲线”之间最大的竖直距离。K-S 检验的缺点是对分布中部的差异敏感、对尾部不敏感；若 $F_0$ 中的参数由样本估计，分布会改变，需要用修正的版本（如 Lilliefors 检验）。
::::

## 本章小结

- **似然比检验**：比较“有约束”与“无约束”的最大似然；Wilks 定理给出 $-2\ln\Lambda\to\chi^2(k)$。
- **$\chi^2$ 拟合优度检验**：$\sum(O-E)^2/E$，自由度 $k-1-r$；**列联表独立性检验** 的自由度为 $(r-1)(c-1)$。期望频数不宜小于 5。
- **正态性检验**：QQ 图看形状，W 检验把“是否为直线”数量化；小样本看图、大样本慎用检验。
- **非参数检验**：符号检验只用正负号，秩和检验只用秩；置换分布不依赖总体形式；对离群值稳健，对正态数据损失很小。

| 检验 | 用途 | 统计量 | 分布 |
| --- | --- | --- | --- |
| 似然比检验 | 一般参数假设 | $-2\ln\Lambda$ | 近似 $\chi^2(k)$ |
| 拟合优度检验 | 分布是否符合假设 | $\sum(O_i-E_i)^2/E_i$ | 近似 $\chi^2(k-1-r)$ |
| 独立性检验 | 两个分类变量是否独立 | $\sum(O_{ij}-E_{ij})^2/E_{ij}$ | 近似 $\chi^2((r-1)(c-1))$ |
| 符号检验 | 成对数据的位置差异 | 正号个数 | $b(n,1/2)$ |
| 秩和检验 | 两组数据的位置差异 | 秩和 $W$ | 置换分布或正态近似 |

## 分层练习

### 基础

**1.** 某路口一周内每天的交通事故数为 3、5、2、4、6、8、7，合计 35 起。能否认为事故在一周七天中是均匀发生的（$\alpha=0.05$）？

::: details 解答
期望各为 5。$\chi^2=\frac{4+0+9+1+1+9+4}{5}=5.6$，自由度 6，$\chi^2_{0.95}(6)=12.59$，不拒绝均匀发生的假设。
:::

**2.** 例 2 中若把调查人数扩大 10 倍、各格频数按比例变为 600、400、450、550，$\chi^2$ 会变成多少？这说明了什么？

::: details 解答
各项 $(O-E)^2/E$ 都扩大 10 倍，$\chi^2\approx45.1$，p 值极小。比例关系完全相同，样本越大，检验越“显著”。$\chi^2$ 的大小同时反映了关联的强度和样本量，要衡量关联强度，应使用 $\varphi$ 系数或列联系数等指标，它们不随样本量变化。
:::

**3.** 15 对数据中，差值为正的有 11 对、为负的有 4 对。用符号检验（双侧）判断两种处理是否有差异（$\alpha=0.05$）。

::: details 解答
$S\sim b(15,0.5)$。$P(S\ge11)=\frac{\binom{15}{11}+\binom{15}{12}+\binom{15}{13}+\binom{15}{14}+\binom{15}{15}}{2^{15}}=\frac{1365+455+105+15+1}{32768}\approx0.059$，双侧 p 值约 0.118，不拒绝。
:::

### 提高

**4.** 某城市对 400 户家庭调查子女数，结果为：0 个 120 户，1 个 160 户，2 个 90 户，3 个及以上 30 户。能否认为子女数服从泊松分布？（提示：用样本均值估计 $\lambda$，“3 个及以上”按 3 计算均值。）

::: details 解答
$\hat\lambda=\frac{0\times120+1\times160+2\times90+3\times30}{400}=1.075$。泊松概率：$P(0)\approx0.341$，$P(1)\approx0.367$，$P(2)\approx0.197$，$P(\ge3)\approx0.095$；期望频数约 136.5、146.8、78.9、37.9。
$$\chi^2\approx\frac{16.5^2}{136.5}+\frac{13.2^2}{146.8}+\frac{11.1^2}{78.9}+\frac{7.9^2}{37.9}\approx2.0+1.2+1.6+1.6=6.4.$$
自由度 $4-1-1=2$（估计了一个参数），$\chi^2_{0.95}(2)=5.99$，拒绝泊松分布的假设：实际家庭中“1 个孩子”比泊松模型预测的更集中，离散程度更小。
:::

**5.** 证明：对正态总体的均值（$\sigma$ 已知），似然比检验与 $u$ 检验等价。

::: details 解答
无约束时 $\hat\mu=\bar x$；$H_0$ 下 $\mu=\mu_0$。
$$-2\ln\Lambda=\frac1{\sigma^2}\Big[\sum(x_i-\mu_0)^2-\sum(x_i-\bar x)^2\Big]=\frac{n(\bar x-\mu_0)^2}{\sigma^2}=u^2.$$
“$\Lambda$ 小”等价于“$|u|$ 大”，所以两者是同一个检验，且 $u^2\sim\chi^2(1)$ 是精确的（不需要大样本）。
:::

### 挑战

**6.** 秩和检验中，$n_1=n_2=6$。不查表，计算 $P(W\le23)$，并说明它与 $\binom{12}6=924$ 的关系。

::: details 解答
秩和最小为 $1+2+\cdots+6=21$。$W=21$ 只有一种取法；$W=22$ 只有 $\{1,2,3,4,5,7\}$ 一种；$W=23$ 有 $\{1,2,3,4,5,8\}$ 和 $\{1,2,3,4,6,7\}$ 两种。所以 $P(W\le23)=4/924\approx0.0043$。置换检验的 p 值就是“比观测更极端的分法数 ÷ 全部分法数”。
:::

**7.** 为什么说 W 检验与 QQ 图本质上是同一件事？设计一个数值实验说明大样本时正态性检验“过于敏感”。

::: details 解答
W 统计量度量排序样本与正态期望次序统计量之间的线性程度，近似等于 QQ 图中点的相关系数的平方，所以“W 接近 1”就是“QQ 图接近直线”。

数值实验：从 $t(30)$ 分布中抽取 $n=5000$ 个数据（它与正态分布非常接近，对 $t$ 检验毫无影响），做正态性检验，常常会得到很小的 p 值。可以用下面的代码验证。这说明正态性检验只回答“是否 **精确地** 正态”，而实践需要的是“是否 **足够** 正态”。
:::

## 代码实现（Python）

::: details 展开代码：χ² 检验、正态性检验与非参数检验
```python
import numpy as np
from scipy import stats

# 例 1：拟合优度检验
print(stats.chisquare([25, 17, 15, 23, 24, 16]))

# 例 2：列联表独立性检验（2×2 表默认做连续性修正，这里关掉以对照正文）
res = stats.chi2_contingency([[60, 40], [45, 55]], correction=False)
print("chi2 =", round(res.statistic, 3), " p =", round(res.pvalue, 4), " 期望频数：", res.expected_freq)

# 例 3：符号检验就是二项检验
print("符号检验 p 值：", stats.binomtest(8, 10, 0.5).pvalue)

# 例 4：秩和检验（Mann-Whitney U，精确分布）
A = [12.1, 13.5, 11.8, 14.2, 12.9, 13.1]
B = [14.5, 15.2, 13.8, 16.1, 14.9, 15.7]
print(stats.mannwhitneyu(A, B, alternative="two-sided", method="exact"))

# 正态性检验：小样本的功效与大样本的“过于敏感”
rng = np.random.default_rng(0)
print("n = 20，t(3) 样本的 Shapiro-Wilk p 值：", stats.shapiro(rng.standard_t(3, 20)).pvalue.round(3))
print("n = 5000，t(30) 样本的 Shapiro-Wilk p 值：", stats.shapiro(rng.standard_t(30, 5000)).pvalue.round(4))
```

::: info 史话：皮尔逊的 χ² 与费希尔的自由度
1900 年，卡尔·皮尔逊提出 $\chi^2$ 拟合优度检验，被认为是现代统计学的开端之一。但他在用估计参数计算期望频数时，没有相应地减少自由度。1922—1924 年，年轻的费希尔指出了这个错误，提出了自由度的正确算法，两人从此结怨。非参数方法的发展则晚得多：威尔科克森在 1945 年提出秩和检验，Mann 与 Whitney 在 1947 年给出了等价的 $U$ 检验；1956 年西格尔的《行为科学的非参数统计》使这些方法在社会科学中广为流行。
:::
