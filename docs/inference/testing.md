# 假设检验

20 世纪 20 年代的一个下午，剑桥的几位学者在喝下午茶。一位女士说，她能尝出一杯奶茶是先倒茶还是先倒奶。在座的人大多不以为然，费希尔却设计了一个试验：准备 8 杯奶茶，4 杯先倒奶、4 杯先倒茶，随机排列后请她辨别。

如果她其实分辨不出、只是瞎猜，把 4 杯“先倒奶”全部挑对的概率只有 $1/\binom84=1/70\approx0.014$。所以一旦她全部挑对，我们就有理由相信她确实有这个本事——这就是 **假设检验** 的基本逻辑：**先假定“没有效果”，再看数据在这个假定下是否太不寻常**。

## 基本思想 {.core}

::: core 原假设、备择假设与检验的逻辑
- **原假设** $H_0$：通常是“没有差异”“没有效果”的保守陈述，如“她是瞎猜的”“新工艺不改变平均产量”；
- **备择假设** $H_1$：与原假设对立、研究者希望证实的陈述。

检验的逻辑是一种 **带概率的反证法**：假定 $H_0$ 成立，计算观测到的数据（或更极端的数据）出现的概率。如果这个概率很小，就说明“$H_0$ 成立”与数据相矛盾，从而 **拒绝** $H_0$。它所依据的是 **小概率原理**：概率很小的事件，在一次试验中几乎不会发生。
:::

::: core 检验统计量、拒绝域与显著性水平
- **检验统计量**：用来作判断的统计量，它在 $H_0$ 下的分布已知；
- **拒绝域** $W$：检验统计量落入其中就拒绝 $H_0$ 的取值范围；
- **显著性水平** $\alpha$：事先规定的“小概率”的标准，常取 0.05、0.01。拒绝域要使 $H_0$ 为真时统计量落入其中的概率不超过 $\alpha$。
:::

## 两类错误 {.hard}

用样本作判断，总有犯错的可能：

| | $H_0$ 为真 | $H_0$ 为假 |
| --- | --- | --- |
| 拒绝 $H_0$ | **第一类错误**（拒真），概率 $\alpha$ | 正确（功效 $1-\beta$） |
| 不拒绝 $H_0$ | 正确 | **第二类错误**（取伪），概率 $\beta$ |

::: core 功效函数
检验拒绝 $H_0$ 的概率作为参数 $\theta$ 的函数，$g(\theta)=P_\theta(\text{拒绝}H_0)$，称为 **功效函数**。$\theta\in H_0$ 时它是犯第一类错误的概率；$\theta\in H_1$ 时它是 **功效** $1-\beta(\theta)$。
:::

::: geo 几何直观：两条曲线与一条线
以检验 $H_0:\mu=0$ 为例。$H_0$ 为真时，样本均值 $\bar X$ 的分布是一条以 0 为中心的钟形曲线；真实均值为 $\mu_1$ 时，是一条以 $\mu_1$ 为中心的钟形曲线。拒绝域由一条 **临界线** 划定：

- 临界线右侧、$H_0$ 曲线下的面积是 $\alpha$；
- 临界线左侧、$H_1$ 曲线下的面积是 $\beta$。

把临界线右移，$\alpha$ 变小、$\beta$ 变大；左移则相反——**样本量固定时，两类错误不能同时减小**。要同时减小，只能增大样本量：两条曲线的宽度 $\sigma/\sqrt n$ 随之缩小，彼此分得更开，重叠部分减少。
:::

<ErrorTradeoff />

**试一试**

1. 固定 $n=16$、$\mu=0.5$，把 $\alpha$ 从 0.05 降到 0.01，$\beta$ 怎样变化？
2. 固定 $\alpha=0.05$，把 $n$ 从 16 增大到 64，功效从多少变成多少？
3. 把真实均值 $\mu$ 拖到 0：此时 $H_0$ 为真，功效函数的值是多少？把 $\mu$ 拖到负值，单侧检验和双侧检验的表现有什么不同？

::: insight 为什么要“保护”原假设
检验的规则是：先把 $\alpha$ 控制在一个小的水平，再尽量提高功效。两类错误的地位并不对称：$\alpha$ 是 **被严格控制** 的，$\beta$ 则 **只能尽量减小**。所以原假设应当放那个“犯错代价更大、需要严格防止误判”的陈述。法庭上“无罪推定”就是这种思想：$H_0$ 是“被告无罪”，冤枉好人（第一类错误）要被严格控制；证据不足时只能“不定罪”，而不是“证明了无罪”。
:::

::: pitfall “不拒绝”不等于“接受”
没有拒绝 $H_0$，只说明 **证据不足以推翻它**，并不证明 $H_0$ 是对的。样本量小、功效低时，即使 $H_0$ 是错的，也常常拒绝不了。所以结论应写成“在 $\alpha=0.05$ 下，没有足够证据表明……”，而不是“证明了……没有差异”。
:::

## p 值 {.core}

::: core p 值
在 $H_0$ 成立的前提下，检验统计量取到 **观测值或比观测值更极端的值** 的概率，称为 **p 值**。若 $p\le\alpha$，则在水平 $\alpha$ 下拒绝 $H_0$。
:::

p 值把“是否拒绝”的二元结论变成了一个连续的证据度量：p 值越小，数据与 $H_0$ 越不相容。几何上，它是在 $H_0$ 的抽样分布曲线下、从观测值往“更极端”方向的尾部面积。在女士品茶的例子中，若她 4 杯全部挑对，$p=1/70\approx0.014$；若只挑对 3 杯，“挑对 3 杯或 4 杯”的概率为 $(16+1)/70\approx0.243$，证据就弱得多。

::: pitfall p 值不是“原假设为真的概率”
$p=0.03$ 的意思是“如果 $H_0$ 为真，出现这么极端的数据的概率是 3%”，即 $P(\text{数据}\mid H_0)$，而 **不是** “$H_0$ 为真的概率是 3%”，即 $P(H_0\mid\text{数据})$。这正是“[条件概率与独立性](/probability/conditional)”一章警告过的混淆。另外：
- p 值小不代表效应大：样本足够大时，微不足道的差异也会“高度显著”——**统计显著不等于实际重要**；
- $p=0.051$ 与 $p=0.049$ 的证据强度几乎相同，不应把 0.05 当成非黑即白的界线。

2016 年美国统计协会专门发表声明，提醒人们正确理解和使用 p 值。
:::

## 正态总体参数的检验 {.core}

设样本来自 $N(\mu,\sigma^2)$，检验的统计量与拒绝域如下（$\alpha$ 为显著性水平，分位数为下侧分位数）：

| 检验 | 条件 | 统计量 | $H_1$ 与拒绝域 |
| --- | --- | --- | --- |
| $u$ 检验 | $\sigma$ 已知 | $u=\dfrac{\bar x-\mu_0}{\sigma/\sqrt n}$ | $\mu>\mu_0$：$u\ge u_{1-\alpha}$；$\mu\neq\mu_0$：$\lvert u\rvert\ge u_{1-\alpha/2}$ |
| $t$ 检验 | $\sigma$ 未知 | $t=\dfrac{\bar x-\mu_0}{s/\sqrt n}$ | $\mu>\mu_0$：$t\ge t_{1-\alpha}(n-1)$；$\mu\neq\mu_0$：$\lvert t\rvert\ge t_{1-\alpha/2}(n-1)$ |
| $\chi^2$ 检验 | 检验 $\sigma^2$ | $\chi^2=\dfrac{(n-1)s^2}{\sigma_0^2}$ | $\sigma^2>\sigma_0^2$：$\chi^2\ge\chi^2_{1-\alpha}(n-1)$ |
| 两样本 $t$ 检验 | $\sigma_1^2=\sigma_2^2$ 未知 | $t=\dfrac{\bar x-\bar y}{s_w\sqrt{1/m+1/n}}$ | $\mu_1\neq\mu_2$：$\lvert t\rvert\ge t_{1-\alpha/2}(m+n-2)$ |
| $F$ 检验 | 检验 $\sigma_1^2=\sigma_2^2$ | $F=s_x^2/s_y^2$ | $\sigma_1^2\neq\sigma_2^2$：$F\le F_{\alpha/2}$ 或 $F\ge F_{1-\alpha/2}$ |

左侧备择（如 $\mu<\mu_0$）的拒绝域与右侧对称。

::: example 例 1　包装是否足量
某食品的标准净重为 500 g。随机抽取 16 袋，测得 $\bar x=497.5$ g，$s=4.2$ g。设净重服从正态分布，在 $\alpha=0.05$ 下检验平均净重是否符合标准。

**解** $H_0:\mu=500$，$H_1:\mu\neq500$。$\sigma$ 未知，用 $t$ 检验：
$$t=\frac{497.5-500}{4.2/\sqrt{16}}=\frac{-2.5}{1.05}\approx-2.381.$$
$t_{0.975}(15)=2.131$，$|t|>2.131$，拒绝 $H_0$，认为平均净重不符合标准。p 值 $=2P(t(15)\le-2.381)\approx0.031$。
:::

::: example 例 2　重量的波动是否超标
例 1 中，若规定净重的标准差不得超过 4 g，检验 $H_0:\sigma^2\le16$，$H_1:\sigma^2>16$。

**解** $\chi^2=\frac{15\times4.2^2}{16}\approx16.54$，$\chi^2_{0.95}(15)=24.996$，$\chi^2<24.996$，不拒绝 $H_0$（p 值约 0.35）：样本标准差 4.2 略大于 4，但这点差别完全可以由抽样波动解释。
:::

::: example 例 3　配对比较
为检验一种新的培训方法，8 名员工培训前后的某项考核成绩之差（后 − 前）为：1.2、0.8、−0.3、1.5、0.9、0.4、1.1、0.6。培训是否有效（$\alpha=0.05$）？

**解** 同一个人的前后成绩不独立，应对 **差值** 作单样本 $t$ 检验。$\bar d=0.775$，$s_d\approx0.555$，
$$t=\frac{0.775}{0.555/\sqrt8}\approx3.95>t_{0.975}(7)=2.365,$$
拒绝“培训无效”的原假设，p 值约 0.006。如果误把两组成绩当作独立样本，个体之间的巨大差异会掩盖培训的效果——**配对设计** 正是为了消除个体差异。
:::

::: quiz 0.0257 0.001
两种工艺的产品强度：工艺甲 $m=10$，$\bar x=20.5$，$s_x=2.0$；工艺乙 $n=12$，$\bar y=18.2$，$s_y=2.4$。设两总体方差相等，双侧 $t$ 检验的 p 值约是多少？（保留四位小数）
> $s_w^2=4.968$，$t=\frac{2.3}{s_w\sqrt{1/10+1/12}}\approx2.410$，自由度 20，p 值 $=2P(t(20)\ge2.410)\approx0.0257$。这与“[区间估计](/inference/interval)”一章练习 5 的结论一致：差的置信区间不含 0。
:::

## 比率检验与大样本检验 {.key}

样本量较大时，由中心极限定理，即使总体不是正态分布，也可以用近似正态的统计量。对比率 $p$：
$$u=\frac{\hat p-p_0}{\sqrt{p_0(1-p_0)/n}}\ \stackrel{\text{近似}}{\sim}\ N(0,1).$$
注意分母用的是 **假设值** $p_0$——检验是在 $H_0$ 成立的前提下进行的。

::: example 例 4　支持率是否过半
随机调查 1000 名选民，535 人支持某候选人。能否认为支持率超过一半？（$\alpha=0.05$）

**解** $H_0:p=0.5$，$H_1:p>0.5$。$u=\frac{0.535-0.5}{\sqrt{0.25/1000}}\approx2.21>u_{0.95}=1.645$，拒绝 $H_0$。单侧 p 值约 0.013。
:::

## 检验与置信区间的对偶 {.key}

::: core 对偶关系
对双侧检验 $H_0:\theta=\theta_0$，**在水平 $\alpha$ 下不拒绝 $H_0$，当且仅当 $\theta_0$ 落在 $\theta$ 的置信水平为 $1-\alpha$ 的置信区间内**。
:::

例如例 1 中均值的 95% 置信区间为 $497.5\pm2.131\times1.05=[495.26,\ 499.74]$，不含 500，所以拒绝 $H_0:\mu=500$。置信区间比检验提供了更多信息：它不仅告诉我们“与 500 不同”，还告诉我们“大约差多少”。“[区间估计](/inference/interval)”一章的深入块从几何上解释了这种对偶。

:::: l2 进阶：样本量与功效
设计试验时，要使检验既控制 $\alpha$、又在差异达到 $\delta$ 时有足够的功效 $1-\beta$，双侧 $u$ 检验所需的样本量约为
$$n=\Big(\frac{(u_{1-\alpha/2}+u_{1-\beta})\,\sigma}{\delta}\Big)^2.$$
例如 $\alpha=0.05$、功效 80%、差异为半个标准差（$\delta/\sigma=0.5$）时，$n\approx\big(\frac{1.96+0.84}{0.5}\big)^2\approx32$。很多研究“没有发现差异”，原因只是样本量太小、功效不足。
::::

:::: l3 深入：奈曼–皮尔逊引理
对于两个简单假设 $H_0:\theta=\theta_0$ 与 $H_1:\theta=\theta_1$，在所有水平为 $\alpha$ 的检验中，功效最大的检验是 **似然比检验**：当
$$\frac{L(\theta_1)}{L(\theta_0)}\ge k$$
时拒绝 $H_0$，$k$ 由水平 $\alpha$ 确定。直观地说：哪些样本点应该放进拒绝域？应该放那些“在 $H_1$ 下比在 $H_0$ 下可能得多”的点，按似然比从大到小依次放入，直到用完 $\alpha$ 的“预算”。正态均值的 $u$ 检验、$t$ 检验都可以由这一思想导出，它也是下一章似然比检验的出发点。
::::

## 本章小结

- 假设检验是 **带概率的反证法**：在 $H_0$ 下，若数据太不寻常（小概率事件发生了），就拒绝 $H_0$。
- **两类错误**：拒真 $\alpha$、取伪 $\beta$；$n$ 固定时此消彼长，增大 $n$ 才能同时减小。原假设受到保护，“不拒绝”不等于“接受”。
- **p 值**：$H_0$ 下出现观测值或更极端值的概率，不是 $H_0$ 为真的概率；统计显著不等于实际重要。
- **正态总体检验**：$u$、$t$、$\chi^2$、两样本 $t$、配对 $t$、$F$ 检验；比率与大样本用近似正态。
- **对偶**：双侧检验不拒绝 ⟺ 参数值在置信区间内。

## 分层练习

### 基础

**1.** 某种零件的长度服从 $N(\mu,0.2^2)$，标准长度为 10 mm。抽检 25 件，得 $\bar x=10.06$ mm。在 $\alpha=0.05$ 下检验 $H_0:\mu=10$。

::: details 解答
$u=\frac{10.06-10}{0.2/5}=1.5<1.96$，不拒绝 $H_0$。p 值 $=2(1-\Phi(1.5))\approx0.134$。
:::

**2.** 说明在下列情形中，第一类错误和第二类错误分别是什么，哪一类后果更严重：(1) 检验“新药无效”；(2) 检验“这批食品合格”。

::: details 解答
(1) 第一类错误：药其实无效，却判为有效——患者服用无效药物，延误治疗；第二类错误：药其实有效，却判为无效——好药被埋没。通常第一类错误更严重，所以把“无效”作为 $H_0$ 并严格控制 $\alpha$。

(2) 第一类错误：合格的食品被判为不合格——厂家受损；第二类错误：不合格的食品被判为合格——消费者健康受损。从保护消费者的角度，应当把“不合格”作为原假设，才能严格控制把不合格判为合格的概率。原假设的设定取决于哪种错误更需要严格控制。
:::

**3.** 某检验的 p 值为 0.03。判断下列说法是否正确：(a) 在 $\alpha=0.05$ 下拒绝 $H_0$；(b) 在 $\alpha=0.01$ 下拒绝 $H_0$；(c) $H_0$ 为真的概率是 3%。

::: details 解答
(a) 正确；(b) 错误，$0.03>0.01$；(c) 错误，p 值是 $H_0$ 下数据如此极端的概率，不是 $H_0$ 为真的概率。
:::

### 提高

**4.** 某产品的次品率按规定不得超过 5%。抽查 200 件，发现 16 件次品。在 $\alpha=0.05$ 下能否认为次品率超标？

::: details 解答
$H_0:p\le0.05$，$H_1:p>0.05$。$\hat p=0.08$，$u=\frac{0.08-0.05}{\sqrt{0.05\times0.95/200}}\approx\frac{0.03}{0.0154}\approx1.95>1.645$，拒绝 $H_0$，认为次品率超标（单侧 p 值约 0.026）。
:::

**5.** 检验 $H_0:\mu=0$，$H_1:\mu>0$，总体为 $N(\mu,1)$，$n=16$，$\alpha=0.05$。求 $\mu=0.5$ 时的功效；要使功效达到 0.9，$n$ 至少为多少？

::: details 解答
拒绝域 $\bar x\ge1.645/4=0.411$。$\mu=0.5$ 时功效 $=P(\bar X\ge0.411)=1-\Phi\big(\frac{0.411-0.5}{0.25}\big)=1-\Phi(-0.355)\approx0.639$，与实验的默认读数一致。

功效达到 0.9 需 $\sqrt n\times0.5\ge1.645+1.2816$，$n\ge(2.9266/0.5)^2\approx34.3$，至少 35。
:::

**6.** 为什么配对 $t$ 检验通常比两独立样本 $t$ 检验更有效？在什么情况下配对反而不划算？

::: details 解答
配对把 $\operatorname{Var}(\bar X-\bar Y)$ 中的个体差异消掉了：$\operatorname{Var}(D)=\sigma_1^2+\sigma_2^2-2\operatorname{Cov}(X,Y)$，同一个体的两次测量正相关时，协方差项使方差大大减小。代价是自由度从 $2n-2$ 降到 $n-1$。若两次测量几乎不相关（配对没有消除任何差异），配对检验会因自由度减半而功效略低。
:::

### 挑战

**7.** 女士品茶试验中，若改为 6 杯（3 杯先倒奶），她全部挑对时 p 值是多少？这样的试验设计有什么问题？费希尔为什么选择 8 杯？

::: details 解答
$1/\binom63=1/20=0.05$。即使她全部挑对，p 值也只是勉强达到 0.05；只要错一对就无法拒绝 $H_0$。试验的“分辨能力”太弱。8 杯时全对的 p 值为 $1/70\approx0.014$，可以给出有力的证据。这说明 **试验设计决定了检验所能达到的功效**，应当在收集数据之前就考虑。
:::

**8.** 设 $X_1,\dots,X_n$ 来自 $N(\mu,1)$。用奈曼–皮尔逊引理推导 $H_0:\mu=0$ 对 $H_1:\mu=\mu_1$（$\mu_1>0$）的最优检验，并说明它对所有 $\mu_1>0$ 都相同。

::: details 解答
似然比 $\frac{L(\mu_1)}{L(0)}=\exp\big\{\mu_1\sum x_i-\frac n2\mu_1^2\big\}$，它是 $\bar x$ 的增函数（因为 $\mu_1>0$），所以“似然比 $\ge k$”等价于“$\bar x\ge c$”，$c$ 由 $P_0(\bar X\ge c)=\alpha$ 确定，即 $c=u_{1-\alpha}/\sqrt n$。拒绝域与 $\mu_1$ 的具体值无关，所以它对整个 $H_1:\mu>0$ 都是功效最大的，称为 **一致最优检验**。
:::

## 代码实现（Python）

::: details 展开代码：常用检验
```python
import numpy as np
from scipy import stats
from statsmodels.stats.proportion import proportions_ztest

# 例 1：单样本 t 检验（由汇总统计量计算）
t = (497.5 - 500) / (4.2 / np.sqrt(16))
print("t =", round(t, 3), " p =", round(2 * stats.t.cdf(t, 15), 4))

# 例 3：配对 t 检验
d = np.array([1.2, 0.8, -0.3, 1.5, 0.9, 0.4, 1.1, 0.6])
print(stats.ttest_1samp(d, 0))

# 两样本 t 检验：由汇总统计量
print(stats.ttest_ind_from_stats(20.5, 2.0, 10, 18.2, 2.4, 12, equal_var=True))

# 例 4：比率的单侧检验
stat, p = proportions_ztest(count=535, nobs=1000, value=0.5, alternative="larger", prop_var=0.5)
print("u =", round(stat, 3), " p =", round(p, 4))

# 功效：n = 16，μ = 0.5，单侧 α = 0.05
from statsmodels.stats.power import NormalIndPower
print("功效", NormalIndPower().power(effect_size=0.5, nobs1=16, alpha=0.05, ratio=0, alternative="larger"))
```
:::

::: info 史话：从婴儿性别比到奈曼–皮尔逊
最早的显著性检验可以追溯到 1710 年：阿布斯诺特统计了伦敦 82 年的出生记录，发现每一年出生的男婴都多于女婴。如果男女出生的机会均等，这样的事连续 82 年发生的概率是 $(1/2)^{82}$，他据此认为性别比并非偶然。20 世纪 20 年代，费希尔用 p 值和显著性检验系统地分析农业试验数据；1928—1933 年，奈曼与 E. 皮尔逊引入了备择假设、两类错误和功效，建立了检验的最优性理论。今天教科书里的假设检验，其实是这两种思想的融合——两派当年对此争论激烈。
:::
