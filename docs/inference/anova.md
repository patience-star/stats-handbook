# 方差分析

三种肥料施在不同的地块上，收成各不相同。差别是肥料造成的，还是地块本身的随机差异？两种肥料可以用两样本 $t$ 检验比较；三种、五种、十种呢？两两比较要做很多次检验，而检验做得越多，越容易“碰巧”得到显著的结果。

**方差分析**（ANOVA）用一个检验同时比较多个总体的均值。它的名字有些误导：检验的对象是 **均值**，方法却是 **分解方差**——把数据的总波动拆成“组与组之间的差异”和“组内的随机误差”两部分，看前者是否显著大于后者。

## 单因素方差分析模型 {.core}

研究的变量（如产量）称为 **指标**，影响指标的条件（如肥料）称为 **因子**，因子的不同状态称为 **水平**。

::: core 单因素方差分析模型
因子 $A$ 有 $r$ 个水平，第 $i$ 个水平下进行 $m$ 次试验（等重复），观测值 $y_{ij}$（$i=1,\dots,r$；$j=1,\dots,m$），设
$$y_{ij}=\mu_i+\varepsilon_{ij}=\mu+a_i+\varepsilon_{ij},\qquad\varepsilon_{ij}\stackrel{\text{iid}}{\sim}N(0,\sigma^2),\qquad\sum_{i=1}^ra_i=0,$$
其中 $\mu$ 为总均值，$a_i=\mu_i-\mu$ 为第 $i$ 个水平的 **效应**。要检验
$$H_0:\ a_1=a_2=\cdots=a_r=0\quad(\text{即}\ \mu_1=\cdots=\mu_r),$$
备择假设是“各 $\mu_i$ 不全相等”。模型隐含三个假定：**正态性**、**方差齐性**（各水平的方差相同）、**独立性**。
:::

## 平方和分解 {.hard}

记第 $i$ 组的均值为 $\bar y_{i\cdot}$，总均值为 $\bar y$，$n=rm$。

::: core 平方和分解公式
$$\underbrace{\sum_{i,j}(y_{ij}-\bar y)^2}_{S_T\ \text{总平方和}}=\underbrace{m\sum_i(\bar y_{i\cdot}-\bar y)^2}_{S_A\ \text{组间平方和}}+\underbrace{\sum_{i,j}(y_{ij}-\bar y_{i\cdot})^2}_{S_e\ \text{组内平方和}},$$
自由度也相应分解：$n-1=(r-1)+(n-r)$。$H_0$ 成立时，
$$F=\frac{S_A/(r-1)}{S_e/(n-r)}\sim F(r-1,\ n-r),$$
$F\ge F_{1-\alpha}(r-1,n-r)$ 时拒绝 $H_0$。
:::

::: geo 几何直观：$\mathbb R^n$ 中的勾股定理
每个数据对总均值的偏差可以分成两段：
$$y_{ij}-\bar y=\underbrace{(\bar y_{i\cdot}-\bar y)}_{\text{组间}}+\underbrace{(y_{ij}-\bar y_{i\cdot})}_{\text{组内}}.$$
把 $n$ 个偏差排成一个 $n$ 维向量，它就分解为两个向量之和：“组间向量”在同一组内取相同的值，“组内向量”在每一组内的和为 0。这两个向量 **互相垂直**（组内偏差在每组内求和为 0，与组内的常数相乘再求和必为 0）。于是平方和的分解就是 **勾股定理**：斜边的平方等于两条直角边的平方和。

这和“[统计量与抽样分布](/inference/sampling)”一章把样本向量分解为“均值方向的投影 + 残差”是同一个几何图像，只是投影的子空间从 1 维（所有分量相同）变成了 $r$ 维（同组分量相同）。自由度就是各子空间的维数：组间 $r-1$，组内 $n-r$。
:::

::: insight F 比较的是两种方差估计
$S_e/(n-r)$ 总是 $\sigma^2$ 的无偏估计，无论 $H_0$ 是否成立——它只用了组内的波动。$S_A/(r-1)$ 只在 $H_0$ 成立时才估计 $\sigma^2$；若各组均值不同，它还包含了组间真实差异的贡献，期望变大：
$$E\Big(\frac{S_A}{r-1}\Big)=\sigma^2+\frac{m\sum a_i^2}{r-1}.$$
所以 $F$ 是“两种方差估计之比”：接近 1 说明组间差异只是随机波动，远大于 1 说明有真实的组间差异。这就是“方差分析”名称的由来。
:::

**试一试**

1. 把组间差异 $\delta$ 调到 0：$F$ 大约多大？多生成几次随机误差，偶尔会不会超过临界值？（会的，概率约 5%——那就是第一类错误。）
2. 固定 $\delta=1$，把组内标准差从 0.5 增大到 3：同样的组间差异，为什么越来越难被检测出来？
3. 观察下方的平方和条形图：$S_A$ 所占比例与 $F$、p 值是什么关系？

::: example 例 1　三种肥料
三种肥料各施于 5 块地，产量（kg）如下：

| 肥料 | 产量 | 均值 |
| --- | --- | --- |
| A | 52, 55, 58, 54, 56 | 55 |
| B | 60, 62, 58, 63, 62 | 61 |
| C | 50, 54, 52, 51, 53 | 52 |

**解** 总均值 $\bar y=56$。$S_A=5\times[(55-56)^2+(61-56)^2+(52-56)^2]=210$；各组内的偏差平方和为 20、16、10，$S_e=46$；$S_T=256$。

| 来源 | 平方和 | 自由度 | 均方 | $F$ |
| --- | --- | --- | --- | --- |
| 肥料（组间） | 210 | 2 | 105 | 27.39 |
| 误差（组内） | 46 | 12 | 3.83 | |
| 总和 | 256 | 14 | | |

$F_{0.95}(2,12)=3.89$，$F=27.39$ 远大于临界值（p 值约 $3\times10^{-5}$），拒绝 $H_0$：三种肥料的平均产量有显著差异。
:::

::: quiz 3.833 0.005
例 1 中误差的均方 $MS_e$（即 $\sigma^2$ 的估计）是多少？（保留三位小数）
> $MS_e=S_e/(n-r)=46/12\approx3.833$。
:::

## 多重比较 {.key}

$F$ 检验只告诉我们“各组均值不全相等”，没有说 **哪几组** 不同。要找出来，就要做两两比较——而这会带来新的问题。

<MultipleTesting />

**试一试**

1. $m=1$ 时误报率是 5%；$m=10$ 时呢？$m=20$ 时，“至少一个显著”几乎成了必然的一半以上。
2. 观察上方的一次模拟：原假设全部成立，却常常有红点——它们全都是假阳性。
3. Bonferroni 校正把每个检验的水平降到 $\alpha/m$，误报率被控制在 5% 以内。代价是什么？

::: core 族错误率与常用的多重比较方法
同时做 $m$ 个水平为 $\alpha$ 的独立检验，原假设都成立时，至少错拒一个的概率（**族错误率**）为 $1-(1-\alpha)^m$，$m=10$ 时约 40%。控制族错误率的常用方法：

- **Bonferroni 法**：每个比较用水平 $\alpha/m$。简单通用，但比较多时偏保守；
- **Tukey 法**（$T$ 法）：专为等重复的全部两两比较设计，用学生化极差分布，两均值之差超过 $q_{1-\alpha}(r,f_e)\sqrt{MS_e/m}$ 即认为显著；
- **Scheffé 法**（$S$ 法）：可以检验任意的线性对比，最为保守。
:::

::: example 例 2　哪两种肥料不同
例 1 中三对差值为：B−A $=6$，A−C $=3$，B−C $=9$。

- **不校正**（Fisher LSD）：$t_{0.975}(12)\sqrt{MS_e\cdot\frac25}\approx2.179\times1.238\approx2.70$，三对差值都超过 2.70，全部“显著”；
- **Tukey 法**：$q_{0.95}(3,12)\sqrt{MS_e/5}\approx3.773\times0.876\approx3.30$，B−A 与 B−C 显著，**A−C 的差值 3 不显著**；
- **Bonferroni 法**：界限约为 $2.779\times1.238\approx3.44$，结论与 Tukey 法相同。

结论：肥料 B 明显优于 A 和 C；A 与 C 之间的差别，在控制了族错误率之后不能确认。
:::

::: pitfall p 值操纵
把数据按性别、年龄、地区、时间……反复切分检验，或者尝试多种模型、多种剔除异常值的方式，只报告“显著”的那一个——即使每一步都“合规”，也是在做大量隐性的多重比较，误报几乎不可避免。这种做法被称为 **p 值操纵**（p-hacking），是近年来许多研究结论无法重复的重要原因。对策是：事先登记分析方案，报告全部检验，并对多重比较进行校正。
:::

## 方差齐性检验 {.key}

方差分析假定各组方差相等。常用的检验：

- **Hartley 检验**：等重复时，用最大样本方差与最小样本方差之比 $F_{\max}=s_{\max}^2/s_{\min}^2$，查专用的临界值表；
- **Bartlett 检验**：基于各组样本方差的对数，近似服从 $\chi^2(r-1)$；它对正态性的偏离很敏感；
- **Levene 检验**：对各组的“绝对离差”做方差分析，对非正态数据更稳健。

例 1 中三组的样本方差为 5.0、4.0、2.5，$F_{\max}=2$；Bartlett 检验的 p 值约 0.81，没有证据表明方差不齐。好在当各组样本量相等时，方差分析对方差不齐并不敏感。

## 双因素方差分析 {.l2}

:::: l2 进阶：两个因子与交互作用
若同时考察两个因子 $A$（$r$ 个水平）和 $B$（$s$ 个水平），每种组合重复 $t$ 次，模型为
$$y_{ijk}=\mu+a_i+b_j+(ab)_{ij}+\varepsilon_{ijk}.$$
总平方和分解为 $S_T=S_A+S_B+S_{A\times B}+S_e$，分别用 $F$ 检验两个因子的主效应和 **交互作用**。

**交互作用** 是指一个因子的效应依赖于另一个因子的水平。例如某种肥料在甲品种上增产明显，在乙品种上却几乎无效。画出各组合的均值（横轴为 $A$ 的水平，每个 $B$ 水平一条折线）：若折线大致平行，说明没有交互作用；若明显不平行甚至交叉，说明有交互作用，这时单独谈“肥料的平均效应”往往没有意义。

每种组合只做一次试验（$t=1$）时，无法把交互作用与误差分开，只能假定没有交互作用。
::::

:::: l3 深入：方差分析就是回归
引入 $r-1$ 个哑变量（如 $D_2=1$ 表示第 2 组，否则为 0），单因素方差分析模型就是一个线性回归模型 $y=\beta_0+\beta_2D_2+\cdots+\beta_rD_r+\varepsilon$。组间平方和就是回归平方和，$F$ 检验就是回归的整体显著性检验。几何上，组均值向量是 $\boldsymbol y$ 在由各组指示向量张成的 $r$ 维子空间上的正交投影——下一章“[相关与回归分析](/inference/regression)”会把这个投影的图像画出来。方差分析、回归分析、$t$ 检验，都是 **线性模型** 这一统一框架的特例。
::::

## 本章小结

- 方差分析检验多个总体的均值是否相等，方法是 **分解平方和**：$S_T=S_A+S_e$，自由度 $n-1=(r-1)+(n-r)$。
- 几何上，平方和分解是 $\mathbb R^n$ 中的勾股定理；$F=\dfrac{S_A/(r-1)}{S_e/(n-r)}$ 比较两种方差估计。
- 拒绝 $H_0$ 后用 **多重比较** 找出差异所在；不校正时族错误率 $1-(1-\alpha)^m$ 迅速增大；Bonferroni、Tukey、Scheffé 法控制族错误率。
- 方差分析的前提是正态、方差齐、独立；方差齐性可用 Hartley、Bartlett、Levene 检验。
- 双因素方差分析要注意 **交互作用**。

## 分层练习

### 基础

**1.** 某单因素方差分析有 4 个水平，每个水平重复 6 次，算得 $S_A=36$，$S_e=80$。列出方差分析表，并在 $\alpha=0.05$ 下作出判断（$F_{0.95}(3,20)=3.10$）。

::: details 解答
$n=24$，$S_T=116$。$MS_A=36/3=12$，$MS_e=80/20=4$，$F=3.0<3.10$，不拒绝 $H_0$。
:::

**2.** 5 组比较，若用不校正的两两 $t$ 检验（$\alpha=0.05$），共要做多少次比较？假设比较相互独立，至少一次误报的概率约是多少？

::: details 解答
$\binom52=10$ 次，$1-0.95^{10}\approx0.40$。（两两比较其实并不独立，真实的误报率略低，但量级相同。）
:::

**3.** 为什么不能用多次两样本 $t$ 检验代替方差分析？

::: details 解答
(1) 多次检验使族错误率膨胀；(2) 每次 $t$ 检验只用两组的数据估计误差方差，方差分析用全部数据估计，自由度更大、更精确。
:::

### 提高

**4.** 证明平方和分解中的交叉项为 0：$\sum_{i,j}(\bar y_{i\cdot}-\bar y)(y_{ij}-\bar y_{i\cdot})=0$。

::: details 解答
对固定的 $i$，$\bar y_{i\cdot}-\bar y$ 是常数，提出来后剩下 $\sum_j(y_{ij}-\bar y_{i\cdot})=0$。所以每一组的和都是 0，总和为 0。这就是“组间向量与组内向量正交”的代数表达。
:::

**5.** 两组比较时，证明方差分析的 $F$ 统计量等于两样本 $t$ 统计量的平方。

::: details 解答
$r=2$，每组 $m$ 个。$S_A=m[(\bar y_1-\bar y)^2+(\bar y_2-\bar y)^2]=\frac m2(\bar y_1-\bar y_2)^2$；$S_e/(2m-2)=s_w^2$。所以
$$F=\frac{\frac m2(\bar y_1-\bar y_2)^2}{s_w^2}=\frac{(\bar y_1-\bar y_2)^2}{s_w^2(\frac1m+\frac1m)}=t^2.$$
又 $F(1,f)$ 是 $t(f)$ 的平方的分布，二者完全等价。
:::

### 挑战

**6.** 证明 $E\Big(\dfrac{S_A}{r-1}\Big)=\sigma^2+\dfrac{m\sum a_i^2}{r-1}$。

::: details 解答
$\bar y_{i\cdot}=\mu+a_i+\bar\varepsilon_{i\cdot}$，$\bar y=\mu+\bar\varepsilon$（因为 $\sum a_i=0$）。于是
$$S_A=m\sum_i(a_i+\bar\varepsilon_{i\cdot}-\bar\varepsilon)^2=m\sum a_i^2+2m\sum a_i(\bar\varepsilon_{i\cdot}-\bar\varepsilon)+m\sum(\bar\varepsilon_{i\cdot}-\bar\varepsilon)^2.$$
中间项期望为 0。最后一项中 $\bar\varepsilon_{i\cdot}$ 是 $r$ 个独立 $N(0,\sigma^2/m)$，其“样本方差”的期望为 $\sigma^2/m$，所以 $E\sum(\bar\varepsilon_{i\cdot}-\bar\varepsilon)^2=(r-1)\sigma^2/m$。合起来 $E(S_A)=m\sum a_i^2+(r-1)\sigma^2$。
:::

**7.** 某研究测量了 20 个基因与某疾病的关联，在 $\alpha=0.05$ 下发现 1 个“显著”的基因（p = 0.03）。你会怎样评价这个结论？

::: details 解答
即使 20 个基因与疾病都无关，平均也会有 1 个 p 值小于 0.05，至少出现一个的概率约 64%。Bonferroni 校正后的界限为 $0.05/20=0.0025$，p = 0.03 远未达到。这个“发现”很可能是假阳性，需要在独立的样本中重复验证。基因组学研究通常要求 $5\times10^{-8}$ 量级的显著性，正是因为同时检验了上百万个位点。
:::

## 代码实现（Python）

::: details 展开代码：方差分析、多重比较与方差齐性检验
```python
import numpy as np
import pandas as pd
from scipy import stats
import statsmodels.formula.api as smf
from statsmodels.stats.anova import anova_lm
from statsmodels.stats.multicomp import pairwise_tukeyhsd

A = np.array([52, 55, 58, 54, 56], dtype=float)
B = np.array([60, 62, 58, 63, 62], dtype=float)
C = np.array([50, 54, 52, 51, 53], dtype=float)

# 1. 单因素方差分析
print(stats.f_oneway(A, B, C))

# 2. 用线性模型得到完整的方差分析表
df = pd.DataFrame({"y": np.r_[A, B, C], "fert": ["A"] * 5 + ["B"] * 5 + ["C"] * 5})
model = smf.ols("y ~ fert", data=df).fit()   # 字符串列自动作为分类变量（变量 C 已被占用，不能再写 C(fert)）
print(anova_lm(model))

# 3. Tukey 多重比较
print(pairwise_tukeyhsd(df["y"], df["fert"]))

# 4. 方差齐性检验（scipy 的 bartlett 需要浮点数组）
print(stats.bartlett(A, B, C))
print(stats.levene(A, B, C))
```

1919 年，29 岁的费希尔来到英国洛桑农业试验站，面对的是几十年积累的作物试验记录。为了从中分离出肥料、品种、气候各自的作用，他发明了方差分析，并提出了随机化、重复、区组等试验设计原则。1925 年的《研究工作者的统计方法》和 1935 年的《试验设计》把这些方法推向了全世界。“方差”（variance）这个词本身也是费希尔在 1918 年创造的。多重比较的系统研究则晚得多，图基在 1949—1953 年间提出了以他命名的方法。
