# 学习指南

这份讲义以两本教材为纲：

- **茆书**：茆诗松、程依明、濮晓龙《概率论与数理统计教程》（第三版，高等教育出版社）——概率论与数理统计的主线，偏数学；
- **黄书**：黄良文《统计学》——数据搜集、描述统计、统计推断、指数与时间序列，偏经济管理应用。

两本书的内容大部分重叠，但讲法和侧重点不同。这里把它们排进同一条主线，每章开头都注明对应的教材章节。时间序列部分在黄书的基础上加深，一直讲到现代时间序列分析。

## 三条学习路线

首页的知识图谱可以按路线高亮，圆圈里的数字是建议顺序：

- **经管路线**：以黄书为主线，L1 为主，从数据搜集、描述统计一直到统计指数和时间序列分解。
- **数学路线**：以茆书为主线，L2 为主，完整的概率论与数理统计。
- **时间序列专精**：先补齐必要的概率与推断基础，再从黄书的水平、速度分析一路走到 ARIMA、单位根、GARCH 与卡尔曼滤波。

## 每章怎么读

每章的结构大致相同：

1. **问题引入**：先给一个具体的问题，说明为什么需要这一章；
2. **知识点**：每个核心知识点按 **直观 → 几何 → 严格 → 应用** 展开，穿插互动实验和即时小测；
3. **本章小结**：知识结构和公式卡；
4. **分层练习**：基础、提高、挑战三档，解答默认折叠，先自己做再看；
5. **代码实现**：用 Python（NumPy、SciPy、statsmodels）实现本章的方法，默认折叠；
6. **延伸阅读**。

**互动实验**的用法：先按实验下方“试一试”里的问题动手操作，猜一猜会发生什么，再看结论。实验里的数据都是随机生成的，每次结果略有不同，这本身就是统计学要研究的现象。

**小测**的用法：选择题点选项即判分；数值题输入数字（可以写分数，如 `2/5`）后回车。作答后会显示解析，结果保存在本机，每章末尾可以把这一章标记为“已学完”。

## 记号约定

全站记号尽量与茆书一致：

| 记号 | 含义 |
| --- | --- |
| $F(x)$，$p(x)$ | 分布函数；概率密度函数（茆书用 $p$ 而不是 $f$） |
| $E(X)$，$\operatorname{Var}(X)$ | 数学期望；方差 |
| $\operatorname{Cov}(X,Y)$，$\operatorname{Corr}(X,Y)$ | 协方差；相关系数 |
| $\bar x$，$s^2$ | 样本均值；样本方差 $s^2=\frac{1}{n-1}\sum (x_i-\bar x)^2$ |
| $u_\alpha$ | 标准正态分布的 **下侧** $\alpha$ 分位数：$P(U\le u_\alpha)=\alpha$ |
| $t_\alpha(n)$，$\chi^2_\alpha(n)$，$F_\alpha(m,n)$ | 相应分布的下侧 $\alpha$ 分位数 |

::: pitfall 分位数的两种写法
茆书用 **下侧** 分位数，95% 置信区间里出现的是 $u_{0.975}=1.96$；经管类教材常用 **上侧** 分位数，同一个数写作 $z_{0.025}$。两种写法说的是同一个数，读不同教材时要换算。
:::
