# 统计指数

“10 月份全国居民消费价格同比上涨 0.2%”——这个数字是怎么来的？猪肉涨了、蔬菜跌了、手机降价了、房租持平……几百种商品和服务的价格各有涨落，计量单位也不同（元/斤、元/台、元/月），不能直接相加。怎样把它们综合成一个数？

**统计指数** 就是解决这个问题的工具：它用一个相对数反映多种不能直接相加的事物在数量上的 **综合变动**。它是黄书中极具特色的一章，在经济统计中应用最广。

## 指数的概念与分类 {.core}

::: core 指数的分类
- **个体指数**：反映单一事物的变动，如某种商品的价格指数 $k_p=p_1/p_0$；
- **总指数**：综合反映多种事物的总变动，如居民消费价格指数；
- **数量指标指数**（物量指数）：反映规模、数量的变动，如销售量指数、产量指数；
- **质量指标指数**：反映价格、成本、劳动生产率等的变动，如价格指数、单位成本指数。

下标 0 表示 **基期**（作为比较基础的时期），1 表示 **报告期**；$p$ 表示价格（质量指标），$q$ 表示销售量（数量指标）。
:::

困难在于总指数：不同商品的销售量不能相加（1 件衣服加 2 千克大米没有意义），价格相加也没有经济意义。解决办法是引入一个 **同度量因素**，把不能相加的量变成可以相加的 **价值量**：$p\times q$ 就是销售额，各种商品的销售额可以相加。

## 综合指数 {.core}

::: core 拉氏指数与帕氏指数
**拉斯贝尔斯指数**（拉氏指数）以 **基期** 的同度量因素为权数：
$$L_q=\frac{\sum q_1p_0}{\sum q_0p_0},\qquad L_p=\frac{\sum p_1q_0}{\sum p_0q_0}.$$
**帕舍指数**（帕氏指数）以 **报告期** 的同度量因素为权数：
$$P_q=\frac{\sum q_1p_1}{\sum q_0p_1},\qquad P_p=\frac{\sum p_1q_1}{\sum p_0q_1}.$$
:::

::: insight 一篮子商品的两种算法
价格指数回答的问题是：**买同样一篮子商品，现在要比过去多花多少钱？** 篮子固定为基期的购买量 $q_0$，就是拉氏价格指数——“按老习惯买东西，现在贵了多少”；篮子固定为报告期的购买量 $q_1$，就是帕氏价格指数——“按现在的习惯买东西，比过去贵了多少”。

价格上涨时，人们往往少买涨得多的商品、多买涨得少的商品（**替代效应**）。拉氏指数用老篮子，没有考虑替代，常常 **高估** 生活成本的上涨；帕氏指数用新篮子，又往往 **低估**。两者的几何平均
$$F_p=\sqrt{L_p\cdot P_p}$$
称为 **费希尔理想指数**，它满足许多良好的数学性质。
:::

::: core 我国通行的编制原则
编制 **数量指标指数** 时，以 **基期** 的质量指标为同度量因素（拉氏数量指数）；编制 **质量指标指数** 时，以 **报告期** 的数量指标为同度量因素（帕氏价格指数）：
$$I_q=\frac{\sum q_1p_0}{\sum q_0p_0},\qquad I_p=\frac{\sum p_1q_1}{\sum p_0q_1}.$$
这样选择的好处是：两个指数的乘积恰好等于销售额指数，可以构成完整的 **指数体系**（见下文）。
:::

::: example 例 1　两种商品的指数
某商店两种商品的资料如下：

| 商品 | 基期销售量 $q_0$ | 报告期销售量 $q_1$ | 基期价格 $p_0$ | 报告期价格 $p_1$ |
| --- | --- | --- | --- | --- |
| 甲（件） | 100 | 90 | 10 | 12 |
| 乙（千克） | 200 | 240 | 5 | 5.5 |

**解** $\sum p_0q_0=2000$，$\sum p_1q_1=1080+1320=2400$，$\sum p_0q_1=900+1200=2100$，$\sum p_1q_0=1200+1100=2300$。

- 销售量指数 $I_q=\frac{2100}{2000}=1.05$，销售量综合增长 5%；
- 价格指数 $I_p=\frac{2400}{2100}\approx1.1429$，价格综合上涨约 14.3%；
- 拉氏价格指数 $L_p=\frac{2300}{2000}=1.15$，比帕氏指数略高——甲涨价 20%，顾客少买了甲、多买了涨价只有 10% 的乙，这正是替代效应；
- 费希尔指数 $\sqrt{1.15\times1.1429}\approx1.1464$。
:::

## 指数体系与因素分析 {.core}

::: core 指数体系
$$\underbrace{\frac{\sum p_1q_1}{\sum p_0q_0}}_{\text{销售额指数}}=\underbrace{\frac{\sum q_1p_0}{\sum q_0p_0}}_{\text{销售量指数}}\times\underbrace{\frac{\sum p_1q_1}{\sum p_0q_1}}_{\text{价格指数}},$$
$$\sum p_1q_1-\sum p_0q_0=\Big(\sum q_1p_0-\sum q_0p_0\Big)+\Big(\sum p_1q_1-\sum p_0q_1\Big).$$
相对数上是 **乘积关系**，绝对数上是 **加和关系**。这样就可以把总量的变动分解为各因素的影响，称为 **因素分析**。
:::

例 1 中，销售额从 2000 元增加到 2400 元，指数 $1.2=1.05\times1.1429$；增加的 400 元中，销售量变动的影响为 $2100-2000=100$ 元，价格变动的影响为 $2400-2100=300$ 元。

::: geo 几何直观：矩形面积的分解
对一种商品，销售额 $p\times q$ 是以 $q$ 为宽、$p$ 为高的矩形的面积。从基期到报告期，矩形从 $p_0\times q_0$ 变成 $p_1\times q_1$，面积的变化可以分成三块：
$$p_1q_1-p_0q_0=\underbrace{\Delta q\cdot p_0}_{\text{数量变动}}+\underbrace{\Delta p\cdot q_0}_{\text{价格变动}}+\underbrace{\Delta p\cdot\Delta q}_{\text{交叉项}}.$$
右上角那块小矩形 $\Delta p\cdot\Delta q$ 是价格和数量 **共同** 变动产生的，它不单独属于任何一个因素。指数体系必须把它分给某一方：我国通行的做法把它归入价格因素（价格影响 $=\Delta p\cdot q_1$），这就是质量指标指数用报告期数量作权数的原因。若反过来用拉氏价格指数 × 帕氏数量指数，交叉项就被分给了数量因素——两种分法都能构成指数体系，只是对交叉项的归属不同。
:::

:::: l2 进阶：多因素分析
若总量由三个因素相乘，例如原材料费用总额 = 产量 $q$ × 单位产品原材料消耗量 $m$ × 原材料单价 $p$，可以 **连锁替代**：按“先数量指标、后质量指标”的顺序，每次只让一个因素从基期变到报告期，前面已变的因素固定在报告期，后面未变的固定在基期：
$$\frac{\sum q_1m_1p_1}{\sum q_0m_0p_0}=\frac{\sum q_1m_0p_0}{\sum q_0m_0p_0}\times\frac{\sum q_1m_1p_0}{\sum q_1m_0p_0}\times\frac{\sum q_1m_1p_1}{\sum q_1m_1p_0}.$$
三个因子分别反映产量、单耗、单价的影响，绝对额的影响也相应地相加。替代的顺序会影响结果，所以必须事先规定并保持一致。
::::

## 平均数指数 {.key}

综合指数需要掌握全部的 $p_0,p_1,q_0,q_1$，实际中常常只有个体指数和销售额资料。这时可以用 **平均数指数**：

::: core 加权算术平均指数与加权调和平均指数
- 已知个体销售量指数 $k_q=q_1/q_0$ 和基期销售额 $p_0q_0$，用 **加权算术平均**：
$$\bar k_q=\frac{\sum k_q\,p_0q_0}{\sum p_0q_0}=\frac{\sum q_1p_0}{\sum q_0p_0};$$
- 已知个体价格指数 $k_p=p_1/p_0$ 和报告期销售额 $p_1q_1$，用 **加权调和平均**：
$$\bar k_p=\frac{\sum p_1q_1}{\sum\frac{p_1q_1}{k_p}}=\frac{\sum p_1q_1}{\sum p_0q_1}.$$
两者分别是综合指数的变形，结果完全相同。
:::

这与“[分布特征的描述](/descriptive/measures)”一章中“已知总量用调和平均”的道理一致。实际编制居民消费价格指数时，用的是 **固定权数的加权算术平均**：先计算各类商品的价格指数，再按居民消费支出构成（定期调查确定的权数）加权平均。

## 平均指标指数 {.key}

总平均数的变动，可能来自各组水平的变化，也可能来自 **各组所占比重（结构）** 的变化。

::: core 可变构成、固定构成与结构影响
设第 $i$ 组的平均水平为 $x_i$、单位数为 $f_i$，总平均数 $\bar x=\sum x_if_i/\sum f_i$。
$$\underbrace{\frac{\bar x_1}{\bar x_0}}_{\text{可变构成指数}}=\underbrace{\frac{\sum x_1f_1/\sum f_1}{\sum x_0f_1/\sum f_1}}_{\text{固定构成指数}}\times\underbrace{\frac{\sum x_0f_1/\sum f_1}{\sum x_0f_0/\sum f_0}}_{\text{结构影响指数}}.$$
固定构成指数把结构固定在报告期，只反映各组水平的变动；结构影响指数把各组水平固定在基期，只反映结构的变动。
:::

::: example 例 2　平均工资为什么涨了这么多
某企业的工资资料：

| 工人类别 | 基期人数 | 基期工资 | 报告期人数 | 报告期工资 |
| --- | --- | --- | --- | --- |
| 技术工人 | 200 | 8000 | 300 | 8400 |
| 普通工人 | 800 | 4000 | 700 | 4200 |

两类工人的工资都只涨了 5%，全厂平均工资却从 4800 元涨到 5460 元，涨了 13.75%。分解：

- 固定构成指数 $=\frac{5460}{(8000\times300+4000\times700)/1000}=\frac{5460}{5200}=1.05$，各类工资水平的提高使平均工资增加 260 元；
- 结构影响指数 $=\frac{5200}{4800}\approx1.0833$，高工资的技术工人比重上升使平均工资增加 400 元。

$1.05\times1.0833=1.1375$，$260+400=660$。超过一半的增长来自 **结构变化**，而不是任何人工资的上涨。这与“[统计学与数据](/descriptive/intro)”一章的辛普森悖论是同一个道理：总体的平均数是各组的加权平均，权重变了，平均数就会变。
:::

## 常用的经济指数

- **居民消费价格指数**（CPI）：反映居民购买的消费品和服务项目价格的变动，涵盖食品烟酒、衣着、居住、生活用品及服务、交通通信、教育文化娱乐、医疗保健、其他用品及服务八大类，用于衡量通货膨胀；我国每五年更换一次基期并调整权数。
- **工业生产者出厂价格指数**（PPI）：反映工业企业产品出厂价格的变动，是观察生产领域价格的重要指标。
- **股票价格指数**：如上证综合指数，以样本股的总股本为权数，计算报告期市值与基期市值之比；它本质上也是一种帕氏型的综合指数。

## 本章小结

- 指数反映多种不能直接相加的事物的综合变动；关键是引入 **同度量因素**，把它们变成可以相加的价值量。
- **拉氏指数** 用基期权数，**帕氏指数** 用报告期权数；替代效应使拉氏价格指数常偏高；费希尔指数是二者的几何平均。
- 我国通行：**数量指标指数用基期质量指标、质量指标指数用报告期数量指标** 作同度量因素，从而构成指数体系。
- **指数体系**：相对数相乘、绝对数相加；几何上是矩形面积的分解，交叉项 $\Delta p\Delta q$ 归入价格因素。
- **平均数指数** 是综合指数的变形；**平均指标指数** 把总平均数的变动分解为组内水平与结构两部分。

| 指数 | 公式 |
| --- | --- |
| 销售量指数（拉氏） | $\frac{\sum q_1p_0}{\sum q_0p_0}$ |
| 价格指数（帕氏） | $\frac{\sum p_1q_1}{\sum p_0q_1}$ |
| 费希尔理想指数 | $\sqrt{L_pP_p}$ |
| 加权算术平均指数 | $\frac{\sum k_qp_0q_0}{\sum p_0q_0}$ |
| 加权调和平均指数 | $\frac{\sum p_1q_1}{\sum p_1q_1/k_p}$ |
| 指数体系 | $\frac{\sum p_1q_1}{\sum p_0q_0}=\frac{\sum q_1p_0}{\sum q_0p_0}\times\frac{\sum p_1q_1}{\sum p_0q_1}$ |

## 分层练习

### 基础

**1.** 例 1 中，分别用加权算术平均法（以基期销售额为权数）求销售量指数、用加权调和平均法（以报告期销售额为权数）求价格指数，验证它们与综合指数相同。

::: details 解答
个体销售量指数：甲 0.9，乙 1.2。$\bar k_q=\frac{0.9\times1000+1.2\times1000}{2000}=1.05$。个体价格指数：甲 1.2，乙 1.1。$\bar k_p=\frac{2400}{1080/1.2+1320/1.1}=\frac{2400}{900+1200}\approx1.1429$。与综合指数相同。
:::

**2.** 某地报告期居民消费支出比基期增长 12%，同期居民消费价格上涨 5%。实际消费量（按不变价格计算）增长了多少？

::: details 解答
消费支出指数 = 消费量指数 × 价格指数，所以消费量指数 $=1.12/1.05\approx1.0667$，实际增长约 6.67%，而不是 $12\%-5\%=7\%$。
:::

**3.** 解释：为什么编制价格指数时不能直接把各种商品的价格相加？

::: details 解答
不同商品的计量单位不同，价格相加没有经济意义；而且单位的选取会任意改变结果（把大米的价格由“元/千克”改成“元/吨”，总和就面目全非）。乘以销售量变成销售额后，才能在“货币”这个共同单位下相加。
:::

### 提高

**4.** 某厂生产两种产品，产量与单位成本如下：A 产品产量由 500 件增至 600 件，单位成本由 20 元降至 18 元；B 产品产量由 300 件减至 280 件，单位成本由 50 元升至 52 元。分析总成本的变动及其中产量与单位成本的影响。

::: details 解答
$\sum z_0q_0=10000+15000=25000$，$\sum z_1q_1=10800+14560=25360$，$\sum z_0q_1=12000+14000=26000$。

总成本指数 $25360/25000=1.0144$，增加 360 元；产量指数 $26000/25000=1.04$，影响 +1000 元；单位成本指数 $25360/26000\approx0.9754$，影响 −640 元。$1.04\times0.9754\approx1.0144$，$1000-640=360$。产量增加使成本上升 1000 元，单位成本降低节约了 640 元。
:::

**5.** 证明：价格同比例变动（各种商品的 $p_1/p_0$ 都等于同一个 $k$）时，拉氏价格指数与帕氏价格指数相等。

::: details 解答
$L_p=\frac{\sum kp_0q_0}{\sum p_0q_0}=k$，$P_p=\frac{\sum kp_0q_1}{\sum p_0q_1}=k$。两者都等于 $k$，与权数无关。拉氏与帕氏指数的差别，来自 **相对价格的变化与数量结构变化之间的相关性**。
:::

### 挑战

**6.** 用面积图说明：若改用“拉氏价格指数 × 帕氏数量指数”构成指数体系，交叉项被分给了哪个因素？两种体系对例 1 的因素分析结果有何不同？

::: details 解答
拉氏价格指数的影响额为 $\sum(p_1-p_0)q_0$，只包含“价格变动”那块矩形；帕氏数量指数的影响额为 $\sum(q_1-q_0)p_1$，包含“数量变动”与交叉项。所以交叉项被分给了数量因素。

例 1 中：价格影响 $2300-2000=300$ 元，数量影响 $2400-2300=100$ 元。恰好与通行体系的结果相同——因为两种商品的交叉项一正一负（甲 $2\times(-10)=-20$，乙 $0.5\times40=20$），合计为 0。一般情况下两种体系的分析结果不同，差别正是交叉项之和 $\sum\Delta p\Delta q$。
:::

## 代码实现（Python）

::: details 展开代码：指数计算与因素分析
```python
import numpy as np

q0 = np.array([100, 200]); q1 = np.array([90, 240])
p0 = np.array([10, 5]);    p1 = np.array([12, 5.5])

v00, v11 = p0 @ q0, p1 @ q1
v01, v10 = p0 @ q1, p1 @ q0
Iq, Ip = v01 / v00, v11 / v01            # 拉氏数量指数、帕氏价格指数
Lp = v10 / v00                           # 拉氏价格指数
print(f"销售额指数 {v11 / v00:.4f} = 销售量指数 {Iq:.4f} × 价格指数 {Ip:.4f}")
print(f"增加额 {v11 - v00:.0f} = 销售量影响 {v01 - v00:.0f} + 价格影响 {v11 - v01:.0f}")
print(f"拉氏价格指数 {Lp:.4f}，费希尔指数 {np.sqrt(Lp * Ip):.4f}")

# 平均指标指数：例 2
f0 = np.array([200, 800]); x0 = np.array([8000, 4000])
f1 = np.array([300, 700]); x1 = np.array([8400, 4200])
avg0, avg1, avg_fix = x0 @ f0 / f0.sum(), x1 @ f1 / f1.sum(), x0 @ f1 / f1.sum()
print(f"可变构成 {avg1 / avg0:.4f} = 固定构成 {avg1 / avg_fix:.4f} × 结构影响 {avg_fix / avg0:.4f}")
```
:::

::: info 史话：从拉斯贝尔斯到费希尔
1871 年和 1874 年，德国经济学家拉斯贝尔斯和帕舍先后提出了以各自名字命名的价格指数公式。1922 年，美国经济学家欧文·费希尔出版《指数的编制》，比较了一百多种指数公式，用一系列“检验”（如时间互换检验、因子互换检验）评价它们，推荐了拉氏与帕氏指数的几何平均，后人称之为费希尔理想指数。我国的统计指数理论在 20 世纪 50 年代以后形成了以指数体系和因素分析为核心的特色体系，黄书的统计指数一章正是这一传统的代表。
:::
