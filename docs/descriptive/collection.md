# 数据的搜集

1936 年美国总统大选前，《文学文摘》杂志寄出了约 1000 万份问卷，收回约 240 万份，据此预测共和党候选人兰登将以 57% 的得票率击败罗斯福。结果罗斯福以 61% 的得票率大胜。同一年，盖洛普只调查了约 5 万人，却正确地预测了罗斯福获胜。

240 万份问卷输给了 5 万份，问题出在哪里？答案是：**数据怎样来的，比数据有多少更重要**。这一章讨论统计数据的来源、统计调查的方式、抽样的方法，以及各种误差的来源。

## 统计调查的方式 {.key}

| 方式 | 做法 | 特点 | 例子 |
| --- | --- | --- | --- |
| **普查** | 对总体的全部单位逐一调查 | 资料全面，但费时费力，一般定期进行 | 全国人口普查（每 10 年一次）、经济普查 |
| **抽样调查** | 按随机原则抽取部分单位调查，推断总体 | 省时省钱，可以计算和控制误差 | 劳动力调查、住户收支调查、民意调查 |
| **重点调查** | 只调查少数“重点单位”，它们在总量中占很大比重 | 能迅速掌握总体的基本情况，不能推断总体 | 调查几家大型钢铁企业以了解全国钢产量 |
| **典型调查** | 有意识地选择若干有代表性的单位深入调查 | 适合研究新情况、总结经验，结论难以推广 | 调查一个先进企业的管理经验 |
| **统计报表** | 基层单位按规定的表式和时间逐级上报 | 资料系统连续，是政府统计的基础 | 企业的月度、年度统计报表 |

::: insight 只有抽样调查能“以部分推断总体”
重点调查和典型调查也只调查部分单位，但它们的单位是 **人为选定** 的，没有办法计算推断的误差。抽样调查按 **随机原则** 抽取单位，样本的统计规律可以用概率论描述：我们不仅能估计总体，还能说出估计的误差有多大（见“[区间估计](/inference/interval)”一章）。这是抽样调查成为现代统计调查主要方式的原因。
:::

## 概率抽样的基本方式 {.core}

::: core 四种基本的概率抽样
- **简单随机抽样**：总体中每个大小为 $n$ 的子集被抽中的可能性相等，如抽签、用随机数表或计算机产生随机数。
- **分层抽样**（类型抽样）：先把总体按某个标志分成若干互不重叠的 **层**，再在每层内独立地进行简单随机抽样。
- **整群抽样**：把总体分成若干 **群**（如村、班级、街区），随机抽取若干群，对抽中的群内所有单位全部调查。
- **系统抽样**（等距抽样）：把总体单位排成一列，随机确定起点后，每隔 $k$ 个单位抽一个。

实际的大型调查常把它们组合起来，例如先抽县、再抽村、再抽户，称为 **多阶段抽样**。
:::

::: geo 几何直观：方差的分解决定了谁更有效
总体的方差可以分解为 **层间（群间）差异** 与 **层内（群内）差异** 两部分（这是“[协方差、相关与条件期望](/probability/dependence)”一章全方差公式的样本版本）：

- **分层抽样** 在每一层都抽取了样本，层间差异被“固定”下来，不进入抽样误差；只有层内差异起作用。所以 **层与层差异越大、层内越相似，分层的效果越好**。
- **整群抽样** 恰恰相反：群内的单位全部调查，群内差异不进入误差；而只抽到少数几个群，群间差异全部变成了抽样误差。所以 **群内越相似、群间差异越大，整群抽样的效果越差**。

分层要“层内同质、层间异质”，分群要“群内异质、群间同质”——两条原则方向相反，背后是同一个方差分解。
:::

::: key 分层抽样的样本分配
- **比例分配**：各层的样本量与层的大小成比例，$n_h=n\cdot\dfrac{N_h}N$；
- **奈曼最优分配**：$n_h\propto N_hS_h$，层越大、层内差异 $S_h$ 越大，分配的样本越多。

分层抽样对总体均值的估计为 $\bar y_{st}=\sum_hW_h\bar y_h$，其中 $W_h=N_h/N$ 为层权；忽略有限总体修正时，其方差为 $\sum_hW_h^2S_h^2/n_h$。
:::

::: pitfall 系统抽样遇上周期
系统抽样简单易行，名单的排列与研究的变量无关时，它的效果与简单随机抽样相当；名单按某个相关标志排序时（如上面的实验按村排列），它相当于一种隐性的分层，效果更好。但如果名单有 **周期性**，而抽样间隔恰好与周期吻合，结果会很糟：例如每层楼 10 户、按门牌号排列，若间隔为 10，抽到的可能全是靠楼梯口的户型，或全是周末的销售数据。
:::

### 非概率抽样

方便抽样（街头拦访）、判断抽样（专家选定）、配额抽样（按性别、年龄等配额拦访）、滚雪球抽样（由已知对象介绍新对象）不遵循随机原则，成本低，适合探索性研究，但 **无法客观地评价误差**，用于推断总体时要格外谨慎。

## 调查误差 {.key}

::: core 抽样误差与非抽样误差
- **抽样误差**：由于只调查部分单位而产生的随机误差，是抽样调查固有的。它可以计算，随样本量增大而减小（约与 $1/\sqrt n$ 成正比）。
- **非抽样误差**：其他一切原因造成的误差，包括
  - **抽样框误差**（覆盖误差）：抽样名单与目标总体不一致；
  - **无回答误差**：被抽中的人拒绝回答或联系不上，而回答者与不回答者有系统差别；
  - **计量误差**：问卷措辞、调查员、受访者记忆或说谎造成的偏差；
  - **处理误差**：录入、编码、汇总中的差错。

非抽样误差往往是 **系统性** 的，**不会因为样本变大而减小**，在普查中同样存在。
:::

::: example 例 1　《文学文摘》为什么失败
《文学文摘》的问卷寄给了杂志订户、电话用户和汽车登记车主。1936 年正值大萧条，拥有电话和汽车的多是较富裕、更倾向共和党的选民——**抽样框误差**。此外，只有约 24% 的人寄回了问卷，愿意回信的人政治热情更高——**无回答误差**。两种偏差叠加，240 万份问卷的“精确”只是在精确地测量一个错误的对象。

盖洛普的样本小得多，但更接近随机样本，偏差更小。这个例子说明：**偏差无法靠增加样本量来消除**。
:::

::: quiz
某城市想了解居民对公共交通的满意度，在地铁站出口随机拦访了 2000 名乘客。这次调查最主要的问题是
- [ ] 样本量太小
- [x] 抽样框与目标总体不一致，不坐地铁的居民被排除在外
- [ ] 应该采用普查
- [ ] 拦访的时间太短

:::

## 问卷设计 {.key}

问卷是收集一手数据最常用的工具。好的问卷要避免以下问题：

- **诱导性提问**：“您是否同意大多数专家支持的这项政策？”会把答案引向“同意”；
- **双重问题**：“您对本店的价格和服务满意吗？”价格满意而服务不满意的人无从回答；
- **含义模糊**：“您经常锻炼吗？”“经常”因人而异，应改为“过去一周您锻炼了几次？”；
- **选项不完备或有重叠**：收入分组“1000～2000、2000～3000”中 2000 归哪一组？
- **敏感问题**：直接问“您是否逃过税”难以得到真实回答，可以采用 **随机化回答技术**（见“[条件概率与独立性](/probability/conditional)”一章练习 5）。

:::: l2 进阶：观测研究与随机化实验
要回答“某种措施有没有效果”这样的因果问题，观测数据常常被混杂因素干扰（参见“[统计学与数据](/descriptive/intro)”一章的辛普森悖论）。**随机化实验** 通过三条原则克服这一点：

1. **对照**：设置不接受处理的对照组；
2. **随机化**：用随机的方式决定谁进入处理组、谁进入对照组，使两组在所有已知和未知的因素上（在概率意义下）可比；
3. **重复**：每组有足够多的实验单位，使随机误差可以被估计和控制。

费希尔在 1920—1930 年代把这些原则系统化，建立了实验设计学科。现代药物的临床试验、互联网公司的 A/B 测试，都遵循这些原则。数据分析方法（如方差分析）只能处理随机误差，**设计不当造成的偏差，任何分析方法都无法事后补救**。
::::

## 本章小结

- 统计调查方式：普查、抽样调查、重点调查、典型调查、统计报表；只有概率抽样能客观地评价推断误差。
- 概率抽样：简单随机、分层、整群、系统、多阶段。分层要层内同质、层间异质；整群在群内相似时误差大；系统抽样怕周期性。
- 误差：抽样误差可计算、随 $n$ 减小；非抽样误差（覆盖、无回答、计量、处理）多为系统偏差，不随 $n$ 减小。
- 问卷要避免诱导、双重、模糊、选项不当；因果问题靠随机化实验。

| 方式 | 适用场合 | 能否推断总体 |
| --- | --- | --- |
| 普查 | 需要全面、精确的基础资料 | 不需要推断 |
| 简单随机抽样 | 总体较均匀、有完整名单 | 能 |
| 分层抽样 | 总体可按某标志分成差异明显的几部分 | 能，通常更精确 |
| 整群抽样 | 缺少单位名单，或单位分散、调查成本高 | 能，通常误差较大 |
| 系统抽样 | 名单已排好序，抽样方便 | 能，注意周期性 |
| 重点调查、典型调查 | 快速了解基本情况、总结经验 | 不能 |

## 分层练习

### 基础

**1.** 下列调查任务宜采用哪种调查方式？(1) 摸清全国人口的数量与结构；(2) 检验一批灯泡的使用寿命；(3) 迅速了解全国钢产量的基本情况；(4) 总结某乡村振兴示范村的经验。

::: details 解答
(1) 普查；(2) 抽样调查（寿命检验是破坏性的，只能抽样）；(3) 重点调查（少数大型钢铁企业的产量占全国的大部分）；(4) 典型调查。
:::

**2.** 某县有甲、乙、丙三个乡镇，分别有 5000、3000、2000 户。要抽取 200 户进行收入调查，采用按乡镇分层、比例分配的分层抽样，各乡镇应抽多少户？

::: details 解答
$n_h=200\times N_h/N$：甲 100 户，乙 60 户，丙 40 户。
:::

**3.** 指出下列做法中可能存在的误差类型：(1) 用电话号码簿抽取样本调查居民收入；(2) 问卷中问“您认为政府应该加大对教育这一关系民族未来的事业的投入吗？”；(3) 一半被抽中的家庭拒绝接受调查。

::: details 解答
(1) 抽样框误差：没有固定电话的家庭被排除；(2) 计量误差：诱导性提问；(3) 无回答误差：拒访家庭可能与接受调查的家庭在收入上有系统差别。
:::

### 提高

**4.** 第 2 题中，若三个乡镇的样本均值分别为 30、50、80（千元），样本标准差分别为 6、8、12。求全县户均收入的分层估计及其标准误（忽略有限总体修正）。

::: details 解答
层权 $W=(0.5,0.3,0.2)$。$\bar y_{st}=0.5\times30+0.3\times50+0.2\times80=46$ 千元。
$$\operatorname{Var}(\bar y_{st})=\frac{0.25\times36}{100}+\frac{0.09\times64}{60}+\frac{0.04\times144}{40}=0.09+0.096+0.144=0.33,$$
标准误约为 0.574 千元。
:::

**5.** 第 4 题中若改用奈曼最优分配，200 户应如何分配？

::: details 解答
$n_h\propto W_hS_h$：$0.5\times6=3$，$0.3\times8=2.4$，$0.2\times12=2.4$，合计 7.8。所以甲 $200\times3/7.8\approx77$ 户，乙、丙各约 61～62 户。差异大的丙镇分到的样本比比例分配时多了一半。
:::

**6.** 某小区有 10 栋楼，每栋 12 层、每层 4 户，住户名单按“楼—层—户”顺序排列。若用系统抽样每隔 4 户抽 1 户来调查住房面积，可能出现什么问题？

::: details 解答
间隔 4 恰好等于每层的户数，随机起点一旦确定，抽到的就全部是同一个位置的户型（例如都是靠楼梯口的小户型），估计会有严重偏差。应改用与周期不相关的间隔，或先把名单随机排列。
:::

### 挑战

**7.** 某次整群抽样中，每个群有 $m=20$ 户，群内相关系数 $\rho=0.4$。整群抽样的方差约为同样样本量的简单随机抽样的 $1+(m-1)\rho$ 倍（称为 **设计效应**）。抽 5 个群共 100 户，相当于多少户的简单随机样本？

::: details 解答
设计效应 $\text{deff}=1+19\times0.4=8.6$。100 户整群样本的精度只相当于约 $100/8.6\approx12$ 户的简单随机样本——同村住户的信息高度重复。所以整群抽样宜多抽群、每群少抽户。
:::

**8.** 设总体分为 $H$ 层，层权 $W_h$，层均值 $\bar Y_h$，层方差 $S_h^2$。忽略有限总体修正，证明比例分配的分层抽样的方差不大于简单随机抽样的方差。

::: details 解答
比例分配时 $n_h=nW_h$，$\operatorname{Var}(\bar y_{st})=\sum W_h^2S_h^2/(nW_h)=\frac1n\sum W_hS_h^2$。简单随机抽样的方差为 $S^2/n$，而总体方差可分解为（近似地）
$$S^2\approx\sum_hW_hS_h^2+\sum_hW_h(\bar Y_h-\bar Y)^2,$$
即层内方差的平均加上层间方差。所以 $\frac{S^2}n-\operatorname{Var}(\bar y_{st})\approx\frac1n\sum W_h(\bar Y_h-\bar Y)^2\ge0$。层间差异越大，分层的收益越大；各层均值相同时，分层没有收益。
:::

## 代码实现（Python）

::: details 展开代码：比较三种抽样方式的标准误
```python
import numpy as np

rng = np.random.default_rng(42)

# 模拟总体：4 个地区、50 个村、每村 20 户；地区差异大，同村收入相似
region_mean = np.repeat([40, 60, 80, 100], [13, 12, 13, 12])          # 每个村所属地区的均值
village_effect = rng.normal(0, 12, 50)
y = (region_mean + village_effect)[:, None] + rng.normal(0, 15, (50, 20))   # 50 村 × 20 户
region = np.repeat(np.repeat([0, 1, 2, 3], [13, 12, 13, 12]), 20)
flat = y.ravel()
print("总体均值：", flat.mean().round(2))

R, n = 5000, 100
srs = [rng.choice(flat, n, replace=False).mean() for _ in range(R)]

def stratified():
    est = 0
    for h in range(4):
        units = flat[region == h]
        k = round(n * len(units) / len(flat))
        est += len(units) / len(flat) * rng.choice(units, k, replace=False).mean()
    return est

strat = [stratified() for _ in range(R)]
cluster = [y[rng.choice(50, 5, replace=False)].mean() for _ in range(R)]

for name, est in [("简单随机", srs), ("分层", strat), ("整群", cluster)]:
    print(f"{name}抽样：估计的均值 {np.mean(est):.2f}，标准误 {np.std(est):.2f}")
```
:::

::: info 史话：从“代表性方法”到奈曼
1895 年，挪威统计局局长凯尔在国际统计学会会议上提出用“代表性方法”（部分调查）代替全面调查，遭到许多人的激烈反对——当时的主流观点认为只有普查才算统计。经过几十年的争论，抽样调查才逐渐被接受。1934 年，奈曼发表论文，比较了随机抽样与“有目的的选择”，从理论上证明了随机抽样的优越性，并给出了分层抽样的最优分配公式。此后，抽样调查迅速成为各国政府统计的基本方法。
:::
