# 数据的整理与显示

调查收回了几百份问卷，录入后是一张密密麻麻的数字表。直接盯着原始数据，几乎看不出任何规律。**整理** 就是把杂乱的原始数据变成有条理的表格和图形，让数据的分布特征显现出来：集中在哪里、分散到多大范围、是否对称、有没有异常值。

## 统计分组 {.core}

::: core 统计分组
根据研究目的，按照某个标志把总体划分为若干性质不同的组，称为 **统计分组**。分组要遵循两条原则：**穷尽**（每个单位都有组可归）和 **互斥**（每个单位只能归入一组）。

- 按 **品质标志** 分组：如按性别、行业、学历；
- 按 **数量标志** 分组：变量值较少时可以一个值一组（**单项式分组**），否则把一个区间作为一组（**组距式分组**）。
:::

组距式分组的几个术语：

- **组限**：每组的两个端点，小的叫下限，大的叫上限；
- **组距** = 上限 − 下限；**组中值** = (上限 + 下限)/2，用来代表这一组的一般水平；
- **开口组**：“60 岁以上”这类缺少下限或上限的组，组中值通常参照相邻组的组距来确定；
- **上限不在内** 原则：恰好等于某组上限的数据，归入下一组。例如“60～70”分一组时，70 分归入“70～80”组。

组数多少合适？太少会掩盖分布的形状，太多则会使分布显得杂乱。常用的经验公式是 **斯特奇斯公式**：
$$k\approx1+\log_2n=1+3.322\lg n.$$
它只是一个参考，最终要看哪种分法最能反映数据的特征。

## 频数分布 {.core}

::: core 频数分布表
把数据分组后，列出各组的单位数（**频数**）和它占总数的比重（**频率**），就得到 **频数分布**。从变量值小的组开始逐组累加，得到 **向上累计** 频数（“不超过某值的有多少”）；从大的组开始累加，得到 **向下累计** 频数（“不低于某值的有多少”）。
:::

::: example 例 1　工人日加工零件数
某车间 40 名工人某日加工的零件数如下（已排序）：

107 108 110 112 113 115 116 117 117 118 119 120 120 121 122 122 123 124 124 125
125 126 127 128 128 129 130 131 132 133 134 135 136 137 138 140 141 143 145 148

极差为 $148-107=41$。斯特奇斯公式给出 $k\approx1+\log_240\approx6.3$ 组，这里取组距 5、分 9 组，以便更细地看清形状：

| 零件数 | 频数 | 频率 | 向上累计频数 | 向上累计频率 |
| --- | --- | --- | --- | --- |
| 105～110 | 2 | 5.0% | 2 | 5.0% |
| 110～115 | 3 | 7.5% | 5 | 12.5% |
| 115～120 | 6 | 15.0% | 11 | 27.5% |
| 120～125 | 8 | 20.0% | 19 | 47.5% |
| 125～130 | 7 | 17.5% | 26 | 65.0% |
| 130～135 | 5 | 12.5% | 31 | 77.5% |
| 135～140 | 4 | 10.0% | 35 | 87.5% |
| 140～145 | 3 | 7.5% | 38 | 95.0% |
| 145～150 | 2 | 5.0% | 40 | 100.0% |

分布呈中间高、两头低的单峰形状，略有右偏。从累计频率可以读出：约一半工人的日加工量不超过 125 件。
:::

## 数据的图示 {.key}

不同类型的数据适合不同的图形：

| 数据类型 | 常用图形 |
| --- | --- |
| 品质数据（定类、定序） | 条形图、饼图、帕累托图 |
| 数值数据的分布 | 直方图、茎叶图、箱线图、累计频率图 |
| 两个数值变量的关系 | 散点图 |
| 时间序列 | 折线图 |

### 直方图

::: core 直方图
用相连的矩形表示频数分布：横轴是变量值，每个矩形的底是一组的组距，**矩形的面积** 表示该组的频数（或频率）。组距相等时，矩形的高也与频数成正比；组距不等时，高度应取 **频数密度**（频数 ÷ 组距）。
:::

::: geo 几何直观：直方图是密度的雏形
如果纵轴取“频率 ÷ 组距”，直方图所有矩形的总面积就是 1。样本量越大、组距越小，这个台阶形的图形就越接近总体的 **概率密度曲线**。“[随机变量及其数字特征](/probability/random-variables)”一章中“概率是密度曲线下的面积”，正是直方图“频率是矩形面积”的理想化。
:::

**试一试**

1. 把组距从 10 调到 2，再调到 20：直方图看起来像一个峰，还是两个峰？哪个组距最能反映这组成绩的结构？
2. 固定组距为 10，只改变起点偏移，图形的形状会不会变？
3. 这组成绩其实来自两个学习状态不同的群体。哪种图形更容易发现“两个峰”？箱线图能看出来吗？

::: pitfall 不等距分组的直方图
收入分组常常不等距，如“0～2000、2000～5000、5000～10000、10000～50000”。若直接用频数作高，最宽的一组会显得人数最多、非常“壮观”，严重误导读者。正确的做法是以 **频数密度** 为高，让面积而不是高度代表频数。
:::

### 茎叶图与箱线图

**茎叶图** 把每个数据拆成“茎”（如十位）和“叶”（如个位），既保留了每个原始数据，又显示出分布的形状，适合数据量不大的情形。上面实验中可以展开看到它。

::: core 箱线图与五数概括
**五数概括**：最小值、下四分位数 $Q_1$、中位数、上四分位数 $Q_3$、最大值。**四分位距** $IQR=Q_3-Q_1$ 是中间 50% 数据的范围。

**箱线图** 用一个箱子画出 $Q_1$ 到 $Q_3$，箱中的线是中位数；两侧的须线延伸到距箱子 $1.5\,IQR$ 以内最远的数据；超出这个范围的点单独标出，作为可能的 **离群值**。
:::

::: example 例 2　工人数据的五数概括
例 1 中 $n=40$。按茆书的样本分位数定义（$np$ 为整数时取第 $np$ 与第 $np+1$ 个次序值的平均）：$Q_1=(x_{(10)}+x_{(11)})/2=118.5$，中位数 $=(x_{(20)}+x_{(21)})/2=125$，$Q_3=(x_{(30)}+x_{(31)})/2=133.5$。$IQR=15$，离群值的判断界限为 $118.5-22.5=96$ 和 $133.5+22.5=156$，数据全在界限之内，没有离群值。
:::

::: pitfall 分位数有不同的算法
样本分位数没有唯一的定义：教材、Excel、numpy、R 的默认算法各不相同（R 就提供了 9 种）。对上面的数据，numpy 默认算法给出的 $Q_1$ 是 118.75，而不是 118.5。样本量较大时差别很小；比较不同来源的结果时，要先确认算法。
:::

::: quiz 15
例 2 中工人日加工零件数的四分位距是多少？
> $IQR=Q_3-Q_1=133.5-118.5=15$。
:::

### 累计频率图与洛伦兹曲线 {.key}

把向上累计频率画成折线，得到 **累计频率图**，它是总体分布函数的近似，称为 **经验分布函数**（见“[统计量与抽样分布](/inference/sampling)”一章）。

:::: l2 进阶：洛伦兹曲线与基尼系数
研究收入分配时，把家庭按收入从低到高排列，横轴取 **累计人口比例**，纵轴取这些家庭的 **累计收入比例**，得到 **洛伦兹曲线**。若收入完全平均，曲线就是对角线；收入越不平等，曲线越向右下方弯曲。

**基尼系数** 是对角线与洛伦兹曲线之间的面积占对角线下三角形面积（1/2）的比例：
$$G=\frac{\text{对角线与洛伦兹曲线之间的面积}}{1/2}=1-2\times(\text{洛伦兹曲线下的面积}).$$
$G=0$ 表示绝对平均，$G$ 越接近 1 越不平等。国际上通常把 0.4 视为收入差距的“警戒线”。

**例**：5 户家庭的收入为 10、20、30、40、100（千元），合计 200。累计收入比例依次为 0.05、0.15、0.30、0.50、1。用梯形法求洛伦兹曲线下的面积：
$$0.2\times\frac{(0+0.05)+(0.05+0.15)+(0.15+0.30)+(0.30+0.50)+(0.50+1)}{2}=0.30,$$
基尼系数 $G=1-2\times0.30=0.40$。几何上一目了然：曲线下的面积越小，弯曲越厉害，分配越不平等。
::::

## 统计表

统计表由 **总标题**（表的名称）、**横行标题**、**纵栏标题** 和 **数字资料** 组成；从内容上分为说明总体的 **主词** 和说明总体特征的 **宾词**。好的统计表应当：标题简明，注明时间、地点和计量单位；数字对齐，小数位一致；必要时注明资料来源；尽量少用竖线，以三线表为主。

## 本章小结

- **统计分组** 要穷尽、互斥；组距式分组注意组限、组中值和“上限不在内”；组数可参考斯特奇斯公式。
- **频数分布**：频数、频率、向上累计与向下累计。
- **图示**：品质数据用条形图、饼图；数值数据用直方图、茎叶图、箱线图；直方图以 **面积** 表示频数，不等距时用频数密度。
- **五数概括与箱线图**：$IQR$ 与 $1.5\,IQR$ 规则判断离群值；分位数有多种算法。
- **洛伦兹曲线与基尼系数** 用面积度量分配的不平等。

| 概念 | 公式或规则 |
| --- | --- |
| 组中值 | (上限 + 下限)/2 |
| 斯特奇斯公式 | $k\approx1+\log_2n$ |
| 频数密度 | 频数 ÷ 组距 |
| 四分位距 | $IQR=Q_3-Q_1$ |
| 离群值界限 | $Q_1-1.5\,IQR$，$Q_3+1.5\,IQR$ |
| 基尼系数 | $G=1-2\times$ 洛伦兹曲线下面积 |

## 分层练习

### 基础

**1.** 某班 50 名学生的统计学成绩分为“60 以下、60～70、70～80、80～90、90 以上”五组，频数分别为 4、9、18、14、5。求各组频率、组中值（开口组参照相邻组的组距）与向上累计频率。

::: details 解答
频率：8%、18%、36%、28%、10%。组中值：55、65、75、85、95（“60 以下”参照相邻组距 10，下限取 50；“90 以上”上限取 100）。向上累计频率：8%、26%、62%、90%、100%。
:::

**2.** 按“上限不在内”原则，成绩 70 分、80 分分别归入第 1 题的哪一组？

::: details 解答
70 分归入“70～80”组，80 分归入“80～90”组。
:::

**3.** 一组数据的 $Q_1=20$，$Q_3=35$。判断 5、58 是否为离群值。

::: details 解答
$IQR=15$，界限为 $20-22.5=-2.5$ 和 $35+22.5=57.5$。5 不是离群值，58 超过 57.5，是离群值。
:::

### 提高

**4.** 某市居民收入分组为“0～2000 元 300 户、2000～5000 元 600 户、5000～10000 元 500 户、10000～50000 元 400 户”。若用频数作直方图的高，会产生什么误导？应怎样画？

::: details 解答
四组的组距分别为 2000、3000、5000、40000。以频数为高时，最宽的一组（10000～50000 元）看起来“面积”最大，仿佛高收入者占了大多数。应以频数密度为高：每千元的户数分别为 150、200、100、10，这样矩形面积才正比于户数，可以看出收入集中在 2000～5000 元，高收入组虽然跨度大但很稀疏。
:::

**5.** 证明：基尼系数也可以写成 $G=\dfrac{1}{2n^2\bar x}\sum_{i=1}^n\sum_{j=1}^n|x_i-x_j|$，并用它验证正文例子中 $G=0.40$。

::: details 解答
（证明从略，可用把洛伦兹曲线下的梯形面积展开整理得到。）验证：5 个收入两两之差的绝对值之和（不计顺序）为 400，计顺序为 800；$\bar x=40$，$n=5$，$G=800/(2\times25\times40)=0.40$，与梯形法一致。这个公式说明基尼系数度量的是 **任意两户之间收入差距的平均水平**（相对于平均收入）。
:::

### 挑战

**6.** 同一组数据，直方图的形状会随组距和起点改变。请说明 **核密度估计** 的思想：它是如何避免对起点的依赖的？

::: details 解答
直方图把每个数据点的“贡献”平均分配到它所在的那一个组里，组的边界是人为划定的，所以图形依赖于起点。核密度估计换一种分配方式：以每个数据点为中心放一个小的“钟形”（核函数，如正态密度），所有小钟形的平均就是密度估计
$$\hat p(x)=\frac1{nh}\sum_{i=1}^nK\Big(\frac{x-x_i}h\Big).$$
它没有组的边界，因此与起点无关，而且是光滑的曲线。它仍然有一个类似组距的 **带宽** $h$ 需要选择：$h$ 太小，曲线锯齿多；$h$ 太大，会把双峰抹成单峰。
:::

## 代码实现（Python）

::: details 展开代码：频数分布表、五数概括与基尼系数
```python
import numpy as np
import pandas as pd

x = np.array([107, 108, 110, 112, 113, 115, 116, 117, 117, 118, 119, 120, 120, 121, 122,
              122, 123, 124, 124, 125, 125, 126, 127, 128, 128, 129, 130, 131, 132, 133,
              134, 135, 136, 137, 138, 140, 141, 143, 145, 148])

# 1. 频数分布表（左闭右开，即“上限不在内”）
bins = np.arange(105, 155, 5)
groups = pd.cut(x, bins=bins, right=False)
table = pd.Series(groups).value_counts(sort=False).to_frame("频数")
table["频率"] = table["频数"] / len(x)
table["向上累计频率"] = table["频率"].cumsum()
print(table)

# 2. 五数概括：numpy 的默认算法与教材的定义略有不同
print("numpy 默认：", np.percentile(x, [0, 25, 50, 75, 100]))
print("中点法：    ", np.percentile(x, [0, 25, 50, 75, 100], method="midpoint"))

# 3. 基尼系数
def gini(v):
    v = np.sort(np.asarray(v, dtype=float))
    return np.abs(v[:, None] - v[None, :]).sum() / (2 * len(v) ** 2 * v.mean())

print("基尼系数：", gini([10, 20, 30, 40, 100]))
```
:::

::: info 史话：南丁格尔的玫瑰图
1854 年克里米亚战争期间，南丁格尔在战地医院发现，死于感染等可预防疾病的士兵远多于战死者。为了说服政府改善医院的卫生条件，她设计了一种极坐标形式的面积图（后人称为“玫瑰图”），用扇形面积表示各月不同原因的死亡人数，一目了然地显示出卫生改革后死亡率的大幅下降。她因此成为英国皇家统计学会的第一位女会员。数据的 **可视化**，从一开始就是为了让数据“说服人”。
