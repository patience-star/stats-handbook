# 统计学与数据

每天的新闻里都有统计数字：GDP 增长率、居民消费价格指数、失业率、民意支持率、药物的有效率……统计学就是 **收集、整理、分析和解释数据** 的科学。它研究的不是某一个具体的数，而是数据背后的 **总体规律**，以及在不确定性下怎样作出可靠的判断。

这一章介绍统计学的研究对象、基本概念和数据的类型，并提醒几个最常见的“统计陷阱”。

## 统计学是什么

统计学通常分为两大部分：

- **描述统计**：用表格、图形和概括性的数字（平均数、比率等）描述数据的特征，例如“本班平均成绩 78 分”；
- **推断统计**：根据 **样本** 的信息推断 **总体** 的特征，并给出推断的可靠程度，例如“由 1000 人的调查推断全市居民的支持率在 49%～55% 之间，置信水平 95%”。

推断统计以概率论为基础，是本讲义“概率论”与“数理统计”两部分的主题；描述统计是一切分析的起点，是本部分的主题。

::: insight 统计学研究的是“变异”
如果每个人的身高都一样，测一个人就够了，根本不需要统计学。正因为个体之间存在 **差异**（统计上叫 **变异**），才需要研究“总体是什么样子”“差异有多大”“差异从何而来”。统计学的全部方法，都是在与变异打交道：描述它、解释它、在它的干扰下作出推断。
:::

## 基本概念 {.core}

::: core 总体、总体单位与样本
- **统计总体**：由客观存在的、具有某种共同性质的许多个别事物组成的整体，简称总体。如某市的全部工业企业、某校的全部学生。
- **总体单位**：构成总体的每一个个别事物，如每一家企业、每一名学生。
- **样本**：从总体中抽取的一部分单位。

总体要满足 **同质性**（各单位在某方面性质相同）、**大量性**（单位足够多）和 **变异性**（单位之间在其他方面有差异）。
:::

::: core 标志与指标
- **标志** 是总体单位的属性或特征。表示性质的称为 **品质标志**（如性别、职业），用文字表示；表示数量的称为 **数量标志**（如年龄、工资），用数值表示。
- **统计指标** 是反映 **总体** 数量特征的概念和数值，由指标名称和指标数值组成，如“2024 年全国居民人均可支配收入 41314 元”。
- 若干相互联系的指标组成 **指标体系**，例如“产值 = 职工人数 × 劳动生产率”。

一句话区分：**标志说明总体单位，指标说明总体**。标志值汇总起来就成了指标。
:::

::: example 例 1　区分概念
研究某高校 2025 级新生的身体状况。
- 总体：该校全部 2025 级新生；总体单位：每一名新生；
- 品质标志：性别、生源地；数量标志：身高、体重、肺活量；
- 统计指标：新生人数、平均身高、男生比例、肺活量达标率。

若从中随机抽取 300 名新生测量，这 300 人就是一个样本，由样本算出的平均身高是 **样本指标**（统计量），用来估计全体新生的平均身高这个 **总体指标**（参数）。
:::

::: core 变量
在统计中，可以取不同值的标志和指标统称为 **变量**。只能取整数或可列个值的称为 **离散变量**（职工人数、次品个数）；可以在某个区间内连续取值的称为 **连续变量**（身高、时间）。对应到概率论，就是离散随机变量与连续随机变量。
:::

## 数据的计量尺度 {.key}

数据并不都是“数”。按照能进行的运算由少到多，计量尺度分为四个层次。

| 尺度 | 特点 | 例子 | 能做的运算 | 常用的概括 |
| --- | --- | --- | --- | --- |
| 定类尺度 | 只能分类，没有顺序 | 性别、民族、行业 | $=,\neq$ | 频数、众数 |
| 定序尺度 | 有顺序，差距无意义 | 学历、满意度、名次 | 加上 $<,>$ | 中位数、分位数 |
| 定距尺度 | 差值有意义，没有绝对零点 | 摄氏温度、年份 | 加上 $+,-$ | 均值、标准差 |
| 定比尺度 | 有绝对零点，比值有意义 | 收入、身高、产量 | 加上 $\times,\div$ | 一切运算 |

::: pitfall 定距尺度不能算比值
今天 20℃，昨天 10℃，能说“今天比昨天热一倍”吗？不能。摄氏温度的 0 度是人为规定的，不代表“没有热量”。换算成华氏温度，20℃=68℉，10℃=50℉，比值就不是 2 了。比值只对有 **绝对零点** 的定比尺度有意义：收入 2 万是 1 万的两倍，换成美元也仍是两倍。

同理，问卷中“1 很不满意……5 很满意”是定序数据，严格说来算平均数是有问题的：“满意 4”与“一般 3”的差距，不一定等于“一般 3”与“不满意 2”的差距。实践中常把它近似当作定距数据处理，但要清楚这是一个假设。
:::

::: quiz
下列数据中，属于定序尺度的是
- [ ] 某地区的邮政编码
- [x] 消费者对产品的满意度（很不满意、不满意、一般、满意、很满意）
- [ ] 某城市的日平均气温（℃）
- [ ] 职工的月工资

> 满意度有顺序，但相邻等级之间的“距离”没有确定意义，是定序尺度。邮政编码只是编号，是定类尺度；摄氏温度是定距尺度；工资是定比尺度。
:::

## 数据的来源与类型

- **观测数据与实验数据**：观测数据是在自然状态下记录的（如居民收入调查），实验数据是在人为控制的条件下得到的（如药物临床试验）。只有设计良好的随机化实验，才能可靠地回答“因果”问题。
- **截面数据、时间序列数据与面板数据**：同一时间不同单位的数据（2024 年各省 GDP）是截面数据；同一单位不同时间的数据（1978—2024 年全国 GDP）是时间序列数据，它是本讲义“时间序列分析”部分的研究对象；二者兼有的（各省历年 GDP）是面板数据。
- **一手数据与二手数据**：自己调查、实验得到的是一手数据；来自统计年鉴、数据库、他人研究的是二手数据。使用二手数据前，要弄清它的定义、口径和采集方法。

## 统计的陷阱 {.key}

统计数字常被用来说服人，也常被用来误导人。下面三个陷阱最为常见。

::: example 例 2　辛普森悖论
1986 年发表的一项研究比较了两种治疗肾结石的方法（数据见 Charig 等，1986）：

| | 方法 A | 方法 B |
| --- | --- | --- |
| 小结石 | 81/87 = **93%** | 234/270 = 87% |
| 大结石 | 192/263 = **73%** | 55/80 = 69% |
| 合计 | 273/350 = 78% | 289/350 = **83%** |

无论小结石还是大结石，方法 A 的成功率都更高；可是合起来，方法 B 的成功率反而更高。这就是 **辛普森悖论**。

原因在于两种方法治疗的病人构成不同：方法 A 治疗了更多 **难治的大结石** 病人（263 人），方法 B 的病人大多是 **容易治的小结石**（270 人）。合计成功率是分组成功率的加权平均，而两种方法的“权重”不同。结石大小是一个 **混杂因素**，它既影响选择哪种方法，也影响治疗效果。
:::

::: insight 加权平均的“魔术”
合计成功率是各组成功率的 **加权平均**，权重是各组病人在这种方法中所占的比例：
$$\text{A}:\ 93\%\times\tfrac{87}{350}+73\%\times\tfrac{263}{350}\approx78\%,\qquad \text{B}:\ 87\%\times\tfrac{270}{350}+69\%\times\tfrac{80}{350}\approx83\%.$$
A 的权重偏向成功率低的大结石组，B 的权重偏向小结石组。只要两种方法的病人 **构成比例** 差得足够多，合计结果就可能与每一组的结论相反。“[统计指数](/applied/index-numbers)”一章中的“结构影响”、方差分析中的“组间与组内”，都在处理同一个问题：**总体差异中，有多少来自构成的不同，有多少来自各组内部的真实差别**。
:::

::: pitfall 幸存者偏差
第二次世界大战期间，军方统计返航飞机上的弹孔，发现机翼和机身弹孔最多，打算加固这些部位。统计学家沃尔德指出：应该加固 **没有弹孔** 的部位——发动机和驾驶舱。因为被击中这些部位的飞机根本没能飞回来。只看“幸存下来”的样本，会得到系统性偏误的结论。成功人士的经验总结、基金的历史业绩排行，都容易落入这个陷阱。
:::

::: pitfall 相关不等于因果
冰淇淋销量与溺水人数高度正相关，但吃冰淇淋并不会导致溺水，二者都受 **气温** 这个共同因素驱动。由观测数据发现的相关关系，可能来自混杂因素、反向因果或纯粹的巧合。要回答因果问题，最可靠的办法是随机化实验。
:::

## 本章小结

- 统计学是收集、整理、分析和解释数据的科学，分为描述统计与推断统计；它研究的核心是 **变异**。
- **总体与总体单位**、**标志与指标**（标志说明单位，指标说明总体）、**样本**、**变量**。
- 计量尺度：定类 < 定序 < 定距 < 定比，尺度越高，能做的运算越多。
- 警惕辛普森悖论、幸存者偏差和“相关即因果”。

## 分层练习

### 基础

**1.** 为了解某市 2024 年规模以上工业企业的生产经营状况，进行了一次全面调查。指出其中的总体、总体单位，各举两个品质标志、数量标志和统计指标。

::: details 解答
总体：该市全部规模以上工业企业；总体单位：每一家规模以上工业企业。品质标志：所属行业、所有制类型；数量标志：职工人数、营业收入。统计指标：企业总数、营业收入总额、平均每家企业的利润、亏损企业所占比重。
:::

**2.** 指出下列数据的计量尺度：(1) 性别；(2) 考试名次；(3) 公元纪年；(4) 产品重量；(5) 身份证号码；(6) 学历。

::: details 解答
(1) 定类；(2) 定序；(3) 定距（公元元年不是“时间的起点”，2000 年不是 1000 年的“两倍”）；(4) 定比；(5) 定类（数字只是编号）；(6) 定序。
:::

**3.** 下列变量哪些是离散的，哪些是连续的：企业数、身高、一天中到达的顾客数、产品使用寿命、家庭人口数。

::: details 解答
离散：企业数、顾客数、家庭人口数；连续：身高、使用寿命。
:::

### 提高

**4.** 某大学两个学院的录取情况如下：甲学院男生申请 100 人录取 60 人，女生申请 20 人录取 14 人；乙学院男生申请 20 人录取 4 人，女生申请 100 人录取 25 人。分别计算两个学院和全校的男女录取率，并解释其中的现象。

::: details 解答
甲学院：男 60%，女 70%；乙学院：男 20%，女 25%。两个学院都是女生录取率更高。全校：男生 64/120 ≈ 53.3%，女生 39/120 = 32.5%，反而男生高。

这是辛普森悖论：女生大多申请了录取率低的乙学院，男生大多申请了录取率高的甲学院。“申请哪个学院”是混杂因素。1973 年美国加州大学伯克利分校的录取数据就出现过这样的情形，一度引发性别歧视的质疑，研究者分学院分析后发现并不存在对女生的不利。
:::

**5.** 某网站发布“本站用户调查：92% 的用户对本站满意”，调查方式是在网站首页放置问卷，由访问者自愿填写。这个结论可靠吗？

::: details 解答
不可靠，至少有两个问题：(1) **覆盖偏差**：只调查了仍在访问网站的用户，已经因为不满而离开的用户不在其中——这是幸存者偏差；(2) **自愿回答偏差**：愿意花时间填问卷的人，往往态度更极端或与网站关系更密切。这样的样本不是随机样本，不能代表全体用户。正确的做法见“[数据的搜集](/descriptive/collection)”一章。
:::

### 挑战

**6.** 构造一个辛普森悖论的数值例子，并说明在什么条件下，“每组都是 A 优于 B”在合并后一定仍然成立。

::: details 解答
构造示例：练习 4 即是一例。

合并后 A 的成功率为 $\sum_kw_k^Aa_k$，B 为 $\sum_kw_k^Bb_k$，其中 $w_k$ 是第 $k$ 组在各自方法中所占的比例。若两种方法的 **组构成相同**（$w_k^A=w_k^B=w_k$），则由 $a_k>b_k$ 立即得到 $\sum w_ka_k>\sum w_kb_k$，悖论不会发生。随机化实验正是通过随机分组使两组的构成（在期望意义上）相同，从而消除了混杂因素——这是随机化实验能回答因果问题的根本原因。
:::

## 代码实现（Python）

::: details 展开代码：用 pandas 重现辛普森悖论
```python
import pandas as pd

df = pd.DataFrame({
    "方法": ["A", "A", "B", "B"],
    "结石": ["小", "大", "小", "大"],
    "成功": [81, 192, 234, 55],
    "病人": [87, 263, 270, 80],
})

# 分组成功率：每一组都是 A 更高
df["成功率"] = (df["成功"] / df["病人"]).round(3)
print(df)

# 合并成功率：B 反而更高
total = df.groupby("方法")[["成功", "病人"]].sum()
print((total["成功"] / total["病人"]).round(3))

# 病人构成：A 治疗的大结石病人更多
print(df.pivot(index="方法", columns="结石", values="病人"))
```
:::

::: info 史话：统计学的三个源头
“统计”一词源自拉丁语的“国家”。17 世纪德国的“国势学派”用文字描述国家的人口、土地、财政，1749 年阿亨瓦尔首先使用了“统计学”（Statistik）这个名称。同一时期，英国的配第在《政治算术》中主张“用数字、重量和尺度来说话”，格朗特分析伦敦的死亡登记，开创了用数量方法研究社会现象的“政治算术学派”。19 世纪，比利时的凯特勒把概率论引入社会统计，提出“平均人”的概念。20 世纪初，皮尔逊、戈塞特、费希尔等人建立了以概率论为基础的数理统计学。今天的统计学，正是这几条源流汇合的结果。
:::
