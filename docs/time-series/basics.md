# 水平分析与速度分析

我国的国内生产总值、年末人口、居民消费价格指数……这些数字每年、每季、每月都会公布一次。把同一个指标在不同时间上的数值按时间先后排成一列，就是 **时间序列**。

面对一个时间序列，最先要回答的是两类问题：**水平** 怎样——平均是多少、增加了多少；**速度** 怎样——增长得多快、平均每年增长百分之几。这一章讲的就是这两类描述方法，它们是黄书时间序列分析的基础，也是统计公报里最常见的数字的来历。后面几章再讨论怎样把序列分解为趋势、季节和随机波动，以及怎样建立概率模型来预测。

## 时间序列的种类 {.core}

::: core 时间序列
把同一现象在不同时间上的观测值按时间先后排列，称为 **时间序列**（也叫时间数列、动态数列）。它有两个要素：观测的 **时间** 和对应的 **发展水平**。本章把各期的发展水平记作 $a_0,a_1,\dots,a_n$，其中 $a_0$ 是最初水平，$a_n$ 是最末水平；作为比较基础的一期称为 **基期**，被研究的一期称为 **报告期**。
:::

::: core 按指标的性质分类
- **绝对数时间序列**，又分两种：
  - **时期序列**：每个数值是一段时间内的 **累计量**（流量），如国内生产总值、产量、销售额。各期数值可以相加，相加得到更长时期的总量；数值大小与时期长短有关。
  - **时点序列**：每个数值是某一 **时刻** 的状态（存量），如年末人口、月末库存、存款余额。各期数值相加没有意义；数值大小与间隔长短没有直接关系。
- **相对数时间序列** 与 **平均数时间序列**：由两个绝对数序列对比得到，如第三产业增加值占比、人均国内生产总值、平均工资。各期数值也不能相加。
:::

::: insight 存量与流量
时点序列和时期序列的关系，就是存量与流量的关系：
$$\text{期末库存}=\text{期初库存}+\text{本期入库}-\text{本期出库}.$$
如果把存量看成一条随时间连续变化的曲线 $a(t)$，时点序列就是在某些时刻量出的曲线的 **高度**；而流量是一段时间内累积起来的量，相当于一块 **面积**。正是这个区别，决定了两种序列的平均数要用不同的公式计算。
:::

::: pitfall 可比性：编制时间序列的基本要求
时间序列是为了比较各期数值而编制的，所以各期数值必须可比：**时期长短** 应当一致（时期序列）；**总体范围** 应当一致（行政区划调整后要换算）；**计算口径与方法** 应当一致（现价还是不变价、用什么汇率换算）；**经济内容** 应当一致。下面的例 4 会看到，用美元现价计算的我国国内生产总值，各年的增长速度会被价格和汇率的变动严重扭曲。
:::

## 序时平均数 {.core}

把各期的发展水平加以平均，得到的平均数称为 **序时平均数**（平均发展水平）。它和前面“[分布特征的描述](/descriptive/measures)”一章的平均数不同：那里是对同一时间的各个单位求平均（静态平均），这里是对同一现象的各个时间求平均（动态平均）。计算方法取决于序列的种类。

::: core 绝对数序列的序时平均数
设各期（各时点）的数值为 $a_1,a_2,\dots,a_n$。

1. **时期序列**：简单算术平均 $\bar a=\dfrac{a_1+a_2+\cdots+a_n}{n}$。
2. **连续时点序列**：逐日登记时用简单算术平均；只在数值变动时才登记，则以每个数值持续的时间 $f_i$ 为权数：$\bar a=\dfrac{\sum a_if_i}{\sum f_i}$。
3. **间隔相等的间断时点序列**：**首末折半法**
$$\bar a=\frac{\frac{a_1}{2}+a_2+\cdots+a_{n-1}+\frac{a_n}{2}}{n-1}.$$
4. **间隔不等的间断时点序列**：以间隔长度 $f_i$（$a_i$ 与 $a_{i+1}$ 之间的时间）为权数，对相邻两点的平均数加权：
$$\bar a=\frac{\frac{a_1+a_2}{2}f_1+\frac{a_2+a_3}{2}f_2+\cdots+\frac{a_{n-1}+a_n}{2}f_{n-1}}{f_1+f_2+\cdots+f_{n-1}}.$$
:::

::: geo 几何直观：平均高度 = 面积 ÷ 宽度
设存量随时间变化的曲线为 $a(t)$，它在 $[0,T]$ 上的平均水平是
$$\bar a=\frac1T\int_0^Ta(t)\,\mathrm dt,$$
也就是与曲线下面积相等的那个矩形的高度。间断时点序列只量出了曲线在几个时刻的高度，中间怎样变化并不知道：

- 假定相邻两次记录之间 **均匀变动**，曲线就是一条折线，曲线下的面积是一串 **梯形** 的面积之和，梯形面积 $\frac{a_i+a_{i+1}}{2}f_i$ 正是公式 4 分子中的各项。间隔相等时，中间的每个点同时属于左右两个梯形，首末两点各只属于一个——这就是“首末折半”。它其实就是数值积分里的 **梯形公式**。
- 若数值 **只在登记时才变动**，曲线是阶梯形，面积是一串矩形之和，这就是公式 2。
- 时期序列的每个数值本身已经是一段时间内累积的“面积”，直接平均即可。
:::

::: example 例 1　间隔不等的时点序列
某仓库 2024 年几次盘点的库存量为：1 月 1 日 120 吨，3 月 1 日 150 吨，7 月 1 日 130 吨，10 月 1 日 160 吨，12 月 31 日 140 吨。求全年平均库存。

**解** 相邻两次盘点的间隔依次为 2、4、3、3 个月：
$$\bar a=\frac{\frac{120+150}{2}\times2+\frac{150+130}{2}\times4+\frac{130+160}{2}\times3+\frac{160+140}{2}\times3}{2+4+3+3}=\frac{1715}{12}\approx142.92\ (\text{吨}).$$
若把五个数直接平均，得 140 吨：它让只代表两个月的 1 月 1 日与代表四个月的 3 月 1 日同等重要。
:::

::: example 例 2　我国人口的序时平均
世界银行公布的我国 2015—2024 年年中人口（万人）依次为：137986.0，138779.0，139621.5，140276.0，140774.5，141110.0，141236.0，141217.5，141071.0，140897.5。这是间隔相等（一年）的时点序列，用首末折半法：
$$\bar a=\frac{\frac{137986.0}{2}+138779.0+\cdots+141071.0+\frac{140897.5}{2}}{9}\approx140391.9\ (\text{万人}),$$
即 2015 年年中到 2024 年年中的 9 年间，平均人口约 14.04 亿。十个数的简单平均是 140296.9 万人，偏低了约 95 万人，因为简单平均给了最低的 2015 年完整的一份权数，而按梯形面积它只应占半份。（数据：世界银行 WDI。）
:::

## 相对数与平均数序列的序时平均 {.key}

::: core 分子、分母分别平均
相对数（或平均数）时间序列 $c_i=a_i/b_i$ 的序时平均数，不能直接平均各期的 $c_i$，而要 **分子、分母分别求序时平均，再相除**：
$$\bar c=\frac{\bar a}{\bar b}.$$
$\bar a$ 与 $\bar b$ 按各自是时期序列还是时点序列，选用上面的公式。
:::

道理和“[分布特征的描述](/descriptive/measures)”一章中“已知总量用调和平均”相同：各期的 $c_i$ 是在大小不同的基数 $b_i$ 上算出来的，直接平均等于给了它们相同的权数。

::: example 例 3　月平均劳动生产率
某厂 2024 年第一季度的总产值：1 月 300 万元，2 月 280 万元，3 月 350 万元；月初职工人数：1 月初 200 人，2 月初 210 人，3 月初 206 人，4 月初 214 人。求第一季度的月平均劳动生产率。

**解** 劳动生产率 = 产值 / 平均职工人数。产值是时期序列，$\bar a=(300+280+350)/3=310$ 万元；职工人数是间隔相等的时点序列，$\bar b=(200/2+210+206+214/2)/3\approx207.67$ 人。于是
$$\bar c=\frac{\bar a}{\bar b}=\frac{310}{207.67}\approx1.4928\ (\text{万元/人}).$$
第一季度的劳动生产率是 $930/207.67\approx4.478$ 万元/人，等于月平均的 3 倍。若先算出各月的劳动生产率（1.4634，1.3462，1.6667）再简单平均，得 1.4921，与正确结果只差一点，这是因为各月的平均人数相差不大；基数差别大时，两种算法会相差很多（见下面的小测）。
:::

::: quiz 100 0.01
某公司三个月的实际产值分别为 200、450、300 万元，计划产值分别为 250、400、300 万元。这三个月总的计划完成程度是百分之几？
> 各月的计划完成程度是 80%、112.5%、100%，简单平均得 97.5%，这是错的：它让计划只有 250 万元的月份与计划 400 万元的月份同等重要。正确的做法是分子、分母分别相加：$950/950=100\%$。
:::

## 增长量与平均增长量

::: core 增长量
- **逐期增长量** $a_i-a_{i-1}$：报告期比前一期增加的绝对量；
- **累计增长量** $a_i-a_0$：报告期比固定基期增加的绝对量。各逐期增长量之和等于累计增长量；
- **平均增长量** $=\dfrac{a_n-a_0}{n}$，即逐期增长量的算术平均；
- 月度、季度数据常用 **年距增长量**（同比增长量），如 $a_t-a_{t-12}$，用来消除季节变动的影响。
:::

## 发展速度与增长速度 {.core}

::: core 发展速度与增长速度
- **发展速度** = 报告期水平 / 基期水平。以固定基期为比较基础的是 **定基发展速度** $a_i/a_0$，以前一期为比较基础的是 **环比发展速度** $a_i/a_{i-1}$。
- 二者的关系：**定基发展速度等于各期环比发展速度的连乘积**，相邻两期的定基发展速度之比等于环比发展速度：
$$\frac{a_n}{a_0}=\frac{a_1}{a_0}\cdot\frac{a_2}{a_1}\cdots\frac{a_n}{a_{n-1}},\qquad \frac{a_i/a_0}{a_{i-1}/a_0}=\frac{a_i}{a_{i-1}}.$$
- **增长速度** = 增长量 / 基期水平 = 发展速度 − 1，也分定基与环比。月度、季度数据还常用 **同比**（年距发展速度、年距增长速度），即与上年同期相比。
:::

::: pitfall 增长速度不能直接相加，也不能直接连乘
定基增长速度既不是各期环比增长速度之和，也不是它们的积。要先加 1 化成发展速度，连乘以后再减 1：
$$\frac{a_n}{a_0}-1=(1+g_1)(1+g_2)\cdots(1+g_n)-1.$$
:::

| 年份 | GDP（十亿美元） | 逐期增长量 | 累计增长量 | 环比发展速度 | 定基发展速度 | 增长 1% 的绝对值 |
| --- | --- | --- | --- | --- | --- | --- |
| 2018 | 13894.91 | — | — | — | 100% | — |
| 2019 | 14279.97 | 385.06 | 385.06 | 102.77% | 102.77% | 138.95 |
| 2020 | 14687.74 | 407.77 | 792.83 | 102.86% | 105.71% | 142.80 |
| 2021 | 17820.46 | 3132.72 | 3925.55 | 121.33% | 128.25% | 146.88 |
| 2022 | 17881.78 | 61.32 | 3986.87 | 100.34% | 128.69% | 178.20 |
| 2023 | 17794.78 | −87.00 | 3899.87 | 99.51% | 128.07% | 178.82 |

（数据：世界银行 WDI，现价美元。）可以验证：各逐期增长量之和等于累计增长量 3899.87；$1.0277\times1.0286\times1.2133\times1.0034\times0.9951\approx1.2806$，与 2023 年的定基发展速度 1.2807 只差舍入误差。5 年的平均增长量为 $3899.87/5\approx779.97$ 十亿美元。

:::

::: insight 增长 1% 的绝对值：速度要和水平结合起来看
$$\text{增长 }1\%\text{ 的绝对值}=\frac{\text{逐期增长量}}{\text{环比增长速度}\times100}=\frac{a_{i-1}}{100}.$$
基数越大，同样的增长速度背后的绝对量越大。例 4 中 2023 年每 1% 对应 1788 亿美元，比 2019 年的 1390 亿美元多了近三成。低速增长可能对应很大的增量，高速增长也可能只是小基数上的变化，只看速度会得出片面的结论。
:::

## 平均发展速度与平均增长速度 {.core}

各期的环比发展速度高低不一，要用一个数概括“平均每期发展到原来的多少倍”。由于总的变化是各期环比的 **连乘积**，合理的平均数应当让连乘积保持不变，于是用几何平均。

::: core 水平法（几何平均法）
$$\bar x=\sqrt[n]{\frac{a_1}{a_0}\cdot\frac{a_2}{a_1}\cdots\frac{a_n}{a_{n-1}}}=\sqrt[n]{\frac{a_n}{a_0}},\qquad \text{平均增长速度}=\bar x-1.$$
从 $a_0$ 出发，每期都按 $\bar x$ 发展，$n$ 期以后恰好达到实际的最末水平 $a_n$。
:::

::: geo 几何直观：对数坐标下的一条弦
取对数，
$$\ln\bar x=\frac1n\sum_{i=1}^{n}\ln\frac{a_i}{a_{i-1}}=\frac{\ln a_n-\ln a_0}{n}.$$
**几何平均就是对数增长率的算术平均。** 在对数坐标下，匀速增长的路径是一条直线，水平法的假想路径就是连接首末两点的那条 **弦**，它的斜率只由两个端点决定——中间无论怎样起伏，都不影响水平法的结果。另一方面，由算术–几何平均不等式，环比发展速度的算术平均总不小于几何平均，用它连乘会超过实际达到的水平。
:::

**试一试**

1. “先快后慢”“先慢后快”“先跌后涨”三组环比各不相同，比较它们的水平法结果。打开对数坐标，橙色的线是什么？
2. 这三组的方程式法结果为什么差别很大？哪一种走势的方程式法结果最大？
3. 选“中国 GDP 2015—2023”，把 2021 年的增长速度改成 10%，水平法和方程式法的结果各怎样变化？
4. 验证环比的算术平均总不小于水平法的几何平均。什么情况下两者相等？

::: core 方程式法（累计法）
要求从 $a_0$ 出发每期按 $\bar x$ 发展时，**各期水平之和等于实际各期水平之和**：
$$a_0\bar x+a_0\bar x^2+\cdots+a_0\bar x^n=\sum_{i=1}^na_i,\qquad\text{即}\quad \bar x+\bar x^2+\cdots+\bar x^n=\frac{\sum_{i=1}^na_i}{a_0}.$$
左边随 $\bar x$ 单调增加，方程有唯一的正根。过去要查专门的“平均增长速度查对表”，现在用数值方法求解即可。
:::

::: insight 两种方法各看什么
水平法着眼于 **最末一期达到的水平**，适合“到某年达到多少”这类目标；方程式法着眼于 **整个时期的累计总量**，适合基本建设投资额这类考察全期总和的指标。走势“先快后慢”时，各期水平偏高，累计量大，方程式法的结果高于水平法；“先慢后快”时则相反。

水平法只取决于首末两期，若这两期受到偶然因素的影响（例如遭遇灾害或疫情的年份），结果就会失真。实际分析时应结合各期的环比速度，或分段计算平均速度。
:::

::: example 例 5　我国 GDP（美元现价）2000—2023 年的平均发展速度
2000 年为 1211.33 十亿美元，2023 年为 17794.78 十亿美元，$n=23$。水平法：
$$\bar x=\sqrt[23]{\frac{17794.78}{1211.33}}=\sqrt[23]{14.690}\approx1.1239,$$
按美元现价计算，平均每年增长约 12.39%。方程式法：$\sum_{i=1}^{23}a_i/a_0\approx163.37$，解得 $\bar x\approx1.1424$，即 14.24%，高于水平法。原因是这一时期“先快后慢”：分段计算，2000—2010 年平均增长 17.52%，2010—2020 年为 9.21%。顺便验证不等式：23 个环比发展速度的算术平均为 1.1270，大于几何平均 1.1239。
:::

:::

:::: l2 进阶：对数增长率与“72 法则”
记 $r_i=\ln(a_i/a_{i-1})$，称为 **对数增长率**（也就是连续复利意义下的增长率）。它的好处是 **可加**：$r_1+\cdots+r_n=\ln(a_n/a_0)$，平均对数增长率就是 $\ln\bar x$。增长率不大时，$\ln(1+g)\approx g-\frac{g^2}{2}\approx g$，所以经济学中常把 $100\,\Delta\ln a_t$ 直接当作百分比增长率使用。

由 $(1+g)^T=2$ 得翻一番所需的期数 $T=\dfrac{\ln2}{\ln(1+g)}\approx\dfrac{0.693}{g}$。考虑到 $\ln(1+g)$ 略小于 $g$，实际中常用 $T\approx\dfrac{72}{100g}$，这就是“72 法则”：年增长 6% 约 12 年翻一番，年增长 9% 约 8 年。增长率越大，近似越粗：例 5 的 12.39% 用 72 法则估计为 5.8 年，精确值为 $\ln2/\ln1.1239\approx5.93$ 年。

另一个关系值得记住：设各期对数增长率的方差为 $s^2$，则近似地有
$$\frac{\text{环比的算术平均}}{\text{几何平均}}\approx1+\frac{s^2}{2}.$$
增长越不稳定，算术平均高估得越多。
::::

## 本章小结

- 时间序列分为 **时期序列**（流量，可加）、**时点序列**（存量，不可加）以及相对数、平均数序列；编制时要保证各期数值 **可比**。
- **序时平均数**：时期序列用简单平均；时点序列的平均是曲线下面积 ÷ 时长，间断记录时用梯形近似，等间隔就是 **首末折半法**；相对数序列 **分子、分母分别平均再相除**。
- **速度分析**：定基发展速度 = 环比发展速度的连乘积；增长速度 = 发展速度 − 1，不能直接相加或连乘；“增长 1% 的绝对值” = 前期水平 / 100。
- **平均发展速度**：水平法是环比的几何平均，只由首末两期决定，在对数坐标下是连接首末两点的弦；方程式法使假想路径的累计总量等于实际总量。

| 指标 | 公式 |
| --- | --- |
| 时期序列的序时平均 | $\bar a=\frac{\sum a_i}{n}$ |
| 首末折半法 | $\bar a=\frac{a_1/2+a_2+\cdots+a_{n-1}+a_n/2}{n-1}$ |
| 间隔不等的时点序列 | $\bar a=\frac{\sum\frac{a_i+a_{i+1}}{2}f_i}{\sum f_i}$ |
| 相对数序列的序时平均 | $\bar c=\bar a/\bar b$ |
| 平均增长量 | $\frac{a_n-a_0}{n}$ |
| 定基与环比 | $\frac{a_n}{a_0}=\prod_{i=1}^n\frac{a_i}{a_{i-1}}$ |
| 水平法 | $\bar x=\sqrt[n]{a_n/a_0}$ |
| 方程式法 | $\sum_{i=1}^n\bar x^i=\sum_{i=1}^na_i/a_0$ |

## 分层练习

### 基础

**1.** 判断下列序列的种类：(a) 历年年末全国总人口；(b) 历年粮食产量；(c) 各月末外汇储备余额；(d) 各季度工业增加值；(e) 历年人均国内生产总值。

::: details 解答
(a) 时点序列；(b) 时期序列；(c) 时点序列；(d) 时期序列；(e) 平均数时间序列（国内生产总值是时期指标，除以平均人口）。
:::

**2.** 某商店 2023 年末商品库存额为 50 万元，2024 年各季度末依次为 62、58、66、54 万元。求 2024 年的平均库存额。

::: details 解答
五个时点间隔相等（各一个季度），用首末折半法：$\bar a=(50/2+62+58+66+54/2)/4=238/4=59.5$ 万元。注意 2023 年末的库存就是 2024 年初的库存，必须用上。
:::

**3.** 某企业连续四年的环比增长速度为 5%、8%、−2%、6%。求四年的定基增长速度和年平均增长速度。

::: details 解答
定基发展速度 $=1.05\times1.08\times0.98\times1.06\approx1.1780$，四年累计增长 17.80%。年平均发展速度 $=1.1780^{1/4}\approx1.0418$，年平均增长 4.18%。四个增长速度的算术平均 4.25% 偏高。
:::

**4.** 甲企业去年利润 2400 万元，今年增长 5%；乙企业去年利润 800 万元，今年增长 12%。哪个企业的利润增加得多？各自增长 1% 的绝对值是多少？

::: details 解答
甲增加 $2400\times5\%=120$ 万元，乙增加 $800\times12\%=96$ 万元，甲增加得多，尽管乙的增长速度高得多。增长 1% 的绝对值：甲 24 万元，乙 8 万元。
:::

### 提高

**5.** 某地区 2020—2024 年的国内生产总值依次为 800、880、940、1000、1080 亿元，其中第三产业增加值依次为 400、451、487、530、583 亿元。求这五年第三产业增加值的平均比重。

::: details 解答
两个序列都是时期序列，分子、分母分别平均（相当于分别求和）：$\bar c=\frac{2451}{4700}\approx52.15\%$。各年比重依次为 50.00%、51.25%、51.81%、53.00%、53.98%，简单平均为 52.01%，偏低，因为它给了基数较小的早期年份同样的权数。
:::

**6.** 用梯形面积证明首末折半法：间隔相等（都为 $h$）时，公式 4 化为公式 3。

::: details 解答
所有 $f_i=h$ 时，公式 4 的分子为
$$\frac h2\big[(a_1+a_2)+(a_2+a_3)+\cdots+(a_{n-1}+a_n)\big]=h\Big(\frac{a_1}{2}+a_2+\cdots+a_{n-1}+\frac{a_n}{2}\Big),$$
因为中间的每个 $a_i$ 出现两次、首末两项各出现一次。分母为 $(n-1)h$，约去 $h$ 即得首末折半法。
:::

**7.** 某县 2020 年的基本建设投资为 300 亿元，计划 2021—2025 年的投资总额达到 1800 亿元。按方程式法，年平均增长速度应为多少？若按这个速度增长，2025 年的投资额是多少？

::: details 解答
方程 $\bar x+\bar x^2+\bar x^3+\bar x^4+\bar x^5=1800/300=6$ 的正根约为 $\bar x\approx1.0614$，年平均增长约 6.14%。2025 年投资额为 $300\times1.0614^5\approx404.1$ 亿元。（$\bar x=1$ 时左边等于 5，所以根略大于 1；可用二分法或 `scipy.optimize.brentq` 求得。）
:::

### 挑战

**8.** 设环比发展速度 $x_i=e^{r_i}$，$\bar r$ 与 $s^2$ 分别是 $r_i$ 的均值与（除以 $n$ 的）方差。用泰勒展开说明 $\dfrac{1}{n}\sum x_i\approx e^{\bar r}\big(1+\frac{s^2}{2}\big)$，并用例 5 的数据检验。

::: details 解答
$e^{r_i}=e^{\bar r}e^{r_i-\bar r}\approx e^{\bar r}\big[1+(r_i-\bar r)+\frac12(r_i-\bar r)^2\big]$。对 $i$ 求平均，一次项的平均为 0，二次项的平均为 $s^2/2$，得结论；而 $e^{\bar r}$ 就是几何平均。

例 5 中，23 个对数增长率的标准差 $s\approx0.0742$，$s^2/2\approx0.00275$；实际上算术平均 / 几何平均 $=1.12704/1.12393\approx1.00277$，吻合得很好。
:::

**9.** 证明方程式法的方程有唯一正根；并证明：方程式法的结果大于水平法 ⟺ 实际各期水平之和大于水平法假想路径的各期之和。

::: details 解答
$F(x)=x+x^2+\cdots+x^n$ 在 $(0,\infty)$ 上连续、严格递增，$F(0^+)=0$，$F(x)\to\infty$，而右边 $S=\sum a_i/a_0>0$，所以 $F(x)=S$ 有唯一正根 $\bar x_c$。

记水平法的结果为 $\bar x_g$，它的假想路径之和为 $a_0F(\bar x_g)$。由 $F$ 严格递增，
$$\bar x_c>\bar x_g\iff F(\bar x_c)>F(\bar x_g)\iff \sum a_i>a_0F(\bar x_g).$$
也就是说，实际路径“整体上”位于水平法路径上方时，方程式法的结果更大——这正是“先快后慢”的情形。
:::

## 代码实现（Python）

::: details 展开代码：序时平均与速度分析
```python
import numpy as np
import pandas as pd
from scipy.optimize import brentq
from scipy.stats import gmean

# 例 1：间隔不等的时点序列，梯形面积 ÷ 总时长
t = np.array([0, 2, 6, 9, 12])              # 月份
a = np.array([120, 150, 130, 160, 140])     # 库存（吨）
print("平均库存：", round(np.trapezoid(a, t) / (t[-1] - t[0]), 2))   # NumPy 2.0 以前用 np.trapz

# 例 4、例 5：我国国内生产总值（十亿美元，现价），2000—2023 年
gdp = pd.Series([1211.33, 1339.4, 1470.56, 1660.28, 1955.35, 2285.96, 2752.12, 3550.33,
                 4594.34, 5101.69, 6087.19, 7551.55, 8532.19, 9570.47, 10475.62, 11061.57,
                 11233.31, 12310.49, 13894.91, 14279.97, 14687.74, 17820.46, 17881.78, 17794.78],
                index=range(2000, 2024))
chain = gdp / gdp.shift(1)                  # 环比发展速度
fixed = gdp / gdp[2018]                     # 以 2018 年为基期的定基发展速度
table = pd.DataFrame({"GDP": gdp, "逐期增长量": gdp.diff(), "环比": chain, "定基": fixed,
                      "增长1%的绝对值": gdp.shift(1) / 100}).loc[2018:]
print(table.round(4))

n = len(gdp) - 1
x_level = (gdp.iloc[-1] / gdp.iloc[0]) ** (1 / n)              # 水平法
print("水平法：", round(x_level, 4), "，即环比的几何平均", round(gmean(chain.dropna()), 4))
S = gdp.iloc[1:].sum() / gdp.iloc[0]
x_eq = brentq(lambda x: sum(x ** i for i in range(1, n + 1)) - S, 0.5, 2)   # 方程式法
print("方程式法：", round(x_eq, 4), "，环比的算术平均：", round(chain.mean(), 4))
```
:::

::: info 史话：72 法则
“本金按某个利率复利增长，多少年翻一番？”这个问题至少有五百多年的历史。1494 年，意大利数学家帕乔利（L. Pacioli）在《算术、几何、比与比例概要》中给出了一个经验规则：用 72 除以年利率的百分数，就得到大约翻一番的年数。他没有给出理由，原理正是上文的 $\ln2\approx0.693$ 再加上一点修正。帕乔利的这本书还第一次系统介绍了复式记账法，他因此被称为“会计学之父”。
:::
