# 指数平滑与预测评价

上一章的分解方法擅长描述过去，用来预测却不太顺手：移动平均缺了最近几期的趋势值；拟合一条趋势曲线，又把几十年前的数据和上个月的数据看得同样重要。预测需要的是这样一种方法：**越近的观测越重要**，每来一个新数据就能 **随时更新**，而且计算简单。

**指数平滑** 正是这样的方法。它在 20 世纪 50 年代为库存管理的需求预测而发明，至今仍是企业预测中使用最广的方法之一，在多次大规模预测竞赛中，它的精度常常不输于复杂得多的模型。这一章介绍三种基本的指数平滑方法，以及怎样客观地评价一个预测方法的好坏。

## 简单指数平滑 {.core}

::: core 定义（简单指数平滑）
用 $\hat y_{t+1}$ 表示在第 $t$ 期末对第 $t+1$ 期的预测：
$$\hat y_{t+1}=\alpha y_t+(1-\alpha)\,\hat y_t,\qquad 0<\alpha\le1,$$
$\alpha$ 称为 **平滑系数**，初值常取 $\hat y_1=y_1$（或前几期的平均）。对更远的未来，简单指数平滑给出水平的预测：$\hat y_{t+h}=\hat y_{t+1}$。

把它改写为
$$\hat y_{t+1}=\hat y_t+\alpha\,(y_t-\hat y_t),$$
就是 **误差修正形式**：每一期都把预测值朝实际值的方向移动“上次误差的 $\alpha$ 倍”。
:::

::: geo 几何直观：按几何级数衰减的权数
把递推式反复代入自身：
$$\hat y_{t+1}=\alpha y_t+\alpha(1-\alpha)\,y_{t-1}+\alpha(1-\alpha)^2y_{t-2}+\cdots+(1-\alpha)^t\hat y_1.$$
预测值是全部历史数据的加权平均，$j$ 期以前的观测值的权数是 $\alpha(1-\alpha)^j$，**按几何级数（指数）衰减**，“指数平滑”因此得名。权数之和 $1-(1-\alpha)^t$ 很快趋于 1。

这些权数的“重心”，即被使用数据的 **平均滞后**，是
$$\sum_{j\ge0}j\,\alpha(1-\alpha)^j=\frac{1-\alpha}{\alpha}.$$
$k$ 项尾部移动平均的平均滞后是 $(k-1)/2$，两者相等时 $\alpha=2/(k+1)$：例如 $\alpha=0.2$ 大致相当于 9 期移动平均。$\alpha$ 越小，权数衰减越慢，预测越平稳但反应越迟钝；$\alpha$ 越大，越重视最近的数据，反应快但容易被噪声带着走；$\alpha=1$ 就是 **朴素预测**：用最后一个观测值作为预测。
:::

::: quiz 103
用平滑系数 $\alpha=0.3$ 的简单指数平滑法预测。上一期的预测值是 100，实际值是 110，本期的预测值是多少？
> $\hat y_{t+1}=0.3\times110+0.7\times100=103$。用误差修正形式看：上次误差为 10，预测值向上修正 $0.3\times10=3$。
:::

## Holt 线性趋势法 {.key}

序列有趋势时，简单指数平滑会系统地 **落后**：设 $y_t=a+bt$ 稳定增长，可以证明一步预测误差最终稳定在 $b/\alpha$（见练习 4）——预测永远追不上实际。Holt 的办法是同时平滑 **水平** 和 **斜率** 两个量。

::: core Holt 线性趋势法
$$\begin{aligned}
\text{水平：}&\quad \ell_t=\alpha y_t+(1-\alpha)(\ell_{t-1}+b_{t-1}),\\
\text{斜率：}&\quad b_t=\beta(\ell_t-\ell_{t-1})+(1-\beta)\,b_{t-1},\\
\text{预测：}&\quad \hat y_{t+h}=\ell_t+h\,b_t.
\end{aligned}$$
每个方程都是“新信息”与“旧估计”的加权平均：$\ell_{t-1}+b_{t-1}$ 是上一期对本期水平的预期，$\ell_t-\ell_{t-1}$ 是本期观察到的斜率。
:::

::: insight 阻尼趋势
Holt 法把最后的斜率一直延伸下去，预测期越长越危险——很少有趋势能永远保持不变。**阻尼趋势法** 把预测改为
$$\hat y_{t+h}=\ell_t+(\phi+\phi^2+\cdots+\phi^h)\,b_t,\qquad 0<\phi<1,$$
斜率的作用逐期打折，长期预测趋于一个水平。在预测竞赛中，阻尼趋势法往往比线性外推更可靠。
:::

## Holt–Winters 季节方法 {.key}

::: core Holt–Winters 方法（乘法季节）
设季节周期为 $m$（月度数据 $m=12$）：
$$\begin{aligned}
\ell_t&=\alpha\frac{y_t}{s_{t-m}}+(1-\alpha)(\ell_{t-1}+b_{t-1}),\\
b_t&=\beta(\ell_t-\ell_{t-1})+(1-\beta)\,b_{t-1},\\
s_t&=\gamma\frac{y_t}{\ell_t}+(1-\gamma)\,s_{t-m},\\
\hat y_{t+h}&=(\ell_t+h\,b_t)\,s_{t+h-m},\qquad h\le m.
\end{aligned}$$
（$h>m$ 时使用同一季节最近的季节因子。）**加法季节** 的形式把除法换成减法、乘法换成加法。用 $y_t/s_{t-m}$ 更新水平，相当于先作季节调整；用 $y_t/\ell_t$ 更新季节因子，相当于先剔除趋势——这与上一章的分解思路一脉相承。
:::

初值的取法不止一种。本站的实验用前两个季节：两季均值之差除以 $m$ 作为初始斜率，第一季末的趋势值作为初始水平，第一季各期与这条直线之比作为初始季节因子。参数 $\alpha,\beta,\gamma$ 通常这样选取：使训练期内一步预测误差的平方和最小。

## 预测的评价 {.core}

::: core 误差指标
设检验期的预测误差为 $e_t=y_t-\hat y_t$：
$$\text{MAE}=\frac1n\sum|e_t|,\qquad \text{RMSE}=\sqrt{\frac1n\sum e_t^2},\qquad \text{MAPE}=\frac{100\%}{n}\sum\left|\frac{e_t}{y_t}\right|.$$
- **MAE**（平均绝对误差）与数据同单位，直观、稳健；
- **RMSE**（均方根误差）对大误差惩罚更重，与最小二乘一致；
- **MAPE**（平均绝对百分比误差）没有单位，便于比较不同序列，但 $y_t$ 接近 0 时失效，而且对高估的惩罚重于低估。
:::

::: core 训练期与检验期
把序列分成两段：在 **训练期** 选定方法和参数，然后假装不知道 **检验期** 的数据，对它作预测，再与实际值比较。检验期的精度才是方法真正的预测能力，训练期的拟合程度总是偏乐观。

评价时一定要和简单的 **基准方法** 比较：

- **朴素预测**：$\hat y_{T+h}=y_T$，用最后一个观测值；
- **季节朴素预测**：$\hat y_{T+h}=y_{T+h-m}$，重复最后一个季节周期。

连基准方法都比不过的预测方法，没有使用价值。
:::

::: pitfall 三个常见错误
1. **用检验期选参数**：一旦根据检验期的结果反复调整，检验期就变成了训练期的一部分，评价不再客观。
2. **打乱时间顺序**：时间序列不能像横截面数据那样随机划分训练集和测试集，未来的数据不能用来预测过去。更稳妥的做法是 **滚动起点** 评价：依次以第 $T,T+1,\dots$ 期为终点训练、向后预测，再把各次的误差平均。
3. **只看训练期的拟合**：参数越多，训练期拟合得越好，但未必预测得越好。
:::

:::: l3 深入：指数平滑、ARIMA 与状态空间模型
**简单指数平滑等价于 ARIMA(0,1,1)。** 记一步预测误差 $e_t=y_t-\hat y_t$。由误差修正形式 $\hat y_{t+1}=\hat y_t+\alpha e_t$，
$$y_{t+1}-e_{t+1}=y_t-e_t+\alpha e_t\quad\Longrightarrow\quad y_{t+1}-y_t=e_{t+1}-(1-\alpha)\,e_t.$$
若预测是最优的，误差 $e_t$ 就是白噪声，于是一阶差分 $\nabla y_t$ 是一个 MA(1)，即 $y_t$ 服从 ARIMA(0,1,1)：$\nabla y_t=\varepsilon_t+\theta\varepsilon_{t-1}$，$\theta=\alpha-1$。反过来，ARIMA(0,1,1)（$-1<\theta<0$）的最优预测正是 $\alpha=1+\theta$ 的简单指数平滑。对尼罗河流量拟合 ARIMA(0,1,1)，得 $\hat\theta\approx-0.733$，对应 $\alpha\approx0.27$，与网格搜索得到的 $\alpha=0.25$ 相近（两者的估计准则略有不同）。

有了模型，就有了 **预测区间**：ARIMA(0,1,1) 向前 $h$ 步的预测误差方差为
$$\sigma^2\big[1+(h-1)\alpha^2\big],$$
随 $h$ 线性增大，预测期越长越不确定。类似地，Holt 线性趋势法对应 ARIMA(0,2,2)，加法 Holt–Winters 法对应一种季节 ARIMA 模型（见“[ARIMA 与单位根](/time-series/unit-root)”一章）。

**状态空间框架（ETS）。** Hyndman 等人把各种指数平滑方法统一写成带随机误差的状态空间模型，按误差（加法 A/乘法 M）、趋势（无 N/加法 A/阻尼 Ad）、季节（N/A/M）组合命名，如 ETS(A,N,N) 就是简单指数平滑。这样就能用极大似然估计参数、用 AIC 选择模型、给出预测区间。statsmodels 中的 `ETSModel` 实现了这一框架。
::::

## 本章小结

- **简单指数平滑**：$\hat y_{t+1}=\alpha y_t+(1-\alpha)\hat y_t$；权数 $\alpha(1-\alpha)^j$ 按几何级数衰减，平均滞后 $(1-\alpha)/\alpha$；$\alpha=1$ 为朴素预测。
- **Holt 法** 同时平滑水平与斜率，适合有趋势的序列；**阻尼趋势** 让长期预测趋于平稳；**Holt–Winters 法** 再加上季节因子，有乘法、加法两种形式。
- **预测评价**：MAE、RMSE、MAPE；在训练期选参数、在检验期评价，并与朴素预测、季节朴素预测比较。
- 简单指数平滑等价于 ARIMA(0,1,1)，$\theta=\alpha-1$；指数平滑可以统一到 ETS 状态空间模型中。

| 方法 | 递推式 | 预测 |
| --- | --- | --- |
| 简单指数平滑 | $\hat y_{t+1}=\alpha y_t+(1-\alpha)\hat y_t$ | $\hat y_{t+h}=\hat y_{t+1}$ |
| Holt | $\ell_t=\alpha y_t+(1-\alpha)(\ell_{t-1}+b_{t-1})$，$b_t=\beta(\ell_t-\ell_{t-1})+(1-\beta)b_{t-1}$ | $\ell_t+hb_t$ |
| Holt–Winters（乘法） | 另加 $s_t=\gamma y_t/\ell_t+(1-\gamma)s_{t-m}$，水平用 $y_t/s_{t-m}$ 更新 | $(\ell_t+hb_t)s_{t+h-m}$ |
| 误差指标 | MAE $=\overline{\lvert e\rvert}$，RMSE $=\sqrt{\overline{e^2}}$，MAPE $=\overline{\lvert e/y\rvert}$ | |

## 分层练习

### 基础

**1.** 某商品前 5 周的销量为 20，22，21，25，24（百件）。取 $\alpha=0.4$，$\hat y_1=20$，用简单指数平滑法计算第 2—6 周的预测值，并求第 2—5 周一步预测的平均绝对误差。

::: details 解答
$\hat y_2=0.4\times20+0.6\times20=20$，$\hat y_3=0.4\times22+0.6\times20=20.8$，$\hat y_4=0.4\times21+0.6\times20.8=20.88$，$\hat y_5=0.4\times25+0.6\times20.88=22.528$，$\hat y_6=0.4\times24+0.6\times22.528\approx23.117$。

第 2—5 周的误差依次为 2，0.2，4.12，1.472，MAE $=7.792/4=1.948$。
:::

**2.** 平滑系数 $\alpha=0.3$ 时，最近 5 期观测值的权数各是多少？它们合计占多少？

::: details 解答
权数依次为 $0.3,\ 0.21,\ 0.147,\ 0.1029,\ 0.07203$，合计 $1-0.7^5\approx0.832$。也就是说，预测值约 83% 的“分量”来自最近 5 期。
:::

**3.** 三期的实际值为 100，120，80，预测值为 110，115，90。求 MAE、RMSE 和 MAPE。

::: details 解答
误差为 −10，5，−10。MAE $=25/3\approx8.33$；RMSE $=\sqrt{(100+25+100)/3}=\sqrt{75}\approx8.66$；MAPE $=\frac13\left(\frac{10}{100}+\frac{5}{120}+\frac{10}{80}\right)\approx8.89\%$。
:::

### 提高

**4.** 设 $y_t=a+bt$（$b>0$），用简单指数平滑预测。证明一步预测误差 $e_t=y_t-\hat y_t$ 满足 $e_{t+1}=(1-\alpha)e_t+b$，并求它的极限。这说明了什么？

::: details 解答

$$e_{t+1}=y_{t+1}-\hat y_{t+1}=(y_t+b)-\alpha y_t-(1-\alpha)\hat y_t=(1-\alpha)(y_t-\hat y_t)+b=(1-\alpha)e_t+b.$$
这是一个收缩映射，极限 $e^*$ 满足 $e^*=(1-\alpha)e^*+b$，即 $e^*=b/\alpha$。

预测值永远比实际值低 $b/\alpha$：$\alpha$ 越小（越平滑），落后得越多。要跟上趋势，必须单独估计斜率，这就是 Holt 法。
:::

**5.** 证明简单指数平滑权数的平均滞后是 $(1-\alpha)/\alpha$，并求与 $\alpha=0.1$ 平均滞后相同的尾部移动平均的项数。

::: details 解答
$\sum_{j\ge0}j\alpha q^j$（$q=1-\alpha$）$=\alpha\cdot\dfrac{q}{(1-q)^2}=\dfrac{q}{\alpha}=\dfrac{1-\alpha}{\alpha}$，这里用到 $\sum_jjq^j=q/(1-q)^2$。

$k$ 项尾部移动平均的平均滞后为 $(k-1)/2$。令 $(k-1)/2=9$，得 $k=19$。
:::

**6.** 用 Holt 法预测，已知 $\ell_{t-1}=100$，$b_{t-1}=5$，本期实际值 $y_t=108$，$\alpha=0.5$，$\beta=0.3$。求 $\ell_t$、$b_t$ 和向前 3 期的预测值 $\hat y_{t+3}$。

::: details 解答
$\ell_t=0.5\times108+0.5\times(100+5)=106.5$；$b_t=0.3\times(106.5-100)+0.7\times5=5.45$；$\hat y_{t+3}=106.5+3\times5.45=122.85$。

本期实际值 108 高于预期的 105，水平和斜率都向上作了修正。
:::

### 挑战

**7.** 设 $y_t$ 服从 ARIMA(0,1,1)：$y_t=y_{t-1}+\varepsilon_t+\theta\varepsilon_{t-1}$，$-1<\theta<0$。证明它的一步最优预测满足简单指数平滑的递推式（$\alpha=1+\theta$），并求向前 $h$ 步预测误差的方差。

::: details 解答
已知到 $t$ 期的信息，$\varepsilon_t$ 可由观测值恢复（可逆性），而 $\varepsilon_{t+1}$ 不可预测，所以 $\hat y_{t+1}=y_t+\theta\varepsilon_t$。又 $\varepsilon_t=y_t-\hat y_t$，代入得
$$\hat y_{t+1}=y_t+\theta(y_t-\hat y_t)=(1+\theta)y_t-\theta\hat y_t=\alpha y_t+(1-\alpha)\hat y_t,\qquad\alpha=1+\theta.$$
向前 $h$ 步：$y_{t+h}=y_t+\sum_{j=1}^{h}(\varepsilon_{t+j}+\theta\varepsilon_{t+j-1})$，展开后
$$y_{t+h}-\hat y_{t+h}=\varepsilon_{t+h}+(1+\theta)(\varepsilon_{t+h-1}+\cdots+\varepsilon_{t+1}),$$
方差为 $\sigma^2\big[1+(h-1)(1+\theta)^2\big]=\sigma^2\big[1+(h-1)\alpha^2\big]$。
:::

**8.** 某商品某期实际销量 100，预测 150；另一期实际销量 150，预测 100。两次的绝对误差相同，各自的绝对百分比误差是多少？据此说明 MAPE 的不对称性，以及它会促使预测者倾向于高估还是低估。

::: details 解答
第一次 $50/100=50\%$，第二次 $50/150\approx33.3\%$。同样大小的误差，发生在实际值小的时候（即预测偏高时）被罚得更重。由于百分比误差在高估方向上可以无限大、在低估方向上最多 100%，以 MAPE 为目标的预测者会倾向于 **低估**。这是用 MAPE 评价预测时需要注意的地方。
:::

::: info 史话：从库存管理到预测竞赛
20 世纪 50 年代，布朗（R. G. Brown）把指数平滑用于库存需求的预测；1957 年，霍尔特（C. C. Holt）在为美国海军研究办公室撰写的报告中加入了趋势与季节；1960 年，温特斯（P. R. Winters）用实际数据检验了季节方法的效果，这一方法因此被称为 Holt–Winters 方法。它们最初都只是“经验公式”。1982 年起，马克里达基斯（S. Makridakis）组织了一系列大规模预测竞赛（M 竞赛），用成百上千条实际序列比较各种方法，发现简单的指数平滑法常常与复杂的模型不相上下。直到 21 世纪初，Hyndman 等人用状态空间模型为指数平滑建立了完整的统计基础。
:::
