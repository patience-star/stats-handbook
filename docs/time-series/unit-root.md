# ARIMA 与单位根

国内生产总值、物价水平、汇率、股票价格……许多经济序列都有一个共同的特点：它们四处游荡，并不围绕一个固定的均值或一条固定的趋势线波动。前几章的平稳 ARMA 模型不能直接描述它们。

对这类序列，有两种截然不同的看法：一种认为序列围绕一条 **确定性趋势** 波动，冲击只有暂时的影响；另一种认为序列本身含有 **随机趋势**，每一次冲击都会永久地改变它的路径。两种看法对预测、对统计推断、对经济含义的结论都大不相同。这一章讨论怎样用 ARIMA 模型描述后一种序列，怎样用单位根检验区分两者，以及忽视这一区别会导致的“伪回归”。

## 确定性趋势与随机趋势 {.core}

::: core 两种非平稳序列
- **趋势平稳**（TS）：$x_t=a+bt+u_t$，$u_t$ 是平稳序列。减去确定性趋势后就平稳。
- **差分平稳**（DS）：$x_t=b+x_{t-1}+u_t$，$u_t$ 是平稳序列。反复代入得
$$x_t=x_0+bt+\sum_{i=1}^tu_i,$$
除了确定性的漂移 $bt$，还有一个 **随机趋势** $\sum u_i$。一阶差分 $\nabla x_t=b+u_t$ 才平稳。$u_t$ 为白噪声时，就是 **带漂移的随机游走**。
:::

把两者放进同一个模型：$x_t=a+bt+u_t$，$u_t=\rho u_{t-1}+\varepsilon_t$。$|\rho|<1$ 时是趋势平稳；$\rho=1$ 时 $u_t$ 是随机游走，$x_t$ 就成了差分平稳的序列。$\rho=1$ 对应 AR 多项式 $1-\rho z$ 有一个等于 1 的根，所以称为 **单位根**。

::: geo 几何直观：冲击会不会消失
在第 $t_0$ 期加入一个冲击，它对 $k$ 期以后的影响是 $\rho^k$：

- $\rho<1$：影响按几何级数消失，序列迟早回到原来的趋势线上，冲击是 **暂时的**；预测时，远期预测回到趋势线，预测区间的宽度有上限 $1.96\,\sigma/\sqrt{1-\rho^2}$。
- $\rho=1$：影响永远是 1，序列从此沿着一条平移了的路径前进，冲击是 **永久的**；远期预测沿着漂移方向从最后一个观测值出发，预测区间按 $\sqrt h$ 无限张开。
:::

<UnitRootLab />

**试一试**

1. $\rho=0.5$：第 40 期的冲击很快就消失了，路径紧贴着绿色的趋势线；预测区间很快就不再变宽。
2. 把 $\rho$ 拖到 0.95：冲击的半衰期是多少？路径看起来已经很像随机游走了。DF 检验能否拒绝单位根？
3. $\rho=1$：冲击的影响永不消失，路径离开了趋势线；预测区间一直张开。
4. 在 $\rho=0.95$ 下多换几组随机冲击：DF 检验有几次能正确地拒绝单位根？这说明了什么？

::: pitfall 用错了处理方法
- 对差分平稳的序列 **回归去趋势**，残差 $\sum u_i$ 仍然是随机游走，后续的推断全部失效。
- 对趋势平稳的序列 **差分**，会造成 **过度差分**：$\nabla(a+bt+\varepsilon_t)=b+\varepsilon_t-\varepsilon_{t-1}$ 是一个 $\theta=-1$ 的 MA(1)，不可逆，差分后序列的 $r_1$ 接近 $-0.5$，方差也变成原来的 2 倍。
:::

## ARIMA 模型 {.core}

::: core 定义（ARIMA($p,d,q$) 模型）
若 $d$ 阶差分 $\nabla^dx_t$ 是平稳可逆的 ARMA($p,q$) 序列，即
$$\phi(B)\,(1-B)^d\,x_t=\theta(B)\,\varepsilon_t,$$
其中 $\phi(z)$、$\theta(z)$ 的根都在单位圆外，称 $x_t$ 服从 **ARIMA($p,d,q$) 模型**，称 $x_t$ 为 **$d$ 阶单整** 序列，记作 $x_t\sim I(d)$。把 $\phi(z)(1-z)^d$ 看成一个整体，它恰有 $d$ 个等于 1 的根。
:::

几个熟悉的例子：随机游走是 ARIMA(0,1,0)；“[指数平滑与预测评价](/time-series/smoothing)”一章证明了简单指数平滑等价于 ARIMA(0,1,1)，Holt 线性趋势法等价于 ARIMA(0,2,2)。

::: insight 差分几次
经济序列的水平值（通常先取对数）大多是 $I(1)$，一阶差分就是增长率；$I(2)$ 较少见，如高通胀时期的价格水平。差分后要重新看 ACF：仍然衰减得很慢，说明还要再差分；$r_1$ 接近 $-0.5$、方差反而变大，说明差分过度了。
:::

## 季节 ARIMA 与航空模型 {.key}

::: core 季节 ARIMA 模型
对周期为 $s$ 的季节性序列，用季节差分 $\nabla_s=1-B^s$ 消除季节性，并用 $B^s$ 的多项式描述同一季节在各年之间的相关：
$$\Phi(B^s)\,\phi(B)\,(1-B)^d(1-B^s)^D\,x_t=\Theta(B^s)\,\theta(B)\,\varepsilon_t,$$
记作 ARIMA$(p,d,q)\times(P,D,Q)_s$。
:::

**试一试**

1. 原序列与取对数：ACF 都从接近 1 开始缓慢下降，在 12、24 处略有凸起。取对数主要改变了什么？（看上方的序列图。）
2. 只作一阶差分 $\nabla\ln x$：趋势没有了，但 $r_{12}$ 高达 0.84，并且在 24、36 处缓慢衰减——还有季节性的单位根。
3. 只作季节差分 $\nabla_{12}\ln x$：季节性没有了，但 ACF 从 0.71 开始缓慢下降——趋势还在。
4. 两者都作，$\nabla\nabla_{12}\ln x$：显著的只剩下滞后 1 和滞后 12 处的负相关，这是什么模型的“指纹”？

::: example 例 1　航空模型
对航空乘客取对数，作一阶差分与季节差分后，样本 ACF 为 $r_1=-0.341$，$r_{12}=-0.387$，其余大多很小（界限 $\pm0.171$）。滞后 1 与 12 处各有一个负相关，提示 MA(1) 与季节 MA(1) 的乘积：
$$\nabla\nabla_{12}\ln x_t=(1+\theta B)(1+\Theta B^{12})\,\varepsilon_t.$$
这就是 Box 与 Jenkins 用这组数据建立的著名的 **航空模型** ARIMA$(0,1,1)\times(0,1,1)_{12}$。极大似然估计为
$$\hat\theta=-0.402\ (0.073),\qquad\hat\Theta=-0.557\ (0.096),\qquad\hat\sigma^2=0.00135,$$
括号内为标准误。残差的 Ljung–Box 统计量 $Q(24)=23.62$，自由度 22，p 值 0.37，通过诊断。预测 1961 年：1 月 450 千人次（95% 区间 419～484），7 月 670 千人次（590～761）。预测是在对数尺度上作的，取指数还原后区间不再对称。
:::

::: insight 模型展开后的含义
把航空模型展开：$\ln x_t=\ln x_{t-1}+\ln x_{t-12}-\ln x_{t-13}+\varepsilon_t+\theta\varepsilon_{t-1}+\Theta\varepsilon_{t-12}+\theta\Theta\varepsilon_{t-13}$。“本月 = 上月 + 去年同月 − 去年上月”，即本月相对上月的增长率与去年同期的增长率相同，再加上冲击的修正。它只有两个参数，却同时刻画了趋势与季节，并且两者都可以随时间缓慢变化。
:::

## 单位根检验 {.core}

::: core Dickey–Fuller 检验
在回归
$$\nabla y_t=\alpha+\beta t+\rho\,y_{t-1}+\varepsilon_t$$
中检验 $H_0:\rho=0$（有单位根，$y_t$ 是 $I(1)$）对 $H_1:\rho<0$（平稳，或趋势平稳）。检验统计量是 $\rho$ 的 t 值 $\tau=\hat\rho/\operatorname{se}(\hat\rho)$，$\tau$ 过小时拒绝原假设。回归中可以不含 $\alpha,\beta$、只含 $\alpha$、或两者都含，三种情形的临界值不同。

**关键之处**：$H_0$ 成立时，$\tau$ **不服从 t 分布**，而服从偏左的 Dickey–Fuller 分布。$n=100$ 时 5% 的临界值约为：不含常数项 −1.94，含常数项 −2.89，含常数项与趋势项 −3.46。
:::

::: geo 为什么分布偏左
在原假设下，$y_{t-1}$ 是随机游走，它的波动随时间不断增大，回归的“自变量”不再平稳，大数定律和中心极限定理的通常结论都不成立。以不含常数项的情形为例，由恒等式 $y_t^2=(y_{t-1}+\varepsilon_t)^2$ 可得
$$\sum_{t=1}^ny_{t-1}\varepsilon_t=\frac12\Big(y_n^2-\sum_{t=1}^n\varepsilon_t^2\Big)\qquad(y_0=0),$$
除以 $n\sigma^2$ 后趋于 $\frac12(Z^2-1)$，$Z\sim N(0,1)$。$\hat\rho$ 的分子在约 68% 的情况下为负（因为 $P(Z^2<1)\approx0.68$），而不是一半对一半——这就是分布偏左的来源（练习 8）。
:::

<DfSimulation />

**试一试**

1. $n=100$：模拟分布的 5% 分位数大约是多少？与正态分布的 −1.645 相差多远？
2. 误用 −1.645 作临界值，原假设成立时会有多大比例被错误地拒绝？
3. 改变 $n$：分位数随 $n$ 变化大吗？它们趋向哪个值？

::: core 增广的 DF 检验（ADF 检验）
若 $\nabla y_t$ 本身有自相关，DF 回归的误差不是白噪声。ADF 检验在回归中加入差分的滞后项来吸收它：
$$\nabla y_t=\alpha+\beta t+\rho\,y_{t-1}+\sum_{i=1}^{k}\gamma_i\nabla y_{t-i}+\varepsilon_t,$$
$\tau$ 的渐近分布与 DF 检验相同，滞后阶数 $k$ 常用 AIC 或 BIC 选择。
:::

::: example 例 2　几个序列的 ADF 检验
（statsmodels 的 `adfuller`，滞后阶数由 AIC 选择。）

| 序列 | 回归 | $\tau$ | p 值 | 结论（5%） |
| --- | --- | --- | --- | --- |
| 航空乘客（对数） | 常数 + 趋势 | −2.15 | 0.52 | 不能拒绝单位根 |
| 猞猁（lg） | 常数 | −3.61 | 0.006 | 拒绝，平稳 |
| 尼罗河流量 | 常数 | −4.05 | 0.001 | 拒绝，平稳 |

航空乘客的对数序列有单位根，需要差分，与例 1 一致。猞猁序列是平稳的，可以直接建立 ARMA 模型，与“[Box–Jenkins 建模与预测](/time-series/box-jenkins)”一章的做法一致。
:::

::: pitfall 单位根检验的局限
- **势很低**：$\rho=0.95$ 的平稳序列与随机游走在 100 期内几乎无法区分（见上面的实验）。“不能拒绝单位根”不等于“证明了有单位根”。
- **结构突变**：尼罗河流量在 1898 年前后有一次水平的下降，这种突变会使平稳序列看起来像有单位根，也会扭曲检验的结论（Perron，1989）。
- **反过来检验**：KPSS 检验以“平稳”为原假设，常与 ADF 检验配合使用：ADF 不拒绝而 KPSS 拒绝，单位根的证据才比较充分。
- **季节性**：对有强烈季节性的序列，应当先处理季节性（季节差分或季节单位根检验），否则 ADF 检验的结论很不稳定。例如对航空乘客的 $\nabla\ln x_t$ 作 ADF 检验，AIC 选了 14 阶滞后，$\tau=-2.72$，p 值 0.07，竟不能在 5% 的水平上拒绝单位根。
:::

## 伪回归 {.hard}

::: core 伪回归
1974 年，Granger 与 Newbold 用模拟发现：把两条 **相互独立** 的随机游走作回归，斜率的 t 检验在名义水平 5% 下拒绝 $H_0:\beta=0$ 的比例远远超过 5%，$R^2$ 也往往不小，而残差的 Durbin–Watson 统计量很接近 0。这种看似显著、实则毫无关系的回归称为 **伪回归**。他们给出了一条经验法则：**$R^2>\text{DW}$ 时要警惕伪回归**。
:::

<RandomWalkPair />

**试一试**

1. “相互独立”模式下多次重新抽样：t 统计量常常远远超过 2，残差像随机游走一样长期偏离 0，R² 大于 DW。
2. 点“模拟 500 次”：t 检验判为“显著”的比例是多少？（$n=100$ 时约为 77%，而名义上应是 5%。）
3. 切换到“协整”模式：残差围绕 0 波动，Engle–Granger 检验拒绝了“无协整”。这时的回归是有意义的——下一章会详细讨论。

::: insight 为什么会出现伪回归
回归的 t 检验假定误差平稳。若 $y_t$ 与 $x_t$ 是独立的 $I(1)$ 序列，任何 $\beta$ 都不能使 $y_t-\beta x_t$ 平稳，误差本身就是随机游走。此时 $\hat\beta$ 不收敛到 0，而收敛到一个随机变量，t 统计量随样本量增大而发散（Phillips，1986）——样本越大，越“显著”。补救的办法有两种：对两个序列都差分后再回归（但丢掉了水平之间的长期关系），或者检验它们是否 **协整**。

“[统计学与数据](/descriptive/intro)”一章提到的“相关不等于因果”，在时间序列中有一个更隐蔽的版本：两个各自有趋势的序列，即使毫不相干，也会表现出很强的相关。
:::

## 本章小结

- **趋势平稳**：冲击暂时，去趋势；**差分平稳**（有单位根）：冲击永久，差分。用错方法会导致伪回归或过度差分。
- **ARIMA($p,d,q$)**：$\phi(B)(1-B)^dx_t=\theta(B)\varepsilon_t$；季节 ARIMA 再加上季节差分与季节多项式；**航空模型** ARIMA$(0,1,1)\times(0,1,1)_{12}$ 是季节序列的经典模型。
- **DF / ADF 检验**：$H_0$：有单位根；统计量服从偏左的 Dickey–Fuller 分布，不能用 t 分布的临界值；检验的势较低，要注意结构突变和季节性。
- **伪回归**：独立的随机游走之间的回归常常“显著”；$R^2>\text{DW}$ 是危险信号。

| 内容 | 要点 |
| --- | --- |
| 趋势平稳 / 差分平稳 | $x_t=a+bt+u_t$ / $\nabla x_t=b+u_t$ |
| ARIMA($p,d,q$) | $\phi(B)(1-B)^dx_t=\theta(B)\varepsilon_t$ |
| 航空模型 | $\nabla\nabla_{12}\ln x_t=(1+\theta B)(1+\Theta B^{12})\varepsilon_t$ |
| DF 回归 | $\nabla y_t=\alpha+\beta t+\rho y_{t-1}(+\sum\gamma_i\nabla y_{t-i})+\varepsilon_t$ |
| DF 临界值（5%，$n=100$） | 无常数 −1.94，常数 −2.89，常数 + 趋势 −3.46 |
| 伪回归信号 | $R^2>\text{DW}$ |

## 分层练习

### 基础

**1.** 写出下列模型的 ARIMA 阶数：(a) $(1-B)x_t=\varepsilon_t-0.4\varepsilon_{t-1}$；(b) $(1-0.5B)(1-B)x_t=\varepsilon_t$；(c) $x_t=1.5x_{t-1}-0.5x_{t-2}+\varepsilon_t$。

::: details 解答
(a) ARIMA(0,1,1)。(b) ARIMA(1,1,0)。(c) AR 多项式 $1-1.5z+0.5z^2=(1-z)(1-0.5z)$，有一个单位根，所以 $\nabla x_t=0.5\nabla x_{t-1}+\varepsilon_t$，是 ARIMA(1,1,0)。直接看系数：$\phi_1+\phi_2=1$，恰好落在平稳三角形的边上。
:::

**2.** 设 $x_t=\varepsilon_t$ 是白噪声，求 $\nabla x_t$ 的方差和一阶自相关系数，并说明过度差分的症状。

::: details 解答
$\nabla x_t=\varepsilon_t-\varepsilon_{t-1}$，方差 $2\sigma^2$，$\gamma_1=-\sigma^2$，$\rho_1=-0.5$。症状：差分后方差变大、$r_1$ 接近 −0.5，拟合 MA(1) 会得到 $\hat\theta\approx-1$（不可逆）。
:::

**3.** 对一个年度序列（$n=100$）作含常数项的 DF 检验，得 $\tau=-2.5$。在 5% 的水平上能否拒绝单位根？若误用标准正态的临界值，结论会怎样？

::: details 解答
含常数项时 5% 的临界值约为 −2.89，$-2.5>-2.89$，不能拒绝单位根。若误用 −1.645，就会错误地拒绝，断定序列平稳。
:::

**4.** 带漂移的随机游走 $x_t=2+x_{t-1}+\varepsilon_t$，$\sigma=3$，$x_n=100$。求向前 4 步的预测值与 95% 预测区间。

::: details 解答
$\hat x_n(4)=100+4\times2=108$，预测误差 $\varepsilon_{n+1}+\cdots+\varepsilon_{n+4}$ 的标准差为 $3\sqrt4=6$，区间为 $108\pm1.96\times6$，即 $[96.24,\ 119.76]$。
:::

### 提高

**5.** 对 $x_t=a+bt+u_t$，$u_t=0.9u_{t-1}+\varepsilon_t$，求冲击的半衰期和远期预测标准误的极限（$\sigma=1$）。若 $\rho=1$ 呢？

::: details 解答
半衰期 $\ln0.5/\ln0.9\approx6.58$ 期；预测标准误的极限 $1/\sqrt{1-0.81}\approx2.29$。$\rho=1$ 时冲击永不衰减，半衰期无穷大，预测标准误 $\sqrt h$ 无限增大。
:::

**6.** 由航空模型的展开式说明：它的远期预测是“一个固定的季节形状 + 一条直线趋势”（在对数尺度上）。

::: details 解答
远期（$h>13$）时，MA 部分的冲击都已是未来的冲击，预测满足齐次方程 $(1-B)(1-B^{12})\hat x(h)=0$。它的通解是 $(1-B)(1-B^{12})$ 的“核”：$1-B^{12}=0$ 的解是周期为 12 的序列，$(1-B)$ 再贡献一个；由于 $1-B$ 是 $1-B^{12}$ 的因子，$z=1$ 是二重根，又贡献一个线性项 $ct$。所以预测函数 = 周期 12 的季节形状 + 直线趋势，具体的形状与斜率由最后的观测值和 $\theta,\Theta$ 决定。
:::

**7.** 设回归残差的一阶自相关系数为 $r_1$。说明 $\text{DW}\approx2(1-r_1)$，并解释为什么伪回归的 DW 接近 0。

::: details 解答
$\text{DW}=\dfrac{\sum(e_t-e_{t-1})^2}{\sum e_t^2}=\dfrac{\sum e_t^2+\sum e_{t-1}^2-2\sum e_te_{t-1}}{\sum e_t^2}\approx2-2r_1$。伪回归的残差本身近似随机游走，$r_1$ 接近 1，所以 DW 接近 0。
:::

### 挑战

**8.** 设 $y_t=y_{t-1}+\varepsilon_t$，$y_0=0$，$\varepsilon_t$ 独立同分布于 $N(0,\sigma^2)$。证明 $\sum_{t=1}^ny_{t-1}\varepsilon_t=\frac12\big(y_n^2-\sum\varepsilon_t^2\big)$，并由此说明：在不含常数项的 DF 回归中，$\hat\rho<0$ 的概率趋于 $P(Z^2<1)\approx0.683$。

::: details 解答
$y_t^2=y_{t-1}^2+2y_{t-1}\varepsilon_t+\varepsilon_t^2$，对 $t=1,\dots,n$ 求和并消去中间项，得 $y_n^2=2\sum y_{t-1}\varepsilon_t+\sum\varepsilon_t^2$，即所证。

不含常数项时 $\hat\rho=\sum y_{t-1}\varepsilon_t\big/\sum y_{t-1}^2$，分母为正，所以 $\hat\rho<0\iff y_n^2<\sum\varepsilon_t^2$。$y_n/(\sigma\sqrt n)\sim N(0,1)$，记为 $Z$；由大数定律 $\sum\varepsilon_t^2/(n\sigma^2)\to1$。于是 $P(\hat\rho<0)\to P(Z^2<1)=P(|Z|<1)\approx0.683$。模拟 $n=100$ 得约 0.676。正态近似下这个概率应为 0.5，多出来的部分正是 DF 分布偏左的原因。
:::

**9.** 两个独立的随机游走 $x_t,y_t$ 之间作回归，Granger–Newbold 的模拟中 t 检验的拒绝率随 $n$ 增大而 **增大**。从“误差项是随机游走”的角度解释原因。

::: details 解答
$y_t-\hat\beta x_t$ 不平稳，残差平方和约与 $n^2$ 同阶，而 OLS 的标准误公式假定误差独立同分布，实际上严重低估了 $\hat\beta$ 的波动；同时 $\hat\beta$ 不收敛到 0，而是收敛到一个非退化的随机变量。t 统计量 = 一个 $O_p(1)$ 的量除以一个以 $1/\sqrt n$ 的速度趋于 0 的“标准误”，所以按 $\sqrt n$ 的速度发散，拒绝率趋于 1。
:::

## 代码实现（Python）

::: details 展开代码：ADF 检验、航空模型与伪回归模拟
```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from statsmodels.stats.diagnostic import acorr_ljungbox
from statsmodels.tsa.stattools import adfuller, kpss
from statsmodels.tsa.statespace.sarimax import SARIMAX

air = [112, 118, 132, 129, 121, 135, 148, 148, 136, 119, 104, 118,
       115, 126, 141, 135, 125, 149, 170, 170, 158, 133, 114, 140,
       145, 150, 178, 163, 172, 178, 199, 199, 184, 162, 146, 166,
       171, 180, 193, 181, 183, 218, 230, 242, 209, 191, 172, 194,
       196, 196, 236, 235, 229, 243, 264, 272, 237, 211, 180, 201,
       204, 188, 235, 227, 234, 264, 302, 293, 259, 229, 203, 229,
       242, 233, 267, 269, 270, 315, 364, 347, 312, 274, 237, 278,
       284, 277, 317, 313, 318, 374, 413, 405, 355, 306, 271, 306,
       315, 301, 356, 348, 355, 422, 465, 467, 404, 347, 305, 336,
       340, 318, 362, 348, 363, 435, 491, 505, 404, 359, 310, 337,
       360, 342, 406, 396, 420, 472, 548, 559, 463, 407, 362, 405,
       417, 391, 419, 461, 472, 535, 622, 606, 508, 461, 390, 432]
y = np.log(pd.Series(air, index=pd.date_range("1949-01", periods=144, freq="MS"), dtype=float))

# ADF 检验（含常数项与趋势项）与 KPSS 检验（原假设：趋势平稳）
tau, p, lags, *_ = adfuller(y, regression="ct", autolag="AIC")
print(f"ADF：τ = {tau:.3f}，p = {p:.3f}，滞后 {lags} 阶")
print("KPSS 的 p 值：", kpss(y, regression="ct", nlags="auto")[1])

# 航空模型 ARIMA(0,1,1)×(0,1,1)_12
fit = SARIMAX(y, order=(0, 1, 1), seasonal_order=(0, 1, 1, 12)).fit(disp=False)
print(fit.params.round(4))
print(acorr_ljungbox(fit.resid.iloc[13:], lags=[24], model_df=2))
fc = fit.get_forecast(12)
print(pd.DataFrame({"预测": np.exp(fc.predicted_mean),
                    "下限": np.exp(fc.conf_int().iloc[:, 0]),
                    "上限": np.exp(fc.conf_int().iloc[:, 1])}).round(1).head(7))

# 伪回归：两条独立随机游走之间的回归
rng = np.random.default_rng(0)
reject = 0
for _ in range(2000):
    a, b = rng.standard_normal((2, 100)).cumsum(axis=1)
    reject += abs(sm.OLS(b, sm.add_constant(a)).fit().tvalues[1]) > 1.984
print("t 检验的拒绝率：", reject / 2000)
```

::: info 史话：单位根革命
1926 年，尤尔就以“为什么时间序列之间有时会出现无意义的相关”为题，指出了两个有趋势的序列之间的虚假相关。半个世纪后，1974 年 Granger 与 Newbold 用模拟把这个问题重新摆到计量经济学家面前。1979 年，Dickey 与 Fuller 给出了单位根检验的分布理论；1982 年，Nelson 与 Plosser 用它检验了美国的 14 个宏观经济序列，发现其中 13 个不能拒绝单位根，这意味着经济冲击可能有永久的影响，在宏观经济学界引起了长期的争论。随后，Phillips 等人用布朗运动的泛函建立了非平稳序列的渐近理论，Engle 与 Granger 提出了协整，这一系列工作被称为计量经济学的“单位根革命”。
:::
